## A.0 阅读说明

### A.0.1 本附录用途

**本附录提供**：
1. **通用数据**（保养周期、扭矩范围、容量等）
2. **规格对照**（螺丝、油液、火花塞等）
3. **车型速查**（常见车型的关键数据）

**本附录不提供**：
- **你具体车型的精确数据**（查说明书）
- **维修步骤**（查各章节正文）
- **诊断流程**（查第 20 章）

### A.0.2 数据使用原则

【严重警告】 **重要原则**：
- **本附录数据是"通用范围"**——**不是"你的车"**
- **你的车具体数据必须查说明书/维修手册**
- **本附录数据仅供"心里有数"用**

### A.0.3 符号说明

## A.1 螺丝规格对照表

### A.1.1 公制（Metric）螺丝

**M（公制）螺丝** = **大部分摩托车用公制**（除了哈雷等老美系）。

**常用规格**：

| 规格 | 螺纹直径 | 一般扭矩范围（钢制） | 一般用途 |
|------|---------|------------------|---------|
| M5 | 5mm | 4-7 Nm | 边盖、装饰件 |
| M6 | 6mm | 8-12 Nm | 边盖、小件 |
| M8 | 8mm | 20-30 Nm | 油箱、座椅 |
| M10 | 10mm | 40-60 Nm | 发动机、轮毂 |
| M12 | 12mm | 70-100 Nm | 曲轴、悬挂 |
| M14 | 14mm | 120-160 Nm | 曲轴大头 |
| M16 | 16mm | 200-280 Nm | 大件 |

【来源】 **数据来源等级**：★（**AI 训练数据的典型范围**，**你的车每个螺丝扭矩查说明书**）。

**强度等级**：
- 8.8 = 一般
- 10.9 = **中等**（发动机、悬挂常用）
- 12.9 = **高强度**（曲轴、安全件）

【注意】 **重要**：
- **换螺丝时强度等级不能降**！
- **公制螺丝 vs 英制螺丝**——**不能混用**！

### A.1.2 英制（SAE）螺丝

**英制螺丝** = **哈雷等美系、部分老欧洲车**。

**常用规格**：

|------|----------------|------------------|---------|
| 1/4-20 | 6.35mm | 8-12 Nm | 边盖 |
| 5/16-18 | 7.94mm | 15-22 Nm | 中等件 |
| 3/8-16 | 9.53mm | 30-45 Nm | 大件 |
| 7/16-14 | 11.11mm | 50-70 Nm | 大件 |
| 1/2-13 | 12.70mm | 70-100 Nm | 大件 |

【来源】 **数据来源等级**：★（**AI 训练数据的典型范围**）。

## A.2 扭矩扳手设定值

### A.2.1 扭矩扳手类型

**按驱动**：
- **1/4 英寸**（小扭矩，2-25 Nm）
- **3/8 英寸**（中等扭矩，5-50 Nm）
- **1/2 英寸**（大扭矩，20-200 Nm）

**按读数**：
- **机械指针式**（**便宜**）
- **数字式**（**贵但精确**）
- **扭角扳手**（**高级**——缸盖螺丝需要）

### A.2.2 扭矩扳手设定范围对照

| 螺栓规格 | 推荐扭矩扳手 |
|---------|------------|
| M5、M6 | 1/4 英寸，2-25 Nm |
| M8、M10 | 3/8 英寸，5-50 Nm |
| M12、M14 | 1/2 英寸，20-200 Nm |
| M16+ | 1/2 英寸，40-200 Nm |

### A.2.3 扭矩精度等级

| 精度 | 误差 | 适用 |
|------|------|------|
| **I 级** | ±4% | 专业（贵） |
| **II 级** | ±6% | 一般（**推荐**） |
| **III 级** | ±10% | 业余（便宜） |

### A.2.4 扭力扳手使用注意事项 ★★

- **使用前归零**（**避免弹簧疲劳**）
- **听到"咔哒"声就停**（**不要继续拧**）
- **定期校准**（每年一次）
- **不要当撬棍用**

## A.5 卡扣大全（新手必看）★★

**卡扣是摩托车维修的"无名英雄"**——**拆得开、装不回去是新手最常见问题**。这一节是老师傅的"扫盲课"。

### A.5.1 卡扣类型速查 ★★

| 类型 | 形状 | 应用 | 拆装难度 |
|------|------|------|---------|
| **塑料胀钉** | 两头尖 | 装饰件 | **易坏** |
| **塑料卡扣（菊花扣）** | 圆形 | **最常见**——覆盖件 | **易坏** |
| **金属卡扣** | U 形 | 高温部件 | 较难 |
| **弹簧卡子** | C 形 | 油管、线束 | **专业** |
| **铆钉** | 实心 | 永久固定 | **一次性** |
| **推拉式** | 圆形 + 卡簧 | 高端车 | 中 |
| **螺丝式** | 内置螺丝 | 高端车 | 难 |

### A.5.2 塑料卡扣（菊花扣）详解 ★★

**最常见的卡扣**——**新手第一关**。

**结构**：
- **中心轴**（销子）
- **卡爪**（4-6 个）
- **卡爪** = **"菊花瓣"**

**工作原理**：
- 装入孔 = 卡爪收拢
- 通过孔 = 卡爪张开
- 拉出 = 卡爪勾住

**拆装**：
```
1. 找到卡扣中心
2. 用小螺丝刀撬中心销（向下推）
3. 销子松 = 整个卡扣可拆
4. 装回 = 销子拉出 + 卡扣压入
```

**装回步骤**：
```
1. 检查卡扣爪是否完好
2. 对准孔
3. 用手压（**不要用锤子**）
4. 听到"啪"声 = 装好
```

【注意】 **常见错误**：
- **用螺丝刀硬撬** = **爪断**
- **爪已经断了** = **必须换新卡扣**
- **对不齐** = **压不进** = **使劲压** = **卡扣坏**

【经验】 **老师傅经验**：**卡扣是消耗品**——**拆几次就坏**——**买一包备用卡扣**（10-50 元，几十个）——**比每次去店便宜**。

### A.5.3 塑料胀钉详解 ★★

**塑料胀钉** = **两端尖的塑料钉**——**用于装饰件**。

**拆装**：
```
1. 用小螺丝刀撬大头
2. 撬出大头
3. 拉出整根钉
4. 装回 = 把胀钉插入 + 拉大头
```

**坏处**：
- **一撬就裂** = **难拆**
- **第二次装 = 装不紧**

**更换**：
- **买同规格的胀钉**（直径、长度）
- **塑料厂零件** = **找原厂件** = **淘宝/汽配城**

### A.5.4 金属卡扣（U 形扣、弹簧卡子）★★

**金属卡扣** = **更耐用**——但**拆装需技巧**。

**U 形扣**：
- 用于油管、线束固定
- 拆 = **用尖嘴钳松开 U 形**
- 装 = **用钳子扣紧**

**弹簧卡子**（**C 形**）：
- 用于油管接头
- 拆 = **用 C 形夹专用工具**（或尖嘴钳）
- 装 = **对准 + 压入**

**重要**：
- **弹簧卡子** = **精密**——**不能装错方向**
- **装错** = **漏油/漏气**

【经验】 **老师傅经验**：**金属卡扣** = **耐操**——**能用很久**——**比塑料好**——**但要找对规格**。

### A.5.5 铆钉 ★

**铆钉** = **永久固定**——**拆了基本就废**。

**类型**：

| 类型 | 应用 | 拆卸 |
|------|------|------|
| **抽芯铝铆钉** | 车身覆盖件 | 钻头钻芯 |
| **实心铝铆钉** | 高强度 | **磨掉或钻** |
| **塑料铆钉** | 装饰件 | 撬/钻 |

**抽芯铝铆钉的拆法**：
```
1. 选比铆钉芯小一号的钻头
2. 对准铆钉头
3. 钻掉铆钉头
4. 用冲子把残芯顶出
5. 装新铆钉（用铆钉枪/钳）
```

**实心铝铆钉**：
- **难拆** = **必须用钻** = **可能毁孔**
- **建议** = **送修** 或 **换成螺栓+螺母**

### A.5.6 推拉式卡扣 ★★

**高端车用** = **圆形 + 卡簧**。

**拆装**：
```
1. 找到释放按钮
2. 按下按钮
3. 拉出接头
4. 装回 = 对准 + 推入
```

**注意**：
- **不要硬拉** = **拉坏卡簧**
- **要看方向** = **有防错设计**

### A.5.7 螺丝式卡扣 ★★

**现代车常用** = **内置螺丝**。

**结构**：
- **外圆** = **卡扣**
- **中心** = **小螺丝**

**拆装**：
```
1. 用合适螺丝刀（**多备几个规格**）
2. 拧螺丝
3. 拉出卡扣
4. 装回 = 拧紧螺丝
```

**特点**：
- **耐用** = **可重复**
- **不坏**

### A.5.9 卡扣常见错误 ★★

**新手最容易犯的错**：

1. **硬撬** = **卡扣坏** = **必须换**
2. **撬错位置** = **划伤漆** = **赔钱**
3. **装不回去** = **方向错** = **装反 = 装不上 = 坏**
4. **用金属撬棒** = **划伤漆** = **伤件** = **赔**
5. **卡扣掉了不找** = **装回去少一个** = **松了** = **异响**
6. **不备卡扣** = **坏了干等** = **耽误时间**

【经验】 **老师傅经验**：**卡扣是"小钱大麻烦"**——**买一包备用** = **100-200 元**——**修整车身必备**。

### A.5.10 备卡扣购买建议 ★

**买什么卡扣**：

**按车型买**：
- **本田 CB500F 卡扣套装**（淘宝 50-100 元）
- **雅马哈 MT-07 卡扣套装**（类似）
- **宝马 R1200GS 卡扣套装**（类似）

**按规格买**：
- **直径**（5mm、6mm、8mm 等）
- **长度**（10mm、15mm、20mm 等）
- **形状**（菊花形、U 形等）

**通用套装**：
- **淘宝搜"摩托车卡扣套装"** = **几十到一百多**
- **一包 50-200 个** = **够用 2-3 年**

### A.5.11 卡扣漏装的影响 ★

**少装一个卡扣**：

| 影响 | 严重程度 |
|------|---------|
| **异响** | 轻 |
| **松动** | 中 |
| **掉落** | 高（高速上掉覆盖件） |
| **进水** | 中（电气部分） |
| **丢三落四** | 难堪 |

【经验】 **老师傅经验**：**拆卡扣时 = 把卡扣放塑料袋**——**不丢**——**装时一个一个数回去**——**确保全装回去**。

### A.5.12 进阶：卡簧（C 形）★

**卡簧** = **挡圈** = **装在轴上防止轴向移动**。

**类型**：
- **轴用卡簧**（装在轴上）
- **孔用卡簧**（装在孔里）
- **外卡** / **内卡**

**拆装**：
```
1. 用卡簧钳（**专用工具**）
2. 装上卡簧
3. 张开钳子
4. 装入槽里
5. 松开钳子
```

**装错** = **弹出** = **可能伤到**

【经验】 **老师傅经验**：**卡簧钳 30-50 元**——**不贵**——**但没有的话别想拆装**——**必备**。
