## 24.1 钱江（QJMOTOR）

### 24.1.1 钱江品牌特点

**背景**：钱江摩托是中国厂商；Benelli（贝纳利）是 1911 年创立的意大利老品牌，2005 年被中国钱江收购。QJ 现在生产部分 Benelli 设计/平台相关车型，但 Benelli 的品牌历史、欧洲传统和当前 QJMOTOR 的市场定位不能简单混为一谈。

**核心特点**：
- **贝纳利 / 钱江平台渊源**（需按具体车型、年份确认）
- **配置丰富、价格有竞争力**（具体差价需按同年份、同级别车型对比）
- **运动车 + 复古**双线
- **V 型双缸 + 直列双缸**都有

### 24.1.2 钱江主要车型

| 系列 | 类型 | 代表车型 |
|------|------|---------|
| **闪**（闪 300/600） | 街车 | 闪 300、闪 600 |
| **赛**（赛 350/600） | 运动 | 赛 350、赛 600 |
| **逸** | 复古 | 逸 500 |
| **骁**（骁 750/800） | ADV | 骁 750、骁 800 |
| **贝纳利相关车型** | ADV / 复古 / 跑车 | TRK 系列、Leoncino（幼狮）、Tornado |

【来源】 **数据来源等级**：★（品牌历史需以 Benelli / QJMOTOR 官方资料和车型公告复核）。

### 24.1.3 钱江常见故障 ★★

**闪 600 常见关注点**：
1. **链条拉长**（双缸震动）
2. **节气门脏**（电喷车）
3. **电瓶**（电子设备）
4. **油路老化**（高里程橡胶件）

**赛 350 常见关注点**：
1. **离合器片磨损**（小排量双缸）
2. **链条拉长**
3. **节气门**

**骁 750/800 常见关注点**：
1. **空气滤芯**（ADV 环境）
2. **链条**
3. **刹车片**

### 24.1.4 钱江保养要点 ★★

**机油**：
- **JASO MA/MA2**
- 粘度：10W-40 主流
- 容量因车型不同

**火花塞**：
- **NGK** 等品牌较常见，但火花塞必须按维修手册核对**型号、热值、螺纹长度、座面形式、电极规格和间隙**；不能只凭其他品牌车型的适配经验判断可用。

**气门间隙**：
- 检查周期按说明书
- 国产车型**部分有** Haynes/Clymer 等第三方手册，但覆盖不全；关键数据以**原厂服务手册、车主手册和厂家技术公告**为准。

【来源】 **数据来源等级**：★★（火花塞选型按 NGK/Denso 等厂商通用选型原则和原厂维修手册规则；第三方手册覆盖需逐车型核实）。

## 24.6 其他国产品牌

### 24.6.1 升仕（Zontes）

**特点**：新势力品牌、外观时尚、性价比高。

**代表车型**：310GK、350GK、310M、350E。

**维修**：网络快速扩展、配件充足。

### 24.6.2 大运（Dayun）

**特点**：大运（Dayun）是独立国产厂；大阳（Dayang）是另一家国产厂，踏板车型较多。两者不是同一品牌，不能把 Dayun 写成大阳。

**代表车型**：大运通勤/巡航系列（具体车型和年份需查厂家资料）。

【来源】 **数据来源等级**：★（品牌中英文名称需以厂家官网和车辆铭牌复核）。

### 24.6.3 银钢（Yinjiang）

**特点**：小排量为主、代步车。

### 24.6.4 五羊本田、新大洲本田（合资）

**特点**：五羊本田、新大洲本田属于本田在中国的合资体系。国产合资车型中，部分车型在配置、性能和制造体系上接近国际品牌；但任何“完全相同”或“全面超过”的结论都必须绑定具体型号、年份、配置、召回记录和长期使用数据，不能泛泛比较。

**代表车型**：五羊本田 190 系列、新大洲本田 CB 系列。

**维修判断**：合资国产不是“天然例外”。选车和维修仍应查车主手册、厂家技术公告、召回信息和当地经销商支持情况；价格差异也要按同年份、同排量、同配置车型比较。

【来源】 **数据来源等级**：★（合资关系和车型资料需以厂家公告复核；质量/价格比较暂不作定论）。

### 24.6.5 大阳、洛嘉、望江、奔达、凯越等

**特点**：覆盖踏板、通勤、巡航、ADV、越野等不同市场，品牌规模和渠道差异很大。

**代表车型**：大阳踏板系列、奔达黑旗/拿破仑、凯越 500F/525F 等。

**维修**：不应按品牌大小直接判断“配件难找、维修店少”。新手购车前应查当地经销商、常用件库存、质保政策和车友长期反馈；拿不准的渠道能力一律标 ❓ 待验证。

## 24.7 【经验】 老师傅经验沉淀（应写尽写）

### 24.7.1 国产品牌的"两个极端" ★★★

**极端 1**：把低价直接等同于低质量（刻板印象）

**更稳妥的写法**：
- 国产车近年在配置、性能、做工一致性和销量上有显著进步。
- 但不同品牌、车型、年份、批次、保养记录差异很大，不能把质量归因简化成“国产好”或“国产差”。

**极端 2**：**国产 = 不好**（刻板印象）

**待验证点**：
- 春风 450SR、钱江闪 600 等车型的市场表现，应写明**国家/地区、年份、统计口径和数据来源**。
- “销量超过部分日欧车”“600cc 级别销量王”“质量达到某国际品牌等级”等说法目前均标为 ❓ 待验证，出版前不得写成定论。
- 维修判断应回到具体车型平台、年份批次、保养记录、召回/技术公告和实测故障码。

【来源】 **数据来源等级**：★（市场销量、质量等级和排名需补充厂家/协会/上险量/第三方统计来源）。

### 24.7.2 国产品牌选择建议 ★★★

**新手第一辆**：
- **预算 1-2 万**：合资品牌（五羊本田、新大洲本田）—— 查具体车型口碑、质保和当地网点
- **预算 2-3 万**：国产一线（春风、钱江、升仕等）—— 配置和价格通常有竞争力，但“最高”需按同级车型对比
- **预算 3 万+**：日欧品牌或国产中大排—— 可靠性、配置、保值和维修便利性逐项比较

**新手第一辆推荐**：
1. **五羊本田 190**（**最便宜的合资**）
2. **春风 300SR**（**性价比运动车**）
3. **钱江闪 300**（**性价比街车**）
4. **升仕 350GK**（**性价比复古**）

### 24.7.4 国产品牌维修工具 ★★

### 24.7.6 国产品牌配件 ★★★

**国产车配件优势**：

| 优势 | 说明 |
|------|------|
| **价格可能更友好** | 国产配件通常比进口件便宜，但具体百分比因配件、品牌、地区和渠道差异大；“30-50%”标 ❓ 待验证 |
| **渠道可能更近** | 常用件是否易找取决于当地保有量、经销商库存和电商渠道 |
| **部分规格相同** | 火花塞、滤芯等必须按原厂件号、尺寸和规格核对，不能只看“通用” |

**国产车配件劣势**：

| 劣势 | 说明 |
|------|------|
| **质量参差不齐** | 副厂件质量差 |
| **品牌辨识难** | 真假难辨 |

【费用】 **省钱贴士**：国产配件价格通常更容易控制，但要买正品或可靠品牌件；别只按“通用”下单，先核对原厂件号、尺寸、电气参数和适配年份。

【来源】 **数据来源等级**：★（配件价格需按具体件号、渠道和地区复核）。

### 24.7.7 国产品牌 vs 进口品牌

**维修师傅的真实评价**：

| 维度 | 国产车 | 日欧车 |
|------|--------|--------|
| **可靠性** | 按车型/年份/保养记录判断 | 按车型/年份/保养记录判断 |
| **性能** | 同级配置差异大，需逐车型对比 | 同级配置差异大，需逐车型对比 |
| **性价比** | 通常配置/价格有竞争力，需逐车型对比 | 品牌、保值和服务成本需纳入对比 |
| **维修成本** | 低 | 中高 |
| **维修网络** | 以当地授权店和库存为准，❓ 待验证 | 以当地授权店和库存为准，❓ 待验证 |
| **配件价格** | 通常更低，但百分比需按件号核实 | 通常更高，但取决于渠道和件号 |
| **改装潜力** | 中 | 高 |

【经验】 **老师傅经验**：
- **预算紧** → 优先看国产一线和合资车型，但逐车型比较总成本
- **不在乎预算** → **日欧品牌**
- **想降低用车风险** → 看合资品牌或保有量大的国产车型，同时核实当地服务能力

【来源】 **数据来源等级**：★（跨品牌比较需按具体车型、年份、地区和维修渠道复核）。

### 24.8.1 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的案例线索**——只能作为按车型/年份/使用场景排查的入口，不能写成“国产品牌常见问题”。

### 案例 A：春风 650NK 链条异响

**症状**：链条响
**踩坑过程**：以为是质量
**可能原因**：链条张紧度、润滑、链轮磨耗、后轮定位或使用强度不匹配。
**处理建议**：按车主手册周期检查张紧度和润滑，异常磨耗时同时查链轮和后轮定位。
**教训**：链条问题按维护记录和使用场景判断，不能按品牌归因。

### 案例 B：钱江贝纳利 600 启动难

**症状**：启动困难
**踩坑过程**：以为是电瓶
**可能原因**：电瓶电压、节气门积碳、喷油/点火、怠速控制、故障码都需要排查。
**处理建议**：先测电瓶和读取故障码，再按手册清洁节气门或做初始化。
**教训**：启动困难要按电、油、气、码逐项排查。

### 案例 C：无极 300R ABS 灯

**症状**：ABS 灯亮
**踩坑过程**：以为是 ABS 坏
**可能原因**：该车型/该年份/雨水泥沙使用场景下，轮速传感器、齿圈间隙、插头进水和线束需要重点检查。
**处理建议**：**清传感器**
**教训**：ABS 灯亮先查传感器、齿圈、线束和故障码。

### 案例 D：凯越 321R 油门线

**症状**：油门卡
**踩坑过程**：以为是油门坏
**可能原因**：油门线磨损、走线角度、把套干涉、节气门回位机构或改装件干涉。
**处理建议**：立即检查油门线自由行程、回位和走线；卡滞不能继续骑。
**教训**：油门卡滞是安全问题，按机构和改装状态排查。

### 案例 E：升仕 310M 链条涨紧

**症状**：链条松
**踩坑过程**：以为是质量问题
**可能原因**：张紧调节、后轮定位、链条磨耗或早期批次部件状态都可能相关。
**处理建议**：按手册调链并检查链轮；若调节余量不足或磨耗异常，送修确认。
**教训**：早期批次问题必须绑定车型年份和批次，不能泛化。

### 案例 F：奔达 金吉拉 300 烧机油

**症状**：机油消耗大
**踩坑过程**：以为是正常
**可能原因**：磨合期机油消耗、活塞环密封、油封、曲轴箱通风或测量方法都可能相关。
**处理建议**：按说明书记录机油消耗量和里程；明显冒蓝烟、液位快速下降或超过厂家允许范围时送修检查。
**教训**：磨合期可能有轻微机油消耗，但不能把“烧机油”一概当正常。

### 案例 G：春风 800MT ADV 散热

**症状**：ADV 高温
**踩坑过程**：以为是节温器
**可能原因**：越野/碎石/泥水场景下散热片堵塞，或冷却液、风扇、节温器、传感器异常。
**处理建议**：先清洁散热片并检查风扇启动、水位和故障码，仍高温再送修。
**教训**：ADV 高温按使用场景和冷却系统排查。

### 案例 H：钱江闪 600 充电

**症状**：充电灯亮
**踩坑过程**：以为是发电机
**可能原因**：电瓶老化、接地不良、插头氧化、定子输出异常或整流调压器故障。
**处理建议**：按 13.2.3 测怠速和 3000 rpm 充电电压、定子交流输出和插头压降，再决定是否更换部件。
**教训**：充电故障必须实测电压，不能直接归因于某类品牌调压器。

### 案例 I：无极 DS525X 链条

**症状**：ADV 链条断
**踩坑过程**：以为是链条质量
**可能原因**：越野冲击、润滑不足、张紧过紧/过松、链轮磨耗、装配或配件来源都可能相关。
**处理建议**：**换正品**
**教训**：ADV 链条要按使用强度缩短检查周期，并核对正品规格。

### 案例 J：凯越 525X 越野后空滤

**症状**：越野后动力下降
**踩坑过程**：以为是发动机
**可能原因**：**空滤堵**
**处理建议**：**清空滤**
**教训**：越野/扬尘后动力下降，先查空滤和进气密封，再查燃油和故障码。

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **按时保养** = 降低故障风险，但不能保证绝对没问题
2. **怠速/油耗异常** = 先查空滤、节气门、故障码和传感器
3. **ABS 灯亮** = 先查轮速传感器、线束、齿圈和故障码
4. **油门卡滞或回位慢** = 立即检查油门线、把套和节气门机构
5. **磨合期机油消耗** = 允许范围看说明书；明显烧机油、冒蓝烟或液位快速下降必须检查

【经验】 **老师傅总结**：国产车的性价比和配件可得性是优势，但具体质量取决于车型平台、年份、装配状态和保养记录。买二手车时，早期批次、改装车和保养记录不清的车要重点检查；质量归因不应按品牌一刀切。

## 本章小结

### 国产品牌核心

1. **钱江** = 吉利旗下、性能强、性价比
2. **春风** = KTM 合作、出口多、品质好
3. **隆鑫/无极** = 大厂代工、性价比
4. **宗申/赛科龙** = 代工大厂、性价比
5. **力帆** = 老品牌、便宜
6. **合资（五羊本田、新大洲本田）** = 本田合资体系内车型，质量和价格结论需按具体车型/年份/配置核实

### 国产品牌 vs 日欧品牌

- **国产车**：配置和价格通常有竞争力，维修成本和网络要按地区/品牌/车型核实
- **日欧车**：品牌、性能、保值和可靠性口碑各不相同，维修成本也要按车型/地区核实
