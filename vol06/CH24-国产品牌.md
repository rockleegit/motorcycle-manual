## 24.1 钱江（QJMOTOR）

### 24.1.1 钱江品牌特点

**背景**：吉利集团旗下，收购贝纳利后实力大增。

**核心特点**：
- **贝纳利技术**（部分车型是贝纳利换标）
- **性价比高**（性能对标进口，价格便宜 30-50%）
- **运动车 + 复古**双线
- **V 型双缸 + 直列双缸**都有

### 24.1.2 钱江主要车型

| 系列 | 类型 | 代表车型 |
|------|------|---------|
| **闪**（闪 300/600） | 街车 | 闪 300、闪 600 |
| **赛**（赛 350/600） | 运动 | 赛 350、赛 600 |
| **逸** | 复古 | 逸 500 |
| **骁**（骁 750/800） | ADV | 骁 750、骁 800 |
| **贝纳利换标** | 进口 | TRK 系列、Leoncino |

### 24.1.3 钱江常见故障 ★★

**闪 600 常见关注点**：
1. **链条拉长**（双缸震动）
2. **节气门脏**（电喷车）
3. **电瓶**（电子设备）
4. **油路老化**（高里程橡胶件）

**赛 350 常见关注点**：
1. **离合器片磨损**（小排量双缸）
2. **链条拉长**
3. **节气门**

**骁 750/800 常见关注点**：
1. **空气滤芯**（ADV 环境）
2. **链条**
3. **刹车片**

### 24.1.4 钱江保养要点 ★★

**机油**：
- **JASO MA/MA2**
- 粘度：10W-40 主流
- 容量因车型不同

**火花塞**：
- **NGK** 是常用（**与本田/雅马哈通用**）

**气门间隙**：
- 检查周期按说明书
- **钱江说明书写得一般**——**可参考 Haynes/Clymer（如有）**

### 24.1.5 钱江维修成本

**国产车优势** = **便宜**。

| 项目 | 4S 店 | 自己 |
|------|-------|------|
| 小保养 | 200-400 元 | 100-200 元 |
| 中保养 | 400-800 元 | 200-400 元 |
| 大保养 | 1000-2000 元 | **送修** |

## 24.6 其他国产品牌

**特点**：新势力品牌、外观时尚、性价比高。

**代表车型**：350GK、310M、350E。

**特点**：踏板为主、电动摩托发力。

**特点**：小品牌、便宜。

**维修**：**配件难找、维修店少**——**不建议新手买**。

## 24.7 【经验】 老师傅经验沉淀（应写尽写）

### 24.7.1 国产品牌的"两个极端" ★★★

**极端 1**：**便宜 = 质量差**（部分老观点）

**事实**：
- **早期国产车**（2000-2010 年）：确实**质量差、配件差**
- **现在的国产车**（2020 年后）：**质量大幅提升**

**极端 2**：**国产 = 不好**（部分人观点）

**事实**：
- **春风 450SR** 在欧洲市场上**销量超过部分日欧车**
- **钱江闪 600** 在国内是 600cc 级别销量王
- **国产车质量**已经**和日本中端车持平**

### 24.7.2 国产品牌选择建议 ★★★

**新手第一辆**：
- **预算 1-2 万**：合资品牌（五羊本田、新大洲本田）—— **质量等同本田**
- **预算 2-3 万**：国产一线（春风、钱江、升仕）—— **性价比最高**
- **预算 3 万+**：日欧品牌—— **更可靠**

**新手第一辆推荐**：
1. **五羊本田 190**（**最便宜的合资**）
2. **春风 300SR**（**性价比运动车**）
3. **钱江闪 300**（**性价比街车**）
4. **升仕 350GK**（**性价比复古**）

### 24.7.3 国产品牌"常见关注点"汇总

**维修经验中提到的国产车常见关注点**：

| 车型 | 常见关注点 |
|------|------|
| **钱江闪 600** | 链条拉长快、油路老化、电瓶 |
| **钱江赛 350** | 离合器片、链条 |
| **春风 450SR** | 链条、节气门、离合器片 |
| **春风 800MT** | 链条、空滤、刹车片 |
| **无极 300R** | 链条、节气门、小毛病 |
| **赛科龙 RC 401** | 链条、节气门 |
| **力帆 KP 350** | 小毛病、配件 |
| **升仕 350GK** | 电子系统、链条 |

【经验】 **老师傅经验**：**国产车小毛病比日欧多**——**但配件便宜**——**整体维修成本比日欧低**。**国产车是"性价比之选"**。

### 24.7.4 国产品牌维修工具 ★★

**国产车优势**：
- **大部分用公制工具**（**和日本车通用**）
- **专用工具少**（大部分通用）
- **维修手册**（部分国产车**说明书不全**——**参考 Haynes/Clymer**）

**必备工具**：
- 套筒套装（公制）
- 扭力扳手
- 火花塞套筒
- 万用表

### 24.7.5 国产品牌维修网络 ★★★

**国产车优势** = **维修网络广**：

| 品牌 | 维修店覆盖 |
|------|----------|
| **钱江** | ★★★★★（全国最广） |
| **春风** | ★★★★★ |
| **隆鑫/无极** | ★★★★ |
| **宗申/赛科龙** | ★★★★ |
| **力帆** | ★★★ |

【经验】 **老师傅经验**：**国产车维修店覆盖比日欧好**——**大部分县镇都有**——**维修方便**。**进口车要找专门店**——**经常要跑大城市**。

### 24.7.6 国产品牌配件 ★★★

**国产车配件优势**：

| 优势 | 说明 |
|------|------|

| **易找** | 配件渠道广 |

【费用】 **省钱贴士**：**国产车配件便宜**——**但要买正品**——**别贪便宜买"通用"**——**有些副厂件质量差**。

### 24.5.1 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的真实案例**——国产品牌（春风/钱江/无极/凯越/升仕/奔达）的常见问题。

### 案例 A：春风 650NK 链条异响

**症状**：链条响
**踩坑过程**：以为是质量
**可能原因**：**国产链条**——**1 万 km 调**
**处理建议**：**按时调**
**教训**：**国产链条** = **按周期**

### 案例 B：钱江贝纳利 600 启动难

**症状**：启动困难
**踩坑过程**：以为是电瓶
**可能原因**：**国产电喷**——**节气门**
**处理建议**：**清+重置**
**教训**：**国产电喷** = **清**

### 案例 C：无极 300R ABS 灯

**症状**：ABS 灯亮
**踩坑过程**：以为是 ABS 坏
**可能原因**：**ABS 传感器**——**国产常见**
**处理建议**：**清传感器**
**教训**：**国产 ABS** = **清**

### 案例 D：凯越 321R 油门线

**症状**：油门卡
**踩坑过程**：以为是油门坏
**可能原因**：**油门线**——**国产抖动大**
**处理建议**：**换油门线**
**教训**：**国产油门线** = **常换**

### 案例 E：升仕 310M 链条涨紧

**症状**：链条松
**踩坑过程**：以为是质量问题
**可能原因**：**涨紧器**——**国产早期问题**
**处理建议**：**送修**
**教训**：**国产早期** = **送修**

### 案例 F：奔达 金吉拉 300 烧机油

**症状**：机油消耗大
**踩坑过程**：以为是正常
**可能原因**：磨合期机油消耗、活塞环密封、油封、曲轴箱通风或测量方法都可能相关。
**处理建议**：按说明书记录机油消耗量和里程；明显冒蓝烟、液位快速下降或超过厂家允许范围时送修检查。
**教训**：磨合期可能有轻微机油消耗，但不能把“烧机油”一概当正常。

### 案例 G：春风 800MT ADV 散热

**症状**：ADV 高温
**踩坑过程**：以为是节温器
**可能原因**：**散热片**——**ADV 国产**
**处理建议**：**清散热片**
**教训**：**国产 ADV** = **清散热**

### 案例 H：钱江闪 600 充电

**症状**：充电灯亮
**踩坑过程**：以为是发电机
**可能原因**：**国产调压器**——**质量不稳**
**处理建议**：**送修**
**教训**：**国产调压器** = **可能坏**

### 案例 I：无极 DS525X 链条

**症状**：ADV 链条断
**踩坑过程**：以为是链条质量
**可能原因**：**ADV 国产**——**链条早期**
**处理建议**：**换正品**
**教训**：**国产 ADV 链条** = **换正品**

### 案例 J：凯越 525X 越野后空滤

**症状**：越野后动力下降
**踩坑过程**：以为是发动机
**可能原因**：**空滤堵**
**处理建议**：**清空滤**
**教训**：**国产 ADV** = **清空滤**

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **按时保养** = 降低故障风险，但不能保证绝对没问题
2. **怠速/油耗异常** = 先查空滤、节气门、故障码和传感器
3. **ABS 灯亮** = 先查轮速传感器、线束、齿圈和故障码
4. **油门卡滞或回位慢** = 立即检查油门线、把套和节气门机构
5. **磨合期机油消耗** = 允许范围看说明书；明显烧机油、冒蓝烟或液位快速下降必须检查

【经验】 **老师傅总结**：国产车的性价比和配件可得性是优势，但具体质量取决于车型平台、年份、装配状态和保养记录。买二手车时，早期批次、改装车和保养记录不清的车要重点检查。
