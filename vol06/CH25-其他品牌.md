## 25.1 电动摩托 ★★★

### 25.1.1 电动摩托是什么

**电动摩托** = **用电机驱动**的摩托车。

**与燃油摩托的区别**：
- **无发动机**（**没有气门、火花塞、机油、冷却液**）
- **电池代替油箱**
- **电机代替内燃机**
- **控制器代替 ECU**

### 25.1.2 电动摩托主要品牌

| 品牌 | 国别 | 代表车型 |
|------|------|---------|
| **Zero** | 美国 | Zero SR、Zero SR/F |
| **LiveWire**（哈雷旗下） | 美国 | LiveWire One |
| **Energica** | 意大利 | Ego、EsseEsse9 |
| **NIU（小牛）** | 中国 | N1S、MQi+ |
| **九号（Segway-Ninebot）** | 中国 | E300P、E200P |
| **雅迪** | 中国 | 换电兽 |
| **新日** | 中国 | 新日系列 |
| **小牛** | 中国 | N1S、U 系列 |
| **春风** | 中国 | **AE 8 电动**（即将推出） |

### 25.1.3 电动摩托的核心组件 ★★★

**电池**：
- **锂电池**（主流）
- 容量用 kWh 表示
- 续航 100-300 km（**看电池容量和驾驶风格**）

**电机**：
- **中置电机**（高端，性能车）
- **轮毂电机**（中低端）
- 功率用 kW 表示（一般 5-150 kW）

**控制器**：
- 控制电机的"大脑"
- **电动摩托的 ECU**

**充电器**：
- 慢充（家用 220V）
- 快充（公共充电桩）

### 25.1.4 电动摩托的维修 ★★★

**核心区别**：**没有发动机维修**——**没有机油、气门、火花塞**。

**主要维修内容**：

| 部件 | 维护内容 |
|------|---------|
| **电池** | 衰减检测、均衡充电 |
| **电机** | 轴承、冷却 |
| **控制器** | 软件更新、诊断 |
| **充电器** | 检查 |
| **刹车** | 和燃油车一样 |
| **轮胎** | 和燃油车一样 |
| **链条/皮带** | 看具体车型 |
| **灯光/电气** | 和燃油车一样 |

### 25.1.5 电动摩托常见故障 ★★★

**电池问题**（**最大问题**）：
1. **电池衰减**（**所有电池都衰减**——3-5 年容量下降 20-30%**）
2. **充电故障**（控制器、充电器、连接器）
3. **低温性能下降**（**冬天续航减半**）

**电机问题**：
1. **轴承损坏**
2. **冷却不良**（**激烈驾驶**电机过热）
3. **霍尔传感器故障**

**控制器问题**：
1. **软件 BUG**
2. **过热保护**
3. **信号丢失**

### 25.1.6 电动摩托维修成本 ★★

**电池更换**（**最贵**）：
- 主流品牌：5000-20000 元
- 高端品牌（Zero、Energica）：30000-80000 元
- **电池价格占整车 40-60%**

【经验】 **老师傅经验**：电动摩托的电池健康决定续航、二手价值和后期成本。电池衰减不等于整车必然报废，但如果换电池价格接近车辆残值，经济上可能不划算。

## 25.2 ADV（Adventure）车型 ★★★

### 25.2.1 ADV 是什么

**ADV**（Adventure）= **探险摩托车**——**能跑长途、能越野、能日常**。

**特点**：
- **大油箱**（长途）
- **长行程避震**（颠簸）
- **高底盘**（通过性）
- **风挡**（高速）
- **货架**（行李）

### 25.2.2 ADV 主要品牌和车型

| 品牌 | 代表车型 |
|------|---------|
| **宝马** | R 1250 GS、R 1300 GS（**ADV 之王**） |
| **KTM** | 790 Adventure、890 Adventure、1290 Super Adventure |
| **雅马哈** | Ténéré 700、Tracer 9 |
| **本田** | CRF 1100L（Africa Twin）、NC 750X |
| **凯旋** | Tiger 900、Tiger 1200 |
| **川崎** | Versys 650、Versys 1000 |
| **铃木** | V-Strom 650、V-Strom 800DE |
| **哈雷** | Pan America 1250 |
| **杜卡迪** | Multistrada V4 |
| **春风** | 800MT、700CL-X ADV |
| **钱江** | 骁 750、骁 800 |

### 25.2.3 ADV 的核心组件 ★★

**ADV 和街车的关键区别**：

| 部件 | ADV 特点 |
|------|---------|
| **避震行程** | 长（200mm+） |
| **底盘离地** | 高（200mm+） |
| **轮胎** | 全地形或越野胎 |
| **油箱** | 大（20L+） |
| **风挡** | 可调 |
| **车架** | 钢架（耐冲击） |

### 25.2.4 ADV 的维护 ★★★

**ADV 比街车维护复杂**：

**核心维护**：
1. **空气滤芯**（**关键**——ADV 经常走烂路）
2. **链条**（**重车、烂路磨损快**）
3. **刹车片**（重车、长行程避震）
4. **轮胎**（**全地形胎寿命短**——1-3 万 km）
5. **避震**（经常过坑容易漏油）

**特殊维护**：
1. **减震油**（重载、经常越野）
2. **轮毂轴承**（越野冲击大）
3. **辐条轮**（如有——经常调）

### 25.2.5 ADV 的维修成本 ★★

**ADV 维修比街车贵 30-50%**：
- 配件大、贵
- 一些车型配件进口
- 维修需要专业知识

## 25.3 踏板车（Scooter）★★★

### 25.3.1 踏板车是什么

**踏板车**（Scooter）= **自动变速 + 实用**。

**特点**：
- **CVT 自动变速**（不用离合器、不用换挡）
- **踏板设计**（脚可以放踏板上）
- **储物空间大**（座桶下）
- **城市通勤为主**

### 25.3.2 踏板车主要品牌和车型

| 品牌 | 代表车型 |
|------|---------|
| **本田** | PCX160、NSS350、Forza 350 |
| **雅马哈** | NMAX 155、Aerox 155、XMAX 300 |
| **铃木** | Burgman 400、Address 110 |
| **KYMCO（光阳）** | Racing King、Like |
| **SYM（三阳）** | DRG、Fiddle |
| **比亚乔** | Beverly、Liberty |
| **Vespa** | Primavera、Sprint |
| **九号** | E300P |
| **小牛** | N1S、U 系列 |

### 25.3.3 踏板车的核心组件 ★★★

**踏板车和挡车最大的区别**：
- **CVT 变速箱**（无级变速）
- **皮带传动**（**不是链条**）
- **后轮毂和发动机一体**（部分车型）

**CVT 结构**：
```
[发动机]
   ↓
[前皮带轮（驱动轮）] ← 重力飞块/扭力凸轮
   ↓
[V 形皮带]
   ↓
[后皮带轮（从动轮）]
   ↓
[后轮轴]
```

### 25.3.4 踏板车的维护 ★★

**关键维护**：

| 部件 | 维护内容 |
|------|---------|
| **CVT 皮带** | 每 1-2 万 km 检查 |
| **CVT 滚轮** | 每 3-5 万 km 检查 |
| **CVT 滤网** | 每次换机油时清洁 |
| **机油** | 按说明书 |
| **齿轮油** | 部分车型有（后轮减速） |
| **刹车** | 和挡车一样 |
| **轮胎** | 和挡车一样 |

### 25.3.5 踏板车常见故障 ★★★

**CVT 系统**：
1. **皮带磨损**（**最常见**——加速无力、起步打滑）
2. **滚轮磨损**（**影响换挡速度**）
3. **滤网堵**（**影响散热**）

**发动机**：
1. **机油问题**（和挡车一样）
2. **气门间隙**（部分踏板车有，传统进气门）
3. **点火系统**（和挡车一样）

### 25.3.6 踏板车维修 ★★

**踏板车和挡车的维修差异**：

| 项目 | 挡车 | 踏板车 |
|------|------|--------|
| **机油** | 相同 | 相同 |
| **链条** | 链条 + 链轮 | **皮带 + 滚轮** |
| **空滤** | 相同 | 相同 |
| **火花塞** | 相同 | 相同 |
| **气门** | 调 | 部分可调 |
| **离合器** | 有 | **无** |
| **变速箱** | 多挡手动 | **CVT 自动** |

【送修】 **该送修了**：
- **CVT 皮带更换**（需要专用工具）
- **CVT 滚轮更换**（需要专用工具）
- **CVT 滤网清洁**（可以自己，但需要拆）

【经验】 **老师傅经验**：踏板车 CVT 是关键保养点。皮带、普利珠、离合器、传动箱滤网和轴承状态会影响加速、抖动和可靠性；维修费用取决于车型和损坏程度，不要拖到断皮带再处理。

## 25.4 其他类型

### 25.4.1 小排量（< 250cc）

**特点**：
- 便宜、简单
- 适合新手、女生、日常通勤
- 配件便宜、维修便宜

**代表**：本田 CB190、春风 250SR、力帆 KPS150。

**维护**：基础保养、简单。

### 25.4.2 大排量（> 800cc）

**特点**：
- 性能强、价格高
- 维修贵
- 适合老司机

**代表**：宝马 R 1250 GS、川崎 ZX-10R、杜卡迪 Panigale V4。

**维护**：**复杂**、**专用工具多**、**大部分送修**。

### 25.4.3 电动自行车/电助力车辆（按当地法规分类）

**特点**：
- 是否属于摩托车、轻便摩托车、电动自行车或电助力自行车，取决于当地法规对速度、功率、脚踏、整备质量和牌照的定义
- 是否需要驾照、牌照、保险和头盔，必须查当地现行法规
- 便宜、简单

**代表**：雅迪、爱玛、台铃。

**维护**：电池、电机、控制器。

### 25.4.4 老车（化油器时代）

**特点**：
- 化油器、简单
- 维修便宜
- **越来越少**

**代表**：本田 CB400、雅马哈 SR400、各种 90/125 老车。

**维护**：化油器、火花塞、基础保养。

### 25.4.5 复古车（Cafe Racer、Scrambler、Bobber）

**特点**：
- 外观为主
- 改装多
- 个性化强

**代表**：凯旋 Bonneville、杜卡迪 Scrambler、本田 CB1100。

**维护**：基础保养 + 改装件维护。

## 25.5 【经验】 老师傅经验沉淀（应写尽写）

### 25.5.1 不同车型的核心区别 ★★★

| 类型 | 核心区别 | 维修要点 |
|------|---------|---------|
| **挡车（燃油）** | 链条/皮带 + 多挡手动 | 见各章 |
| **踏板车** | CVT 自动 | CVT 是命门 |
| **电动摩托** | 电池 + 电机 + 控制器 | 电池是命门 |
| **ADV** | 长行程避震 + 越野能力 | 空滤 + 链条 + 刹车 |
| **小排量** | 简单、便宜 | 基础保养 |
| **大排量** | 复杂、贵 | **大部分送修** |

### 25.5.2 不同类型的选择建议 ★★★

**新手选什么**：

| 用途 | 推荐 | 原因 |
|------|------|------|
| **通勤代步** | 踏板车（NMAX、PCX） | 不用换挡、实用 |
| **学驾驶** | 小排量挡车（150-250cc） | 简单、便宜 |
| **跑山** | 中排量挡车（300-650cc） | 操控好 |
| **长途** | ADV 或大排量旅行 | 舒适、续航 |
| **个性** | 复古或欧洲品牌 | 风格独特 |

### 25.5.3 电动摩托的真实评价 ★★★

**电动摩托的优势**：
- **扭矩大**（电动车特性）
- **维护少**（无发动机维护）
- **安静**（没声音）
- **城市通勤方便**

**电动摩托的劣势**：
- **续航焦虑**（**电池不够用**）
- **充电麻烦**（**不像加油那么快**）
- **电池衰减**（**所有电池都衰减**）
- **冬天续航减半**

【经验】 **老师傅经验**：电动摩托是否适合，取决于通勤半径、充电条件、电池质保、换电网络、当地法规和二手残值。没有固定车位/充电条件时要谨慎；有稳定充电或成熟换电网络时，通勤体验会好很多。

### 25.5.4 ADV 的真实评价 ★★★

**ADV 的优势**：
- **能跑长途**（油箱大）
- **能走烂路**（长行程避震）
- **能装行李**（货架）
- **能装两个人**（双人友好）

**ADV 的劣势**：
- **重**（250-300kg）
- **操控不如运动车**
- **维修贵**
- **油耗高**

【经验】 **老师傅经验**：**ADV** = **"想去哪就去哪"的车**——**适合有探险欲望的车友**。**纯城市通勤买 ADV 是浪费**——**用不上越野能力**。

### 25.5.5 踏板车的真实评价 ★★★

**踏板车的优势**：
- **不用换挡**（自动）
- **城市通勤方便**（小巧）
- **储物空间大**（座桶）
- **实用**（买菜、接娃）

**踏板车的劣势**：
- **高速不稳**（重心高）
- **跑山不行**（操控差）
- **CVT 是命门**（维修贵）

【经验】 **老师傅经验**：**踏板车** = **"买菜车"的延伸**——**城市通勤首选**。**想玩车的不买踏板车**——**想通勤的买踏板车**。

### 25.5.6 不同类型车的维修工具 ★★

| 类型 | 必备工具 |
|------|---------|
| **挡车（燃油）** | 套筒、扭力扳手、火花塞套筒 |
| **踏板车** | 套筒、扭力扳手、**CVT 工具** |
| **电动摩托** | 万用表、**电池诊断仪**、电气工具 |
| **ADV** | 套筒、扭力扳手、长柄塞尺（避震） |
| **老车（化油器）** | 套筒、**化油器清洗剂**、**化油器工具** |

### 25.5.7 进阶学习路径 ★★

学完本章后想进阶：

1. **【入门】** 知道自己的车是哪种类型
2. **【基础】** 了解核心区别
3. **【进阶】** 用 Haynes/Clymer 手册
4. **【高级】** 调校、改装
5. **【专业】** 大修

### 25.5.1 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的真实案例**——其他品牌（KTM/胡斯瓦纳/凯旋/皇家恩菲尔德）的常见问题。

### 案例 A：KTM 390 Duke 链条异响

**症状**：链条响
**踩坑过程**：以为是质量
**可能原因**：**KTM 链条**——**1 万 km 调**
**处理建议**：**按时调**
**教训**：**KTM 链条** = **按周期**

### 案例 B：胡斯瓦纳 701 启动

**症状**：冷车启动困难
**踩坑过程**：以为是电瓶
**可能原因**：**KTM 系电喷**——**节气门**
**处理建议**：**清+重置**
**教训**：**KTM 系** = **清**

## 本章小结

### 不同车型类别核心

1. **电动摩托** = 电池 + 电机，**电池是命门**
2. **ADV** = 长行程避震 + 越野，**空滤 + 链条是命门**
3. **踏板车** = CVT 自动，**皮带 + 滚轮是命门**
4. **小排量** = 简单、便宜
5. **大排量** = 复杂、贵

### 不同类型选择建议

- **通勤** → 踏板车
- **学驾驶** → 小排量挡车
- **跑山** → 中排量挡车
- **长途** → ADV 或大排量
- **个性** → 复古或欧洲品牌
