## 5.1 发动机系统故障

### 5.1.1 启动困难

#### 【高频】 故障1：电瓶电量不足

**症状**：
- 启动机转动缓慢
- 大灯变暗
- 喇叭声音小
- 仪表盘指示灯闪烁

**原因**：
- 电瓶老化
- 充电系统故障
- 漏电
- 长时间未骑

**诊断**：
```
1. 测电瓶静态电压
   - 铅酸电瓶满电常见：约12.6V（来源：⭐⭐ 物理）
   - AGM、锂电池静态电压与放电曲线不同，以电瓶厂家说明和车型手册为准
   - 明显异常：<12V（先充电/负载测试，不只看静态电压）

2. 启动车辆，测充电电压
   - 常见正常范围：13.5-14.5V（来源：⭐⭐ 工业标准；以车型手册为准）
   - 异常：>15V（调压/稳压整流器或接地参考异常，也可能是线束问题；按 CH13 流程复测，来源：⭐）
   - 异常：<13V（充电不足）

3. 测漏电
   - 关闭所有电器
   - 拔下电瓶负极
   - 串入万用表（电流档）
   - 车辆待机电流差异很大（防盗、无钥匙、ECU休眠时间不同），以维修手册为准
   - 起动机短时电流常见约100-200A（来源：⭐ 经验），不要用普通万用表电流档直接串测启动回路
```

**处理**：
- 电瓶老化：更换电瓶
- 充电不足：检查充电系统
- 漏电：找出漏电部位
- 亏电：充电或搭电启动

#### 【高频】 故障2：火花塞故障

**症状**：
- 启动困难
- 怠速不稳
- 加速无力
- 油耗增加
- 启动机转但不着火

**原因**：
- 火花塞积碳
- 电极烧蚀
- 间隙过大
- 火花塞型号错误

**诊断**：
```
1. 拆下火花塞
2. 看外观：
   - 正常：浅褐色
   - 黑：混合气过浓
   - 白：混合气过稀
   - 油糊：烧机油
   - 积碳：燃烧不完全
3. 测间隙：
   - 常见：0.6-1.0 mm，按车型/火花塞型号；参考 A01/CH06/CH13（街车常见 0.6-0.8 mm、跑车常见 0.7-0.9 mm、ADV 常见 0.8-1.0 mm；来源：⭐/❓）
   - 异常：过大或过小
4. 测跳火：
   - 装回高压帽
   - 火花塞搭铁
   - 启动电机
   - 跳火：正常
   - 不跳火：故障
```

**处理**：
- 积碳：清洗或更换
- 烧蚀：更换
- 间隙不对：调整或更换

#### 【高频】 故障3：点火系统故障

**症状**：
- 启动机转但不着火
- 火花塞不跳火
- 行驶中熄火
- 加速断火

**原因**：
- 点火线圈故障
- CDI/ECU故障
- 触发线圈故障
- 高压线漏电
- 接插件松脱

**诊断**：
```
1. 检查火花塞跳火
   - 跳火：火花塞
   - 不跳火：继续

2. 检查点火线圈电阻
   - 不同 CDI / TCI / 笔式线圈电阻差异很大
   - 初级、次级电阻以维修手册为准（固定范围只作经验参考：❓）
   - 异常：0或∞

3. 检查触发线圈
   - 测电阻
   - 测电压

4. 检查高压线
   - 看外观
   - 测电阻

5. 检查ECU/CDI
   - 供电是否正常
   - 接地是否良好

6. 检查接插件
   - 是否松脱
   - 是否氧化
```

**处理**：
- 点火线圈：更换
- CDI/ECU：不要直接更换，先做低成本验证（来源：⭐⭐⭐）
  1. 测电瓶电压
  2. 查接地（主搭铁 / ECU搭铁）
  3. 查保险丝 + 继电器
  4. 查曲轴/凸轮位置传感器信号
  5. 查线路（接头/插头/线束）
  6. 以上都没问题，才怀疑 CDI / ECU
- 高压线：更换
- 接插件：清洁或更换

【注意】 ⚠️ CDI/ECU 更换前先咨询专业。ECU 误换可能损失几千元，而且常见问题反而是供电、接地、保险、继电器、传感器信号或线束接触不良。

#### 【高频】 故障4：燃油系统故障

**症状**：
- 启动困难
- 加速无力
- 怠速不稳
- 行驶中熄火

**原因**：
- 油泵故障
- 喷油嘴堵塞
- 燃油滤芯堵塞
- 油管堵塞
- 燃油压力调节器故障

**诊断**：
```
1. 检查油量
   - 油表是否准确
   - 油箱是否有油

2. 听燃油泵
   - 打开钥匙时是否有"嗡"声
   - 无声：油泵或继电器

3. 测燃油压力
   - 装压力表
   - 启动车辆
   - 测压力
   - 电喷进气道喷射常见怠速 2.5-3.5 bar、预压 2.5-4.0 bar；具体看手册；真空调压车型还要看相对歧管压差（来源：⭐/❓）

4. 拆喷油嘴测试
   - 启动车辆看是否喷油
   - 喷油量是否正常
   - 【严重警告】 测试前必须：备接油容器、远离火源、断开点火高压、按手册给燃油系统泄压（详见 CH04 4.4 节）

5. 检查燃油滤芯
   - 是否堵塞
```

**处理**：
- 油泵：更换
- 喷油嘴：清洗或更换
- 燃油滤芯：更换
- 油管：更换
- 压力调节器：更换

#### 【中频】 故障5：气缸压力不足

**症状**：
- 启动困难
- 动力下降
- 怠速不稳
- 启动机转动正常但不着火

**原因**：
- 活塞环磨损
- 气门密封不良
- 缸垫漏气
- 气缸磨损

**诊断**：
```
1. 测气缸压力
   - 拆火花塞
   - 装压力表
   - 捏住节气门
   - 启动电机5秒
   - 读数

2. 标准值（举例）：
   - 凯旋1200X：11-13bar（❓ 车型专属示例；以该车型维修手册为准）
   - 低于标准：故障

3. 漏气部位：
   - 进气管漏气：冒气声
   - 排气漏气：排气有异响
   - 缸垫漏气：冷却液中有气泡
```

**处理**：
- 活塞环磨损：镗缸+换环
- 气门密封：研磨或更换
- 缸垫漏气：更换缸垫
- 气缸磨损：镗缸+换活塞

#### 【中频】 故障6：化油器故障（老车）

**症状**：
- 启动困难
- 怠速不稳
- 加速不顺
- 油耗高

**原因**：
- 浮子室油面不对
- 主油针磨损
- 喷嘴堵塞
- 启动加浓器失效
- 真空泄漏

**诊断**：
```
1. 检查浮子室油面
   - 拆下化油器
   - 检查油面高度
   - 标准：浮子室有刻度线

2. 检查喷嘴
   - 拆下喷嘴
   - 看是否堵塞
   - 用化油器清洁剂清洗

3. 检查启动加浓器
   - 冷车时是否工作

4. 检查真空泄漏
   - 优先用烟雾检漏、目视检查或转速变化法
   - 防火提示：转速变化法不要靠近明火/高温排气，少量、短喷
   - 找出漏气点
```

**处理**：
- 浮子调整
- 喷嘴清洗
- 启动加浓器更换
- 真空泄漏处密封

### 5.1.2 怠速不稳

#### 【高频】 故障7：进气管路漏气

**症状**：
- 怠速忽高忽低
- 怠速偏高
- 怠速熄火
- 加速反应慢

**原因**：
- 进气管接头漏气
- 进气歧管垫片漏气
- 节气门垫片漏气
- 真空管漏气

**诊断**：
```
1. 听：用听诊器或耳朵听
2. 烟雾检测：注入烟雾找漏点
3. 目视检查：看进气管、歧管垫片、真空管是否开裂/松脱
4. 转速变化法：
   - 在可疑处喷
   - 转速变化 = 漏气点
   - 防火提示：远离明火/高温排气，少量、短喷（来源：⭐）
```

**处理**：
- 紧固卡箍
- 更换垫片
- 更换真空管

#### 【高频】 故障8：节气门脏污

**症状**：
- 怠速不稳
- 加速不顺
- 怠速偏高
- 熄火

**原因**：
- 积碳堆积
- 油液污染
- 灰尘

**诊断**：
```
1. 拆下节气门
2. 看积碳情况
3. 转动节气门
   - 顺滑：好
   - 卡滞：脏
```

**处理**：
- 拆下清洗
- 用节气门清洁剂
- 重置学习值

#### 【中频】 故障9：怠速电机故障

**症状**：
- 怠速不稳
- 怠速熄火
- 冷车怠速高

**原因**：
- 怠速电机损坏
- 怠速电机脏
- 控制信号问题

**诊断**：
```
1. 读故障码
2. 测怠速电机电阻
3. 测控制信号
```

**处理**：
- 清洁或更换怠速电机
- 检查控制信号

#### 【中频】 故障10：传感器故障

**症状**：
- 怠速不稳
- 加速不顺
- 油耗高
- 故障灯亮

**原因**：
- 氧传感器老化
- MAP传感器故障
- IAT传感器故障
- TPS传感器故障

**诊断**：
```
1. 读故障码
2. 检查各传感器数据
3. 测传感器电阻
4. 测传感器电压
```

**处理**：
- 更换故障传感器

### 5.1.3 加速无力

#### 【高频】 故障11：空气滤芯堵塞

**症状**：
- 加速无力
- 油耗高
- 怠速不稳
- 最高速下降

**原因**：
- 空滤长期未换
- 灰尘多
- 油液污染

**诊断**：
```
1. 拆下空滤
2. 看是否脏污
3. 对着光看透光性
```

**处理**：
- 更换空滤（推荐）
- 吹洗（应急）

#### 【中频】 故障12：燃油滤芯堵塞

**症状**：
- 加速无力
- 启动困难
- 怠速不稳

**原因**：
- 燃油滤芯堵塞
- 长期未换

**诊断**：
```
1. 检查燃油压力
   - 压力低：可能滤芯堵塞
2. 拆下滤芯看
```

**处理**：
- 更换燃油滤芯

#### 【中频】 故障13：排气管堵塞

**症状**：
- 加速无力
- 加速发闷
- 油耗高
- 发动机过热

**原因**：
- 催化器堵塞
- 消音器堵塞
- 排气管内积碳

**诊断**：
```
1. 测排气背压
2. 拆下消音器测试
3. 看排气管内是否堵塞
```

**处理**：
- 清洗消音器
- 更换催化器
- 更换消音器

### 5.1.4 发动机过热

#### 【高频】 故障14：冷却液不足

**症状**：
- 水温表偏高
- 故障灯亮
- 发动机过热
- 冷却液壶有液位下降

**原因**：
- 泄漏
- 蒸发
- 未加足

**诊断**：
```
1. 检查冷却液壶液位
2. 检查地面是否有水迹
3. 测压力
4. 检查各连接处
```

**处理**：
- 加足冷却液
- 找出泄漏点
- 维修泄漏

#### 【高频】 故障15：节温器故障

**症状**：
- 水温高
- 冷车时无大循环
- 故障灯亮

**原因**：
- 节温器卡死（关闭状态）
- 节温器失效
- 型号错误

**诊断**：
```
1. 观察水温上升过程
2. 摸上下水管温差
3. 拆下节温器测试
   - 加热到开启温度
   - 应该打开
```

**处理**：
- 更换节温器

#### 【中频】 故障16：水泵故障

**症状**：
- 水温高
- 漏水
- 异响

**原因**：
- 水泵轴磨损
- 密封件老化
- 叶轮损坏

**诊断**：
```
1. 看是否有漏水
2. 听是否有异响
3. 启动时观察冷却液流动
4. 拆下检查
```

**处理**：
- 更换水泵
- 更换密封件

#### 【中频】 故障17：散热器堵塞

**症状**：
- 水温高
- 散热片脏
- 风扇一直转

**原因**：
- 散热片堵塞
- 散热管堵塞
- 灰尘多

**诊断**：
```
1. 看散热片
2. 用风枪吹
3. 看风扇是否转
```

**处理**：
- 清洁散热片
- 更换散热器

### 5.1.5 异响

#### 【高频】 故障18：气门异响

**症状**：
- 缸头有"哒哒"声
- 怠速明显
- 加速时也有

**原因**：
- 气门间隙过大
- 机油压力不足
- 凸轮轴磨损
- 挺杆磨损

**诊断**：
```
1. 听位置：缸头
2. 检查气门间隙
3. 检查机油压力
4. 拆检
```

**处理**：
- 调整气门间隙
- 维修机油系统
- 更换凸轮/挺杆

#### 【中频】 故障19：活塞敲缸

**症状**：
- 缸体有"铛铛"声
- 冷车明显
- 加速时明显

**原因**：
- 活塞与缸壁间隙过大
- 活塞环磨损
- 连杆磨损

**诊断**：
```
1. 听位置
2. 测气缸压力
3. 拆检
```

**处理**：
- 镗缸
- 换活塞
- 镗缸+换活塞+换环

#### 【中频】 故障20：传动链条异响

**症状**：
- 外部传动链条有"哗啦"声
- 行驶中、加速或收油时明显
- 原地怠速通常不是外部传动链条在响；若怠速时发动机内部有链条声，应按正时链条检查

**原因**：
- 链条磨损伸长
- 链轮磨损
- 链条太松或太紧
- 后轮未对中

**诊断**：
```
1. 听位置
   - 行驶中后轮/输出轴附近异响：优先查外部传动链条
   - 怠速时发动机内部异响：优先查正时链条和张紧器
2. 检查链条垂度
3. 检查链轮齿形
4. 检查后轮对中
```

【注意】 本故障指**外部传动链条**（drive chain，连接变速箱输出轴和后轮的链条），不是发动机内部的**正时链条**（timing chain）。正时链条异响需检查正时链条张紧器，涉及发动机内部，先咨询专业。

**处理**：
- 外部传动链条：调整链条垂度和后轮/链轮对齐
- 外部传动链条：清洁润滑
- 外部传动链条：必要时更换链条+链轮
- 怠速时发动机内部链条异响：检查正时链条张紧器，先咨询专业

#### 【中频】 故障21：曲轴异响

**症状**：
- 发动机下部"咚咚"声
- 加速时明显
- 机油压力低

**原因**：
- 主轴瓦磨损
- 连杆瓦磨损

**诊断**：

## 本章小结

### 核心要点

1. **60+典型故障**汇总，覆盖发动机/传动/行走/制动/电气/冷却/燃油7大系统
2. **每个故障**给出症状+原因+诊断+处理
3. **车型专属**部分涵盖7种主流车型（含用户的两台车）
4. **故障速查表**可以按症状快速查找
5. **季节性故障**特别说明

### 使用方法

**遇到故障时**：
1. 查速查表（5.10节）→ 找到症状
2. 看具体章节 → 看可能原因
3. 按诊断步骤 → 找出根本原因
4. 实施维修

**学习时**：
1. 先看高频故障（5.9.1）
2. 再看高紧急度故障（5.9.2）
3. 重点看自己车型的故障（5.8节）

### 与第4章的关系

```
第4章 故障诊断方法论：教"怎么诊断"
第5章 典型故障汇总：教"诊断什么"

两者结合 = 完整的诊断能力
```

### 重点提醒

> **维修是修车，不是赌运气。** 看完这一章，你应该能快速识别大部分常见故障。但不要因为"看起来像"就换零件——**测量验证**才是关键。
> 
> **遇到没见过的故障**：查速查表 → 看诊断方法 → 测量验证。一步步来，别急。
