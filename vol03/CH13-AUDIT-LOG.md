## 经验教训（沉淀）

**问题**:CH13 是 9 个系统章节里唯一没走审校流程的,首次审校就报 6.3/10。

**根因**:
1. 写作端:AI 对"看起来对但其实错"的内容有盲区（CDI 数量级、搭电原因这种)
2. 规范端:PRINCIPLES.md 来源等级规则存在但执行不严
3. 审校端:原 V1 审校 prompt 只"挑错"不"查缺",覆盖度盲区
4. 流程端:审校凭印象判断,没强制对照标准 / 教科书

**修法**（已落地）:
- 审校 prompt V2:加"覆盖度"维度,9 个系统章节各有必查清单
- PRINCIPLES.md 加"必查标准"附录,关键物理量必须对照标准
- 审校报告存档(本文件),可追溯
- 未来:两遍审校机制(广度审 + 深度对照)
