### 11.1.1 行走系统原理层：系统功能与设计目标

摩托车行走系统（chassis+wheel+tyre+brake+ABS，刹车和 ABS 在第 12 章讲）是**唯一与地面接触的部件群**——轮胎、前叉、后避震、车轮——共同决定了摩托车的**操控性、舒适性、安全性**（来源：⭐⭐⭐）。

【机制】 **设计目标 1：把路面作用力精确传到车架。** 摩托车在骑行中受三类路面作用力：**驱动力**（后轮推车向前）、**制动力**（刹车让车减速）、**转向力**（前轮侧向力让车转向）。**这些力都通过轮胎→车轮→悬挂→车架的路径传递**。行走系统的任务就是**尽可能精确、可控、即时地传递这些力**（来源：⭐⭐⭐）。

【机制】 **设计目标 2：吸收路面冲击，保护骑手和车架。** 路面不可能绝对平整——坑洼、接缝、碎石都会产生高频冲击。**悬挂系统（弹簧+阻尼）的任务是吸收这些冲击**，让骑手不感到颠簸、车架不受冲击疲劳。**弹簧储能、阻尼耗能**——这是悬挂的核心物理机制（来源：⭐⭐⭐）。

【机制】 **设计目标 3：维持轮胎与地面的接触。** 摩托车的所有性能（加速、刹车、转向）都通过**轮胎与地面的接触**实现。**接触面积、接触压力、接触时间**直接决定性能极限。**悬挂的设计要让轮胎在各种工况下都「贴地」**——跳起来就丢牵引力（来源：⭐⭐⭐）。

【问答】 **为什么摩托车悬挂比汽车硬？**
摩托车轮胎接触面积小（前后加起来约一张 A4 纸大小），路面对轮胎的扰动更直接；**侧向支撑**全靠轮胎和车手重心转移，没有汽车那种「四轮宽体」的稳定性。**所以摩托车悬挂必须硬**——软悬挂会让车在过弯时车身侧倾过大，前轮抓地力急剧下降。**但太硬又会让路面冲击直接传到手和屁股**——这是摩托车工程的核心矛盾（来源：⭐）。

【经验】 **老师傅一句话**：行走系统不是「轮子+减震」那么简单——它要在「精确传力」「吸收冲击」「维持贴地」三个目标间走钢丝；任何一项过弱都会出大事。

### 11.1.2 核心物理原理一：轮胎抓地力的粘附与滞后

【机制】 摩托车轮胎和地面的摩擦**不只来自经典摩擦系数 μN**——橡胶胎面的真实抓地力来自**两种机理叠加**（来源：⭐⭐⭐）：

1. **粘附（adhesion）**：胎面橡胶分子和地面分子间的范德华力。**取决于胎面材质、温度、压力、接触时间**。这是「胶皮能贴住东西」的物理基础。
2. **滞后（hysteresis）**：胎面在接触区被压缩、滑过、微变形——**橡胶分子链被反复拉伸释放，能量变成热**。这个「内摩擦」消耗了动能，等效于摩擦力。**温度升高、橡胶越软、变形越大，滞后效应越强**。

**反直觉点**：**光滑湿地抓地反而好**（湿地热熔胎 slick）。**为什么？** 因为：
- 粘附力：湿地时表面没有污染物，橡胶和地面直接接触
- 滞后力：橡胶变形大，滞回损耗大
- 「排水」反而是其次——排水是为了**避免水膜把橡胶和地面隔开**

**滑移率（slip ratio）**是描述轮胎抓地状态的关键参数：

s = (v_wheel - v_vehicle) / max(v_wheel, v_vehicle)

- s = 0：纯滚动（自由滚）
- s = 0.1-0.3：**最大抓地区间**（急加速/急刹车）
- s = 1.0：纯滑动（抱死）

摩托车轮胎在 s=0.1-0.2 左右**纵向力最大**；侧向力则在更宽的 s 区间（0-0.1）。**这就是为什么 ABS 让轮胎留在 s=0.1-0.3 是最优的**（来源：⭐⭐⭐）。

【经验】 **老师傅一句话**：轮胎抓地不是「摩擦力」两个字能说清的——是粘附+滞后两个机理；湿地比干地抓地还好的反直觉，正是这两个机理在不同条件下的不同表现。

### 11.1.3 核心物理原理二：轮胎结构与帘布层

【机制】 摩托车轮胎是多层复合结构（来源：⭐⭐⭐）：

```
[胎面 Tread]            ← 和地面接触，橡胶层
[带束层 Belt]            ← 钢带或尼龙带，限制周向伸长
[帘布层 Ply]            ← 尼龙/聚酯/人造丝帘线，承受气压
[胎侧 Sidewall]          ← 橡胶+帘布层，弯曲变形区
[胎圈 Bead]              ← 钢丝圈，把轮胎锁在轮辋上
[内胎/无内胎]            ← Tubeless 主流
```

**带束层方向**：
- **斜交轮胎**（bias-ply）：帘线斜向交叉。早年主流，胎壁厚、耐用，但高速稳定性差。
- **子午线轮胎**（radial）：帘线径向（从胎圈到胎圈）。**现代摩托车主流**——胎壁软（舒适）、接地面积大（抓地好）、高速稳定。

**反直觉点**：**子午线轮胎的胎壁看起来很软很弱**——其实它的强度来自**带束层**（钢带）。胎壁的「软」是设计故意——让它在转弯时**侧向变形吸收路面起伏**。

【机制】 **胎压对接触印迹的影响**：
- **正常胎压**：接触印迹近似**圆形**，接地面积最大
- **过高胎压**：接触印迹**变小变圆**（中心压力高、边缘不接触），抓地面积下降
- **过低胎压**：接触印迹**拉长但接触压力不均**（中间高、边缘低），转向重、磨损快、操控钝
- **严重过低**：胎壁屈曲变形、**脱圈**（胎圈从轮辋脱出）、**爆胎**

**正确胎压的核心原则**：让接触印迹**在正常骑姿和负载下接近圆**——具体数值以车主手册为准（来源：⭐⭐⭐，**胎压数据 ⭐，必须查手册**）。

【经验】 **老师傅一句话**：胎压不是「数字对了就行」，是「接触印迹对不对」；太高抓地变差，太低转向变重又爆胎。

### 11.1.4 核心物理原理三：滑水现象与临界速度

【机制】 雨天骑车最危险的物理现象是**滑水（hydroplaning）**——轮胎在积水路面高速行驶时，**水膜把轮胎和地面隔开**，抓地力瞬间归零（来源：⭐⭐⭐）。

**滑水的物理过程**：
1. 轮胎高速碾过积水区
2. 轮胎花纹有**排水能力**——把水从接触区挤出去
3. 当速度过高或积水过深，**排水能力跟不上**——水堆积在接触区前缘
4. 水形成楔形，**水压顶起轮胎**
5. 轮胎**完全离地**——骑手感觉「车飘了」

**临界滑水速度**（经验公式）：

v_c ≈ k × √(P)

其中 v_c 是临界速度（km/h），P 是胎压（kPa），k 是常数（约 7-9）。

**举例**：胎压 250 kPa（2.5 bar），v_c ≈ 7.5 × √250 ≈ 119 km/h。**这就是为什么高速雨天必须减速**（来源：⭐⭐，实际取决于花纹深度、积水深度）。

**反直觉点**：**光头胎（slick）在湿地比花纹胎差**——光头胎无排水沟，水无处可去。**花纹胎湿地抓地好**——花纹沟是排水通道。**光头胎干地抓地最强**——没有花纹破坏接触面积。

【经验】 **老师傅一句话**：雨天高速像踩在冰上——不是因为水「滑」，是水把轮胎「顶起来」了；花纹是排水沟，没花纹的高速湿胎就是滑水漂移。

### 11.1.5 核心物理原理四：前叉的工作原理

【机制】 前叉（front fork）= **弹簧 + 阻尼 + 导向**——**承重、缓冲、转向**三大功能合一（来源：⭐⭐⭐）。

**基本力学**：
- **静载荷**：车重 + 骑手重 + 前轴负载分配 → 前叉压缩到平衡位置
- **动载荷**：路面冲击 → 前叉**压缩行程**吸收 → 弹簧储能
- **回弹**：弹簧释放 → 阻尼把能量变热耗散 → 防止「无限弹跳」

**伸缩式（telescopic）前叉**（摩托车主流）：
- **两根套管**：外管（接车架）、内管（接前轴）
- 内管在外管内上下滑动
- 内部有：**弹簧**（线性或渐进）+ **阻尼器**（油 + 节流孔）

**倒置式（inverted）前叉**：
- 外管粗且固定在车架上端，内管较细并连接前轴（与伸缩式相反）
- 优势：刚性高（粗外管受力）、簧下质量小（下端细内管较轻）
- 常见于运动车

**关键概念**：
- **行程**（travel）：前叉能压缩的总长度，常见 100-200 mm
- **阻尼系数**：压缩阻尼 + 回弹阻尼，分别控制压缩和回弹速度
- **预载**（preload）：弹簧的初始压缩量，决定前叉「软硬基线」
- **液压油粘度**：阻尼的关键因素，**冬天油变稠阻尼变大**（这是为什么冬天车「硬」）

反直觉点：**前叉越软不一定越舒适**。太软的车在过弯时前叉压缩到底，**减震器触底后没有缓冲**——冲击直接传到手。**好的前叉在常用工况内能吸收 70-80% 的能量**，剩下的 20-30% 通过阻尼和轮胎耗散。

【经验】 **老师傅一句话**：前叉不是「越软越舒服」也不是「越硬越运动」——是「在常用工况内能吸能、回弹可控」才好；调前叉是师傅活，新手别乱调。

### 11.1.6 核心物理原理五：阻尼的物理——粘性阻尼与速度平方

【机制】 前叉阻尼（damping）的物理本质是**粘性阻尼**——油液通过节流孔时受到阻力，**阻力大小和油液流速相关**（来源：⭐⭐⭐）。

**基本公式**：

F_damping = c × v^n

其中：
- F_damping：阻尼力（N）
- c：阻尼系数（N·s/m 或 N·s²/m²）
- v：阻尼器活塞相对运动速度（m/s）
- n：指数（1 = 线性阻尼，2 = 速度平方阻尼）

**两种阻尼特性**：
- **线性阻尼**（n=1）：低速阻尼小、高速阻尼大。**城市骑行舒适**。
- **速度平方阻尼**（n=2）：低速阻尼极小、高速阻尼暴涨。**赛道骑行稳定**，但低速会有「不够紧实」的感觉。

**压缩阻尼 vs 回弹阻尼**：
- **压缩阻尼**：控制前叉压缩速度（吸收冲击的速度）
- **回弹阻尼**：控制前叉回弹速度（防止过度回弹导致二次冲击）
- **两者独立可调**——常见：压缩阻尼小（吸收冲击），回弹阻尼大（控制回弹）

反直觉点：**阻尼不是「越大越好」**。阻尼太大 → 前叉不灵活 → 路面起伏传递不上去 → 轮胎**不能贴地**。**优秀的阻尼是「刚好压住弹簧」**——既不软塌也不死硬。

【经验】 **老师傅一句话**：阻尼是「压住弹簧」的力量，不是「锁死弹簧」的力量；调太大是「高级的烂路感」。

### 11.1.7 核心物理原理六：油-气平衡式（cartridge）前叉

【机制】 现代中高端前叉**不再是简单的弹簧+油阻尼**——而是用**cartridge（插入式芯）**结构（来源：⭐⭐⭐）。

**基本原理**：
- 一根**插入管**装在前叉里，内部有**气室**（通常是氮气）+ **油路**
- 气压提供**渐进弹簧特性**——前叉越压缩，气压越大，**弹簧越硬**（比纯钢簧线性弹簧好得多）
- 油路提供**精确阻尼**——压缩油从一组节流孔流过，回弹油从另一组节流孔流过

**优势**：
- **渐进弹簧**：低速压缩软（舒适），高速压缩硬（防触底）
- **独立阻尼**：压缩阻尼和回弹阻尼完全独立可调
- **热稳定性**：气体不热膨胀，长期骑不会失效（油的阻尼会受温度影响）

**高端版（Öhlins、Showa BPF、Kayaba）**：
- **平衡弹簧**（Balance Free）：去掉传统弹簧，用油柱自身压力
- **电子控制**：电磁阀实时调阻尼（如 Ducati Skyhook Suspension、Aprilia APRC）

反直觉点：**气压不是「主弹簧」**——气压是**辅助弹簧**（主弹簧还是钢簧或油压柱）。气压的存在让前叉在**行程末端**变得很硬（防触底），而在**行程中段**保持软（舒适）。这是渐进特性的来源。

【经验】 **老师傅一句话**：cartridge 前叉的「气室」是渐进弹簧的关键——气压让前叉在行程末段变硬防触底，不是普通钢簧能比的。

### 11.1.8 核心物理原理七：后避震——单枪、连杆、阻尼

【机制】 后避震（rear shock）结构与前叉不同——通常只有一个减震器（**单枪 monoshock**），通过**连杆机构**（linkage）和**摇臂**（swingarm）把后轮和减震器连起来（来源：⭐⭐⭐）。

**单枪后避震的优势**：
- **左右车轮共一个减震器**——重心集中
- **布置灵活**——可以放在车架中央（运动车）或下方（巡航车）
- **连杆机构提供杠杆比**——后轮的小位移可以变成减震器的大位移
- **渐进特性**——连杆几何让压缩比不是 1:1（避震器压缩 10mm，可能后轮才动 5mm）

**连杆机构**：
- 摇臂后端接后轮轴
- 摇臂中段通过连杆接减震器下端
- 减震器上端接车架
- 连杆几何（杠杆比曲线）决定**避震器对路面的响应特性**

**单枪 vs 双枪（twin shock）**：
- **单枪**：单减震器 + 连杆；现代主流（更好的渐进特性、重量轻）
- **双枪**：两个减震器分别装在摇臂两侧；老车/复古车常见；**无连杆**（杠杆比恒定，阻尼调校受限）

反直觉点：**连杆机构不是「传力」那么简单**——它的**杠杆比曲线**是后避震特性的核心。**连杆几何变了，骑乘感受可以完全不一样**。很多改装店调后避震就是换不同几何的连杆。

【经验】 **老师傅一句话**：单枪后避震的连杆不是「机械连接」是「几何调校器」——换连杆 = 换性格。

### 11.1.9 核心物理原理八：簧载质量与非簧载质量

【机制】 摩托车重量分两类（来源：⭐⭐⭐）：

- **簧载质量（sprung mass）**：由弹簧支撑的重量——车架、骑手、发动机、油箱、座椅等
- **非簧载质量（unsprung mass）**：不被弹簧支撑的重量——车轮、轮胎、刹车盘、卡钳（部分）、前叉下端/摇臂后端

**簧载质量 vs 非簧载质量的工程意义**：
- 非簧载质量越大，悬挂对路面冲击的响应越**迟钝**（惯量大）
- 非簧载质量越大，轮胎**贴地性越差**（路面起伏把轮胎弹离地面的概率大）

**反直觉点**：**倒置前叉不是把更重的粗管放到车轮端**——它把粗外管固定在车架上端，把较轻的细内管放在前轴端。这样既提高弯曲刚性，又降低非簧载质量；代价是结构更复杂、成本更高。

**实操建议**：
- 减非簧载质量：换锻造轮毂（比铸造轻 20-30%）、换轻量化刹车盘
- 减簧载质量：减车架重量、减电池重量、减整流罩重量
- **优先减非簧载质量**——对操控的影响大得多

【经验】 **老师傅一句话**：减重先减非簧载，簧上减 1kg 顶不上非簧载减 0.5kg。

### 11.1.10 核心物理原理九：轮胎动平衡的物理

【机制】 轮胎+轮辋的**重量分布不可能绝对均匀**——总有某个方向偏重。**不平衡**会让车轮在旋转时产生**离心力波动**（来源：⭐⭐⭐）。

**两种不平衡**：
- **静不平衡**（static imbalance）：重心偏离旋转轴线，车轮会**停在偏重点向下**的位置
- **偶不平衡**（couple imbalance）：重心在轴线上但**左右分布不均**——车轮**不会停**在特定位置，但转动时会有摆动

**动平衡校正**：
- 把车轮放在动平衡机上
- 机器让车轮旋转，**测量哪个角度需要补偿**
- 在补偿点对侧贴**平衡块**（铅或锌合金小片）
- 平衡块质量有 5g、10g、15g、20g、25g 等规格

**反直觉点**：平衡块贴在哪里不重要，**关键是贴在「需要补偿的角度」**。动平衡机的屏幕会精确告诉你贴哪里、贴多重。

**不平衡的物理表现**：
- 高速时**车把抖**（前轮）或**车身抖**（后轮）
- 抖动频率主要等于车轮转频；不平衡量越大，抖动力幅值越大
- 抖到一定程度骑手会**疲劳**、**看不清前方**——**严重安全隐患**

**实操要点**：
- **新轮胎必须平衡**——出厂已经有内嵌平衡块，但**换位或换装后要重新平衡**
- 平衡块丢失必须补
- 补胎后**必须重新平衡**（修补位置改变重量分布）

【经验】 **老师傅一句话**：动平衡不是「差不多就行」——离心力要按 F = m × ω² × r 估算（ω 为角速度，r 为半径，来源：⭐⭐⭐）。例如半径约 0.3 m 的车轮在 100 km/h 时，5 g 不平衡约产生 12.9 N、也就是约 1.3 kgf 的周期性离心力波动，**足以让车把反复抖动**。

### 11.1.11 核心物理原理十：车轮转动的陀螺效应

【机制】 旋转的车轮有**陀螺效应**（gyroscopic effect）——快速旋转的物体有**保持旋转轴方向**的物理倾向（来源：⭐⭐⭐）。

**陀螺力矩公式**：

T = I × ω × Ω

其中：
- T：陀螺力矩（N·m）
- I：转动惯量（kg·m²）
- ω：车轮自转角速度（rad/s）
- Ω：转向角速度（rad/s，车把转动快慢）

**对摩托车的影响**：
- **高速稳定**：陀螺效应让前轮在颠簸下仍保持「指向前方」——**不容易摔倒**
- **低速变重**：低速时陀螺效应小，**转向灵活但需要主动输入**
- **事故率分布**：**摩托车低速摔车比高速多**——**不是因为高速安全**，是因为低速的稳定性全靠骑手主动控制

**反直觉点**：**陀螺效应不是「扶稳」的全部**——它是车手转向输入和车把角度变化的**「阻力」**。高速急转向要克服陀螺力矩（推车把费力），高速直行稳定性好（陀螺保持轴向）。

**轻量化轮毂的优势**：
- 转动惯量 I 小
- 同样角速度 ω 下，陀螺力矩小
- **转向更轻**（高速变向响应快）

【经验】 **老师傅一句话**：陀螺效应是双刃剑——高速帮稳定、低速帮倒忙；轻量化轮毂减转动惯量，转向响应提升一档。

### 11.1.12 主要组件与工作机制：从路面到车架

【机制】 **轮胎**：唯一与地面接触的部件。传递牵引力、制动力、转向力；吸收路面高频振动（来源：⭐⭐⭐）。

【机制】 **车轮**：支撑轮胎、提供旋转轴线。**轮辋**（rim）固定轮胎，**辐条或铸造**结构连接轮毂和轮辋（来源：⭐⭐⭐）。

【机制】 **前叉**：前轮的悬挂和导向结构。承重、缓冲、转向**三合一**（来源：⭐⭐⭐）。

【机制】 **后避震**：后轮的悬挂结构。吸收路面冲击、维持轮胎贴地（来源：⭐⭐⭐）。

【机制】 **后摇臂**（swingarm）：后轮的横向定位结构。**让后轮在纵向（前后）能跳动，横向不能偏**（来源：⭐⭐⭐）。

【机制】 **转向柱**（steering stem）：前叉和车架的连接结构。**让前叉能左右转动**，连接骑手车把输入和前轮方向（来源：⭐⭐⭐）。

【经验】 **老师傅一句话**：行走系统每个部件有明确任务——轮胎接地、车轮旋转、前叉承重缓冲+转向、后避震缓冲、摇臂横向定位、转向柱传力；出故障就按这个链条查。

### 11.1.13 类型对比与工程取舍

| 部件 | 类型 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| 轮胎 | 街胎 | 寿命长、湿地好、干地够用 | 极限不如运动胎 | 街车主力（来源：⭐） |
| 轮胎 | 运动胎 | 极限高、干地强 | 寿命短、雨天差 | 赛道、运动街车（来源：⭐） |
| 轮胎 | 越野胎 | 越野脱困 | 铺装路抓地差 | 越野车（来源：⭐） |
| 轮胎 | 全地形胎 | 越野+铺装平衡 | 都不极致 | ADV（来源：⭐） |
| 前叉 | 伸缩式 | 结构简单、维护方便、便宜 | 刚性比倒置差 | 绝大多数摩托车（来源：⭐） |
| 前叉 | 倒置式 | 刚性高、簧下质量小 | 结构复杂、贵 | 运动车、高端车（来源：⭐） |
| 后避震 | 单枪 | 重心集中、渐进特性好 | 调校复杂、贵 | 几乎所有现代车（来源：⭐） |
| 后避震 | 双枪 | 结构简单、复古风格 | 无连杆、特性受限 | 复古车、巡航（来源：⭐） |

【机制】 **为什么 ADV 选全地形胎不选越野胎？** ADV 多数时间在铺装路长途骑行，**越野花纹在铺装路抓地差、磨损快、噪声大**。全地形胎的中间花纹 + 两侧街胎设计是**铺装为主+偶尔越野**的最佳平衡。

【机制】 **为什么运动车都选倒置前叉？** 运动车过弯时前叉受**巨大侧向力**，需要**更高的弯曲刚性**。倒置前叉把更粗、更重的外管固定在车架上端，提升前叉上部受力刚性；下端连接前轴的是较轻的内管，有利于降低簧下质量。它的代价主要是成本和维护复杂度，**刚性 + 簧下质量**才是关键取舍。

【问答】 **新手改行走系统，先改什么？**
答：**不推荐新手先改行走系统**。原厂行走系统是厂家平衡的结果。新手改车常换「高抓地轮胎」「倒置前叉」「锻造轮毂」——结果：
- 换了运动胎，雨天更容易摔
- 换了硬悬挂，过坑颠簸难受
- 换了轻量化轮毂，原厂刹车可能配不上

**真想提升性能**，先把基础保养做好（胎压正确、链条润滑调紧、刹车片厚度够），这些比改件有效得多（来源：⭐）。

【经验】 **老师傅一句话**：行走系统不是「越贵越好」——原厂平衡是综合最优；新手改车常把平衡改成单点优化，结果丢了其他维度。

【机制小结】

- 行走系统是「轮胎→车轮→悬挂→车架」的力学传递链；要同时管传力、缓冲、贴地三件事（来源：⭐⭐⭐）。
- 轮胎抓地力是粘附+滞后两种机理叠加；湿地比干地抓地好是反直觉点（来源：⭐⭐⭐）。
- 子午线轮胎用带束层限制周向伸长，胎壁软、接地大、高速稳；现代摩托车主流（来源：⭐⭐⭐）。
- 胎压通过接触印迹形状影响操控；太高抓地差、太低转向重且易爆（来源：⭐⭐⭐）。
- 滑水是水膜把轮胎顶离地面；临界速度 v_c ≈ k√P（k≈7-9）；花纹是排水沟（来源：⭐⭐）。
- 前叉 = 弹簧 + 阻尼 + 导向；伸缩式主流，倒置式刚性高（来源：⭐⭐⭐）。
- 阻尼 F = cv^n；线性 vs 速度平方；压缩/回弹独立（来源：⭐⭐⭐）。
- cartridge 前叉的气室提供渐进弹簧特性；高端电磁阀实时调阻尼（来源：⭐⭐⭐）。
- 后避震单枪 + 连杆；连杆几何决定杠杆比曲线（来源：⭐⭐⭐）。
- 簧载/非簧载质量划分；减非簧载对操控影响大（来源：⭐⭐⭐）。
- 动平衡是消除车轮旋转时的离心力波动；5 g 不平衡在 100 km/h、0.3 m 半径车轮上约产生 12.9 N（约 1.3 kgf）的周期性离心力（来源：⭐⭐⭐）。
- 陀螺效应让高速稳定、低速灵活；轻量化轮毂减转动惯量提升响应（来源：⭐⭐⭐）。

## 11.2 前叉（核心部件）

### 11.2.1 前叉干什么的 ★★

**支撑前轮 + 缓冲路面冲击 + 转向**。

### 11.2.2 前叉类型

**1. 传统正立叉**（Conventional Forks）：
- 叉管在上，叉筒在下
- 结构简单、维护方便
- 街车主力

**2. 倒立叉**（USD, Up-Side-Down）：
- 叉筒在上，叉管在下
- 刚性好、簧下质量小
- 运动车、ADV

**3. 单摇臂叉**（Single-Sided）：
- 一侧露出（方便换轮）
- 顶级运动车

### 11.2.3 前叉结构

```
[上联板]
   ↓
[叉管（上）] ← 活塞杆、密封
   ↓
[叉筒（下）] ← 内管、油液、弹簧
   ↓
[前轴]
```

**核心部件**：
- **弹簧**：缓冲冲击
- **阻尼油/气**：吸收振动
- **油封**：防止漏油
- **防尘封**：防止灰尘进叉管

### 11.2.4 前叉漏油（核心故障）★★★

**症状**：前叉下端有油渍。

**原因**：
1. **油封老化**（最常见）
2. **叉管划伤**（沙土、撞击）
3. **叉管弯曲**（事故）

**处理**：
- 油封老化：**换油封**（DIY 可行但有难度）
- 叉管划伤：**换叉管或整个前叉**（送修）
- 叉管弯曲：**换前叉**（送修）

【严重警告】 **严重警告**：**前叉漏油不修 = 危险**！**漏油会让前叉阻尼失效**，**刹车时前叉会"前窜"**，**可能摔车**。

### 11.2.5 换前叉油封（进阶技能）

**步骤**：
```
1. 拆前轮
2. 拆前叉（松开上下联板夹紧螺丝）
3. 倒出旧油（用注射器）
4. 拆下油封（用油封起子或自制工具）
5. 检查叉管（看有无划伤）
6. 装新油封（用专用工具或木块 + 锤子）
7. 加新前叉油（**按说明书容量和粘度**）
8. 装回前叉
9. 装回前轮
10. 试骑
```

【经验】 **老师傅经验**：**换前叉油**分两种：
- **更换油封**：油封坏了才换（一般 3-5 万 km）
- **换油**：**每 1-2 万 km**（油会老化，阻尼变差）

**只换油不换油封**也能改善手感——**老车前叉"软"往往不是弹簧问题，是油老化**。

【送修】 **该送修了**：
- 没油封起子
- 叉管划伤
- 第一次换（建议老手指导）

### 11.2.6 前叉预载调整

**目的**：根据骑手重量、骑行风格调整前叉软硬。

**步骤**：
```
1. 找到前叉顶盖（叉管顶端）
2. 用专用扳手（或卡尺）调整
3. 顺时针拧 = 弹簧预载增加（前叉更硬）
4. 逆时针拧 = 弹簧预载减少（前叉更软）
5. **左右两边调整量一致**（用刻度）
6. 试骑
```

【经验】 **老师傅经验**：**预载调整常识**：
- **单人骑**：标准预载
- **双人骑 + 行李**：增加预载
- **山路/越野**：减少预载（更舒适）
- **赛道**：增加预载（更稳）

### 11.2.7 前叉压缩阻尼调整

**高端前叉才有**——可以调压缩阻尼（高速压缩和低速压缩）。

**调整方法**（按说明书）：
- 顺时针 = 阻尼大（前叉硬）
- 逆时针 = 阻尼小（前叉软）

## 11.3 后避震

### 11.3.1 后避震干什么的

**支撑后轮 + 缓冲路面冲击**。

### 11.3.2 后避震类型

| 类型 | 特点 | 应用 |
|------|------|------|
| **双筒避震** | 两个避震器 | 大部分车 |
| **单筒避震** | 一个中央避震 | 部分运动车、ADV |
| **多连杆避震** | 杠杆机构连接 | 部分车 |
| **气压避震** | 不用弹簧，用高压气 | ADV、BMW |

### 11.3.3 后避震结构

**核心**：
- 弹簧（承受重量）
- 阻尼器（吸收振动）
- 油液/气体

### 11.3.4 后避震维护 ★★

**车主可做的**：
- **预载调整**（**车主必会**）
- **清洁**（擦油泥）
- **检查漏油**（漏油要送修）

**预载调整（车主技能）**：
```
1. 找到后避震下方的调整环
2. 用专用扳手（一般是钩形扳手）
3. 顺时针 = 弹簧预载增加（更硬）
4. 逆时针 = 弹簧预载减少（更软）
5. 试骑
```

**调整建议**：
- **单人**：标准预载
- **双人/载重**：增加 1-2 圈
- **载重 + 山路**：增加 2-3 圈
- **单人越野**：减少 1-2 圈

### 11.3.5 后避震漏油

**症状**：后避震有油渍。

**含义**：密封圈坏。

**处理**：**送修**——一般要换避震总成（**一体化结构**）。

【费用】 **参考价格**：
- **原厂后避震**：500-3000 元
- **改装后避震**（如 Öhlins、WP）：3000-10000 元
- **工时费**：200-500 元

【经验】 **老师傅经验**：**后避震 5-10 万 km 检查一次**。**漏油不修**会让车身姿态不稳，**影响操控和安全**。

## 11.4 车轮

### 11.4.1 车轮结构

```
[轮辋]（铝合金或钢丝）
   ↓
[辐条/铸铝]（连接轮辋和轮毂）
   ↓
[轮毂]（装轴承和刹车盘）
   ↓
[轴承]
   ↓
[轴]
```

### 11.4.2 车轮类型

**1. 铸铝轮**（**主流**）：
- 铝合金铸造
- 轻、美观
- 街车、运动车主力

**2. 辐条轮**（Spoke Wheel）：
- 钢丝辐条
- 韧性好、越野性能好
- 越野车、ADV、复古车

### 11.4.3 车轮轴承 ★★

**作用**：让车轮顺畅转动。

**故障**：
- **异响**（"嗡嗡"声随车速增加）
- **卡顿**（转动不顺）
- **旷量**（左右晃动车轮能感觉到间隙）

**检查**：
```
1. 架起大撑
2. 抓住车轮上下/左右摇
3. 没有旷量 = 正常
4. 有旷量 = 轴承坏
5. 转动车轮听异响
```

**更换**（进阶技能）：
```
1. 拆车轮
2. 拆轴
3. 用轴承拉拔器拆旧轴承
4. 装新轴承（用专用工具或木块+锤子）
5. 装回车轮
6. 试骑
```

【送修】 **该送修了**：
- 没轴承拉拔器
- 第一次换

### 11.4.4 辐条调整（辐条轮）

**症状**：
- 车轮摆动
- 轮胎位置不正

**调整**：
```
1. 找到辐条扳手（专用）
2. 转动辐条螺母
3. 顺时针 = 拉紧辐条
4. 逆时针 = 放松辐条
5. 每次调整 1/4 圈
6. 调整后用车轮平衡机检查
```

【严重警告】 **严重警告**：**辐条调整需要经验**！**调整不当**会让车轮变形。**新手建议送修**。

### 11.4.5 轮辋检查

**检查项目**：
- 变形（目视+测量）
- 腐蚀（影响气密性）
- 裂纹（**看到立即换**）

## 11.5 前叉/后避震调整

### 11.5.1 前叉综合调整（进阶）

**现代运动前叉可调**：

| 调整 | 工具 | 效果 |
|------|------|------|
| **预载** | 卡尺/钩形扳手 | 静态高度 |
| **压缩阻尼（高速）** | 螺丝刀 | 高速压缩时的阻尼 |
| **压缩阻尼（低速）** | 螺丝刀 | 低速压缩时的阻尼 |
| **回弹阻尼** | 螺丝刀 | 压缩后回弹的速度 |

【经验】 **老师傅经验**：**调整逻辑**：
- **软（阻尼小）**：舒适，但操控差
- **硬（阻尼大）**：操控好，但颠簸
- **找到适合自己的平衡点**

**专业建议**：**第一次调整按说明书**，**然后试骑**，**每次只调一个参数**。

### 11.5.2 后避震综合调整

**基本相同**：
- **预载**：静态高度
- **压缩阻尼**：压缩时的阻尼
- **回弹阻尼**：回弹的速度

【经验】 **老师傅经验**：**回弹阻尼**最影响操控：
- **回弹太快**：车身颠簸，操控不稳
- **回弹太慢**：过坑时压缩后弹不回来
- **标准**：压缩后 1-2 次稳定

## 11.7 【经验】 老师傅经验沉淀（应写尽写）

### 11.7.1 新手必踩的 13 个行走系统坑 ★★★

**轮胎类**：
1. **骑前不查胎压** —— **爆胎风险**、操控差
2. **胎压测"热胎"当"冷胎"** —— 长期跑磨损不均
3. **轮胎鼓包还骑** —— **随时爆胎**
4. **轮胎超龄不换** —— 橡胶老化，抓地下降
5. **胎压过高** —— 抓地下降、刹车距离变长
6. **胎压过低** —— 转向重、磨损快、**爆胎风险**

**前叉类**：
7. **前叉漏油不修** —— 阻尼失效、刹车"前窜"、**摔车风险**
8. **前叉调整左右不对称** —— 车跑偏

**后避震类**：
9. **后避震漏油不修** —— 车身姿态不稳
10. **双人骑不调预载** —— 避震触底，损坏
11. **后避震调节器生锈不处理** —— 无法调整

**车轮类**：
12. **车轮轴承坏不修** —— 高速时车轮可能抱死
13. **辐条松动不调整** —— 车轮变形、轮胎磨损不均

【经验】 **老师傅经验**：**行走系统**第一公敌是**胎压**。**胎压**决定**一切**——抓地、磨损、操控、油耗、安全。**骑前 1 分钟查胎压 = 安全保证**。

### 11.7.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 胎压冷胎测**：骑了 1 km 内测，热胎 +0.2-0.3 bar
2. **【维修】 鼓包立即换**：补胎救不了
3. **【维修】 轮胎超 5 年换**：即使胎纹好，橡胶也老化
4. **【维修】 前叉漏油立即修**：漏油 = 阻尼失效 = 摔车风险
5. **【维修】 前叉调整左右对称**：差 1 圈 = 跑偏
6. **【维修】 后避震预载按体重调**：体重 + 装备 + 载重都要算
7. **【维修】 轴承旷量立即换**：旷量 = 轴承坏
8. **【维修】 辐条轮定期紧辐条**：松动的辐条会越松越多

### 11.7.3 时间预估的真相 ★★

| 项目 | 老手实际 | 新手实际 |
|------|---------|---------|
| 检查胎压 | 1-2 分钟 | 2-3 分钟 |
| 检查轮胎 | 5-10 分钟 | 10-20 分钟 |
| 换轮胎 | 30-60 分钟 | 1-3 小时 |
| 换前叉油封 | 1-2 小时 | 3-5 小时 |
| 换后避震 | 30 分钟 | 1-2 小时 |
| 调前叉预载 | 5-10 分钟 | 10-20 分钟 |
| 换车轮轴承 | 30-60 分钟 | 1-3 小时 |

【经验】 **老师傅经验**：轮胎拆装、胎唇就位、气门嘴和动平衡都直接影响安全。第一次不要独自换胎，至少让专业店或有经验的人现场指导；高速车、真空胎、辐条轮和带胎压传感器的车更建议专业店处理。

### 11.7.4 哪些钱不能省 ★★

**工具**：
- 胎压表：30-100 元（**不要用气站免费胎压表**，不准）
- 轮胎撬棍：50-150 元（**不要买塑料的**，会断）
- 平衡块：30-100 元
- 辐条扳手（如辐条轮）：50-150 元
- 轴承拉拔器（如换轴承）：100-300 元

**零件**：
- 轮胎：买正品（米其林、倍耐力、普利司通、邓禄普、IRC）—— **不要买"通用"杂牌**
- 油封：买正品
- 轴承：买正品（SKF、NTN、NSK）

**送修的智慧**：
- 轮胎平衡 → **送修**（需要平衡机）
- 辐条调整 → **建议送修**
- 避震维修 → **送修**
- 轮辋修复 → **送修**

【费用】 **省钱贴士**：**行走系统车主能省钱的部分**：
- 查胎压、调胎压：省 0 元（本来就免费）
- 换轮胎：省 100-400 元
- 调避震预载：省 0 元
- 清洁保养：省 50-150 元

**一年总计省 150-550 元**。**但换来的是安全**——**轮胎好的车骑行信心完全不同**。

### 11.7.5 容易漏的小细节 ★★

- 【维修】 **气门嘴帽**：丢了会让气门嘴漏气（**几毛钱的事别省**）
- 【维修】 **轮胎 DOT 编码**：在胎侧
- 【维修】 **前叉油粘度**：不同温度地区不同（**说明书**）
- 【维修】 **后避震调节器**：有些车要专用工具（**很多车友不知道**）
- 【维修】 **车轮轴承润滑**：换轴承时涂润滑脂

【经验】 **老师傅经验**：**气门嘴帽**几毛钱，但丢了会让气门嘴漏气。**一年漏 0.1 bar** 看似不多，**但累积起来会让你频繁打气**。**每次打完气**顺手拧上气门嘴帽。

### 11.7.6 骑前必查清单 ★★★

```
[ ] 胎压（前/后，冷胎）
[ ] 轮胎外观（无鼓包、裂纹、扎钉）
[ ] 轮胎磨损（胎纹深度）
[ ] 前叉无漏油
[ ] 后避震无漏油
[ ] 车轮轴承无异响
[ ] 链条松紧（按 10.2.4）
```

【经验】 **老师傅经验**：**骑前 5 分钟**做这套检查 = **减少 90% 的故障**。**老司机都有这习惯**——**看一眼、摸一下、转一下**，比什么都管用。

### 11.7.7 进阶学习路径 ★★

学完本章后想进阶，按这个顺序学：

1. **【入门】** 查胎压、检查轮胎、调避震预载
2. **【基础】** 换轮胎、换气门嘴、补胎（应急）
3. **【进阶】** 换前叉油封、换后避震
4. **【高级】** 调前叉阻尼、换轮辋
5. **【专业】** 倒立叉维护、避震翻新

【经验】 **老师傅经验**：**行走系统**的核心是**轮胎 + 胎压**。**轮胎保养得当延寿 1-2 万 km**。**胎压正确**操控好、油耗低、磨损均匀。**从胎压开始，认真做**。

### 11.7.9 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的真实案例**——给新手看"别人怎么翻车的"。

### 案例 A：宝马 R1200GS 前叉漏油

**症状**：前叉管上有油迹
**踩坑过程**：以为是前叉坏了
**可能原因**：**前叉油封老化**——**正常磨损**
**处理建议**：换前叉油封（**专业店**）
**教训**：**前叉漏油** = **先换油封** = **别大修**

### 案例 B：本田 CB500F 轮胎偏磨

**症状**：前胎中间比两侧磨得多
**踩坑过程**：以为是轮胎质量
**可能原因**：**胎压过高**——**中央磨损**
**处理建议**：**按说明书胎压**
**教训**：**偏磨** = **先查胎压** = **简单**

### 案例 C：雅马哈 MT-07 轮胎裂纹

**症状**：胎侧有裂纹
**踩坑过程**：以为是老化
**可能原因**：**阳光/热老化**——**正常**
**处理建议**：**换胎**——**不能用**
**教训**：**裂纹 = 必换** = **别省**

### 案例 D：哈雷 Sportster 前叉弹簧响

**症状**：压前叉有咯吱声
**踩坑过程**：以为是前叉坏
**可能原因**：**弹簧底垫磨损**
**处理建议**：换底垫
**教训**：**前叉响** = **先看底垫** = **便宜**

### 案例 E：川崎 Ninja 400 胎压监测失灵

**症状**：TPMS 灯亮
**踩坑过程**：以为是传感器坏
**可能原因**：**胎压真的低**
**处理建议**：**补胎压**
**教训**：**TPMS 亮** = **先看胎压**

### 案例 F：杜卡迪 Monster 后轮轴承坏

**症状**：后轮有异响
**踩坑过程**：以为是后轮辋变形
**可能原因**：**后轮轴承磨损**
**处理建议**：**送修**——**换轴承**
**教训**：**后轮异响** = **送修**

### 案例 G：凯旋 Tiger 900 前轮辋凹陷

**症状**：骑过坑后轮辋凹
**踩坑过程**：以为是轮辋质量问题
**可能原因**：轮辋受冲击变形，可能伴随裂纹、失圆或慢漏气
**处理建议**：停止高速骑行，送专业店检查跳动、裂纹和气密性；是否能修复或必须更换，由检测结果决定
**教训**：轮辋凹陷不是“正常现象”，结构件不能只看外观判断

### 案例 H：本田 Africa Twin 越野后轮胎夹石子

**症状**：越野完胎面有石子
**踩坑过程**：正常现象
**可能原因**：**石子夹在花纹里**
**处理建议**：**清石子**
**教训**：**越野后清石子** = **必备**

### 案例 I：铃木 SV650 平衡块掉了

**症状**：骑到一半轮辋上啪响
**踩坑过程**：平衡块掉
**可能原因**：**粘合剂老化**
**处理建议**：**贴新平衡块**
**教训**：**平衡块掉** = **贴新的** = **10 元**

### 案例 J：本田 NC750X 前叉油量不够

**症状**：前叉下沉
**踩坑过程**：以为是前叉坏
**可能原因**：前叉油老化、油量不对、油封泄漏或内部磨损
**处理建议**：检查是否漏油和左右油量；按手册拆检、定量更换前叉油，不能只凭手感随意补油
**教训**：**前叉下沉** = **补油** = **简单**

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **不查胎压** = **轮胎磨损快** = **几百元**
2. **不查花纹深度** = **湿滑失控** = **危险**
3. **不查前叉油封** = **漏油严重 = 换前叉** = **千元**
4. **越野不清石子** = **爆胎**
5. **不查车轮轴承** = **高速甩尾** = **危险**

【经验】 **老师傅总结**：行走系统 = 轮胎 + 胎压 + 前叉 + 后避震 + 车轮。胎压和轮胎状态可以自己勤查；换胎、轮辋变形、前叉漏油和轴承松旷要按手册或送专业店处理。
