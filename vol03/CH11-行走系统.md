## 11.1 轮胎（核心部件）★★★

### 11.1.1 轮胎干什么的 ★★★

**接触地面的唯一部件**——摩托车所有动力、刹车、转向都通过轮胎传到地面。**轮胎状态 = 安全性**。

**轮胎的功能**：
- 传递牵引力（加速、刹车、转弯）
- 缓冲路面冲击
- 提供转向反馈

### 11.1.2 轮胎规格（怎么看）

**侧壁标记**（例：`120/70 ZR17 58W`）：

| 部分 | 含义 |
|------|------|
| **120** | 胎面宽度（mm） |
| **70** | 扁平比（侧壁高度/胎面宽度 × 100） |
| **ZR** | 速度等级（Z + R = 子午线高速） |
| **17** | 轮辋直径（英寸） |
| **58** | 载重指数 |
| **W** | 速度等级（W = 270 km/h） |

**速度等级**：

| 标记 | 最高速度 |
|------|---------|
| H | 210 km/h |
| V | 240 km/h |
| W | 270 km/h |
| Y | 300 km/h |

【来源】 **数据来源等级**：★（**你的车用什么轮胎，看说明书/侧壁**）。

### 11.1.3 胎压（骑前必查）★★★

**胎压对骑行的影响巨大**：

| 胎压 | 影响 |
|------|------|
| **正常** | 操控好、磨损均匀、舒适 |
| **过高** | 抓地力下降、刹车距离变长、颠簸 |
| **过低** | 转向重、轮胎磨损快、油耗高、爆胎风险 |
| **严重过低** | **爆胎风险极高**（高速尤其危险） |

**一般胎压范围**（冷胎时）★：

| 类型 | 前胎 | 后胎 |
|------|------|------|
| 街车 | 2.2-2.5 bar | 2.5-2.9 bar |
| 运动车 | 2.3-2.6 bar | 2.6-3.0 bar |
| 越野车 | 1.5-2.0 bar | 1.5-2.0 bar |
| ADV | 2.2-2.5 bar | 2.5-2.9 bar |

【来源】 **数据来源等级**：★（**你的车具体胎压看说明书/侧壁**，运动型可能更高）。

【注意】 **严重警告**：骑前检查冷胎胎压。胎压偏离手册值会影响操控、磨损和发热；严重偏低时有胎体过热、脱圈或爆胎风险。

【经验】 **老师傅经验**：**胎压要"冷胎"测**——**骑了 1 km 之内测**。**热胎胎压**比冷胎高 0.2-0.3 bar。**很多人把"热胎 2.5 bar"误认为"冷胎 2.5 bar"**，**实际冷胎只有 2.2-2.3 bar**，**长期跑会磨损不均**。

### 11.1.4 轮胎磨损检查 ★★★

**检查项目**：

**胎纹深度**：
- 用胎纹尺测
- **最低要求 1.6 mm**（法规）
- **建议 2-3 mm**（湿地排水）
- 低于 1.6 mm = **必须换**

**磨损不均**：
- 中间磨损快 = **胎压过高**
- 两边磨损快 = **胎压过低**或**过弯太狠**
- 一边磨损快 = **前叉/后避震问题**（车轮不正）

**鼓包/裂纹**：
- **鼓包 = 必须立即换**（爆胎前兆）
- **可见裂纹** = 老化，要换
- **扎钉** = 看深度，浅的补，**深的或侧壁的换**

**胎龄**：
- 轮胎从生产日期起 **5-6 年**
- 看侧壁 DOT 编码（如 DOT XXXX 2320 = 2020 年第 23 周）
- **超过 5 年**即使胎纹还好也要换（**橡胶老化**）

【严重警告】 **严重警告**：**鼓包 = 立即停车换胎**！**鼓包是内部帘线断裂**，**随时爆胎**。**补胎都救不了**——**只能换**。

### 11.1.5 轮胎类型 ★★

| 类型 | 特点 | 应用 |
|------|------|------|
| **街胎**（Sport-Touring） | 寿命长、抓地好、湿地好 | 街车主力 |
| **运动胎**（Track） | 抓地极强、寿命短 | 赛道、运动街车 |
| **越野胎**（Knobby） | 越野花纹、铺装路差 | 越野车 |
| **全地形胎**（Dual-Sport） | 中间越野、两边街胎 | ADV |
| **胎压监测**（TPMS） | 实时显示胎压 | 高端车 |
| **防爆胎**（Run-Flat） | 漏气还能跑 | BMW 等 |

### 11.1.6 轮胎更换（车主可学）★★

**车主能自己换轮胎，但要认真学**。

**工具**：
- 轮胎撬棍（2-3 根）
- 轮辋保护垫
- 轮胎蜡或润滑剂
- 气泵
- 胎压表

**步骤**：
```
1. 拆下车轮（松开轴螺丝/螺母）
2. 放气（按压气门芯）
3. 涂轮胎蜡在新轮胎和轮辋上
4. 第一根撬棍撬开一侧胎唇
5. 第二根撬棍逐步撬出胎唇
6. 取下旧轮胎
7. 检查轮辋（看有无变形、腐蚀）
8. 检查新轮胎方向（有"箭头"朝前进方向）
9. 装新轮胎一侧胎唇
10. 装气门芯（先不上紧）
11. 装另一侧胎唇（同样方法）
12. 充气（**关键**）
   - 充到 3.5-4.0 bar（让胎唇"啪"一声归位）
   - 听到"啪"声 = 装好了
   - 慢慢放到规定胎压
13. 检查胎唇是否均匀贴合
14. 装回车轮
15. 按扭矩拧紧轴螺丝/螺母
16. 检查转动是否顺畅
17. 平衡（**见下**）
```

【严重警告】 **严重警告**：
- **充气时远离轮胎**！**爆胎可能伤人**。
- **不要超压**！按规格充气（侧壁标记）。
- **新轮胎要平衡**！

### 11.1.7 轮胎平衡 ★★

**为什么要平衡**：轮胎+轮辋的重量分布不可能完全均匀。**不平衡**会让高速时车把抖。

**平衡方法**：
```
1. 用车轮平衡机（专业）
2. 找不平衡点（机器会显示）
3. 在不平衡点对侧贴平衡块
4. 反复测试直到平衡
```

【费用】 **省钱贴士**：
- **自己换轮胎省 50-200 元/条**（送店里两条 200-500 元工时）
- **但需要买工具**：轮胎撬棍 50-150 元，气泵 100-300 元，平衡块 50-100 元
- **第一次建议找师傅教**，**以后自己换**

【送修】 **该送修了**：
- **轮胎平衡**——需要平衡机
- **第一次换轮胎**——建议老手指导
- **真空胎扎胎**——专业补胎（蘑菇钉）

## 11.2 前叉（核心部件）

### 11.2.1 前叉干什么的 ★★

**支撑前轮 + 缓冲路面冲击 + 转向**。

### 11.2.2 前叉类型

**1. 传统正立叉**（Conventional Forks）：
- 叉管在上，叉筒在下
- 结构简单、维护方便
- 街车主力

**2. 倒立叉**（USD, Up-Side-Down）：
- 叉筒在上，叉管在下
- 刚性好、簧下质量小
- 运动车、ADV

**3. 单摇臂叉**（Single-Sided）：
- 一侧露出（方便换轮）
- 顶级运动车

### 11.2.3 前叉结构

```
[上联板]
   ↓
[叉管（上）] ← 活塞杆、密封
   ↓
[叉筒（下）] ← 内管、油液、弹簧
   ↓
[前轴]
```

**核心部件**：
- **弹簧**：缓冲冲击
- **阻尼油/气**：吸收振动
- **油封**：防止漏油
- **防尘封**：防止灰尘进叉管

### 11.2.4 前叉漏油（核心故障）★★★

**症状**：前叉下端有油渍。

**原因**：
1. **油封老化**（最常见）
2. **叉管划伤**（沙土、撞击）
3. **叉管弯曲**（事故）

**处理**：
- 油封老化：**换油封**（DIY 可行但有难度）
- 叉管划伤：**换叉管或整个前叉**（送修）
- 叉管弯曲：**换前叉**（送修）

【严重警告】 **严重警告**：**前叉漏油不修 = 危险**！**漏油会让前叉阻尼失效**，**刹车时前叉会"前窜"**，**可能摔车**。

### 11.2.5 换前叉油封（进阶技能）

**步骤**：
```
1. 拆前轮
2. 拆前叉（松开上下联板夹紧螺丝）
3. 倒出旧油（用注射器）
4. 拆下油封（用油封起子或自制工具）
5. 检查叉管（看有无划伤）
6. 装新油封（用专用工具或木块 + 锤子）
7. 加新前叉油（**按说明书容量和粘度**）
8. 装回前叉
9. 装回前轮
10. 试骑
```

【经验】 **老师傅经验**：**换前叉油**分两种：
- **更换油封**：油封坏了才换（一般 3-5 万 km）
- **换油**：**每 1-2 万 km**（油会老化，阻尼变差）

**只换油不换油封**也能改善手感——**老车前叉"软"往往不是弹簧问题，是油老化**。

【送修】 **该送修了**：
- 没油封起子
- 叉管划伤
- 第一次换（建议老手指导）

### 11.2.6 前叉预载调整

**目的**：根据骑手重量、骑行风格调整前叉软硬。

**步骤**：
```
1. 找到前叉顶盖（叉管顶端）
2. 用专用扳手（或卡尺）调整
3. 顺时针拧 = 弹簧预载增加（前叉更硬）
4. 逆时针拧 = 弹簧预载减少（前叉更软）
5. **左右两边调整量一致**（用刻度）
6. 试骑
```

【经验】 **老师傅经验**：**预载调整常识**：
- **单人骑**：标准预载
- **双人骑 + 行李**：增加预载
- **山路/越野**：减少预载（更舒适）
- **赛道**：增加预载（更稳）

### 11.2.7 前叉压缩阻尼调整

**高端前叉才有**——可以调压缩阻尼（高速压缩和低速压缩）。

**调整方法**（按说明书）：
- 顺时针 = 阻尼大（前叉硬）
- 逆时针 = 阻尼小（前叉软）

## 11.3 后避震

### 11.3.1 后避震干什么的

**支撑后轮 + 缓冲路面冲击**。

### 11.3.2 后避震类型

| 类型 | 特点 | 应用 |
|------|------|------|
| **双筒避震** | 两个避震器 | 大部分车 |
| **单筒避震** | 一个中央避震 | 部分运动车、ADV |
| **多连杆避震** | 杠杆机构连接 | 部分车 |
| **气压避震** | 不用弹簧，用高压气 | ADV、BMW |

### 11.3.3 后避震结构

**核心**：
- 弹簧（承受重量）
- 阻尼器（吸收振动）
- 油液/气体

### 11.3.4 后避震维护 ★★

**车主可做的**：
- **预载调整**（**车主必会**）
- **清洁**（擦油泥）
- **检查漏油**（漏油要送修）

**预载调整（车主技能）**：
```
1. 找到后避震下方的调整环
2. 用专用扳手（一般是钩形扳手）
3. 顺时针 = 弹簧预载增加（更硬）
4. 逆时针 = 弹簧预载减少（更软）
5. 试骑
```

**调整建议**：
- **单人**：标准预载
- **双人/载重**：增加 1-2 圈
- **载重 + 山路**：增加 2-3 圈
- **单人越野**：减少 1-2 圈

### 11.3.5 后避震漏油

**症状**：后避震有油渍。

**含义**：密封圈坏。

**处理**：**送修**——一般要换避震总成（**一体化结构**）。

【费用】 **参考价格**：
- **原厂后避震**：500-3000 元
- **改装后避震**（如 Öhlins、WP）：3000-10000 元
- **工时费**：200-500 元

【经验】 **老师傅经验**：**后避震 5-10 万 km 检查一次**。**漏油不修**会让车身姿态不稳，**影响操控和安全**。

## 11.4 车轮

### 11.4.1 车轮结构

```
[轮辋]（铝合金或钢丝）
   ↓
[辐条/铸铝]（连接轮辋和轮毂）
   ↓
[轮毂]（装轴承和刹车盘）
   ↓
[轴承]
   ↓
[轴]
```

### 11.4.2 车轮类型

**1. 铸铝轮**（**主流**）：
- 铝合金铸造
- 轻、美观
- 街车、运动车主力

**2. 辐条轮**（Spoke Wheel）：
- 钢丝辐条
- 韧性好、越野性能好
- 越野车、ADV、复古车

### 11.4.3 车轮轴承 ★★

**作用**：让车轮顺畅转动。

**故障**：
- **异响**（"嗡嗡"声随车速增加）
- **卡顿**（转动不顺）
- **旷量**（左右晃动车轮能感觉到间隙）

**检查**：
```
1. 架起大撑
2. 抓住车轮上下/左右摇
3. 没有旷量 = 正常
4. 有旷量 = 轴承坏
5. 转动车轮听异响
```

**更换**（进阶技能）：
```
1. 拆车轮
2. 拆轴
3. 用轴承拉拔器拆旧轴承
4. 装新轴承（用专用工具或木块+锤子）
5. 装回车轮
6. 试骑
```

【送修】 **该送修了**：
- 没轴承拉拔器
- 第一次换

### 11.4.4 辐条调整（辐条轮）

**症状**：
- 车轮摆动
- 轮胎位置不正

**调整**：
```
1. 找到辐条扳手（专用）
2. 转动辐条螺母
3. 顺时针 = 拉紧辐条
4. 逆时针 = 放松辐条
5. 每次调整 1/4 圈
6. 调整后用车轮平衡机检查
```

【严重警告】 **严重警告**：**辐条调整需要经验**！**调整不当**会让车轮变形。**新手建议送修**。

### 11.4.5 轮辋检查

**检查项目**：
- 变形（目视+测量）
- 腐蚀（影响气密性）
- 裂纹（**看到立即换**）

## 11.5 前叉/后避震调整

### 11.5.1 前叉综合调整（进阶）

**现代运动前叉可调**：

| 调整 | 工具 | 效果 |
|------|------|------|
| **预载** | 卡尺/钩形扳手 | 静态高度 |
| **压缩阻尼（高速）** | 螺丝刀 | 高速压缩时的阻尼 |
| **压缩阻尼（低速）** | 螺丝刀 | 低速压缩时的阻尼 |
| **回弹阻尼** | 螺丝刀 | 压缩后回弹的速度 |

【经验】 **老师傅经验**：**调整逻辑**：
- **软（阻尼小）**：舒适，但操控差
- **硬（阻尼大）**：操控好，但颠簸
- **找到适合自己的平衡点**

**专业建议**：**第一次调整按说明书**，**然后试骑**，**每次只调一个参数**。

### 11.5.2 后避震综合调整

**基本相同**：
- **预载**：静态高度
- **压缩阻尼**：压缩时的阻尼
- **回弹阻尼**：回弹的速度

【经验】 **老师傅经验**：**回弹阻尼**最影响操控：
- **回弹太快**：车身颠簸，操控不稳
- **回弹太慢**：过坑时压缩后弹不回来
- **标准**：压缩后 1-2 次稳定

## 11.7 【经验】 老师傅经验沉淀（应写尽写）

### 11.7.1 新手必踩的 13 个行走系统坑 ★★★

**轮胎类**：
1. **骑前不查胎压** —— **爆胎风险**、操控差
2. **胎压测"热胎"当"冷胎"** —— 长期跑磨损不均
3. **轮胎鼓包还骑** —— **随时爆胎**
4. **轮胎超龄不换** —— 橡胶老化，抓地下降
5. **胎压过高** —— 抓地下降、刹车距离变长
6. **胎压过低** —— 转向重、磨损快、**爆胎风险**

**前叉类**：
7. **前叉漏油不修** —— 阻尼失效、刹车"前窜"、**摔车风险**
8. **前叉调整左右不对称** —— 车跑偏

**后避震类**：
9. **后避震漏油不修** —— 车身姿态不稳
10. **双人骑不调预载** —— 避震触底，损坏
11. **后避震调节器生锈不处理** —— 无法调整

**车轮类**：
12. **车轮轴承坏不修** —— 高速时车轮可能抱死
13. **辐条松动不调整** —— 车轮变形、轮胎磨损不均

【经验】 **老师傅经验**：**行走系统**第一公敌是**胎压**。**胎压**决定**一切**——抓地、磨损、操控、油耗、安全。**骑前 1 分钟查胎压 = 安全保证**。

### 11.7.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 胎压冷胎测**：骑了 1 km 内测，热胎 +0.2-0.3 bar
2. **【维修】 鼓包立即换**：补胎救不了
3. **【维修】 轮胎超 5 年换**：即使胎纹好，橡胶也老化
4. **【维修】 前叉漏油立即修**：漏油 = 阻尼失效 = 摔车风险
5. **【维修】 前叉调整左右对称**：差 1 圈 = 跑偏
6. **【维修】 后避震预载按体重调**：体重 + 装备 + 载重都要算
7. **【维修】 轴承旷量立即换**：旷量 = 轴承坏
8. **【维修】 辐条轮定期紧辐条**：松动的辐条会越松越多

### 11.7.3 时间预估的真相 ★★

| 项目 | 老手实际 | 新手实际 |
|------|---------|---------|
| 检查胎压 | 1-2 分钟 | 2-3 分钟 |
| 检查轮胎 | 5-10 分钟 | 10-20 分钟 |
| 换轮胎 | 30-60 分钟 | 1-3 小时 |
| 换前叉油封 | 1-2 小时 | 3-5 小时 |
| 换后避震 | 30 分钟 | 1-2 小时 |
| 调前叉预载 | 5-10 分钟 | 10-20 分钟 |
| 换车轮轴承 | 30-60 分钟 | 1-3 小时 |

【经验】 **老师傅经验**：轮胎拆装、胎唇就位、气门嘴和动平衡都直接影响安全。第一次不要独自换胎，至少让专业店或有经验的人现场指导；高速车、真空胎、辐条轮和带胎压传感器的车更建议专业店处理。

### 11.7.4 哪些钱不能省 ★★

**工具**：
- 胎压表：30-100 元（**不要用气站免费胎压表**，不准）
- 轮胎撬棍：50-150 元（**不要买塑料的**，会断）
- 平衡块：30-100 元
- 辐条扳手（如辐条轮）：50-150 元
- 轴承拉拔器（如换轴承）：100-300 元

**零件**：
- 轮胎：买正品（米其林、倍耐力、普利司通、邓禄普、IRC）—— **不要买"通用"杂牌**
- 油封：买正品
- 轴承：买正品（SKF、NTN、NSK）

**送修的智慧**：
- 轮胎平衡 → **送修**（需要平衡机）
- 辐条调整 → **建议送修**
- 避震维修 → **送修**
- 轮辋修复 → **送修**

【费用】 **省钱贴士**：**行走系统车主能省钱的部分**：
- 查胎压、调胎压：省 0 元（本来就免费）
- 换轮胎：省 100-400 元
- 调避震预载：省 0 元
- 清洁保养：省 50-150 元

**一年总计省 150-550 元**。**但换来的是安全**——**轮胎好的车骑行信心完全不同**。

### 11.7.5 容易漏的小细节 ★★

- 【维修】 **气门嘴帽**：丢了会让气门嘴漏气（**几毛钱的事别省**）
- 【维修】 **轮胎 DOT 编码**：在胎侧
- 【维修】 **前叉油粘度**：不同温度地区不同（**说明书**）
- 【维修】 **后避震调节器**：有些车要专用工具（**很多车友不知道**）
- 【维修】 **车轮轴承润滑**：换轴承时涂润滑脂

【经验】 **老师傅经验**：**气门嘴帽**几毛钱，但丢了会让气门嘴漏气。**一年漏 0.1 bar** 看似不多，**但累积起来会让你频繁打气**。**每次打完气**顺手拧上气门嘴帽。

### 11.7.6 骑前必查清单 ★★★

```
[ ] 胎压（前/后，冷胎）
[ ] 轮胎外观（无鼓包、裂纹、扎钉）
[ ] 轮胎磨损（胎纹深度）
[ ] 前叉无漏油
[ ] 后避震无漏油
[ ] 车轮轴承无异响
[ ] 链条松紧（按 10.2.4）
```

【经验】 **老师傅经验**：**骑前 5 分钟**做这套检查 = **减少 90% 的故障**。**老司机都有这习惯**——**看一眼、摸一下、转一下**，比什么都管用。

### 11.7.7 进阶学习路径 ★★

学完本章后想进阶，按这个顺序学：

1. **【入门】** 查胎压、检查轮胎、调避震预载
2. **【基础】** 换轮胎、换气门嘴、补胎（应急）
3. **【进阶】** 换前叉油封、换后避震
4. **【高级】** 调前叉阻尼、换轮辋
5. **【专业】** 倒立叉维护、避震翻新

【经验】 **老师傅经验**：**行走系统**的核心是**轮胎 + 胎压**。**轮胎保养得当延寿 1-2 万 km**。**胎压正确**操控好、油耗低、磨损均匀。**从胎压开始，认真做**。

### 11.7.9 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的真实案例**——给新手看"别人怎么翻车的"。

### 案例 A：宝马 R1200GS 前叉漏油

**症状**：前叉管上有油迹
**踩坑过程**：以为是前叉坏了
**可能原因**：**前叉油封老化**——**正常磨损**
**处理建议**：换前叉油封（**专业店**）
**教训**：**前叉漏油** = **先换油封** = **别大修**

### 案例 B：本田 CB500F 轮胎偏磨

**症状**：前胎中间比两侧磨得多
**踩坑过程**：以为是轮胎质量
**可能原因**：**胎压过高**——**中央磨损**
**处理建议**：**按说明书胎压**
**教训**：**偏磨** = **先查胎压** = **简单**

### 案例 C：雅马哈 MT-07 轮胎裂纹

**症状**：胎侧有裂纹
**踩坑过程**：以为是老化
**可能原因**：**阳光/热老化**——**正常**
**处理建议**：**换胎**——**不能用**
**教训**：**裂纹 = 必换** = **别省**

### 案例 D：哈雷 Sportster 前叉弹簧响

**症状**：压前叉有咯吱声
**踩坑过程**：以为是前叉坏
**可能原因**：**弹簧底垫磨损**
**处理建议**：换底垫
**教训**：**前叉响** = **先看底垫** = **便宜**

### 案例 E：川崎 Ninja 400 胎压监测失灵

**症状**：TPMS 灯亮
**踩坑过程**：以为是传感器坏
**可能原因**：**胎压真的低**
**处理建议**：**补胎压**
**教训**：**TPMS 亮** = **先看胎压**

### 案例 F：杜卡迪 Monster 后轮轴承坏

**症状**：后轮有异响
**踩坑过程**：以为是后轮辋变形
**可能原因**：**后轮轴承磨损**
**处理建议**：**送修**——**换轴承**
**教训**：**后轮异响** = **送修**

### 案例 G：凯旋 Tiger 900 前轮辋凹陷

**症状**：骑过坑后轮辋凹
**踩坑过程**：以为是轮辋质量问题
**可能原因**：轮辋受冲击变形，可能伴随裂纹、失圆或慢漏气
**处理建议**：停止高速骑行，送专业店检查跳动、裂纹和气密性；是否能修复或必须更换，由检测结果决定
**教训**：轮辋凹陷不是“正常现象”，结构件不能只看外观判断

### 案例 H：本田 Africa Twin 越野后轮胎夹石子

**症状**：越野完胎面有石子
**踩坑过程**：正常现象
**可能原因**：**石子夹在花纹里**
**处理建议**：**清石子**
**教训**：**越野后清石子** = **必备**

### 案例 I：铃木 SV650 平衡块掉了

**症状**：骑到一半轮辋上啪响
**踩坑过程**：平衡块掉
**可能原因**：**粘合剂老化**
**处理建议**：**贴新平衡块**
**教训**：**平衡块掉** = **贴新的** = **10 元**

### 案例 J：本田 NC750X 前叉油量不够

**症状**：前叉下沉
**踩坑过程**：以为是前叉坏
**可能原因**：前叉油老化、油量不对、油封泄漏或内部磨损
**处理建议**：检查是否漏油和左右油量；按手册拆检、定量更换前叉油，不能只凭手感随意补油
**教训**：**前叉下沉** = **补油** = **简单**

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **不查胎压** = **轮胎磨损快** = **几百元**
2. **不查花纹深度** = **湿滑失控** = **危险**
3. **不查前叉油封** = **漏油严重 = 换前叉** = **千元**
4. **越野不清石子** = **爆胎**
5. **不查车轮轴承** = **高速甩尾** = **危险**

【经验】 **老师傅总结**：行走系统 = 轮胎 + 胎压 + 前叉 + 后避震 + 车轮。胎压和轮胎状态可以自己勤查；换胎、轮辋变形、前叉漏油和轴承松旷要按手册或送专业店处理。
