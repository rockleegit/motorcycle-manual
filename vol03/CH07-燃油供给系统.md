### 7.0.5 【严重警告】 总警告：油路作业安全

油路作业**最容易出事**——汽油易燃易爆。

**绝对不能做的事**：
- ✗ 在明火、热源附近工作
- ✗ 抽烟（包括电子烟）
- ✗ 用手泵式喷嘴对着人喷
- ✗ 油管接错（**回油管和进油管不能接反**）
- ✗ 漏油不处理就启动

**应该做的事**：
- ✓ 通风良好的环境工作
- ✓ 准备好灭火器
- ✓ 准备吸油棉/沙土（应急）
- ✓ 电瓶负极断开（防误点火）
- ✓ 燃油进眼/皮肤立即清水冲洗

【经验】 **老师傅经验**：**化油器清洗剂比汽油好用一万倍**——不伤手、不易燃、不伤橡胶件。**汽油清洗化油器是上世纪的做法**，现在只有最老的车主才这么干。

## 7.1 燃油系统总览

### 7.1.1 燃油系统干什么的

发动机需要**油气混合物**才能燃烧。燃油系统的任务就是把油箱里的汽油**按精确比例**和空气混合，按精确时刻喷进气缸。

**核心功能**：
- 储存燃油
- 输送燃油
- 过滤燃油
- 控制喷油量（混合气浓度）
- 控制喷油时间（喷油时刻）

**形象比喻**：
```
燃油系统就像人的血液循环：
- 油箱 = 血库（储存燃油）
- 油泵 = 心脏（真正的泵，推动燃油流动）
- 油管 = 血管（输送燃油）
- 喷油嘴 = 喷壶（雾化喷射）
- 滤芯 = 过滤器（滤除杂质）
```

### 7.1.2 燃油系统类型

| 类型 | 大致年代 | 应用 | 特点 |
|------|--------|------|------|
| 化油器 | 1980s 以前 | 老车、复古车 | 机械控制，简单可靠 |
| 电喷（EFI/PGM-FI/Motec 等） | 1990s 以后 | **现代主流** | ECU 控制，精确高效 |
| 直接喷射 | 2000s 以后 | 高端运动车 | 喷油嘴在气缸内，效率最高 |

【来源】 **数据来源等级**：★（年代范围 AI 训练数据）。

【问答】 **新手问答**：化油器车和电喷车维护上有什么不同？

答：
- **化油器**：机械调整，靠经验；自己可以清洗、调整、修复
- **电喷**：电子控制，需要诊断仪；自己能做的有限（换滤芯、查油压）
- **直喷**：技术含量高，**车主基本只能做基础保养**

【经验】 **老师傅经验**：**化油器不是"老古董"**。它可靠、可修、能调出最佳空燃比。很多玩复古车的车友**反而不喜欢电喷**——电喷一坏就一整套，换一套化油器才几百元。**修得了化油器的人，技术不会差**。

### 7.1.3 油路基本走向（所有燃油系统通用）

```
[油箱]
   ↓（重力 + 油泵吸力）
[燃油滤芯]
   ↓
[燃油泵]
   ↓ 加压到 2.5-4.0 bar（电喷）或送到化油器（化油器车）
[燃油压力调节器]（电喷）
   ↓ 多余的油从这里回到油箱
[喷油嘴 / 化油器]
   ↓ 喷入进气道/气缸
[燃烧室]
```

**化油器车**：
```
[油箱] → [燃油开关] → [化油器]（这里混合空气和油） → [气缸]
```

**电喷车**：
```
[油箱] → [燃油泵] → [燃油滤芯] → [油轨] → [喷油嘴]（ECU 控制喷油时刻） → [进气道/气缸]
                                                                    ↑
                                                              [进气压力传感器反馈给 ECU]
```

### 7.1.4 空燃比（基础物理）

空燃比 = 空气质量 / 燃油质量

| 空燃比 | 含义 | 燃烧状态 |
|--------|------|---------|
| 14.7:1 | 理论空燃比 | 完全燃烧（理论） |
| 12-13:1 | 浓混合气 | 功率大、费油 |
| 15-16:1 | 稀混合气 | 省油、动力小 |
| < 11:1 | 过浓 | 冒黑烟、积碳 |
| > 18:1 | 过稀 | 熄火、过热 |

【经验】 **老师傅经验**：**理论空燃比 14.7:1 不是最佳动力比**。要最大功率，要 12-13:1；要最省油，要 16:1 左右。**ECU 的任务就是在动力、油耗、排放之间找平衡**。

## 7.2 化油器（机械时代经典）

### 7.2.1 化油器是什么

化油器是一个**利用空气流动产生低压、把燃油吸出来和空气混合**的机械装置。

**核心原理**（文丘里效应）：
```
[气流通过狭窄处] → [流速加快] → [压力降低] → [吸出燃油] → [与空气混合]
```

### 7.2.2 化油器结构（CV 化油器 / 真空膜片式，现代主流）

```
[进气管] ← 来自空滤
    ↓
[节气门]（油门控制开度）
    ↓
[化油器主体]
    ├── [浮子室]（储存燃油，浮子控制油位）
    ├── [主喷嘴 + 主油针]（中高速供油）
    ├── [怠速油嘴 + 怠速空气调整螺丝]（怠速供油）
    ├── [过渡喷嘴]（过渡工况）
    └── [启动加浓阀]（冷启动）
    ↓
[气缸]
```

### 7.2.3 浮子室

**作用**：储存适量燃油，靠浮子自动控制油位。

**结构**：
- 浮子（塑料或黄铜）
- 浮子针阀（油位高时关闭进油）
- 浮子室盖

【经验】 **老师傅经验**：**浮子室有溢流管**——如果针阀关不严，油从这里流到地上，**不会**进到气缸里。**这是化油器的安全设计**。**但溢流管**漏油**也说明针阀坏了**。

### 7.2.4 主供油系统

**主喷嘴 + 主油针**：负责中高速供油。

**主油针**通常是**锥形或楔形**，有几个位置可以卡（一般 3-5 档）：
- **油针往下卡**（降一档）：混合气变浓（油针尖端离开喷孔更近，喷油多）
- **油针往上提**（升一档）：混合气变稀

【问答】 **新手问答**：怎么调化油器浓稀？

答：调主油针的位置。**降一档浓，升一档稀**。一般先按说明书装中间档，试车再细调。

### 7.2.5 怠速系统

**怠速油嘴 + 怠速空气调整螺丝**：
- **怠速空气螺丝**：调混合气浓稀。顺时针拧 = 混合气变浓。
- **怠速转速螺丝**：调怠速转速。顺时针拧 = 转速升高。

【注意】 **常见误解**：怠速空气螺丝顺时针是浓。

错（对大部分化油器而言）：
- **怠速空气螺丝（mixture screw）** 顺时针拧 = 混合气变稀（因为空气通道变窄，进气减少）
- 但有些化油器反过来（早期日系车）
- **唯一可靠的方法**：看说明书

### 7.2.6 启动加浓系统

**冷启动时**发动机需要**更浓的混合气**：
- **手拉风门**：拉风门拉杆 → 节气门微开，进气减少 → 混合气变浓
- **自动风门**：热膨胀蜡式元件自动控制

【经验】 **老师傅经验**：**冬天启动前拉风门，热车启动不用拉**。**热车拉风门**会造成混合气过浓、启动困难、淹火花塞。

### 7.2.7 化油器调整（动手技能）

**调整顺序（必须按顺序来）**：

1. **调怠速转速**（怠速螺丝调到厂家规定值，一般 1200-1500 rpm）
2. **调怠速混合气**（怠速空气螺丝调到发动机转速最高点，然后来回找最高点）
3. **再调怠速转速**（混合气变浓后转速会变化，再调回规定值）
4. **重复 2-3** 几次，找到平衡点

**主油针调整**：
- 中速/高速试车
- 加速无力、动力断档 → 油针降一档（加浓）
- 油耗高、火花塞黑 → 油针升一档（变稀）

【送修】 **该送修了**：
- 化油器膜片破损（要拆开换膜片）
- 浮子破损进油（要换浮子）
- 喷油孔堵死无法清洗（要拆开所有油道）

【费用】 **省钱贴士**：化油器清洗剂 + 自己动手，50-100 元搞定。送修 200-500 元。**学一手化油器，老车省心一辈子**。

## 7.3 电喷系统（现代主流）

### 7.3.1 电喷是什么

电喷（Electronic Fuel Injection, EFI）是用**电子控制单元（ECU）**控制喷油嘴喷油的系统。

**核心组件**：
- ECU（行车电脑）
- 燃油泵（在油箱内）
- 燃油压力调节器
- 喷油嘴（一般 1 个/缸）
- 各种传感器（进气压力、空气温度、冷却液温度、曲轴位置、氧传感器等）

### 7.3.2 电喷工作流程

```
[驾驶员拧油门] → [节气门位置传感器（TPS）发出信号]
                ↓
[ECU 接收] + [其他传感器：进气压力、空气温度、冷却液温度、曲轴位置、氧传感器...]
                ↓
[ECU 计算] 需要的喷油量 = 进气量 × 目标空燃比的倒数 × 各种修正系数
                ↓
[ECU 发出指令] 给喷油嘴（精确到毫秒）
                ↓
[喷油嘴喷油] → 进气管 / 气缸
                ↓
[氧传感器反馈] 实际空燃比 → ECU 修正
```

【经验】 **老师傅经验**：**电喷的核心是反馈控制**——氧传感器监测尾气氧含量，ECU 根据这个反馈调喷油量。**氧传感器坏了，油耗立刻飙升**。这就是为什么电喷车要定期检查氧传感器。

### 7.3.3 燃油压力（核心参数）★★★

**电喷车的燃油压力是关键参数**。压力不对，所有问题都来。

| 车型 | 燃油压力（一般范围）★ |
|------|---------------------|
| 普通电喷街车 | 2.5-3.5 bar |
| 高性能电喷 | 3.0-4.0 bar |
| 直喷 | 100-200 bar（高压！非常危险） |

【来源】 **数据来源等级**：★（**用前查说明书**，不同车型天差地别）。

【严重警告】 **严重警告**：**直喷系统压力可达 200 bar**——相当于普通家用自来水的 200 倍。**千万不要自己拆直喷系统的油管**，需要专用工具和极高安全意识。

### 7.3.4 燃油泵

**位置**：现代电喷车的燃油泵**集成在油箱内**。

**工作原理**：
- 通电后电机转动 → 涡轮泵叶轮高速旋转 → 油被加压送出
- 油压调节器维持稳定压力
- 多余的油回到油箱（回油管）

**故障表现**：
- 启动困难（油泵压力不够）
- 高速断油（油泵流量不足）
- 完全不着车（油泵坏）

**检查方法**：
```
1. 打开电门（不启动发动机）
2. 听油箱方向，应该有 2-3 秒的"嗡"声（油泵预压）
3. 没声音 = 油泵不工作
4. 看是否漏保险丝
```

【送修】 **该送修了**：油泵坏了一般要送修（需要拆油箱、专用工具）。

### 7.3.5 燃油滤芯（核心技能）★★★

**这是车主最常换的油路件**。

**位置**：
- 大部分车：油箱外部（油管中间）
- 部分车：油箱内部（不可换，除非拆油箱）

**更换周期**：
- 一般 10000-20000 km
- 高压直喷：可能 30000-50000 km

**更换步骤**：
```
1. 冷车
2. 拔电瓶负极（防误启动）
3. 准备好容器（接漏油）
4. 用化油器清洗剂喷一下接口周围（除尘）
5. 用燃油管快接工具（或专用扳手）拆滤芯
6. 取下旧滤芯，注意进出油方向
7. 装新滤芯（方向和原来一致，一般有箭头）
8. 接回油管（听到咔哒声）
9. 装回电瓶负极
10. 打开电门（不启动）2-3 秒让油泵预压
11. 检查是否漏油
12. 启动测试
```

【注意】 **重要细节**：
- **燃油滤芯有方向**！箭头指向油流方向（从油箱到发动机）
- **装反**会导致油路堵塞、动力下降
- 部分车型滤芯上有"IN/OUT"或"←"标记

【经验】 **老师傅经验**：**换滤芯前**用化油器清洗剂把周围喷一下——这样拆的时候沙土不会掉进油管。**这一下能避免 80% 的"换完滤芯油路堵了"的事故**。

【费用】 **省钱贴士**：自己换燃油滤芯 50-150 元搞定；4S 店 200-500 元。**油路件自己换能省一半**。

### 7.3.6 喷油嘴

**喷油嘴的作用**：ECU 控制喷油嘴电磁阀开闭，精确喷油。

**故障**：
- 堵塞：单缸不工作、抖动
- 漏油：油耗高、冒黑烟
- 线圈坏：喷油嘴不工作

**检查**（需要基础设备）：
```
1. 启动发动机，让每缸失火（拔喷油嘴插头）
2. 听声音变化（转速变化）
3. 没有变化 = 那缸喷油嘴不工作
```

**清洗喷油嘴**：
- **免拆清洗**：加清洗剂到油箱里（适合轻微堵塞）
- **拆下清洗**：用喷油嘴清洗机或超声波清洗（中等堵塞）
- **更换**：严重堵塞或线圈坏（送修）

【送修】 **该送修了**：
- 喷油嘴拆洗（需要专用清洗设备）
- 喷油嘴漏油（要换密封圈或总成）

### 7.3.7 节气门体

**节气门** = 控制进气量 = 控制发动机转速（驾驶员通过油门控制）。

**电喷车的节气门**有两种：
- **机械式（拉线）**：传统车
- **电子式（线控）**：现代车（"电控油门"）

**节气门脏了**：
- 怠速不稳
- 油门响应迟钝
- 偶尔熄火

**清洗节气门**（基础技能）：
```
1. 拆下进气管
2. 露出节气门
3. 用节气门清洗剂喷在抹布上
4. 手动开闭节气门，擦洗积碳
5. 用清洗剂喷到节气门边缘
6. 装回
7. **重要**：清洗后要重置 ECU（具体看车型）
   - 部分车：拔电瓶负极 10 分钟
   - 部分车：需要诊断仪重置
   - 部分车：开钥匙不启动，等几秒
```

【严重警告】 **严重警告**：**电子节气门清洗后一定要重置**！不重置会导致怠速异常、加速异常、油耗飙升。

【经验】 **老师傅经验**：**节气门每 2-3 万 km 清洗一次**。**但也别洗太勤**——频繁清洗会导致节气门翻板磨损、节气门位置传感器不准。**修车不是越勤越好**。

### 7.3.8 燃油压力调节器

**作用**：维持稳定的燃油压力，多余的油通过回油管回到油箱。

**故障**：
- 压力过高：喷油多、冒黑烟
- 压力过低：动力不足、熄火
- 漏油：油耗高

【送修】 **该送修了**：燃油压力调节器一般要送修（涉及压力测试）。

## 7.4 化油器清洗（动手技能）★★★

### 7.4.1 什么时候需要清洗化油器

- 长时间没用的车（1 个月以上）
- 怠速不稳
- 油门响应迟钝
- 启动困难（特别是冷车）
- 油耗上升

【经验】 **老师傅经验**：**化油器清洗剂不要随便往油箱里倒**。市面上有些"燃油宝"号称清洗化油器，实际上**对橡胶膜片有腐蚀**。**老老实实用化油器清洗剂喷洗**。

### 7.4.2 不拆化油器清洗（基础）

**适合**：化油器轻微脏、怠速不稳、加速迟钝。

**步骤**：
```
1. 启动发动机，让它热
2. 拆下空滤
3. 怠速运转
4. 用化油器清洗剂喷管（伸到化油器节气门下方）
5. 短促喷 2-3 秒
6. 看发动机转速变化（先升后降）
7. 等转速恢复
8. 再喷一次
9. 反复 3-5 次
10. 装回空滤
11. 试车
```

【注意】 **注意**：喷的时候发动机可能熄火，这是正常的——瞬间缺氧。**过几秒再启动**。

### 7.4.3 拆下化油器清洗（深度）

**适合**：长时间不用、油箱有杂质进油路、怠速空气螺丝完全失效。

**步骤**：
```
1. 拔电瓶负极
2. 关闭燃油开关（或拔油管）
3. 拆空滤
4. 拆进气管（标记位置）
5. 拆油门线（标记位置）
6. 拆化油器固定螺丝
7. 取下化油器
8. 拆浮子室盖（4 个螺丝）
9. 取出浮子、针阀
10. 拆主喷嘴、主油针（小心弹簧飞了）
11. 拆怠速油嘴
12. 用化油器清洗剂浸泡所有零件
13. 用化油器清洗剂 + 细针通所有油道
14. 吹干（压缩空气最好）
15. 装回（按反顺序）
16. 装回车上
17. 接回油管
18. 启动调试
```

【严重警告】 **严重警告**：
- **浮子室里有汽油**，拆的时候准备好容器接
- **所有零件**洗干净后**不要用抹布擦**（纤维会堵油道）
- **喷油孔**用专用针通，不要用铁丝（会扩孔）

【经验】 **老师傅经验**：**化油器拆开后拍 5 张照片**——每个角度一张。**装回去的时候看照片**，新手能省一半时间。**老师傅都是这么做笔记的**。

### 7.4.4 化油器常见故障表

| 故障 | 症状 | 处理 |
|------|------|------|
| 浮子针阀漏油 | 溢流管漏油、油耗高 | 换针阀或化油器总成 |
| 浮子破损 | 油面过高、漏油 | 换浮子 |
| 主油针磨损 | 油耗高、混合气浓 | 换油针 |
| 怠速油嘴堵 | 怠速不稳、熄火 | 拆下清洗 |
| 启动加浓阀坏 | 冷启动困难 | 换加浓阀 |
| 膜片破损 | 油门响应慢、过渡不良 | 换膜片 |
| 节气门轴磨损 | 进气管漏气、混合气稀 | 换化油器总成 |

【送修】 **该送修了**：
- 化油器磨损严重（要换总成）
- 内部油道无法清洗
- 启动加浓阀失效

## 7.5 燃油管路维护

### 7.5.1 油管类型

- **橡胶油管**（大部分车）：3-5 万 km 老化
- **金属油管**（部分性能车）：寿命长，但难修

### 7.5.2 油管老化检查

**检查项目**：
```
1. 油管表面龟裂（肉眼可见的裂纹）
2. 油管变硬（按下去没有弹性）
3. 油管接头处漏油痕迹
4. 油管卡箍松动
```

【严重警告】 **严重警告**：**油管老化必须换**。**漏油 = 火灾隐患**。**别等到骑半路漏油了再换**。

【经验】 **老师傅经验**：**油管"漏一点点"就是该换了**。油管压力不高，但汽油易燃。**一次漏油事故的代价 = 100 根油管**。

### 7.5.3 油管更换

**步骤**：
```
1. 准备同规格油管（耐油橡胶）
2. 准备合适卡箍
3. 拔电瓶负极
4. 关闭燃油开关
5. 准备好容器（接油）
6. 拆旧油管（先远端，再近端）
7. 装新油管（先近端，再远端）
8. 卡箍固定
9. 检查不漏油
10. 启动测试
```

### 7.5.4 油管接头

**两种类型**：
- **卡箍式**（老车）：用螺丝卡箍
- **快接式**（新车）：按一下卡子拔出

【经验】 **老师傅经验**：**快接式接头**拆的时候**先看清楚结构再动手**。**有些要按两侧，有些要按中间**。**拔坏了要换整个油管总成**。

## 7.6 油箱维护

### 7.6.1 油箱结构

- 油箱本体
- 油箱盖（带压力阀）
- 燃油开关（化油器车）/ 油泵总成（电喷车）
- 油浮子（油表传感器）

### 7.6.2 油浮子检查

**油浮子坏的症状**：油表不准。

**检查**（需要拆油箱盖）：
```
1. 拆座椅和油箱盖
2. 拔下油浮子插头
3. 万用表测油浮子电阻（移动浮子看电阻变化）
4. 标准：满油时电阻小，空油时电阻大
5. 电阻不变 = 浮子坏
```

【送修】 **该送修了**：油浮子要换一般要拆油箱。

### 7.6.3 油箱清洁

**什么时候清洗**：
- 长期存放后重新使用
- 油箱里有水（车翻过、进过水）
- 油箱有锈（老车）

**清洗步骤**：
```
1. 拆下油箱（放空汽油）
2. 倒出残油（合规处理）
3. 加入少量化油器清洗剂
4. 摇晃油箱（每个方向都摇到）
5. 倒出清洗剂
6. 用清水冲洗 2-3 次
7. 彻底晾干（或吹干）
8. 检查油箱内部（有锈要处理）
```

【经验】 **老师傅经验**：**油箱有锈**用碎核桃壳 + 化油器清洗剂摇晃清洗——核桃壳硬度适中，不会刮伤油箱。**核桃壳用过的核桃仁别浪费，可以做菜**。

## 7.7 燃油系统故障诊断

### 7.7.1 燃油压力测试 ★★★

**核心技能**——能测燃油压力，几乎能诊断一半的油路故障。

**工具**：燃油压力表（几十到几百元）。

**步骤（电喷车）**：
```
1. 找到测试口（一般在油轨上）
2. 拆下测试口保护帽
3. 接上压力表
4. 打开电门（不启动发动机）—— 读预压值
5. 启动发动机 —— 读怠速压力
6. 油门拉到 3000 rpm —— 读高负荷压力
7. 关闭发动机 —— 读保持压力（30 秒内不应下降太快）
8. 取下压力表
9. 装回保护帽
```

**判断**（电喷车一般标准）：

| 状态 | 压力 |
|------|------|
| 预压 | 2.5-4.0 bar |
| 怠速 | 2.5-3.5 bar |
| 高负荷 | 3.0-4.0 bar |
| 保持（30 秒后） | 不应下降超过 0.5 bar |

【来源】 **数据来源等级**：★（**用前查说明书**，具体车型不同）。

【经验】 **老师傅经验**：**保持压力是关键**——发动机熄火后压力下降太快，说明喷油嘴漏油或燃油压力调节器漏油。**两个故障部位不一样**，诊断思路也不同。

### 7.7.2 喷油嘴测试（不拆下）

**方法 1：听声音**
```
1. 启动发动机怠速
2. 用长螺丝刀（或听诊器）听每个喷油嘴
3. 应该有"咔哒咔哒"的快速开闭声
4. 没有声音 = 那缸喷油嘴不工作
```

**方法 2：拔插头对比**
```
1. 启动发动机怠速
2. 依次拔每个喷油嘴插头
3. 拔掉后转速应该明显变化
4. 没有变化 = 那缸不工作（喷油嘴坏或电路问题）
```

### 7.7.3 油泵测试

**方法 1：听声音**
```
1. 打开电门（不启动）
2. 听油箱方向 2-3 秒
3. 应该听到"嗡"声（油泵预压）
4. 没有声音 = 油泵不工作
```

**方法 2：测电流**
```
1. 万用表电流档串联到油泵电路
2. 启动发动机
3. 读电流值（一般 3-7 A）
4. 电流过大 = 油泵卡死
5. 电流过小 = 油泵弱或电路问题
```

### 7.7.4 油路堵塞诊断

**症状**：启动困难、加速无力、怠速不稳。

**检查步骤**：
```
1. 拔火花塞看（湿油 = 油太多，干油 = 油太少）
2. 测燃油压力（压力低 = 油路堵）
3. 拆下油管，看油是否流畅流出
4. 拆下燃油滤芯，看是否堵
5. 拆下化油器，检查滤网
```

### 7.7.5 油路进气诊断

**症状**：发动机抖动、加速无力、熄火后难以启动。

**原因**：油管接口漏气（不是漏油，是进气）。

**检查**：
```
1. 启动发动机
2. 用化油器清洗剂喷每个油管接口
3. 如果转速有变化 = 那个接口漏气
```

【经验】 **老师傅经验**：**漏油看得见，漏气看不见**。**漏气是油路最难诊断的故障**——因为油管压力低，漏气不容易看到油渍。**化油器清洗剂喷到接口**，转速变化的地方就是漏气点。**这一招能解决 80% 的"换完滤芯车变差"问题**。

## 7.8 常见油路故障案例

### 7.8.1 案例 1：发动机启动困难 ★★★

**症状**：钥匙转到 START 位，发动机转但不启动。

**诊断流程**：
```
1. 闻尾气（有没有汽油味）
   - 有汽油味 = 有油，但不点
   - 没汽油味 = 没油到

2. 没汽油味：
   a. 油箱空了？
   b. 燃油开关关闭？
   c. 燃油滤芯堵？
   d. 油泵坏？
   e. 油管漏气？

3. 有汽油味但不启动：
   a. 火花塞坏？
   b. 点火线圈坏？
   c. ECU 故障？
```

【维修】 **维修场景**：发动机不启动
```
步骤 1：打开电门听油泵（2-3 秒的嗡声）
步骤 2：检查油量、油开关
步骤 3：拆火花塞看是否湿油
步骤 4：测火花塞跳火
步骤 5：测燃油压力
步骤 6：用诊断仪读故障码
```

### 7.8.2 案例 2：怠速不稳 ★★

**症状**：怠速忽高忽低，发动机颤抖。

**原因**（从常见到不常见）：
1. 化油器混合气失调（化油器车）
2. 节气门脏（电喷车）
3. 单缸不工作（喷油嘴、火花塞、点火线圈）
4. 进气漏气
5. 燃油压力不稳

**处理**：
- 化油器：调怠速空气螺丝 + 怠速转速螺丝
- 电喷：清洗节气门 + 重置 ECU
- 单缸问题：见第 6 章火花塞诊断

### 7.8.3 案例 3：油耗飙升 ★★

**诊断**：
```
1. 看火花塞颜色（黑 = 混合气浓）
2. 测燃油压力（高 = 油压调节器坏）
3. 看是否有漏油痕迹
4. 检查氧传感器（用诊断仪）
5. 检查进气压力传感器
```

**处理**：
- 火花塞黑：清洗喷油嘴、检查油压
- 油压高：换油压调节器
- 漏油：换油管或油封
- 氧传感器坏：换氧传感器

【经验】 **老师傅经验**：**油耗飙升第一查氧传感器**。**氧传感器寿命约 10 万 km**，到时间油耗会慢慢涨。**很多人以为油耗高是油品问题，其实是氧传感器老化**。**换氧传感器 200-500 元，工时 50-100 元**，比加满油箱便宜多了。

### 7.8.4 案例 4：加速无力 ★★

**诊断**：
```
1. 检查油门自由行程（拉线式）
2. 测燃油压力
3. 拆火花塞看颜色
4. 测缸压（见第 6 章）
5. 检查进气压力传感器
```

**处理**：
- 油门自由行程大：调油门线
- 油压低：换油泵或滤芯
- 火花塞黑：见油耗飙升处理
- 缸压低：见第 6 章

### 7.8.5 案例 5：冒黑烟 ★★

**原因**：混合气过浓。

**检查**：
```
1. 空滤是否堵塞
2. 燃油压力是否过高
3. 喷油嘴是否漏
4. 油压调节器是否坏
5. 氧传感器是否坏（电喷车）
```

【经验】 **老师傅经验**：**冒黑烟先看空滤**——这是最便宜的检查项。**空滤 50 元，火花塞几十元**，**别一冒黑烟就跑去 4S 店**。

### 7.8.6 案例 6：发动机抖动 ★★★

**症状**：怠速或行驶中发动机明显颤抖。

**诊断步骤（按从常见到不常见）**：
```
1. 检查火花塞（单缸不工作最常见）
2. 检查喷油嘴（同上）
3. 检查点火线圈（单缸不点火）
4. 检查进气漏气（混合气稀）
5. 检查缸压（见第 6 章）
6. 检查油压（油压波动）
```

【经验】 **老师傅经验**：**单缸不工作是发动机抖动最常见原因**。**找到哪一缸不工作是关键**——四缸车可以**依次拔火花塞插头**，拔到哪个转速变化最大，那个就是问题缸。

## 7.9 油路系统实战

### 7.9.1 实战 1：清洗化油器（不拆）

（见 7.4.2，5-10 分钟）

### 7.9.2 实战 2：更换燃油滤芯

（见 7.3.5，30-60 分钟）

### 7.9.3 实战 3：测燃油压力 ★★★

（见 7.7.1，30-60 分钟）

**实测步骤**：
```
1. 准备燃油压力表
2. 找到测试口（油轨上）
3. 拆下保护帽
4. 接上压力表（要密封好）
5. 打开电门 → 读预压
6. 启动发动机 → 读怠速压力
7. 油门拉 3000 rpm → 读高负荷压力
8. 关闭发动机 → 30 秒后读保持压力
9. 拆下压力表
10. 装回保护帽
11. 比对标准值
```

【问答】 **维修场景**：测完压力后判断
```
压力过低：
  → 燃油滤芯堵
  → 油泵弱
  → 油管漏气（油泵吸空气）

压力过高：
  → 油压调节器坏

保持压力下降快：
  → 喷油嘴漏油
  → 油压调节器漏油

预压为 0：
  → 油泵不工作
  → 油路严重堵塞
```

### 7.9.4 实战 4：清洗节气门（电喷车）

**步骤**：
```
1. 拆下空滤和进气管
2. 露出节气门
3. 怠速运转发动机（有人帮忙）
4. 另一人用化油器清洗剂喷节气门翻板
5. 看积碳被冲掉（变干净）
6. 关闭发动机
7. 等 5 分钟（让清洗剂挥发）
8. 启动发动机
9. 怠速可能会高（正常）
10. **重置 ECU**（按车型不同）
11. 试车
```

【严重警告】 **重置 ECU**（这是关键）：
- **本田/雅马哈部分车**：关钥匙，拔电瓶负极 10 分钟，装回
- **宝马/杜卡迪等**：需要诊断仪
- **部分国产车**：开钥匙不启动，等 5 分钟

【经验】 **老师傅经验**：**节气门清洗完一定要试车 30 km 以上**——ECU 在重新学习驾驶习惯。**这期间可能会有怠速不稳、油耗偏高**，都是正常的。**别清洗完节气门就跑 4S 店说没修好**。

### 7.9.5 实战 5：诊断单缸不工作

**步骤**：
```
1. 启动发动机怠速
2. 依次拔火花塞插头
3. 每拔一个，转速应该有明显变化
4. 没有变化的缸 = 不工作
5. 检查那个缸：
   a. 火花塞（拆下看、换新测试）
   b. 点火线圈（换其他缸的试试）
   c. 喷油嘴（拔插头听声音）
   d. 缸压（见第 6 章）
```

## 7.10 【经验】 老师傅经验沉淀（应写尽写）

**这是本章独有的"老师傅不外传"经验块**。

### 7.10.1 新手必踩的 12 个油路坑 ★★★

**加油类**：
1. **加错油**（加柴油、加劣质汽油）—— 化油器堵、油泵坏
2. **空油箱骑** —— 油泵过热（电喷车的油泵靠汽油散热）
3. **长期存放不加油** —— 油箱生锈、油路堵

**化油器类**：
4. **热车拉风门** —— 火花塞淹湿、启动困难
5. **用错化油器清洗剂**（便宜的含丙酮会腐蚀橡胶膜片）
6. **化油器装反**（真空管接错）—— 怠速不稳、油耗高
7. **主油针装错位置** —— 混合气失调
8. **浮子卡住装反** —— 油面过高或过低

**电喷类**：
9. **不清洗节气门后跑 4S 店说没修好** —— ECU 没重置，正常现象
10. **燃油滤芯装反** —— 油路堵、动力下降
11. **直喷系统自己拆** —— 高压危险
12. **电喷车油泵坏了自己拔油管** —— 油管漏油、气阻

**通用类**（附加）：
- 油管"漏一点点"不换 → 火灾隐患
- 油浮子坏了不换 → 油表不准，没油了都不知道
- 油箱有水不处理 → 冬天结冰堵油路

【经验】 **老师傅经验**：**油路故障大部分是"小问题拖成大故障"**。火花塞黑了不查 → 喷油嘴堵 → 油压调节器坏 → 油泵坏。**一个 50 元的空滤，能省 5000 元的大修**。

### 7.10.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 化油器清洗剂比汽油好用**：不伤手、不易燃、不伤橡胶。
2. **【维修】 化油器拆前拍 5 张照片**：装回去看照片，省一半时间。
3. **【维修】 化油器清洗剂喷接口测漏气**：转速变化的地方就是漏气点。
4. **【维修】 燃油滤芯先喷清洗剂再拆**：避免沙土进油管。
5. **【维修】 油泵预压 2-3 秒**：听油箱方向，有嗡声说明油泵工作。
6. **【维修】 单缸不工作拔火花塞插头**：转速变化最大的就是问题缸。
7. **【维修】 油管老化立即换**：漏油 = 火灾隐患。
8. **【维修】 直喷系统不自己拆**：200 bar 压力 = 危险。

### 7.10.3 时间预估的真相 ★★

| 项目 | 老手实际 | 新手实际 |
|------|---------|---------|
| 不拆清洗化油器 | 5 分钟 | 15-30 分钟 |
| 拆下化油器清洗 | 30-60 分钟 | 2-4 小时 |
| 换燃油滤芯 | 15-30 分钟 | 1-2 小时 |
| 测燃油压力 | 20-30 分钟 | 1-2 小时 |
| 清洗节气门 | 30 分钟 | 1-2 小时 |
| 加油管 | 30 分钟 | 1-2 小时 |
| 清洗油箱 | 1-2 小时 | 3-5 小时 |

【经验】 **老师傅经验**：**第一次拆化油器，预估 4 小时**。**工具找错、零件对不上、密封件忘记位置**——这些都要时间。**别跟老婆说"就 1 小时"**。

### 7.10.4 哪些钱不能省 ★★

**工具**：
- 燃油压力表：200-500 元（**不要买 50 元的**）
- 化油器清洗剂：正品 30-50 元（不要买 10 元的杂牌）
- 节气门清洗剂：正品 30-50 元
- 喷油嘴清洗机（家用）：500-1500 元

**零件**：
- 燃油滤芯：买正品（曼牌、马勒、博世）—— **不要买"通用"杂牌**
- 油管：买耐油橡胶（认准 SAE 30R9 规格）
- 喷油嘴：买正品或拆车件

**送修的智慧**：
- 油泵坏 → **送修**（要拆油箱）
- 喷油嘴拆洗 → **送修**（要专用设备）
- 直喷系统 → **永远送修**
- 化油器深度清洗 → 可送可自己（自己有工具就自己）

【费用】 **省钱贴士**：**化油器车省钱、电喷车花钱**——化油器能自己修，电喷核心件要送。**所以化油器车一年能省 1000-3000 元**。

### 7.10.5 容易漏的小细节 ★★

- 【维修】 **化油器装回时密封圈换新** —— 旧密封圈会漏气
- 【维修】 **燃油滤芯垫圈** —— 不能重复使用
- 【维修】 **油管卡箍** —— 用喉箍比弹簧卡箍可靠
- 【维修】 **浮子室密封** —— 化油器漏气最常见原因
- 【维修】 **电喷车拆油管前要泄压** —— 拔油泵保险丝，启动几次

### 7.10.6 修车前的检查清单 ★★★

```
[ ] 看了车型说明书或维修手册
[ ] 准备化油器清洗剂 / 节气门清洗剂（正品）
[ ] 准备容器接油
[ ] 准备吸油棉（应急漏油）
[ ] 拔电瓶负极
[ ] 通风良好的环境工作
[ ] 没有明火、热源
[ ] 灭火器在手边
[ ] 拍照记录原状态
[ ] 知道"什么时候该停手送修"
```

【经验】 **老师傅经验**：**油路作业最容易出大事**——汽油易燃、油气爆炸。**修车前默念三遍安全守则**："通风、断电、不点火"。

### 7.10.7 进阶学习路径 ★★

学完本章后想进阶，按这个顺序学：

1. **【入门】** 不拆清洗化油器、换空滤、加油管
2. **【基础】** 拆化油器清洗、换燃油滤芯、清洗节气门
3. **【进阶】** 测燃油压力、清洗喷油嘴、油泵测试
4. **【高级】** 油泵更换、喷油嘴匹配、ECU 重置
5. **【专业】** 直喷系统维修、燃油系统诊断仪编程

【经验】 **老师傅经验**：**化油器是机械时代的基本功**——电喷时代也要懂化油器原理。**修好化油器的人，对燃油系统理解更深**。

## 本章小结

### 7.10.9 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的真实案例**——给新手看"别人怎么翻车的"。

### 案例 A：本田 CB500F 加油门熄火（化油器版）

**症状**：低速加油门熄火，高速正常
**踩坑过程**：以为是火花塞问题
**可能原因**：**化油器主油针脏了**——**低速供油不均**
**处理建议**：**拆化油器 → 泡化油器清洗剂 → 装回 → 调整同步**
**教训**：**化油器车低速熄火** = **先清洗化油器**——**不是火花塞**

### 案例 B：雅马哈 MT-07 油耗突然变高

**症状**：之前 4L/100km，突然变 6L/100km
**踩坑过程**：换了火花塞、机油——没用
**可能原因**：**氧传感器老化**——**ECU 一直按浓混合气供油**
**处理建议**：换氧传感器（500-1000 元）
**教训**：**油耗高** = **查氧传感器**——**不要乱换零件**

### 案例 C：宝马 R1200GS 油表不准

**症状**：油表显示还有 1/4，但没油熄火了
**踩坑过程**：以为是浮子坏
**可能原因**：**油位传感器**（**不是浮子**）——**电喷车的浮子** = **不是油位判断**
**处理建议**：换油位传感器（**宝马特定型号**）
**教训**：**宝马油表故障** = **油位传感器**——**不是浮子**

### 案例 D：川崎 Ninja 400 加速不畅

**症状**：油门到底，加速没力
**踩坑过程**：换了排气管、空气滤芯——没用
**可能原因**：**喷油嘴堵了**（**用了劣质汽油**）
**处理建议**：拆喷油嘴 → 超声波清洗 → 装回
**教训**：**用了便宜油** = **喷油嘴堵** = **要清洗**

### 案例 E：哈雷 Sportster 燃油渗漏

**症状**：油箱底部有油迹
**踩坑过程**：擦了又漏——以为是油箱裂缝
**可能原因**：**化油器浮针密封圈老化**
**处理建议**：换浮针 + 密封圈（**20 美元**）
**教训**：**油迹** = **不一定是油箱**——**可能是化油器/油管**

### 案例 F：本田 CRF250L 越野后难启动

**症状**：越野完很难启动
**踩坑过程**：以为是发动机问题
**可能原因**：**空气滤芯进泥水**——**泥水进入进气道**
**处理建议**：不要尝试启动。拆检空滤和进气道；疑似泥水进缸时，拆火花塞后由有经验的人手动转动或低速带动发动机排水，并检查机油是否乳化。新手最稳妥做法是拖回服务站。
**教训**：越野涉水后必须检查空滤盒、进气道和火花塞孔；不要反复启动，液体不可压缩，可能顶弯连杆。

### 案例 G：杜卡迪 Monster 1214 启动后熄火

**症状**：启动后 2 秒熄火
**踩坑过程**：以为是油泵坏
**可能原因**：**防盗芯片钥匙没电**（**杜卡迪/宝马/哈雷都有**）
**处理建议**：换钥匙电池（**CR2032**）——**5 分钟搞定**
**教训**：**欧系车"启动问题"** = **先看钥匙电池**——**不是零件**

### 案例 H：凯旋 Tiger 900 冷车抖动

**症状**：早上冷车启动后怠速不稳，5 分钟后好转
**踩坑过程**：以为是火花塞问题
**可能原因**：**水温传感器偏值**——**ECU 收到错误温度**——**给错混合气**
**处理建议**：换水温传感器（**300-500 元**）
**教训**：**冷车问题** = **先查温度传感器**——**不是火花塞**

### 案例 I：铃木 SV650 油耗高

**症状**：油耗从 4.5 升到 5.5L/100km
**踩坑过程**：换了空滤、火花塞、机油
**可能原因**：**进气压力传感器（MAP）漂移**
**处理建议**：换 MAP 传感器
**教训**：**油耗变高** = **先看传感器**——**再考虑机械问题**

### 案例 J：本田 NC750X 油表指针乱跳

**症状**：油表指针在 1/2 到 1/4 之间跳
**踩坑过程**：以为是仪表问题
**可能原因**：**油位传感器接触不良**
**处理建议**：拆油位传感器 → 清洁触点 → 装回
**教训**：**指针跳** = **接触不良**——**先清洁**——**别直接换**

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **不查故障码** = **修了 1 万个零件 = 修不好** = **ECU 自带诊断**
2. **乱换传感器** = **原厂没坏** = **换了反而坏**
3. **不测压力** = **不知道是油泵还是喷油嘴** = **换了浪费**
4. **不清洁进气** = **化油器/节气门脏了** = **以为是 ECU**
5. **不查钥匙电池** = **以为是电瓶坏** = **换了电瓶还是熄火**

【经验】 **老师傅总结**：**油路故障** = **80% 是传感器/小问题**——**20% 是真零件坏**——**先诊断后维修**——**别乱拆**。
