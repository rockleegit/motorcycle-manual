## 14.1 车架结构

### 14.1.1 车架干什么的 ★★

**摩托车的"骨架"**——装发动机、轮子、油箱、座椅等所有部件的载体。

### 14.1.2 车架类型 ★★

| 类型 | 特点 | 应用 |
|------|------|------|
| **摇篮式**（Cradle Frame） | 发动机挂在车架下方 | 老车、低端 |
| **双摇篮式** | 两个摇篮臂夹紧发动机 | 部分中端 |
| **钻石型**（Diamond） | 钢管焊接的菱形结构 | **主流** |
| **双翼梁**（Twin-Spar） | 两根主梁夹紧发动机 | 运动车 |
| **铝合金双梁** | 铝合金铸造梁 | 顶级运动车 |
| **钢管编织**（Trellis） | 多根钢管编织成网 | 杜卡迪、川崎部分 |
| **铸铝** | 整体铸造 | 少数特殊车 |

【来源】 **数据来源等级**：★（**你的车是什么车架，看说明书**）。

【经验】 **老师傅经验**：**车架**决定了**整车的刚性和操控**。**钢管车架**韧性好、修复容易；**铝合金车架**刚性高、轻，但**一旦变形/损坏修复困难**（**铝合金焊接需要氩弧焊 + 特殊工艺**）。

### 14.1.3 车架号（VIN）

**车架号**是车的"身份证"：
- 17 位编码
- 包含厂家、车型、年份、生产地等
- **过户、上牌、保险、查维修记录都要用**

**位置**：
- 一般在车架右侧（车头方向看）
- 部分车型在转向头管附近
- 部分车型在摇架上

【注意】 **重要**：**车架号是唯一识别码**——**不要涂改**（违法）。

### 14.1.4 车架常见故障

**故障类型**：
- **变形**（事故撞击）
- **裂纹**（应力集中点）
- **锈蚀**（长期使用）

【严重警告】 **严重警告**：**车架变形/裂纹** = **结构强度下降** = **危险**！**事故车**要**严格检查车架**——**修复过的车架**通常**不安全**。

【送修】 **该送修了**：
- 车架变形 → **必须送修**（找专业车架修复店）
- 车架裂纹 → **必须送修**（焊接修复）
- 车架大面积锈蚀 → **必须送修**（可能影响结构）

## 14.2 紧固件（螺丝、螺母）★★★

### 14.2.1 紧固件基础知识 ★★★

**摩托车有几百个螺丝**——**长期震动会让它们松动**。

**常见紧固件类型**：
- **内六角螺栓**（最常见）
- **外六角螺栓**
- **十字/一字螺丝**
- **自攻螺丝**（塑料件）
- **卡簧/卡扣**
- **膨胀螺栓**

### 14.2.2 螺丝规格 ★★

**公制（Metric）**（**主流**）：
- M5、M6、M8、M10、M12、M14
- 数字 = 直径（mm）

**英制（SAE）**（少数老车）：
- 1/4、5/16、3/8、7/16、1/2 英寸

**强度等级**（**关键**）：
- 公制：8.8、10.9、12.9（**数字越大越硬**）
- **发动机/重要部位用 10.9 或 12.9**
- 装饰件用 8.8

【来源】 **数据来源等级**：★（**你的车用什么螺丝，看说明书**）。

【经验】 **老师傅经验**：**换螺丝时强度等级不能降**！**原厂 10.9 螺丝你换成 8.8**，**重要部位可能松动**——**事故**。

### 14.2.3 紧固扭矩 ★★★

**扭矩** = **拧螺丝的力度**。

**每个螺丝都有规定扭矩**——说明书或维修手册里。

**扭矩一般范围**（**典型值**，具体看说明书）：

| 螺丝规格 | 一般扭矩 |
|----------|---------|
| M6 | 8-12 Nm |
| M8 | 20-30 Nm |
| M10 | 40-60 Nm |
| M12 | 70-100 Nm |
| M14 | 120-160 Nm |

【来源】 **数据来源等级**：★（**你的车每个螺丝扭矩查说明书/维修手册**）。

【严重警告】 **严重警告**：
- **扭矩不足 = 螺丝松动**（**最常见**）→ **脱落** → **事故**
- **扭矩过紧 = 螺丝滑丝/断裂** → **维修麻烦**

**唯一可靠的方法**：**扭力扳手** + **说明书扭矩值**。

### 14.2.4 紧固顺序 ★★

**重要部件**（如缸盖、连杆）**有规定的紧固顺序**：

**原则**：
- **对角线紧固**（避免单边受力）
- **分多次紧固**（每次拧到扭矩的 50%、80%、100%）
- **从中心向外**（如缸盖）

【来源】 **数据来源等级**：★（**具体每个部件查说明书**）。

【经验】 **老师傅经验**：**缸盖螺丝**的紧固顺序和扭矩是**发动机大修的关键**。**顺序错、扭矩错** = **缸盖变形、漏气**。**不查说明书** = **大概率出问题**。

### 14.2.5 螺丝防松 ★★

**为什么螺丝会松**：
- **震动**（摩托车行驶时）
- **热胀冷缩**
- **塑料件老化**

**防松方法**：

| 方法 | 适用 |
|------|------|
| **弹簧垫圈** | 一般 |
| **螺纹胶**（蓝色/中等强度） | **重要部件** |
| **尼龙螺母** | 一次性 |
| **双螺母** | 高负荷 |
| **钢丝**（如火花塞） | 老方法 |

【经验】 **老师傅经验**：**螺纹胶**（Loctite 蓝色 243）**是修车神器**——**涂一点点在螺丝上**，**再也不松**。**但不要用红色（高强度）**——**以后拆不下来**。

### 14.2.6 全面紧固螺丝（车主必学）★★★

**多久做一次**：**每 5000-10000 km 一次**。

**步骤**：
```
1. 准备工具（套筒套装、扭力扳手、说明书）
2. 准备示意图（每个螺丝位置标记好）
3. 从车头开始：
   a. 大灯
   b. 转向手柄
   c. 上联板
   d. 前叉上端
   e. 前叉下端
   f. 前轴
4. 到车身：
   a. 油箱固定螺丝
   b. 边盖
   c. 座椅
   d. 脚踏
5. 到车尾：
   a. 后视镜
   b. 牌照架
   c. 后挡泥板
   d. 后架
6. 用扭力扳手按扭矩拧紧
```

⏱ 用时：30-90 分钟
【费用】 费用：工具一次性投入（套筒 100-300 元，扭力扳手 200-500 元）

【经验】 **老师傅经验**：**第一次全面紧固**会发现一堆**松动的螺丝**——**很多车出厂就没拧紧**。**新车 1000 km 紧一次**很重要。**很多车主从不紧螺丝**——**这是事故隐患**。

【费用】 **省钱贴士**：**自己紧固螺丝**省 100-300 元（工时费）。**每 5000 km 做一次**。

### 14.2.7 螺丝滑丝处理 ★★

**症状**：拧螺丝"打滑"——拧不紧。

**原因**：螺纹损坏（拧过紧、锈蚀、拆装次数多）。

**处理**：

| 严重度 | 处理 |
|--------|------|
| 轻微 | **用丝攻修复螺纹**（DIY 可行） |
| 中度 | **打螺纹胶** |
| 严重 | **换大一号的螺丝（+0.5 mm）+ 攻丝** |
| 非常严重 | **焊补后重新攻丝**（送修） |

【送修】 **该送修了**：
- 螺丝断在孔里（要专用工具取）
- 重要部位（如发动机内）滑丝

### 14.2.8 螺丝断在孔里（应急处理）

**步骤**：
```
1. 用断螺丝取出器（专用工具）
2. 在断螺丝上钻孔（先小后大）
3. 反向拧出
4. 重新攻丝
5. 装新螺丝
```

【送修】 **该送修了**：
- 重要部位的断螺丝（如发动机内）
- 自己取不出来

## 14.3 塑料件维护

### 14.3.1 塑料件类型

- ABS 塑料（**主流**）：车架外罩、整流罩
- PP 聚丙烯：内部件
- 玻璃纤维：高端车定制件

### 14.3.2 塑料件老化 ★★

**老化表现**：
- 发白/发灰（紫外线氧化）
- 变脆
- 裂纹
- 失去光泽

**预防**：
- **避免长时间暴晒**（用罩车衣）
- 定期用塑料翻新剂

### 14.3.3 塑料翻新 ★★

**步骤**：
```
1. 用洗车液清洗塑料件
2. 干燥
3. 用塑料翻新剂（或 WD-40 临时用）
4. 用抹布均匀涂抹
5. 等 5 分钟
6. 用干净抹布擦亮
```

**塑料翻新剂品牌**：
- **Meguiar's**：专业
- **Turtle Wax**：性价比高
- **AutoGlym**：欧洲货

【费用】 **省钱贴士**：**塑料翻新剂 30-100 元/瓶**——**一瓶用半年**。**比 4S 店"翻新服务"便宜 10 倍**。

### 14.3.4 塑料件修复（基础）

**小裂纹修复**：
```
1. 清洁裂纹
2. 用塑料焊枪（或 AB 胶）
3. 粘合或焊接
4. 打磨平整
5. 上漆（同色漆）
```

**断件修复**：
```
1. 找到所有碎片
2. 按顺序粘合
3. 内部加固（玻璃纤维布 + 树脂）
4. 外部打磨
5. 上漆
```

【送修】 **该送修了**：
- 大面积塑料件损坏
- 高端车的复杂整流罩
- 自己没经验的修复

## 14.4 漆面维护

### 14.4.1 漆面组成 ★★

```
[透明漆层（最外）]
   ↓
[色漆层]
   ↓
[底漆层]
   ↓
[电泳层（防锈）]
   ↓
[金属/塑料基材]
```

**最怕**：
- 紫外线（褪色）
- 鸟粪/虫尸（腐蚀）
- 树胶（留痕）
- 划痕（破坏透明漆）
- 海水/融雪盐（腐蚀）

### 14.4.2 洗车 ★★★

**车主必学**！

**洗车步骤**：
```
1. 先用水冲（去掉沙土）—— **不要上来就用抹布！**
2. 用洗车液 + 海绵洗（**从上到下**）
3. 用水冲净
4. 用麂皮或超细纤维毛巾擦干
5. 边缝用毛巾擦
```

**注意事项**：
- **不要用洗洁精**（**会洗掉车蜡**）
- **不要在太阳下洗**（**会留水渍**）
- **不要用脏海绵**（**会划伤漆面**）

【经验】 **老师傅经验**：**洗车最伤漆的是"上来就用抹布"**！**沙土 + 抹布 = 砂纸**！**先用水冲掉沙土**是洗车第一原则。**很多洗车店都做错了**。

### 14.4.3 打蜡 ★★

**打蜡频率**：**每 1-3 个月一次**。

**打蜡步骤**：
```
1. 洗车、擦干
2. 用蜡拖蘸蜡（少量）
3. 均匀涂抹（**画圈或直线**）
4. 等几分钟（**蜡变白雾状**）
5. 用超细纤维毛巾擦亮
```

**蜡的种类**：

| 蜡 | 特点 | 寿命 |
|----|------|------|
| **棕榈蜡**（Carnauba） | 自然光泽、好 | 1-2 个月 |
| **合成蜡** | 持久 | 3-6 个月 |
| **封体剂**（Sealant） | 持久、抗污 | 6-12 个月 |
| **镀晶**（Ceramic Coating） | 最持久、专业 | 1-3 年 |

【费用】 **省钱贴士**：**自己打蜡 30-100 元/次**（蜡 + 工具）；**4S 店打蜡 200-800 元/次**。**一年自己打蜡 4 次，省 800-2000 元**。

### 14.4.4 抛光 ★★

**什么时候抛光**：
- 漆面有氧化层（黯淡）
- 漆面有浅划痕
- 漆面有瑕疵

**抛光步骤**：
```
1. 洗车、擦干
2. 用抛光机（带抛光盘）
3. 涂抛光蜡
4. 低速均匀抛光
5. 检查效果
6. 抛光后打蜡（**保护新表面**）
```

【注意】 **警告**：**抛光会磨掉薄薄一层透明漆**——**每次抛光都减薄**。**一生不能抛光超过 5-10 次**。

### 14.4.5 漆面损伤修复

**浅划痕**：
```
1. 清洁划痕
2. 用补漆笔（同色号）
3. 涂抹
4. 等干
5. 打磨平整
6. 打蜡
```

**深划痕（露出底漆/金属）**：
- **必须送修**
- 不修会生锈

【送修】 **该送修了**：
- 大面积损伤
- 凹陷（要钣金）
- 重新喷漆（专业）

## 14.5 锈蚀处理

### 14.5.1 为什么会生锈 ★★

**铁/钢 + 水 + 氧气 = 锈**。

**摩托车生锈高发区**：
- 排气管
- 链轮（链条/链轮见第 10 章）
- 螺丝
- 排气管吊胶处
- 油箱底部
- 边盖内部

### 14.5.2 防锈处理 ★★★

**新车/新买的车**：
```
1. 全车检查（底盘、排气管、螺丝）
2. 喷防锈剂（底盘装甲 / WD-40 防锈型）
3. 重点部位多喷（排气管、螺丝、焊接处）
```

**使用中的车**：
- **每年春季喷一次防锈剂**
- **海边用车每月一次**（盐分高）
- **冬季后必喷**（融雪盐腐蚀严重）

### 14.5.3 已有锈蚀的处理 ★★

**轻微表面锈**：
```
1. 用钢丝刷或砂纸除锈
2. 清洁、干燥
3. 涂防锈漆（自喷漆）
4. 等干
5. 可选：再涂上面漆
```

**中度锈蚀**：
```
1. 除锈（同上，更彻底）
2. 涂防锈底漆
3. 涂防锈面漆
```

**严重锈蚀**：
```
1. 除锈（可能要打磨或切割）
2. 焊接补片（送修）
3. 重新涂装
```

【送修】 **该送修了**：
- 结构性锈蚀（车架、排气管）
- 大面积锈蚀

### 14.5.4 排气管防锈 ★★

**排气管**是摩托车**最容易生锈的部件**之一。

**防锈方法**：
```
1. 用钢丝刷除锈
2. 用排气管专用防锈漆（**耐高温**）
3. 喷涂
4. 保持排气管干燥（**避免长时间湿存**）
```

【经验】 **老师傅经验**：**排气管内壁也会锈**——**长时间湿存**（雨天骑完不骑了）会让**冷凝水聚集在排气管底部**——**几个月内锈穿**。**骑完让车热几分钟**，**让水分蒸发**。

## 14.6 车架与外观故障诊断

### 14.6.1 案例 1：车架异响 ★★★

**症状**：骑行时车架有异响（"嘎嘎"或"咯咯"）。

**诊断**：
```
1. 找大致位置（声音来自哪里）
2. 检查相关螺丝是否松动
3. 检查塑料件是否干涉
4. 检查排气管吊胶
5. 检查链条护板
```

**处理**：
- 螺丝松：紧固
- 塑料件松：固定
- 排气管吊胶烂：换吊胶

### 14.6.2 案例 2：漆面起泡

**症状**：漆面有气泡或翘起。

**原因**：
- 漆下生锈
- 底漆破坏
- 补漆质量问题

**处理**：**必须送修**——**彻底处理 + 重新喷漆**。

### 14.6.3 案例 3：仪表壳裂

**诊断**：
- 撞击裂：换壳
- 老化裂：换壳

**处理**：
- 自己换壳：100-300 元
- 4S 店换：200-500 元

### 14.6.4 案例 4：座垫塌陷

**症状**：座垫坐着塌。

**处理**：
- **换座垫海绵**：50-200 元（**车主可做**）
- **换整个座垫总成**：200-1000 元
- **专业改装**：500-3000 元

【经验】 **老师傅经验**：**座垫塌陷**很多车主用**加海绵垫**解决——**便宜**但**不舒服**。**换原厂海绵**才是正确方案。

### 14.6.5 案例 5：大灯雾化 ★★

**症状**：大灯灯罩发雾、透光差。

**原因**：紫外线让塑料老化。

**处理**：
- **抛光恢复**（轻度）：用大灯专用抛光剂
- **换灯罩**（严重）：100-500 元
- **换总成**（非常严重）：500-2000 元

【费用】 **省钱贴士**：**大灯抛光套装 30-100 元**——**一次使用亮度提升 80%**。**比换灯罩便宜 5 倍**。

## 14.7 【经验】 老师傅经验沉淀（应写尽写）

### 14.7.1 新手必踩的 12 个车架/外观坑 ★★★

**车架/紧固类**：
1. **新车不紧螺丝** —— **出厂就没拧紧**
2. **不用扭力扳手** —— 重要部位扭矩不对 = 事故
3. **螺纹胶用红色** —— **以后拆不下来**
4. **螺丝滑丝强行拧** —— **彻底坏掉**
5. **车架变形继续骑** —— **结构强度下降** = **危险**

**漆面/塑料类**：
6. **上来就用抹布洗车** —— **沙土 + 抹布 = 砂纸**
7. **洗洁精当洗车液** —— **洗掉车蜡**
8. **太阳下洗车** —— **留水渍**
9. **用错抛光** —— **每次抛光减薄透明漆**
10. **鸟粪不及时清** —— **腐蚀漆面**

**防锈类**：
11. **海边用车不防锈** —— **盐分快速腐蚀**
12. **排气管长时间湿存** —— **内壁锈穿**

【经验】 **老师傅经验**：**车架/外观**第一公敌是**"锈"**。**锈一旦开始就难停**——**预防胜于治疗**。**新车第一次保养就是喷防锈剂**——**能省后期很多麻烦**。

### 14.7.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 新车 1000 km 紧螺丝**：出厂就松
2. **【维修】 螺纹胶用蓝色**：红色以后拆不下来
3. **【维修】 洗车先水冲**：沙土 + 抹布 = 砂纸
4. **【维修】 塑料件用罩车衣**：防止紫外线老化
5. **【维修】 抛光不要超过 5-10 次**：透明漆会被磨光
6. **【维修】 鸟粪 1 小时内清**：腐蚀漆面
7. **【维修】 排气管骑完热几分钟**：蒸发水分
8. **【维修】 每年春季防锈一次**：特别是冬季骑过的车

### 14.7.3 时间预估的真相 ★★

| 项目 | 老手实际 | 新手实际 |
|------|---------|---------|
| 全面紧螺丝 | 30-45 分钟 | 1-3 小时 |
| 洗车 | 15-30 分钟 | 30-60 分钟 |
| 打蜡 | 30-60 分钟 | 1-3 小时 |
| 抛光 | 30-60 分钟 | 1-3 小时 |
| 除锈 | 30-60 分钟 | 1-3 小时 |
| 换座垫海绵 | 30 分钟 | 1-2 小时 |
| 换大灯灯罩 | 15-30 分钟 | 30-60 分钟 |

【经验】 **老师傅经验**：**第一次全面紧螺丝**，**预估 3 小时**。**会找到一堆松的**——**不要急**。**找到一处紧一处**。**不要图快**。

### 14.7.4 哪些钱不能省 ★★

**工具**：
- 套筒套装：100-300 元
- 扭力扳手：200-500 元（**重要部位必备**）
- 螺纹胶（蓝色）：30-50 元
- 防锈剂：50-150 元

**耗材**：
- 洗车液：30-80 元/瓶（**不要用洗洁精**）
- 车蜡：50-300 元/盒
- 大灯抛光剂：30-100 元/套
- 排气管防锈漆：30-80 元

**送修的智慧**：
- 车架变形 → **必须送修**
- 重新喷漆 → **必须送修**（专业喷漆房）
- 锈穿补片 → **必须送修**（焊接）
- 塑料件大面积修复 → **送修为主**

【费用】 **省钱贴士**：**车架/外观车主能省钱的部分**：
- 自己洗车：省 200-500 元/年
- 自己打蜡：省 800-2000 元/年
- 全面紧螺丝：省 100-300 元/年
- 轻微除锈：省 100-300 元/年

**一年总计省 1200-3100 元**。**而且车更保值**——**保养好的车卖价高 10-20%**。

### 14.7.5 容易漏的小细节 ★★

- 【维修】 **排气管吊胶**：老化不换会导致排气管断裂
- 【维修】 **后视镜螺丝**：松了影响视线
- 【维修】 **牌照架螺丝**：掉了会被交警拦
- 【维修】 **脚踏防滑钉**：磨光了要换
- 【维修】 **油箱盖密封圈**：老化漏油

【经验】 **老师傅经验**：**油箱盖密封圈**老化会**漏油**——**加油时漏油危险**。**几元钱的密封圈**，**换一个能用 5 年**。**很多人不知道要换这个**。

### 14.7.6 车架/外观保养清单 ★★★

```
[ ] 每 5000-10000 km 紧固所有螺丝
[ ] 每月洗车 1-2 次
[ ] 每 1-3 个月打蜡
[ ] 每年春季防锈处理
[ ] 长期停车用罩车衣
[ ] 鸟粪/虫尸及时清除
[ ] 排气管骑完热几分钟
[ ] 仪表/大灯/尾灯正常工作
```

【经验】 **老师傅经验**：**车架/外观保养**看起来是小事——**但 5 年后区别明显**。**保养好的车**看起来像**3 年车**；**保养差的**看起来像**8 年车**。**爱车的车主**省的不只是钱——**是面子**。

### 14.7.7 进阶学习路径 ★★

学完本章后想进阶，按这个顺序学：

1. **【入门】** 全面紧螺丝、洗车、打蜡
2. **【基础】** 抛光、除锈、换塑料件
3. **【进阶】** 局部补漆、塑料件修复
4. **【高级】** 大面积喷漆（专业）、防锈处理
5. **【专业】** 钣金、车架修复

【经验】 **老师傅经验**：**车架/外观**的核心是**预防**。**新车就防锈**比**锈了再修**好 100 倍。**新车就紧螺丝**比**松了再紧**好 100 倍。**预防胜于治疗**——**这条原则**在车架/外观最明显。

**新手最常踩的 5 个大坑**（基于论坛统计）：
