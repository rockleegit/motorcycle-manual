## 6.1 发动机到底是什么

### 6.1.1 一句话理解

发动机就是一个**靠油气燃烧产生推力的机器**。把燃油和空气按比例混合，点燃，爆炸，推动活塞，活塞带动曲轴，曲轴带动后轮。

剩下的内容——气门、凸轮、正时、冷却——都是为了让这件事**持续、稳定、高效**地发生。

### 6.1.2 你车上的发动机长什么样

```
        [油箱]
           ↓
       [气缸盖]    ← 顶部，盖着气门机构
           ↓
       [气缸体]    ← 活塞在里面上下跑
           ↓
       [活塞]      ← 像一个金属塞子，被爆炸推着走
           ↓
       [曲轴箱]    ← 底部，装曲轴和变速箱
           ↓
       [后轮]
```

不同车型的发动机位置不一样：
- **街车/ADV**：发动机在车架中部、骑手两腿之间，重心位置
- **踏板车**：发动机挂在车架底部，脚踏板下面
- **越野车**：发动机位置偏高，给离地间隙让路

发动机和车架之间不是硬连的，**有减震橡胶垫**，否则发动机的振动会传到屁股上。

### 6.1.3 怎么认出自己发动机的类型

看你车的参数表（说明书、官网都能查到），认准四个东西：

| 车型示例 | 缸数 | 排列 | 冷却 |
|---------|------|------|------|
| 凯旋 Scrambler 1200X | 2 | 直列（1200 T 系列平台） | 水冷 |
| 意塔杰特 Dragster 300 | 1 | 单缸 | 水冷 |
| 雅马哈 MT-07 | 2 | 跨平面（270°曲轴） | 水冷 |
| 哈雷 Street Bob | 2 | V 型 | 风冷+油冷 |
| 本田 CBR1000RR | 4 | 直列 | 水冷 |
| 杜卡迪 Monster | 2 | L 型（90°） | 水冷 |

【问答】 **新手问答**：跨平面、L 型、V 型有什么区别？

答：本质都是双缸，但**曲轴的相位**不一样。直列双缸两个活塞同起同落（同步曲轴），跨平面/L 型/V 型两个活塞**错开**着动。这样做的好处是动力输出更平顺，震动更小。

【经验】 **老师傅经验**：判别发动机类型后，先做一件事——**把说明书里的气缸排列图、点火顺序图背下来**。修车时这图天天用，比记任何文字都管用。

### 6.1.4 排量是怎么算出来的 ★★（数学通用）

排量 = 一个气缸的工作容积 × 气缸数

一个气缸的工作容积 = π × (缸径/2)² × 行程

**举个例子**（基于 AI 训练数据）：

雅马哈 MT-07：
- 缸径 80mm，行程 68.6mm，两个缸
- 一个缸的容积 = 3.14 × 40² × 68.6 ≈ 344.6cc
- 总排量 = 344.6 × 2 = **689cc**（标称 700）

【来源】 **数据来源等级**：★（AI 训练数据。MT-07 缸径行程是公开常识，但具体数值**用前请到雅马哈官网核对**）。

排量越大一般动力越强，但不是绝对的（还有压缩比、进气效率等）。

### 6.1.5 压缩比 ★★（通用物理概念）

压缩比 = （气缸总容积 + 燃烧室容积）/ 燃烧室容积

简单理解：活塞把混合气压多狠。

| 类型 | 压缩比（行业典型值） |
|------|--------|
| 街车 | 10:1 - 11:1 |
| 运动车 | 12:1 - 13:1 |
| 越野 | 11:1 - 12:1 |
| 复古 | 9:1 - 10:1 |

【问答】 **新手问答**：压缩比高好吗？

答：压缩比高 → 功率大、油耗高、对汽油标号要求高。压缩比超过 12 一般要 95# 以上汽油，不然会爆震（6.2.2 节讲）。

【来源】 **数据来源等级**：★（AI 训练数据的典型范围。具体车型**查说明书**）。

### 6.1.6 发动机从上到下的部件

| 部件 | 位置 | 它干啥 |
|------|------|--------|
| 气门室盖 | 最上面 | 盖住气门机构，方便调气门 |
| 缸盖 | 中上 | 装气门、燃烧混合气 |
| 缸垫 | 缸盖和缸体之间 | 密封（油道、水道、气道都不能漏） |
| 缸体 | 中间 | 活塞在里面上下跑 |
| 活塞 | 缸体里 | 被燃烧气体推着走 |
| 活塞环 | 活塞上 | 密封气缸+刮油 |
| 连杆 | 活塞和曲轴之间 | 传力 |
| 曲轴 | 曲轴箱里 | 把活塞的上下运动变成旋转 |
| 曲轴箱 | 最下 | 装曲轴、变速箱、机油 |
| 油底壳 | 曲轴箱底 | 储机油 |

记忆方法：**盖-缸-塞-杆-轴-箱-壳**，从上到下。

【经验】 **老师傅经验**：这表要背得**比女友生日还熟**。任何发动机维修——换气门、换活塞环、查异响——你脑子里第一时间要浮现这张图。

## 6.2 四冲程发动机怎么工作的

### 6.2.1 一个完整循环 ★★★（四冲程原理）

曲轴转两圈（720°），四个冲程轮流来一遍：

**第一冲程：进气**（活塞从上往下）
- 进气门打开
- 活塞下行，把新混合气吸进缸里

**第二冲程：压缩**（活塞从下往上）
- 进排气门都关
- 活塞把混合气压得很小很烫

**第三冲程：做功**（活塞从上往下）
- 火花塞在活塞到顶之前点火
- 混合气爆燃，推活塞下行
- 这就是发动机出力的那一刻

**第四冲程：排气**（活塞从下往上）
- 排气门打开
- 活塞上行，把废气推出

四个冲程里只有第三冲程在做功。所以你看到发动机一直"突突突"喘气，但大部分时间是**准备**出力和**清理**现场。

【注意】 **常见误解**：发动机一直有动力输出。

错。**四冲程里只有 1/4 在出力**。多缸发动机的存在就是为了让出力间隔短一些——双缸每 360° 出力一次，四缸每 180° 出力一次。

【经验】 **老师傅经验**：记住四冲程的口诀——**进、压、做、排**。哪天你憋屈了，对墙念一遍"进压做排进压做排"——瞬间治愈。

### 6.2.2 爆震是什么鬼 ★★★（重要，故障诊断关键）

点火是火花塞干的，正常情况下**只有火花塞**这一个点火源。

但有时候混合气**自己**被压燃了——这叫爆震。

**爆震听起来像**：金属敲击声，"哒哒哒"或者"叮叮叮"，加速时更明显。

**爆震的后果**：爆震产生的压力波和正常燃烧的活塞运动方向相反，轻则损伤活塞环，重则活塞熔顶、气门变形。

**爆震的常见原因**（从常见到不常见）：
1. 用了低标号汽油
2. 点火提前角太大
3. 燃烧室积碳太多（积碳占据空间，等于提高了压缩比）
4. 发动机过热
5. 用了错误的火花塞热值

【经验】 **老师傅经验**：爆震听着像"叮叮叮"，别和气门响（"哒哒哒"）搞混——气门响是节奏规律的低沉声，爆震是尖锐的金属撞击声。**爆震要立即停**；气门响可以暂时继续骑但要尽快修。

### 6.2.3 点火提前角 ★★（通用物理概念）

火花塞**不是**在活塞到顶的瞬间点火的，而是**提前**。

| 提前角 | 效果 |
|--------|------|
| 0° | 太晚，动力小 |
| 15° 左右 | 适合怠速 |
| 25° 左右 | 适合中转速 |
| 35° 左右 | 适合高转速 |
| 太大 | 爆震 |

为啥要提前？因为混合气从点火到完全燃烧需要时间（约几毫秒），提前点才能在活塞到顶时燃烧压力达到最大。

【问答】 **新手问答**：点火提前角怎么调？

答：现代电喷车都是 ECU 自动调的，老化油器车有手动调节机构。**新手不要碰**——交给 ECU 或修车师傅。

### 6.2.4 配气相位 ★★

"气门什么时候开、开多大、开多久"就叫配气相位，由凸轮轴的形状决定。

四个关键角度（一般范围，**具体车型查手册**）：
- **进气提前角**：活塞到顶前 5-25° 进气门就开了
- **进气迟后角**：活塞到底后 30-70° 进气门才关（多吸一点）
- **排气提前角**：活塞到底前 30-70° 排气门就开了（早排一点）
- **排气迟后角**：活塞到顶后 5-25° 排气门才关

为什么这么复杂？因为**气流的惯性**可以利用——气门早开晚关能多吸进一点混合气、多排出一点废气。

**重叠角**：进排气门同时打开的那段角度（在上止点附近）。它能让废气带走一部分新鲜混合气，也能利用进气惯性扫气。

- 重叠角大：高转速功率大，怠速不稳
- 重叠角小：怠速稳，高转速功率小

**可变气门正时（VVT）**：现代发动机可以根据转速**自动**调重叠角，低速稳定，高速有劲。代表技术：宝马 ShiftCam、雅马哈 VVA、本田 VETC。

【来源】 **数据来源等级**：★（行业通用范围，**具体车型查厂家手册**）。

### 6.2.5 配气机构怎么传动的

```
[凸轮轴]  ←  转动时凸起部分顶下去
   ↓
[挺柱]    ←  被凸轮顶起来
   ↓
[摇臂]    ←  （如果有的话）把上下运动变成按气门的动作
   ↓
[气门]    ←  被压下去，气道打开
```

**OHC（顶置凸轮轴）**：凸轮轴在气缸盖里，离气门近。
**DOHC（双顶置凸轮轴）**：两根凸轮轴，一根管进气门一根管排气门。现代高性能发动机都是这个。

链条还是皮带把曲轴的转动传到凸轮轴：

| 类型 | 优点 | 缺点 |
|------|------|------|
| 链条 | 寿命长 | 噪音大、要换张紧器 |
| 皮带 | 安静 | 寿命短（一般 3-6 万 km），断了就顶气门 |

【严重警告】 **严重警告**：**正时皮带必须按周期换**！断了正时就乱了，活塞会撞气门（"打气门"），直接报废发动机。

【经验】 **老师傅经验**：链条传动的车，**张紧器**和**链条导板**要和链条一起换。很多车主图省钱只换链条，结果一年后导板磨损把链条磨断——**整套换才几千元，发动机报废要几万**。

### 6.2.6 点火顺序 ★★

多缸发动机的点火有先后，让动力间隔均匀。

**通用规律**：
- **直列双缸**：1-2-1-2（一个缸做功完另一个接着来）
- **直列三缸**：1-3-2-1-3-2
- **直列四缸**：常见 1-2-4-3（雅马哈风格）或 1-3-4-2（本田风格）
- **V 型双缸**：根据曲轴相位决定（哈雷 Twin Cam 45°：0-315-540-765；杜卡迪 L 型 90°：0-165-495-630）

【维修】 **维修场景**：调整气门时，**必须**知道自己车的点火顺序。1 缸在压缩上止点时，可以同时调这组气门——调错顺序，气门和活塞会撞上。

【口诀】 **记忆口诀**：
- 双缸：1-2-1-2
- 三缸：1-3-2-1-3-2
- 四缸：1-2-4-3（雅马哈风格）

## 6.3 气门间隙调整（核心技能 1）

### 6.3.1 什么是气门间隙

气门和驱动它的部件（摇臂、挺柱）之间留的一点点缝。

**为什么要留缝**：
金属受热会膨胀。冷车时合适，热车时气门杆膨胀，关不严。

**间隙太大的后果**：
- 哒哒哒的金属敲击声（"气门响"）
- 气门开得不够、关得不及时
- 动力下降、费油
- 气门、摇臂异常磨损

**间隙太小的后果**（这个更危险）：
- 气门关不严
- 燃烧的高温气体烧蚀气门
- 严重的会烧穿气门

### 6.3.2 你车的气门间隙是多少 ★★★

**别瞎猜，查手册**。这是最重要的一条经验。

下面是 AI 训练数据中的常见值，**用前必查厂家手册**：

| 车型 | 进气 | 排气 | 检查周期（厂家建议） |
|------|------|------|--------------------|
| 凯旋 Scrambler 1200X | 0.10-0.20mm | 0.20-0.30mm | 1.2 万 km |
| 雅马哈 MT-07 | 0.11-0.20mm | 0.21-0.30mm | 4 万 km |
| 哈雷 Twin Cam | 见手册 | 见手册 | 8000 km |
| 本田 CBR1000RR | 0.16-0.24mm | 0.21-0.29mm | 2.4 万 km |
| 川崎 Z650 | 0.10-0.18mm | 0.18-0.25mm | 1.8 万 km |

【来源】 **数据来源等级**：★（AI 训练数据，**用前必须查官方手册或 Haynes/Clymer**）。

【问答】 **新手问答**：为什么排气门间隙普遍比进气门大？

答：排气门工作在更热的环境，热膨胀更大，所以要预留更多。

【经验】 **老师傅经验**：查气门间隙**一定要查两遍**——第一次是为了记住标准值，第二次是为了确认你记对了。**记忆会骗你，文档不会**。

### 6.3.3 需要哪些工具

| 工具 | 用途 |
|------|------|
| 套筒套装（8-19mm） | 拆气门室盖、缸盖等 |
| 塞尺（feeler gauge） | 测气门间隙 |
| 扭力扳手 | 按扭矩拧紧螺丝 |
| 火花塞套筒 | 拆火花塞（辅助找 TDC） |
| 螺丝刀（一字/十字） | 调气门 |
| 厂家专用工具 | 部分车型必须 |

高端车型还需要：
- 凸轮轴固定工具（凯旋、宝马、本田部分车型）
- 飞轮固定工具
- TDC 指示销
- 扭角扳手（带角度指示的扭力扳手）

【经验】 **老师傅经验**：**工具不要贪便宜**。便宜的塞尺厚度不标准，量出来的间隙会差 0.02mm——0.02mm 看着小，气门是金属对金属的精密配合，能要命。建议买 **Mitutoyo 或 Insize 的塞尺**（几百元一套）。

【费用】 **省钱贴士**：塞尺、扭力扳手、火花塞套筒这三样**必须自己买**，加起来 200-500 元。一次性投入，长期使用，调一次气门就回本了。

### 6.3.4 调整气门步骤（详细版）

#### 第 1 步：准备工作

```
1. 冷车（停机后至少 30 分钟，温度降到 35°C 以下）
2. 把车架稳（大撑或者工作架）
3. 准备工具、零件盒（放小螺丝）
4. 拆座椅（如需要）
5. 拆油箱（如需要）
6. 准备相机拍照记录（拆每一步都拍）
```

**为什么必须冷车**：
金属热胀冷缩。热车测量永远比真实值小，间隙调出来就偏紧，长期烧气门。

【经验】 **老师傅经验**：夏天热时不要马上调气门。让车在阴凉处停一晚上，第二天早晨调最准。**早起的修车人调出来早准**。

#### 第 2 步：找到 1 缸压缩上止点（TDC）

**TDC（Top Dead Center）** = 活塞最高点。但要找的是**压缩冲程的 TDC**，不是排气冲程的 TDC——两个 TDC 活塞位置相同，但气门状态完全不同。

**怎么找**：

**方法 A：手指法（最常用）**
```
1. 拆下 1 缸火花塞
2. 用手指堵住火花塞孔（或者塞一团布）
3. 缓慢转动曲轴（顺时针，正常方向）
4. 感到气体往外推手指 = 压缩冲程
5. 继续转到曲轴箱上的 TDC 标记对正
6. 转动时另一只手扶着曲轴防回弹
```

**方法 B：看凸轮轴法**（拆了气门室盖之后）
```
1. 看 1 缸的进排气凸轮
2. 两个凸轮的"基圆"（最矮部分）都对着气门
3. 这就是 1 缸压缩 TDC
```

**方法 C：专用工具法**
```
1. 用厂家提供的 TDC 指示销
2. 插入 TDC 孔
3. 缓慢转动曲轴
4. 销子被推到顶 = TDC
```

【严重警告】 **别搞错 TDC**：找错了 TDC，调气门时活塞和气门会**撞**！每一步慢一点，多确认一次。

【经验】 **老师傅经验**：找 TDC 时**不要一气呵成**。每转一点就停下来，看标记对不对、活塞到哪了。**修车师傅和车毁人亡之间，往往就差一个"急"字**。

#### 第 3 步：测量气门间隙

塞尺是一片一片的薄钢片，每片有厚度标注。

```
1. 选一片接近标准值的塞尺
2. 插入气门和驱动件之间
3. 感到轻微拖拽 = 刚好
4. 插入无阻力 = 太松（换厚的）
5. 插不进去 = 太紧（换薄的）
```

**举个例子**（进气门标准 0.15mm）：
- 0.10mm 塞尺轻松滑过 = 太松
- 0.15mm 塞尺有阻力 = 合适
- 0.20mm 塞尺插不进 = 太紧

塞尺可以**叠加**使用，但要避免一次叠太多片（容易夹不稳）。

【经验】 **老师傅经验**：测间隙时塞尺要**顺着气门杆方向插**，不要歪着插。**塞尺和气门杆平行**——这个角度下测出来的值才准。

#### 第 4 步：调整气门间隙

**三种调整方式**：

**方式 1：螺钉+锁紧螺母**（凯旋 1200X、本田 CB 系列）
```
1. 松开锁紧螺母（一般 10mm）
2. 用螺丝刀调调整螺钉
3. 边调边塞塞尺进去试
4. 感到合适 = 锁紧螺母
5. 锁紧后一定要复测（拧螺母会让间隙变化）
```

【经验】 **老师傅经验**：锁紧螺母时**塞尺不要抽出来**。保持在位锁紧，这样能避免螺母转动带动螺钉造成间隙变化。

**方式 2：垫片式**（很多日系小排量、一些欧系车）
```
1. 拆下挺柱
2. 取出旧垫片
3. 测旧垫片厚度（千分尺）
4. 算出新垫片厚度
5. 装新垫片
6. 装回挺柱
7. 复测间隙
```

垫片厚度计算公式：

新垫片厚度 = 旧垫片厚度 + （实测间隙 - 标准间隙）

举个例子：
- 实测间隙 0.30mm（过大）
- 标准 0.20mm
- 旧垫片 2.50mm
- 新垫片 = 2.50 + (0.30 - 0.20) = 2.60mm

【注意】 **重要**：**必须**买专用垫片。垫片有不同直径，错了装不进去。

【经验】 **老师傅经验**：垫片型号一定要查**配件手册**。同一款发动机，**不同年份、不同地区版本**用的垫片厚度可能不一样。**用错垫片**最常见的症状是——刚调好，过 5000 km 又要调。

**方式 3：液压挺柱**（一些现代车）
- 不用手动调，机油压力自动补偿
- 坏了就换，没有调整余地
- 故障时会有"哒哒"声

【经验】 **老师傅经验**：液压挺柱的"哒哒"声——**冷车响、热车消失**就是它。如果一直响，可能是机油压力不够或挺柱本身坏了。**别急着拆**，先换机油试试。

#### 第 5 步：多缸调整顺序

**双缸**（通用逻辑，**具体车型查手册**）：
```
第 1 次：1 缸 TDC（压缩）
- 调 1 缸进气门
- 调 1 缸排气门
- 调 2 缸排气门（曲轴相位关系，2 缸排气门此刻也"松"）

第 2 次：转曲轴到 2 缸 TDC
- 调 2 缸进气门
```

**四缸**（通用逻辑，**具体车型查手册**）：
```
1 缸 TDC → 调 1 缸进排 + 3 缸排
转 180°（2 缸 TDC） → 调 2 缸进排 + 4 缸排
转 180°（3 缸 TDC） → 调 3 缸进
转 180°（4 缸 TDC） → 调 4 缸进
```

【注意】 **重要**：每款车的调整顺序**不一样**，必须查手册。

【经验】 **老师傅经验**：多缸调气门时，**画一张表**。表头是缸号，列是"1号TDC/2号TDC/..."。每调一个气门打勾。**不画表漏一个气门是常事**，然后骑了 5000 km 又得拆一次。

#### 第 6 步：组装复原

```
1. 装气门室盖（按扭矩，一般 8-12Nm，对角顺序）
2. 装火花塞（按扭矩，20Nm 左右）
3. 装回油箱、座椅
4. 拔电瓶负极的记得接上
5. 启动测试
```

#### 第 7 步：验证

```
1. 启动发动机
2. 怠速 5 分钟（热车）
3. 听有没有"哒哒"声（间隙过大）
4. 慢加速几次（看动力）
5. 试骑（高速工况下检查）
```

**如果还有异响**：
- 重新检查间隙
- 可能找错 TDC 了
- 可能用了错误的车型数据

### 6.3.5 容易翻车的地方

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 找错 TDC | 调错气门、气门撞活塞 | 多确认 |
| 热车调整 | 数据不准、间隙偏紧 | 必须冷车 |
| 锁紧螺母不复测 | 间隙跑偏 | 锁紧后 100% 复测 |
| 紧固过度 | 螺母滑丝 | 按扭矩 |
| 漏装垫圈 | 漏油 | 注意垫圈 |
| 用错型号的塞尺 | 测出来的间隙错 | 一套塞尺几十到几百元，**别用便宜货** |

【费用】 **省钱贴士**：自己调气门一般省 200-500 元工时费，工具是一次性投入（一套塞尺几十元，扭力扳手一二百元）。

【送修】 **该送修了**：
- 拆气门室盖后看到凸轮磨损、明显划痕
- 缸盖螺丝扭矩数据查不到
- 没有专用工具（如凯旋 1200X 凸轮固定工具）
- 自己没做过，第一次不敢下手

## 6.4 火花塞（核心部件）

### 6.4.1 火花塞做什么 ★★★

点火。火花塞在燃烧室顶端，火花塞跳火 → 点燃混合气 → 爆炸。

点火系统怎么工作的：
```
ECU / CDI（行车电脑）
  ↓ 发指令
点火线圈（升压变压器，把 12V 变成 10000-30000V）
  ↓ 高压电
火花塞
  ↓ 电极跳火
点燃混合气
```

### 6.4.2 火花塞长什么样

```
[接线端子] ← 接点火线圈的高压线
     ↓
[陶瓷绝缘体] ← 白色陶瓷部分，耐高压、散热
     ↓
[中心电极] ← 接高压电
     ↓
[火花间隙] ← 电极之间放电的距离
     ↓
[侧电极（搭铁）] ← 接发动机壳体，地线
     ↓
[外壳螺纹] ← 拧进缸盖
```

### 6.4.3 关键参数

| 参数 | 含义 | 常见值 |
|------|------|--------|
| 螺纹直径 | 安装螺纹规格 | 10 / 12 / 14 mm |
| 六角对边 | 拆装时套筒规格 | 16 / 21 mm |
| 火花间隙 | 电极间距离 | 0.6-0.9 mm |
| 热值 | 散热能力 | 按原厂型号；不同品牌编号规则不同 |
| 材质 | 电极材质 | 铜/铂金/铱金 |

### 6.4.4 火花塞热值怎么选 ★★★

热值是火花塞的散热能力。以 NGK 等常见品牌为例，编号越大通常越冷；但不同品牌的编号体系不能直接互换，必须按厂家手册或火花塞厂商目录选型。

【严重警告】 **严重警告**：热值必须按厂家规定。不要为了"提升动力"擅自换更冷或更热的火花塞。热值过热可能导致早燃、电极过热；热值过冷可能积碳、失火。两者都可能损坏发动机。

【经验】 **老师傅经验**：火花塞盒子上有型号，型号里有热值代号。比如 NGK CR9E，**9 就是热值**。**数字 = 散热等级**，但不同品牌的"数字"不能直接比较——NGK 的 9 等于 Denso 的 9 还是多少，**两家算法不一样**。

### 6.4.5 火花塞材质怎么选 ★★

| 材质 | 典型寿命（行业共识） | 价格 | 适合 |
|------|---------|------|------|
| 镍铜合金 | 15,000-25,000 km | 低 | 老车、低预算 |
| 铂金 | 40,000-60,000 km | 中 | 街车主力 |
| 铱金 | 60,000-100,000 km | 高 | 现代高性能车 |
| 双铱金/铱铂金 | 100,000+ km | 最高 | 顶配 |

【来源】 **数据来源等级**：★（行业典型寿命，**实际受工况影响很大**——短途代步烧机油车寿命减半）。

【问答】 **新手问答**：贵的就是好吗？

答：寿命长是肯定的，但**除非你的车原厂就用贵的火花塞**，否则不要自己升级。贵火花塞的电极直径细（铱金 0.4mm vs 铜 2.5mm），点火能量集中，但**如果原车点火系统设计是按铜火花塞来的**，换铱金反而可能点火不好。

【经验】 **老师傅经验**：原厂型号是最可靠的起点。副厂火花塞可以用，但必须按原厂等价型号或火花塞厂商目录确认热值、电极材质、间隙、螺纹长度、六角对边和电阻结构。新手不要凭"升级"宣传改型号。

### 6.4.5.1 火花塞型号解读（新手必看）★★

**这是新手最容易搞错的部分**——看着包装上的一串字母数字，不知道什么意思。

### NGK 型号解读（**最常用**）★★

NGK 火花塞型号一般由 **4-5 段**组成。

**示例**：`NGK CR9E` 或 `NGK SILMAR9C9`（凯旋 1200X）

**拆解 CR9E**：

```
C - 螺纹直径（C=10mm, D=12mm, B=14mm）
R - 结构（R=电阻型, 抑制电磁干扰）
9 - 热值（5=热 → 10=冷，**数字越大越冷**）
E - 螺纹长度（E=19mm, H=12.7mm）
```

**完整型号示例**：

| 型号 | 含义 |
|------|------|
| NGK **BPR6ES** | 14mm 螺纹 / 凸出型 / 电阻 / 热值 6 / 19mm |
| NGK **CR9E** | 10mm 螺纹 / 电阻 / 热值 9 / 19mm |
| NGK **SILMAR9C9** | 凯旋 1200X 用 / 铱金 / 电阻 / 热值 9 / 螺纹 19mm |
| NGK **LMAR8A-9** | 凯旋 Scrambler 1200X 用 / 铂金 / 热值 8 / 间隙 0.9mm |

【来源】 **数据来源等级**：★★（基于 NGK 通用命名规则，**具体车型按说明书**）。

### Denso 型号解读

**示例**：`Denso IU24` 或 `Denso IXU27`

```
I - 铱金（IX = 双铱金, U = 凸出型）
U - 凸出电极结构
24 - 热值（**和 NGK 相反**——24=冷，16=热）
```

**重要**：Denso 和 NGK 的热值编号尺度不同，不能直接拿数字相等来替代。跨品牌替换必须查官方对照表或车型目录。

**粗略换算**：

| NGK 热值 | Denso 热值（粗略） |
|---------|-------------------|
| NGK 6 | Denso 20 |
| NGK 7 | Denso 22 |
| NGK 8 | Denso 24 |
| NGK 9 | Denso 27 |
| NGK 10 | Denso 30 |

【注意】 **不同品牌的热值不能直接比较**——这是老师傅的常识，**很多新手不知道**。

### Champion 型号解读

**示例**：`Champion RA8HC`

```
R - 电阻型
A - 凸出电极
8 - 热值（5=热 → 12=冷）
H - 螺纹长度（H=12.7mm）
C - 六角对边（C=16mm, F=21mm）
```

【来源】 **数据来源等级**：★★（基于 Champion 通用命名规则）。

### 三家型号对照（**这是老师傅的"暗语"**）

**同样适用本田 CB500F 的火花塞**（NGK / Denso / Champion 等价型号）：

| NGK | Denso | Champion | 备注 |
|-----|-------|----------|------|
| CR9E | IU24 | RA8HC | 本田常用 |
| LMAR8A-9 | — | — | 凯旋常用 |
| BPR6ES | W20EPR-U | RN9YC | 老车常用 |

【注意】 **重要**：**等价型号只是大致相当**，**间隙可能不同**。**换型号前必查间隙**。

【经验】 **老师傅经验**：
- NGK、Denso、Champion 都有大量车型配套应用
- 有些车型允许多个等价型号，但必须查车型目录
- 三者热值不能直接按数字对比，这是新手换火花塞最容易搞错的

### 火花塞型号不一致时的处理

**如果你不确定型号**：
1. 拆下旧火花塞（**记住方向和位置**）
2. 看旧火花塞型号（**侧面打印**）
3. **买完全一样的型号**——**不要"升级"**

**如果型号相同但间隙不同**：
- 查说明书确认间隙值
- 用圆形塞尺测量
- 用专用工具调整（**不要用钳子掰中心电极**——会断）

【严重警告】 **严重警告**：**火花塞型号不一致是新手最常犯的错**：
- ✗ 用了**不同热值**的火花塞 = 过热/积碳
- ✗ 用了**不同长度**的火花塞 = 凸出燃烧室顶活塞 / 损坏电极
- ✗ 用了**不同直径**的火花塞 = 装不上
- ✗ 用了**不同电阻**的火花塞 = ECU 报警 / 干扰电子设备

【问答】 **新手问答**：**"升级到铱金火花塞可以吗？"**

答：
- 如果**原厂就是铱金** = **直接买同型号正品**（NGK SILMAR9C9 等）
- 如果**原厂是铜/铂金** = **想升级可以**（**热值必须一样**）
- **不要随便"升级"**——**热值不匹配会损坏发动机**

### 6.4.6 火花塞间隙 ★★

| 类型 | 间隙 |
|------|------|
| 普通街车 | 0.6-0.7mm |
| 中端 | 0.7-0.8mm |
| 高性能 | 0.8-0.9mm |
| 赛车 | 0.9-1.0mm |

【来源】 **数据来源等级**：★（行业典型范围，**你的车具体值查说明书**）。

**怎么测**：用圆形塞尺（圆形塞片刚好卡进间隙），或者用普通塞尺片轻轻塞进去测。

**怎么调**：轻轻掰侧电极。注意力度均匀，不要掰中心电极（中心电极和陶瓷是封死的，掰会损坏）。

【经验】 **老师傅经验**：调间隙时**用硬币或专用工具掰**。钳子太粗会夹伤电极，金属屑掉进电极间——这粒金属屑烧红后会黏在电极上，火花塞就废了。

### 6.4.7 看火花塞判断故障（这是真功夫） ★★★

拆下火花塞，看颜色：

| 颜色 | 含义 | 处理 |
|------|------|------|
| 浅褐色/浅灰色 | 正常 | 无需处理 |
| 黑色、湿 | 混合气过浓 | 检查空滤、喷油嘴、油压 |
| 黑色、干 | 积碳 | 长期低速、烧机油 |
| 白色 | 混合气过稀 | 检查进气漏气、油压低、喷油嘴堵 |
| 油糊状 | 烧机油 | 活塞环、气门油封 |
| 灰白、过干 | 过热 | 点火提前角、散热 |
| 中心电极熔化 | 爆震 | 检查点火、辛烷值 |
| 电极烧蚀 | 寿命到 | 更换 |

【维修】 **维修场景**：火花塞是黑的

```
症状：怠速不稳、加速无力、油耗高、尾气黑
可能原因：
1. 空气滤芯堵了（最常见）
2. 喷油嘴漏油
3. 燃油压力调节器坏
4. 浮子室油位高（化油器车型）
5. 长期怠速/低速行驶（短途代步常见）
6. 点火弱（高压线、点火线圈）

诊断步骤：
1. 先换空滤（最便宜）
2. 测燃油压力
3. 检查喷油嘴
4. 检查点火系统

【费用】 省钱贴士：换火花塞前先检查空滤。很多时候火花塞变黑不是火花塞的锅。
```

【经验】 **老师傅经验**：看火花塞要**看四个缸的对比**。如果**一缸独黑、其他正常**，那是这缸的问题（喷油嘴、气缸压力）；如果**四缸全黑**，那是共性问题（空滤、油压、ECU）。**对比是诊断的金标准**。

### 6.4.8 更换火花塞（详细步骤）★★★

**这是车主最常做的维修，自己来**。

**步骤**：
```
1. 冷车 30 分钟（重要！热车拆会损坏缸盖螺纹）
2. 准备工具：火花塞套筒、扭力扳手、新火花塞
3. 拆座椅或边盖（如需要，挡住火花塞的话）
4. 拔火花塞帽（抓住帽拔，不要拉线！）
5. 用火花塞套筒逆时针旋转，拆下旧火花塞
6. 检查旧火花塞颜色（判断发动机状态）
7. 检查新火花塞间隙（用圆形塞尺）
8. 手动把新火花塞拧入几圈（顺时针）
9. 确认手感顺滑（螺纹对正，没错牙）
10. 用扭力扳手拧到规定扭矩
11. 装回火花塞帽（听到"咔哒"声）
12. 启动测试
```

**NGK 火花塞扭矩通用参考** ★★（**不同车型可能不同，务必查手册**）：

| 火花塞规格 | 平座型扭矩 |
|-----------|------|
| 10mm 螺纹 | 10-12 Nm |
| 12mm 螺纹 | 15-25 Nm |
| 14mm 螺纹 | 25-35 Nm |
| 18mm 螺纹 | 35-45 Nm |

【来源】 **数据来源等级**：★★（基于 NGK 技术文档通用规范）。**锥座型火花塞**（带垫圈锥面密封的）扭矩要降低 30-40%。

【严重警告】 **严重警告**：
- **不要**用套筒紧死！螺纹会损坏，要换缸盖。
- **不要**热车拆！螺纹热胀冷缩会咬死。
- **不要**让杂物掉进火花塞孔！掉进缸里就完了。

【经验】 **老师傅经验**：装火花塞前**用压缩空气吹一下火花塞孔**。这一下能避免 50% 的"杂物掉进缸里"事故。**那粒小沙子看着没事，跑到活塞顶上能磨出划痕**。

【维修】 **维修场景**：自己换火花塞全过程
```
工具：火花塞套筒（16 或 21mm，看车）、扭力扳手、新火花塞

1. 冷车 30 分钟
2. 拆座椅（部分车型需要）
3. 拔火花塞帽（抓帽不抓线）
4. 套筒逆时针拆旧火花塞
5. 看旧火花塞颜色（健康检查）
6. 检查新火花塞间隙
7. 手动拧入新火花塞几圈
8. 扭力扳手拧到规定扭矩
9. 装火花塞帽（咔哒）
10. 启动测试

用时：30-60 分钟
费用：火花塞 30-150 元/个
```

【口诀】 **记忆口诀**：**冷车拆、手动拧、扭力扳手、用对型号**。

【费用】 **省钱贴士**：火花塞套装（4 缸 4 个）网上买通常 100-400 元。4S 店单这一项要收 200-500 工时。

【送修】 **该送修了**：
- 火花塞拧不下来（螺纹咬死，需要专用工具拆）
- 火花塞掉进缸里了（必须拆缸盖取）
- 火花塞拧到底漏气（螺纹损坏，要修缸盖）

## 6.5 缸盖维修（进阶技能）

### 6.5.1 缸盖是什么

缸盖是发动机的"头"，里面装着：
- 气门（进气门、排气门）
- 气门弹簧
- 气门导管（引导气门上下）
- 气门座（气门密封的接触面）
- 凸轮轴（如果是顶置凸轮）
- 燃烧室（混合气燃烧的地方）

缸盖和缸体之间是**缸垫**，密封油道、水道、气道。

### 6.5.2 什么时候要拆缸盖

- 烧缸垫（冷却液进油道、排气冒白烟）
- 缸盖变形漏气
- 换气门油封
- 换气门
- 修气门座
- 镗缸换活塞
- 大修发动机

### 6.5.3 拆缸盖步骤

**这一步要小心**。

#### 准备
```
1. 冷车（30 分钟以上，最好完全冷却）
2. 拔电瓶负极
3. 准备工具、零件盒、相机（拍照记录每一步）
4. 准备专用工具（如凯旋 1200X 的凸轮轴固定工具）
```

#### 放冷却液（水冷车型）
```
1. 找到放水螺丝（在缸体下侧或水泵处）
2. 准备容器
3. 拆散热器盖（让空气进入）
4. 打开放水螺丝
5. 等冷却液流尽
6. 检查是否流干净
```

#### 拆外部连接
```
1. 拆油管/水管（拍照、标记位置）
2. 拆进气管、排气管（标记位置）
3. 拆各种传感器插头（标记！）
4. 拆火花塞
5. 拆正时链条盖（如需要）
```

【注意】 **重要**：拆下来的东西一定要**标记**。传感器、油管、水管接头位置不能搞混。**拍照最保险**。

【经验】 **老师傅经验**：拆之前**画一张接线图**，每个插头标号。复装时按图对接，**新手最快的方法**。**靠记忆复装，10 次有 3 次装错**。

#### 找正时
```
1. 转动曲轴到 1 缸 TDC
2. 检查正时标记对正
3. 用专用工具固定曲轴和凸轮轴
4. 确认正时正确
```

【严重警告】 **不固定正时**：装回去可能错位，活塞和气门撞上。

#### 拆凸轮轴
```
1. 拆凸轮轴支架螺丝（对角顺序松）
2. 多次松（不要一次松到底）
3. 取下凸轮轴（注意弹簧的张力）
4. 取下挺柱/垫片（每个单独放，标记位置！）
5. 标记凸轮轴方向
```

#### 拆缸盖
```
1. 拆缸盖螺丝（对角顺序松）
2. 多次松（不要一次松到底）
3. 取下缸盖（注意气门不要脱落丢失）
4. 取下缸垫（报废，必须换新）
5. 清洁缸盖接触面（塑料刮刀，不要金属刀）
```

【严重警告】 **严重警告**：拆缸盖属于发动机大修范围。正常情况下气门由弹簧座和锁片固定，不会因为取下缸盖就弹出；但缸盖总成沉重、定位销和链条导轨容易卡住，不能撬伤结合面，必须按维修手册顺序操作。

【经验】 **经验提示**：气门弹簧压缩工具用于分解缸盖、拆气门锁片和气门，不是拆缸盖前的固定工具。需要拆气门时，把缸盖放在工作台上再用专用工具操作，并标记每个气门、弹簧和挺柱位置。

### 6.5.4 缸盖检查

**这是判断能不能继续用的关键**。

| 项目 | 方法 | 标准 |
|------|------|------|
| 平面度 | 直尺+塞尺 | < 0.05 mm |
| 燃烧室积碳 | 目视 | 清除 |
| 气门座 | 目视 | 良好接触 |
| 气门导管间隙 | 塞规/百分表 | 见手册 |
| 缸盖裂纹 | 渗透检测 | 无裂纹 |
| 火花塞孔 | 目视 | 螺纹完好 |

**平面度检查方法**：
```
1. 把直尺放在缸盖平面（两个方向都放）
2. 用塞尺测试直尺和缸盖之间最大缝隙
3. 缝隙厚度 = 平面度偏差
```

**平面度处理**：
- < 0.05 mm：直接用
- 0.05-0.10 mm：研磨（送到机加工店）
- > 0.10 mm：报废换新

【经验】 **老师傅经验**：平面度检查**至少量两个方向**（前后、左右），最好加两个对角线方向。**变形是不均匀的**，一个方向准不代表整个面平。

### 6.5.5 装缸盖步骤（详细）

#### 清洁
```
1. 清洁缸体平面（塑料刮刀）
2. 清洁缸盖平面
3. 清洁缸盖螺栓孔（压缩空气吹）
4. 检查定位销是否在位
```

**不要**让任何杂物进入气缸。哪怕一小颗螺丝垫片，掉进去就要拆发动机重做。

#### 装气门（如拆了）
```
1. 装气门油封（新件）
2. 装气门（涂机油）
3. 装弹簧、座
4. 用专用工具压缩弹簧
5. 装气门卡簧（两个半圆，要装牢）
6. 释放弹簧
7. 轻轻敲气门顶部（确认就位）
```

【严重警告】 **严重警告**：气门卡簧没装牢的话，气门会**掉进缸里**——后果是发动机报废。

【经验】 **老师傅经验**：装气门卡簧时**用黄油粘**。先在卡簧槽里挤一点黄油，把卡簧往黄油里一按——黄油的粘性会防止卡簧脱落。**这是修车老师傅的秘传**。

#### 装新缸垫
```
1. 确认方向（有"TOP"或"上"标记的一面朝上）
2. 对准定位销
3. 不要用密封胶（除非厂家特别说明）
4. 不要重复使用旧缸垫
```

【经验】 **老师傅经验**：缸垫**只能用一次**。哪怕看上去"还好"，装回去十有八九漏气。**省这几十元，赔上的是几百元工时**。

#### 装缸盖
```
1. 小心放下缸盖（对准定位销）
2. 装入缸盖螺丝
3. 手动拧入几圈（确认螺纹顺滑）
```

#### 紧固缸盖螺丝（这是最关键的一步）

**通用原则**：
```
1. 对角顺序分多次紧
2. 一般分 3-4 次达到规定扭矩
3. 部分车型最后还要转角度（如 90°）
```

**常见车型的缸盖螺丝工艺**（**具体查手册**）：

| 车型 | 工艺（基于 AI 训练数据） |
|------|--------|
| 凯旋 1200X | 第一遍 20Nm → 第二遍 40Nm → 再转 90°角度 |
| 本田 CBR1000RR | 第一遍 30Nm → 再转 90°角度 |
| 雅马哈 MT-07 | 多次分步 + 角度法 |

【来源】 **数据来源等级**：★（AI 训练数据，**用前查厂家手册**）。

【严重警告】 **严重警告**：
- 缸盖螺丝紧固**必须按扭矩+角度**。
- 过松：缸垫漏气、漏水、漏油
- 过紧：缸盖变形、螺丝断裂
- 顺序错：缸盖翘曲变形

【经验】 **老师傅经验**：缸盖螺丝紧固**最容易翻车**——肉眼看不到扭矩对不对。**唯一可靠的方法是用扭力扳手 + 扭角扳手**。**没有扭角扳手？去买一个**——发动机大修一次几千上万，一个扭角扳手几百元，**值**。

#### 装凸轮轴
```
1. 涂凸轮轴油
2. 装入凸轮轴（注意方向、标记）
3. 安装支架
4. 手动拧螺丝
5. 按扭矩紧固（一般 10-15 Nm，对角顺序）
6. 确认正时
```

#### 调整气门间隙
见 6.3 节。

#### 装回外部件
反向装回。注意所有扭矩、所有标记。

#### 加冷却液
```
1. 关闭放水螺丝
2. 加注冷却液（从散热器口加）
3. 启动发动机（开盖状态）
4. 等节温器打开、液位下降
5. 继续加，直到液位稳定
6. 关闭散热器盖
7. 检查副水箱液位
8. 检查泄漏
```

#### 测试
```
1. 启动发动机
2. 听异响
3. 看水温
4. 看是否漏油/水
5. 短距离试骑
```

### 6.5.6 缸盖常见故障

| 故障 | 症状 | 处理 |
|------|------|------|
| 缸垫漏 | 冷却液进油道（油面升高）、排气冒白烟、冷却液冒气泡 | 换缸垫 |
| 缸盖变形 | 漏气、漏水 | 研磨或更换 |
| 气门烧蚀 | 动力下降、异响 | 更换气门 |
| 气门油封老化 | 烧机油（冒蓝烟） | 更换油封 |
| 凸轮轴磨损 | 异响、动力下降 | 更换凸轮轴 |
| 气门弹簧失效 | 异响、动力下降 | 更换弹簧 |

【送修】 **该送修了**：
- 拆缸盖这种活**新手第一次建议送修**。
- 自己能做的是换火花塞、调气门、换机油、换冷却液。
- 缸盖维修需要专用工具（凸轮轴固定工具、扭角扳手等）、经验和判断。

## 6.6 活塞与气缸（基础认知）

### 6.6.1 活塞是什么

活塞是一个金属圆柱体，在气缸里上下跑，把燃烧的力传给曲轴。

```
[活塞顶]            ← 接触高温气体
[活塞环槽]          ← 装活塞环
[活塞销孔]          ← 装活塞销
[活塞裙部]          ← 和气缸壁接触
```

**活塞环**（一般 2-3 道）：
- **第一道气环**（顶部）：密封气体
- **第二道气环**（中间）：辅助密封
- **油环**（底部）：刮油，防止机油进燃烧室

### 6.6.2 活塞材质

- **铝合金**（主流）：轻、散热好
- **铸铁**（少数）：耐磨，但重

### 6.6.3 活塞环检查（烧机油时必查）

**端隙**（活塞环放进气缸后，端口的间隙）：
```
1. 把活塞环放进气缸
2. 用活塞头推平（保证环水平）
3. 用塞尺测端隙
4. 标准见手册
```

- 端隙过大 = 环磨损
- 端隙过小 = 受热膨胀会卡死

**侧隙**（环和环槽之间的间隙）：
```
1. 测环厚（千分尺）
2. 测环槽深度（深度尺）
3. 侧隙 = 环槽深度 - 环厚
```

### 6.6.4 什么时候要镗缸换环

- 气缸磨损（量缸径，超出标准）
- 活塞环端隙过大
- 动力下降
- 烧机油严重（环和缸壁都磨了）

**镗缸**：
```
1. 拆发动机
2. 拆缸体
3. 量缸径（多个位置、垂直/水平方向都量）
4. 算出磨损量
5. 镗缸（专业设备，送到机加工店）
6. 买对应尺寸的新活塞（加大活塞）
7. 装新活塞环
8. 装回发动机
```

【送修】 **该送修了**：镗缸是**专业活**，普通车主做不了。送到有镗缸设备的修理店，价格 500-2000 元（看缸数和精度要求）。

### 6.6.5 活塞拆装（专业）

**拆**：
```
1. 拆缸体
2. 拆活塞销卡簧
3. 推出活塞销（用铜棒轻敲）
4. 取下活塞
5. 拆活塞环（用专用工具，或徒手小心张开）
6. 标记（哪个缸）
```

**装**：
```
1. 装活塞环
   - 第一道气环（最上面）
   - 第二道气环
   - 油环（一般是组合式，多片）
2. 环口错开 120°（避免窜气）
3. 注意环的方向（部分环有"上"标记）
4. 用活塞环压缩器把活塞装入气缸
5. 装活塞销
6. 装卡簧
```

【维修】 **维修场景**：发动机烧机油
```
症状：排气管冒蓝烟、机油消耗快、怠速冒烟

可能原因：
1. 活塞环磨损（最常见）
2. 气门油封老化（特别是冷车冒蓝烟，热车消失）
3. 缸体磨损（动力也下降）

诊断步骤：
1. 测气缸压力（见 6.11 节）
2. 拆火花塞看（油糊 = 烧机油）
3. 看尾气颜色（蓝烟 = 烧机油）
4. 检查气门油封（拆缸盖才能确认）

处理：
- 活塞环问题：换环或镗缸
- 气门油封：换油封（不用镗缸，便宜很多）
- 缸体磨损：镗缸+换活塞+换环

【费用】 省钱贴士：换油封比镗缸便宜 70%。先判断是哪个问题再修。
```

## 6.7 配气机构维修

### 6.7.1 凸轮轴检查

**检查项目**：
```
1. 凸轮磨损（看表面，光滑无剥落）
2. 轴颈直径（千分尺）
3. 凸轮高度（高度尺，对比标准）
4. 轴向间隙（塞尺）
```

**凸轮磨损的症状**：
- 异响（特别是启动时）
- 动力下降
- 怠速不稳
- 配气相位不准

### 6.7.2 摇臂与挺柱

**摇臂**：从凸轮到气门的传力件，一端有调整螺钉（如果有的话）。

**挺柱**：凸轮和摇臂之间的传力件。

**液压挺柱**（部分现代车）：
- 机油压力自动调整气门间隙
- 不用手动调
- 损坏需要整套更换
- 故障时会有"哒哒"声

【经验】 **老师傅经验**：液压挺柱出问题**别急着拆**。先换机油（用对规格的），让车怠速 5 分钟，再听。如果还响才是挺柱坏了。**90% 的"哒哒"声其实是机油问题**——太稀、太脏、压力不够。

### 6.7.3 正时链条维修 ★★★

**正时链条**是发动机里**最关键的传动件**之一——断了正时乱，**气门和活塞会撞**，发动机报废。

**什么时候要检查**：
- 3-6 万 km 看情况
- 异响（链条响）
- 张紧器失效（链条松）
- 启动困难

**检查方法**：
```
1. 拆正时盖
2. 看链条伸长量
3. 看链轮齿是否磨损
4. 看张紧器是否还能工作
```

**更换步骤**（专业活）：
```
1. 拆发动机（或部分车型可车上做）
2. 拆正时盖
3. 转到 TDC，固定曲轴和凸轮轴
4. 拆张紧器（按对角松）
5. 拆旧链条
6. 装新链条（注意正时标记对正）
7. 装新张紧器
8. 检查正时（多处标记）
9. 装回
```

【严重警告】 **严重警告**：
- 正时链条断了或跳过齿，**气门会撞活塞**，维修费几千到上万。
- **必须**按周期检查/更换。

**正时皮带**（部分车型）：
- 寿命：3-6 万 km
- 到期必须换，**断了必坏发动机**
- 比链条安静，但寿命短

【费用】 **省钱贴士**：自己换正时链条工时费 500-1500 元；4S 店/修理店 1500-4000 元。但**没经验不建议自己干**——错了就毁发动机。

【送修】 **该送修了**：正时链条维修几乎都要送修。需要专用工具（飞轮固定、凸轮轴对正工具）和经验。

### 6.7.4 张紧器

**张紧器**自动保持链条/皮带的张紧度。

**故障表现**：
- 链条异响（"哗啦哗啦"）
- 链条明显松弛
- 配气相位偏移

**处理**：更换张紧器。一般和链条一起换。

【经验】 **老师傅经验**：**张紧器、链条、导板**这三个是一套的。**只换链条不换张紧器 = 半年后又松**。三件一起换，**多花几百元省几千工时**。

## 6.8 润滑系统

### 6.8.1 润滑系统干什么的

发动机里有很多高速运动的金属部件（曲轴、连杆、凸轮、气门等）。没有油润滑，**几分钟就报废**。

润滑系统组成：
```
[油底壳] → 储存机油
    ↓
[机油泵] → 把机油泵出去
    ↓
[机油滤芯] → 过滤杂质
    ↓
[油道] → 把油送到各个部位
    ↓
[曲轴/凸轮/气门...] → 被润滑
    ↓
[回油] → 回到油底壳
```

### 6.8.2 机油泵

**类型**：
- 齿轮泵（大部分）
- 转子泵（一些车）
- 活塞泵（少数）

**故障表现**：机油压力低、警告灯亮。

**检查**：拆下看磨损，测间隙。

**【送修】 该送修了**：机油泵坏了基本要送修。

### 6.8.3 机油滤芯

**位置**：
- 外部（可换，大部分车）
- 内部（不可换，少数老车）
- 油道里（一次性滤网）

**更换周期**：5000-10000 km（看车）。

**更换步骤**：
```
1. 准备容器
2. 用滤芯扳手拆旧滤芯
3. 清洁接触面
4. 新滤芯密封圈涂新机油
5. 手动紧固（不要用扳手死拧！）
6. 启动检查
```

【严重警告】 **常见错误**：用扳手死拧滤芯。**下次拆不下来**——扳手要紧到拧不动后再多拧 3/4 圈。

【经验】 **老师傅经验**：新滤芯**装之前先灌满机油**（如果滤芯是立式安装的）。这样第一次启动时油道不会缺空气。**卧式滤芯不需要灌**，看你的车型。

### 6.8.3.1 机滤技术规格（新手必看）★★

**这是新手最常买错的零件之一**——看着外形差不多就买，结果**装不上**或**滤纸不行**。

### 机滤的三大核心组件

**机滤看着简单，其实有 4 个关键部件**——**任何一个坏了，机滤就失效**：

1. **滤纸**（滤芯）：**过滤机油的金属碎屑**
2. **旁通阀**（By-Pass Valve）：**滤芯堵了时让油绕过**
3. **逆止阀**（Anti-Drainback Valve）：**停车时防止油回流**
4. **外壳**（金属壳）：**承受压力 + 密封**

【严重警告】 **为什么要懂这三个**：

- **滤纸太差** = **金属屑进入发动机** = **磨损**
- **旁通阀压力不对** = **滤芯堵了不绕行** = **油路堵塞**
- **逆止阀失效** = **停车后油漏回油底壳** = **冷启动磨损**

### 旁通阀（By-Pass Valve）★★

**作用**：**滤芯堵塞时**，让机油**绕过滤芯直接到发动机**。

**触发压力**：一般 **0.8-1.5 bar**（不同滤芯不同）

**为什么要有旁通阀**：
- 滤芯堵塞时，**继续走滤芯 = 油路断流** = **润滑失败** = **抱瓦**
- 旁通阀打开 = **绕过滤芯** = **润滑不中断** = **滤纸牺牲但发动机保命**

【经验】 **老师傅经验**：**便宜的机滤 = 旁通阀压力不准**。**太早打开 = 滤芯没发挥作用**。**太晚打开 = 油路堵塞**。**正品机滤** = **旁通阀压力精确**。

### 逆止阀（Anti-Drainback Valve）

**作用**：**停车后防止机油从滤芯漏回油底壳**。

**为什么重要**：
- 摩托车经常**侧倾停车**——机油可能漏出
- 漏了 = **下次启动前油道是空的**
- 干启动 = **磨损**（启动瞬间 80% 的发动机磨损来自冷启动）

【经验】 **老师傅经验**：便宜机滤的逆止阀和旁通阀一致性可能较差。不要用"机油窗气泡"判断逆止阀好坏；更可靠的做法是按原厂滤芯型号选正品，冷启动后若长时间机油压力报警或异响，应立即熄火检查。

### 滤纸材质

| 材质 | 特点 | 价格 |
|------|------|------|
| **纤维素** | 普通、便宜、过滤效率 95% | 低 |
| **合成纤维** | 过滤效率 99%、寿命长 | 中 |
| **玻璃纤维** | 高端、抗高温、长寿命 | 高 |

【来源】 **数据来源等级**：★（行业典型范围，**具体看品牌技术参数**）。

### 常见机滤品牌（正品）

**正品**（推荐）：
- **Mahle（马勒）**：德国老牌，OEM 供应商
- **Bosch（博世）**：德系强势品牌
- **Mann-Filter（曼牌）**：德系 OEM
- **Hengst（汉格斯特）**：德系
- **WIX**：美系
- **FRAM**：美系
- **K&N**：美系高端
- **Purolator**：美系老牌
- **本田原厂**：日系车 OEM
- **丰田原厂**：日系 OEM
- **GS（吉田）/ 汤浅**：日系
- **豹王/索菲玛**：国产中端

**假冒重灾区**（**避免买**）：
- 不知名品牌**价格特别低**的 = 假货高发
- **没有防伪码**的 = **高风险**
- **包装粗糙**的 = **高风险**

### 机滤选型速查

**最可靠的选法**：
1. **查说明书**看 OEM 滤芯型号
2. **买正品**对应的 OEM 滤芯
3. **不要买副厂"通用"滤芯**

**车友口诀**：
- **原厂用什么 = 你用什么**
- **副厂正品（如 Mahle、Bosch）= 可以用**
- **杂牌便宜货 = 赌运气**

【经验】 **老师傅经验**：**机滤省钱 30 元/次 = 赌发动机几千到几万**。**机滤不要省**。

### 6.8.3.2 机油技术规格详解（新手必看）★★

**机油看着一样，其实内部学问很深**——这一节是老师傅的"扫盲课"。

### 基础油分类（API 1509 / ATIEL 标准）

**基础油决定机油的本质性能**。行业按加工深度分为 5 类：

| 类别 | 加工方法 | 性能 | 成本 |
|------|---------|------|------|
| **I 类** | 传统溶剂精制 | 一般 | 低 |
| **II 类** | 加氢处理 | 较好 | 中 |
| **III 类** | 高度加氢（**VHVI**） | 很好 | 中高 |
| **IV 类** | **PAO 合成** | 优秀 | 高 |
| **V 类** | **酯类** 等特殊合成 | 顶级 | 最高 |

【来源】 **数据来源等级**：★★（API 1509 / ATIEL 工业标准）。

**对应市场产品**：

- **矿物油** = I/II 类基础油 + 添加剂
- **半合成** = III 类为主 + 部分 II 类 + 添加剂
- **全合成** = IV/V 类基础油 + 添加剂

【注意】 **重要**：**"全合成"标签在不同厂家含义不同**——美孚全合成（Mobil 1）= PAO 真正合成；某些国产品牌"全合成" = III 类基础油（仍是**加氢矿物油**）。

### 粘度指数（VI, Viscosity Index）★★

**什么是粘度指数**：机油粘度随温度变化的稳定性指标。**VI 越高 = 温度变化时粘度越稳定**。

| VI 值 | 通俗理解 |
|------|------|
| 较低 | 温度变化时粘度变化较大 |
| 较高 | 温度变化时粘度更稳定 |

【来源】 **数据来源等级**：★★（基于 ASTM D2270 标准）。

【经验】 **老师傅经验**：VI 只是机油性能指标之一，不能单独用来判断矿物油、半合成或全合成。选摩托车机油优先看说明书要求的 SAE 粘度、API/JASO 等级、湿式离合兼容性和正规渠道。

### 机油添加剂功能详解 ★★

**机油 = 基础油 + 添加剂**。添加剂决定了**机油的特殊性能**。

| 添加剂 | 作用 | 比例 |
|--------|------|------|
| **抗磨剂**（ZDDP 等） | 减少金属摩擦 | 主要 |
| **清净剂**（金属盐） | 清洗油泥积碳 | 主要 |
| **分散剂**（聚合物） | 让污染物悬浮 | 主要 |
| **抗氧化剂** | 延缓机油氧化 | 主要 |
| **粘度指数改进剂**（VII） | 提高粘度指数 | 主要 |
| **防锈剂** | 防止金属锈蚀 | 少量 |
| **抗泡剂**（硅油） | 防止泡沫 | 少量 |
| **降凝剂**（PMA） | 降低凝固点 | 少量 |
| **抗乳化剂** | 防止水分乳化 | 少量 |
| **摩擦改进剂**（有机钼） | 进一步降低摩擦 | 微量 |

【来源】 **数据来源等级**：★（行业共识，**具体配比厂家不公开**）。

【注意】 **注意**：
- **ZDDP（抗磨剂）**含磷——**会毒害触媒**——**有触媒的车要用低硫低磷配方**
- **有机钼摩擦改进剂**——好但**贵**——全合成才有
- **抗乳化剂**——摩托车常用——**涉水后油乳化** = **该换油**

### 真假机油识别（**这是老师傅的"防忽悠指南"**）★★

**市场上假机油确实存在**，但比例会随品牌、渠道和地区变化，不能只靠传闻判断。

**如何识别**：

**1. 价格判断**：
- 明显低于正规渠道常见价格 → 高风险
- 包装、批号、防伪信息和渠道互相对不上 → 高风险
- 无法提供正规发票或授权渠道信息 → 高风险

**2. 包装判断**：
- 防伪码**扫不出来** → 假
- 防伪码**重复出现** → 假
- 包装**印刷模糊** → 假
- 包装**油渍、漏封** → 假

**3. 内容判断**：
- 颜色**异常深或异常浅** → 假
- 气味**刺鼻** → 假
- 流动性**异常稀或稠** → 假
- **有沉淀物** → 假

**4. 官网验证**：
- 找包装上的防伪码
- 官方 APP 扫描
- 官方电话查询

【经验】 **老师傅经验**：
- 不要只按平台判断真假，关键看店铺授权、批次、防伪和售后
- 过低价格、散装来路不明、"特供油"但查不到来源的，按高风险处理
- 正规授权店、品牌旗舰店、可验证批次和发票，可靠性更高

### 机油粘度选择决策树 ★★

```
你的车什么工况？
├── 街车通勤
│   └── 10W-40 半合成（API SN/SP, JASO MA/MA2）
├── 运动/赛道
│   └── 10W-50 或 15W-50 全合成（API SN+, JASO MA2）
├── 冬季
│   └── 0W-40 或 5W-40 全合成
├── 热带/夏季
│   └── 15W-50 或 20W-50
├── 老车（> 20 年）
│   └── 20W-50 半合成（保护磨损）
├── ADV/越野
│   └── 10W-50 全合成
└── 美式巡航（哈雷等）
    └── 20W-50 半合成/全合成
```

### 6.8.4 机油压力低怎么办

**先排除简单的**：
```
1. 机油量够吗？（看机油窗或机油尺）
2. 用了正确的机油吗？
3. 机油滤芯堵了吗？
4. 有没有漏油？
```

**以上都正常还是低油压**：
- 机油泵磨损
- 油道堵塞
- 轴瓦磨损（这是大修级别的问题）

【送修】 **该送修了**：油压低是大问题，**不要继续骑**——拉缸、曲轴抱死就完蛋了。

### 6.8.5 更换机油（核心技能 2）★★★

**这是车主最常做的保养**。

**步骤**：
```
1. 热车 3-5 分钟（机油流动性好）
2. 关发动机
3. 准备容器（够装 4L）
4. 找到放油螺丝（油底壳底部）
5. 17mm 或 19mm 扳手
6. 容器放到放油螺丝下面
7. 慢慢拧开放油螺丝（注意别烫着）
8. 等机油流尽（10-15 分钟）
9. 拆机油滤芯（滤芯扳手）
10. 清洁接触面
11. 新滤芯密封圈涂新机油
12. 装新滤芯（手动紧固）
13. 装回放油螺丝（带新垫圈，按扭矩）
14. 从加注口加新机油
15. 加到标准量（看机油窗或机油尺）
16. 启动 30 秒
17. 关闭
18. 复检液位
19. 检查是否漏油
```

【经验】 **老师傅经验**：放完机油**不要急着装新油**。先**把放油螺丝和油底壳擦干净**，看看有没有金属屑。**大量金属屑 = 发动机大修前兆**；少量正常磨屑 = 没事；**铁屑+铝屑混合 = 严重内伤**。

**机油规格参考** ★（**用前查说明书**）：
- 凯旋 1200X：10W-40 半合成，约 3.5L（基于 AI 训练数据）
- 雅马哈 MT-07：常见 10W-40，约 2.4L（基于 AI 训练数据）
- 标准：API SG 以上，JASO MA/MA2（湿式离合器需要）

【来源】 **数据来源等级**：★（AI 训练数据，**用前必须查说明书**）。

【费用】 **省钱贴士**：自己换机油 100 元搞定，4S 店 200-500 元。

【送修】 **该送修了**：
- 放油螺丝拧不下来（螺纹咬死）
- 机油里大量金属屑
- 机油压力警告灯亮

## 6.9 冷却系统（水冷）

### 6.9.1 冷却系统组成

```
[水箱（散热器）]
     ↓
[水管]
     ↓ ↑          ← 进水/回水管
[节温器]
     ↓ ↑
[水泵] →
     ↓
[气缸水道] [缸盖水道]
     ↓
[副水箱]    ← 储存冷却液、补偿膨胀
```

**冷却液怎么循环**：
```
1. 水泵推动冷却液
2. 冷却液经过气缸和缸盖（吸热）
3. 冷却液经过节温器
   - 冷车：节温器关闭，走小循环（不经过水箱）
   - 热车：节温器打开，走大循环（经过水箱散热）
4. 冷却液到散热器（散热）
5. 风扇辅助散热
6. 回到水泵
```

### 6.9.2 冷却液

**类型**：

| 类型 | 颜色 | 特点 |
|------|------|------|
| 乙二醇基 | 绿/红/蓝 | 防冻、防腐、长效 |
| 丙二醇基 | 无色 | 环保、低毒 |
| OAT（有机酸） | 橙色 | 长寿命（5 年以上） |

【注意】 **重要**：**不要混用不同类型冷却液**！化学成分冲突会生成胶状物堵塞水道。

**冷却液浓度**：
- 一般 50%（乙二醇:水 = 1:1），防冻到 -35°C
- 极寒地区用 60%

【经验】 **老师傅经验**：**冷却液不能用纯水代替**。纯水沸点 100°C，乙二醇混合液沸点 110-130°C；纯水冰点 0°C，混合液 -35°C；纯水会腐蚀铝制缸体。**短途应急可以加蒸馏水，但事后必须换回冷却液**。

### 6.9.3 节温器

**工作原理**：
- 冷车：节温器关闭，冷却液走小循环 → 快速升温
- 热车：节温器打开，走大循环 → 散热

**开启温度**（行业典型值）：80-90°C
**全开温度**（行业典型值）：95-105°C

【来源】 **数据来源等级**：★（**你的车具体查手册**）。

**检查方法**：
```
1. 拆下节温器
2. 放入冷水中
3. 慢慢加热
4. 看什么时候开始打开
5. 标准：80-90°C 开始打开
```

**故障**：
- 卡死关闭 → 过热
- 卡死打开 → 升温慢、油耗高
- 漏液 → 液位下降

【经验】 **老师傅经验**：判断节温器好坏**别只看温度**。**拆下来在水里看它开不开**——这比装车上测温度更直接。**修车师傅的看家本事**。

### 6.9.4 水泵

**故障表现**：
- 过热
- 漏水（水泵下方滴水）

**检查**：
- 看是否有漏水痕迹
- 转轴是否灵活（拆下后手动转）
- 听异响

**更换**：放冷却液 → 拆水管 → 拆水泵螺丝 → 装新水泵（涂密封胶）→ 装回。

### 6.9.5 散热器

**清洁**：
```
1. 用水冲洗（低压，不要用高压水枪）
2. 用压缩空气吹
3. 必要时用专用清洁剂
```

【严重警告】 **不要用高压水枪**！会损坏散热片。

### 6.9.6 风扇

**故障**：
- 风扇不转 → 过热
- 风扇一直转 → 节温器或温度传感器问题

**检查**：
- 风扇电机是否工作
- 温控开关（一般 95-105°C 接通）
- 继电器
- 保险丝

### 6.9.7 更换冷却液（核心技能 3）★★

**步骤**：
```
1. 冷车
2. 准备容器
3. 找到放水螺丝（缸体下侧）
4. 打开散热器盖（让空气进入）
5. 打开放水螺丝
6. 等流尽
7. 装回放水螺丝
8. 加新冷却液（从散热器口加）
9. 启动发动机
10. 让节温器打开（等水温上升）
11. 液位会下降，继续加
12. 等气泡排出
13. 关闭发动机
14. 装回散热器盖
15. 检查副水箱液位（在 MIN-MAX 之间）
16. 试车
```

【经验】 **老师傅经验**：**加冷却液时不要一次加满**。先加 70%，启动让水循环，再补到 95%，再启动再补。**两次启动后排气比一次加满少很多气泡**。

【费用】 **省钱贴士**：自己换冷却液 50-100 元搞定；4S 店 150-400 元。

【送修】 **该送修了**：
- 冷却液里有油花（缸垫漏）
- 排气管冒大量白烟（缸垫漏或缸盖变形）
- 水温持续偏高（节温器或水泵问题）

### 6.11.3 实战 3：测量气缸压力 ★★★

**工具**：气缸压力表、火花塞套筒。

**步骤**：
```
1. 启动车辆让发动机热
2. 关闭发动机
3. 拆下所有火花塞
4. 拔燃油泵继电器或保险丝（防止启动时着车）
5. 拔喷油嘴插头（同上）
6. 装上气缸压力表（密封好）
7. 捏住节气门（全开）
8. 按启动按钮 5-10 秒
9. 看压力表读数
10. 每个缸都测一遍
11. 装回火花塞、继电器
12. 启动测试
```

**通用缸压标准**（AI 训练数据，**用前查手册**）：

| 状态 | 压力范围（一般） |
|------|----------|
| 正常 | 11-13 bar |
| 轻微磨损 | 9-11 bar |
| 严重磨损 | < 9 bar |

【来源】 **数据来源等级**：★（行业典型值，**不同车型不同**）。

**各缸差异**：
- 各缸差 < 10%：正常
- 差 > 15%：有问题

【经验】 **老师傅经验**：测缸压有**进阶玩法**——**湿缸压测试**。步骤：
1. 测干缸压（活塞没油）
2. 从火花塞孔加一勺机油（约 5ml）
3. 再测一次
4. **缸压上升 1-2 bar = 活塞环磨损**
5. **缸压不变 = 气门或缸垫问题**

这个方法能区分是活塞环坏还是气门坏，**省得你换完环发现是气门问题白干**。

【问答】 **维修场景**：缸压低
```
可能原因：
1. 气门漏气（气门烧蚀、气门座磨损）
2. 活塞环磨损（窜气）
3. 缸垫漏气（缸盖和缸体之间）

诊断：
- 用湿缸压测试法判断（见老师傅经验）
- 缸压升高 = 活塞环问题
- 缸压不变 = 气门或缸垫问题

处理：
- 活塞环：换环或镗缸
- 气门：换气门、修气门座
- 缸垫：换缸垫
```

## 6.12 发动机故障诊断实战

### 6.12.1 案例 1：发动机过热 ★★★

**症状**：
- 水温表到红线
- 故障灯亮
- 动力下降
- 严重时熄火

**诊断流程**：
```
1. 检查冷却液
   - 足量吗？
   - 副水箱液位
   - 地面是否有泄漏（绿色液体）

2. 检查节温器
   - 启动后长时间水温不上升 = 节温器卡死打开
   - 启动后水温快速到红线 = 节温器卡死关闭

3. 检查水泵
   - 漏水吗？（水泵下方）
   - 转动灵活吗？

4. 检查散热器
   - 散热片脏吗？（虫尸、泥沙）
   - 风扇转吗？

5. 检查缸垫
   - 油底壳机油变白（冷却液进油道）
   - 排气管冒白烟（冷却液进燃烧室）
   - 冷却液有气泡（气缸里气体进入水道）

6. 检查散热风扇
   - 高温时风扇转吗？
   - 温控开关坏了吗？
```

**处理**：
- 冷却液不足：加注
- 节温器坏：更换
- 水泵坏：更换
- 散热器堵：清洁
- 风扇不转：检查电机、继电器、温控开关
- 缸垫漏：更换缸垫

【严重警告】 **严重警告**：发动机过热**必须立即停车**！继续骑会导致活塞熔顶、气门变形、拉缸——大修发动机几千上万。

【经验】 **老师傅经验**：发动机过热后不要立即打开水箱盖或直接猛加冷水。先在安全处停车熄火，让系统自然降温；确认不再高温高压后再按手册补充冷却液。高温状态下突然加入大量冷液有热冲击风险，打开热水箱盖还可能被高温蒸汽烫伤。

### 6.12.2 案例 2：发动机异响 ★★★

**听位置判断问题**：

| 异响位置 | 可能的故障 |
|----------|-----------|
| 缸头 | 气门、凸轮、摇臂 |
| 缸体 | 活塞、活塞环、活塞销 |
| 底部 | 曲轴、连杆 |
| 前面 | 正时链条 |

**听时机判断**：

| 时机 | 可能的故障 |
|------|-----------|
| 怠速响 | 气门、活塞 |
| 加速响 | 轴承、活塞 |
| 冷车响、热车消失 | 液压挺柱 |
| 一直响 | 严重磨损 |

**听声音特点**：

| 声音 | 故障 |
|------|------|
| 哒哒哒 | 气门间隙大 |
| 铛铛铛 | 活塞敲缸（磨损） |
| 嗡嗡嗡 | 轴承磨损 |
| 嘶嘶嘶 | 漏气 |
| 哗啦哗啦 | 正时链条松 |

**处理**：
- 气门响：调气门
- 活塞响：镗缸换活塞
- 轴承响：大修
- 漏气：找漏点（进气、排气、缸垫）

【经验】 **老师傅经验**：**用长螺丝刀听异响**——把螺丝刀刀尖顶在发动机不同部位，刀柄贴耳朵。这叫"听诊器法"。比直接用耳朵听得清 5 倍。**老师傅的看家本事之一**。

### 6.12.3 案例 3：烧机油 ★★★

（见 6.6.5 节）

【经验】 **老师傅经验**：**冷车冒蓝烟 vs 热车冒蓝烟** —— 这是金标准。
- **冷车冒蓝烟，热车消失**：气门油封老化。便宜修，几十到几百元。
- **热车也冒蓝烟**：活塞环磨损。贵修，几千到上万。

**新手最容易混淆**：以为冒蓝烟就是"该大修了"。**其实 70% 的烧机油是油封问题**，换油封几百元搞定。

### 6.12.4 案例 4：动力不足 ★★

**诊断流程**：
```
1. 检查进排气
   - 空滤堵了吗？
   - 排气管堵了吗？（消音器进水/进虫）

2. 检查点火
   - 火花塞状态
   - 点火线圈
   - 高压线

3. 检查燃油
   - 燃油压力
   - 喷油嘴

4. 检查压缩
   - 测气缸压力

5. 检查正时
   - 正时是否错位
   - 张紧器是否失效

6. 检查进气压力
   - 涡轮车（如果有）：增压值
   - 进气管路漏气
```

**处理**：
- 空滤堵：换
- 燃油压力低：换油泵
- 点火弱：换火花塞/线圈
- 缸压低：维修
- 正时错：调整

【经验】 **老师傅经验**：**动力不足的最常见原因不是发动机，是空滤**。**空滤 50 元，火花塞 30-150 元/个**——这两个是动力问题的"低垂果实"。先换这两个再查别处。

### 6.12.5 案例 5：发动机异响类型速查（按声音分类）★★★

**这是 6.12.2 的补充视角**——按声音类型直接判断处理优先级。

| 异响类型 | 主要特点 | 优先检查 | 处理优先级 |
|----------|---------|----------|-----------|
| 哒哒哒（顶置） | 怠速明显、节奏规律 | 气门间隙 | 自行调整 |
| 咣咣咣 | 突然出现、急加速明显 | 连杆瓦 | **立即停车送修** |
| 嗡嗡嗡 | 中高转速、持续 | 轴承 | 近期送修 |

## 6.13 【经验】 老师傅经验沉淀（应写尽写）

**这一章是本章独有的"老师傅不外传"经验块**。新手最容易栽跟头的地方、老车友多年积累的窍门、课本上找不到的细节，全在这里。

### 6.13.1 新手必踩的 15 个坑 ★★★

**调气门类**：
1. **不查手册，凭印象调** — 不同车型数据天差地别。
2. **热车调气门** — 永远不准。
3. **找错 TDC** — 气门撞活塞，发动机报废。
4. **不复测** — 锁紧螺母后必测，不测就漏。
5. **用便宜塞尺** — 厚度不准，间隙差 0.02mm 就要命。

**火花塞类**：
6. **套筒紧死** — 螺纹损坏，要换缸盖。
7. **热车拆** — 螺纹咬死，下次拆不下来。
8. **杂物掉进缸里** — 一粒沙子能磨出划痕。
9. **用错型号** — 热值、间隙、长度不一致 = 发动机损坏。
10. **拉高压线而不是拔火花塞帽** — 拉坏高压线。

**缸盖类**：
11. **缸盖螺丝不按扭矩/角度** — 漏气或缸盖变形。
12. **缸垫重复使用** — 漏气漏水。
13. **不固定正时** — 装错位气门撞活塞。
14. **气门卡簧没装牢** — 气门掉进缸里。
15. **忘记对定位销** — 缸垫位置偏，漏气漏水。

**机油/冷却液类**（附加）：
- 用错规格机油（湿式离合器要用 JASO MA/MA2，否则离合打滑）
- 冷却液混用（不同类型会反应生成胶状物）
- 机油滤芯用扳手死拧（下次拆不下来）

【经验】 **老师傅经验**：**修车最贵的不是零件，是返工**。这 15 个坑，每踩中一个，多花 500-5000 元。**修车前把这表打印出来，贴墙上**。

### 6.13.2 老师傅不外传的 10 个诀窍 ★★★

1. **【维修】 黄油粘气门卡簧**：装气门卡簧时涂一点黄油在槽里，黄油的粘性防止卡簧脱落。
2. **【维修】 压缩空气吹火花塞孔**：装火花塞前吹一下，杂物掉进缸里的事故减少 50%。
3. **【维修】 手指法找 TDC**：用手指堵火花塞孔，转曲轴感到气压就是压缩冲程。最简单实用的方法。
4. **【维修】 塞尺保持平行使**：测气门间隙时塞尺和气门杆平行，测的值才准。
5. **【维修】 锁紧螺母时塞尺不抽**：保持塞尺在位锁紧，避免螺母带动螺钉让间隙变化。
6. **【维修】 加冷却液分两次**：先加 70%，启动让水循环，再补到 95%，再启动再补。气泡比一次加满少很多。
7. **【维修】 测缸压用湿缸法**：干缸压低，加点机油再测，区分活塞环还是气门问题。
8. **【维修】 螺丝刀听异响**：长螺丝刀刀尖顶发动机，刀柄贴耳朵，比耳朵听清 5 倍。
9. **【维修】 换机油放完看金属屑**：大量金属屑 = 发动机大修前兆；铁铝混合 = 严重内伤。
10. **【维修】 副水箱液位检查要看停车 30 分钟后**：刚停车液位不准，冷却液回流后看才准。

新手预估时间：**实际要 × 2 到 × 3**。

| 换火花塞 | 30 分钟 | 15 分钟 | 60-90 分钟 |
| 调气门（双缸） | 1 小时 | 30 分钟 | 2-3 小时 |
| 调气门（四缸） | 2 小时 | 1 小时 | 4-6 小时 |
| 换机油 | 20 分钟 | 10 分钟 | 45 分钟 |

【经验】 **老师傅经验**：**第一次做某个新活，预估 4 倍时间**。工具找错、零件对不上、说明书看错——这些都要时间。**别告诉老婆你 1 小时搞定**——除非你想晚上跪键盘。

### 6.13.4 哪些钱不能省 ★★

**工具**：
- 塞尺：买 Mitutoyo 或 Insize（几百元一套，**不要买地摊货**）
- 扭力扳手：国产 200-500 元能用（**不要买 50 元的**）
- 火花塞套筒：磁性或橡胶内衬（防止滑丝）

**零件**：
- 火花塞：买正品 NGK、Denso、Champion（**不要买"通用"杂牌**）
- 机油：买正品壳牌、美孚、嘉实多（**不要买"全合成"杂牌**）
- 冷却液：买正品长城、壳牌、防冻液（**不要加自来水**）
- 缸垫：买正品（**不要用副厂便宜货**，漏气返工更贵）

**送修的智慧**：
- 拆缸盖 → 第一次送修（**没经验硬干，毁发动机的概率 30%+**）
- 调气门 → 第一次送修，看着师傅做一次
- 换正时链条 → 建议送修（**错一次就毁发动机**）

【费用】 **省钱贴士**：**该省的钱省，不该省的钱别省**。工具买好的、零件买正品、自己动手做基础保养——这三样下来，**一年省 2000-5000 元**。

### 6.13.5 容易漏的小细节 ★★

- 【维修】 **气门室盖垫圈**：换气门时**顺手换新**，不要重复使用旧垫圈。
- 【维修】 **火花塞垫圈**：锥座型火花塞**每次换新垫圈**。
- 【维修】 **机油滤芯垫圈**：换滤芯时**确认旧垫圈没黏在车上**（装两个垫圈会漏油）。
- 【维修】 **放油螺丝垫圈**：每次换机油**换新垫圈**（铜或铝的）。
- 【维修】 **缸盖螺丝**：很多车型螺丝是**一次性**的，重复使用会断。

### 6.13.9 网络实战案例汇编（来自论坛、技师分享）★★

**这是从 ADVrider、Reddit、BikeChat 等论坛整理的真实案例**——给新手看"别人怎么翻车的"。

### 案例 A：宝马 R1200GS 加油门熄火

**症状**：低速加油门熄火，高速正常
**踩坑过程**：以为是火花塞问题，换了没用
**可能原因**：节气门位置传感器（TPS）需要重新学习
**处理建议**：拔电瓶负极 30 分钟 → 装回 → 启动后不加油门等 5 分钟 → 自动学习完成
**教训**：**电喷车出问题先看是不是传感器需要重置**——**不是所有问题都是零件坏了**

### 案例 B：雅马哈 MT-07 冬天难启动

**症状**：气温低于 5°C 时启动困难，要踩好几脚
**踩坑过程**：换了电瓶、火花塞、节气门清洗——都没用
**可能原因**：低温下机油粘度大（10W-40 在 -10°C 流动性差）
**处理建议**：冬天换 0W-40 机油 + 智能充电器保持电瓶满电
**教训**：**冬季用车要换低温粘度机油**——不要全年 10W-40

### 案例 C：哈雷 Sportster 启动后熄火

**症状**：启动正常，2 秒后熄火，反复如此
**踩坑过程**：以为是燃油泵坏
**可能原因**：**防盗芯片钥匙没电**（哈雷用芯片钥匙识别车主）
**处理建议**：换钥匙电池（CR2032），5 分钟搞定
**教训**：**哈雷/宝马/杜卡迪的"启动问题"先看钥匙电池**——不是零件坏了

### 案例 D：本田 CB500F 链条频繁断

**症状**：每 5000 km 链条就断一次
**踩坑过程**：换了三次链条，每次都是骑了 5000 km 断
**可能原因**：**前后链轮没换**（旧链轮齿尖"鲨鱼鳍"剪链条）
**处理建议**：**链条+链轮同时换**
**教训**：**链条+链轮要同时换**——这是 CH10 已经讲过的，但**真的有人栽在这上面**

### 案例 E：川崎 Ninja 400 频繁熄火

**症状**：低速偶尔熄火，高速正常
**踩坑过程**：换了节气门、火花塞、点火线圈——都没用
**可能原因**：**燃油泵滤网堵了**（油箱杂质积累）
**处理建议**：拆燃油泵，清洗滤网（**不必换新泵**）
**教训**：**电喷车燃油泵滤网要定期检查**——一般 3-5 万 km 必查

### 案例 F：凯旋 Tiger 900 高温报警

**症状**：夏天堵车时水温报警
**踩坑过程**：以为是节温器坏
**可能原因**：**散热片堵了**（树叶、虫尸堆积）
**处理建议**：拆下散热器，**用水管冲洗散热片**（不要用高压水枪！）
**教训**：**ADV 车散热片要经常检查**——越野环境特别容易堵

### 案例 G：本田 CBR650R 加速抖动

**症状**：油门到底时动力断断续续
**踩坑过程**：换火花塞、清洗节气门——都没用
**可能原因**：**燃油滤芯堵了**（用了劣质汽油）
**处理建议**：换燃油滤芯 + 燃油管路清洗
**教训**：**用正规加油站**——便宜油容易堵滤芯

### 案例 H：杜卡迪 Monster 链条异响

**症状**：每次加速时链条"咣当"响
**踩坑过程**：反复调整链条松紧——没用
**可能原因**：**链条+链轮都到寿命了**——调整只能暂时缓解
**处理建议**：**链条+链轮整套换**
**教训**：**异响不消失 = 该换了**，不要一直调

### 案例 I：宝马 F750GS 充电故障

**症状**：电瓶经常没电，启动困难
**踩坑过程**：换了三次电瓶——还是没电
**可能原因**：**发电机调压器坏**——充电电压过高，电瓶过充损坏
**处理建议**：测发电机输出电压（应该 13.5-14.5V），换调压器
**教训**：**充电故障先测发电机电压**——不是所有电瓶问题都换电瓶

### 案例 J：铃木 SV650 怠速不稳

**症状**：怠速忽高忽低，转速表在 1000-1500 之间摆动
**踩坑过程**：清洗节气门、调怠速——都没用
**可能原因**：**怠速控制阀（ISC）脏了**——藏在节气门体里
**处理建议**：拆下 ISC 阀，用化油器清洗剂清洗
**教训**：**怠速不稳的 80% 是 ISC 阀或节气门脏**——先清洗这两个再查别处

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **换了 N 个零件** = **没有先诊断** = **花了几千元才发现是个小问题**
2. **听商家忽悠换件** = **原厂件更可靠** = **省钱反而亏钱**
3. **不查手册** = **用了错误数据** = **修出新故障**
4. **没拍照就拆** = **装不回去** = **小问题变大故障**
5. **不试车就交车** = **留下隐患** = **下次再修**

【经验】 **老师傅总结**：**论坛上 80% 的"修车经历"** 都是**本可以避免的**——**诊断对了，5 分钟搞定；诊断错了，5000 元也修不好**。**这就是 CH20 强调的"诊断比维修重要"**。

### 6.13.10 修车心理建设（老师傅忠告）★★

**这一节不是技术，是心理**——但**比技术重要**。

**修车五大心理准备**：

1. **接受"可能修不好"**：**新手第一次修车 50% 概率修不好**——**正常**。**别怕修坏**——**坏了再修**。
2. **接受"花时间"**：**修车时间 = 预估 × 2**——**新手要 × 3**。**别急**——**急就出错**。
3. **接受"花钱"**：**工具一次性投入 1000-2000 元**——**值**——**用 10 年**。**别想省钱买便宜工具**——**更亏**。
4. **接受"犯错"**：**每个师傅都犯过错**——**大错小错**。**记录错误**——**下次不犯**。
5. **接受"送修不丢人"**：**老师傅也不是什么都自己修**——**送修为主**。

【经验】 **老师傅经验**：**修车不是比拼技术**——**是比拼心态**。**心态好的车主**——**慢慢学、修得好**。**心态急的车主**——**买工具、买零件、买教训**——**最后还是送修**。

### 6.13.13 数据可靠性判断（看资料时要谨慎）★★

**不是所有资料都可信**——**关键看**：

**可信度高**：
- 厂家官网 / 官方手册
- Haynes / Clymer 第三方维修手册
- 资深技师（BikeChat、Reddit 高 karma 用户）的具体型号建议

**可信度中**：
- YouTube 视频（看步骤，不看结论）
- 论坛长帖（看回复，看有没有反对意见）
- 修理店老板的话（他可能有利益相关）

**可信度低**：
- 单人帖、无回复、无来源的"经验"
- "网上说"的引用
- 维修店老板推的东西（特别是他店里卖的）

【经验】 **老师傅经验**：**网上 50% 的"经验"是错的**——**特别是**：
- "加了 XX 油省油 20%"（不可能）
- "XX 牌火花塞比 NGK 好"（NGK 行业标杆）
- "XX 改装提升 50%"（夸大）
- "我的车用 XX 修好了"（个案，不能推及）

**怎么识别错信息**：
1. **看来源**：官网 > Haynes > 论坛 > 营销文
2. **看具体数据**：说"提升 X%"而不说怎么测的 = **不可信**
3. **看有没有反例**：所有车都好用？没有例外？= **不可信**
4. **看你自己**：**结合说明书**——**说明书 = 准**
