## 1.1 摩托车分类（按维修重要性重新组织）

### 1.1.0 为什么分类很重要？

【问答】 **新手问答**：为什么要先学分类？

因为不同类型的摩托，结构差异巨大。比如你骑的是凯旋Scrambler 1200X（双缸水冷），但网上查到的资料大部分是日系四缸教程。两者的气门调整、点火顺序都不一样。

**简单说**：学错了分类，就像学开车却把方向盘装反了——方向全错。

【注意】 **常见误解**："摩托车都差不多" — 错！哈雷V双和雅马哈跨平面双，结构完全不同。

### 1.1.1 按用途分类（最实用）

这是新手最需要了解的分类。不同用途的摩托，维修重点天差地别。

#### 街车（Street/Naked）

**是什么**：没有大整流罩，发动机裸露在外，骑行姿势相对舒适的车型。

**为什么长这样**：
- 厂家发现很多城市骑手不喜欢导流罩
- 露发动机散热更好
- 维修时拆装更方便（不用拆一堆覆盖件）
- 价格相对便宜

**详细特点**：

| 项目 | 数据/说明 |
|------|-----------|
| 重量 | 180-220kg |
| 油箱 | 12-18L |
| 座椅高 | 780-850mm |
| 骑行姿势 | 上身略前倾，手把较宽 |
| 适用场景 | 城市通勤+偶尔山路 |
| 不适用 | 长途（风阻大）、赛道 |

**代表车型**（新手要认识）：

| 车型 | 品牌 | 排量 | 你该知道的 |
|------|------|------|-----------|
| MT-07 | 雅马哈 | 689cc | 跨平面双缸，新手街车标杆 |
| Z650 | 川崎 | 649cc | 直列双缸，平顺 |
| CB650R | 本田 | 649cc | 直列四缸，性能街车 |
| Street Triple 765 | 凯旋 | 765cc | 直列三缸，运动街车 |
| Monster 821 | 杜卡迪 | 821cc | L型双缸，意式激情 |
| Scrambler 1200X | 凯旋 | 1200cc | 双缸，兼具Scrambler风格 |

【维修】 **维修场景**：
- 街车维修空间大，工具容易到达
- 油底壳一般在底部，拆装简单
- 链条调整在后轴两侧
- 空滤位置通常在油箱下方或侧盖内

【注意】 **常见误解**：
- "街车就是最便宜的" — 错。杜卡迪Monster比很多运动车还贵
- "街车没有性能" — 错。KTM 1290 Super Duke是野兽级街车

【数据】 **数据举例**（MT-07 vs Monster 821）：

| 项目 | MT-07 | Monster 821 |
|------|-------|-------------|
| 发动机 | 跨平面双缸 | L型双缸 |
| 排量 | 689cc | 821cc |
| 最大功率 | 73PS | 109PS |
| 最大扭矩 | 68Nm | 86Nm |
| 整备重量 | 182kg | 206kg |
| 油箱 | 14L | 16.5L |
| 售价 | 约7万 | 约14万 |
| 维修便利 | ●●●●● | ●●● |
| 配件价格 | 低 | 高 |

#### 运动跑车（Sport Bike）

**是什么**：全包围整流罩，骑行姿势激进（前倾），高转速高功率。

**为什么长这样**：
- 高速时整流罩减少风阻
- 趴着骑可以减少迎风面积
- 高转速发动机需要大进气量，整流罩上有进气口
- 高速稳定性靠低重心和长轴距

**详细特点**：

| 项目 | 数据/说明 |
|------|-----------|
| 重量 | 175-210kg（看着大实际不重） |
| 油箱 | 16-22L |
| 座椅高 | 820-880mm |
| 骑行姿势 | 极度前倾，手把低 |
| 适用场景 | 赛道、高速、山路 |
| 不适用 | 长途（累）、城市（累） |

**代表车型**：

| 车型 | 品牌 | 排量 | 特点 |
|------|------|------|------|
| YZF-R1 | 雅马哈 | 998cc | 跨平面曲轴，赛道利器 |
| CBR1000RR-R | 本田 | 999cc | 电子系统丰富 |
| Ninja ZX-10R | 川崎 | 998cc | 多次WSBK冠军 |
| GSX-R1000R | 铃木 | 999cc | 长寿命经典 |
| Panigale V4 | 杜卡迪 | 1103cc | V4，顶级超跑 |

【维修】 **维修场景**：
- 必须拆整流罩才能维修（螺丝多）
- 部分油底壳位置特殊（如ZX-10R需要从下方拆）
- 电瓶通常在座椅下
- 空气滤芯位置不一
- ECU需要专用诊断仪

【注意】 **常见误解**：
- "运动车容易坏" — 错。同级别保养下，运动车寿命不输街车
- "运动车不适合日常" — 部分对。取决于路况和体力

【口诀】 **记忆口诀**：运动车 = "趴着骑、整流罩、高转速、保养贵"

#### 巡航车（Cruiser）

**是什么**：低座椅、长轴距、前伸脚踏，骑姿像"坐沙发"。

**为什么长这样**：
- 美式文化，强调舒适
- 长轴距让高速稳定
- 重心低，操控简单
- 大量镀铬件是装饰文化

**详细特点**：

| 项目 | 数据/说明 |
|------|-----------|
| 重量 | 250-380kg（重） |
| 油箱 | 15-25L |
| 座椅高 | 650-750mm（极低） |
| 骑行姿势 | 脚在前、手直伸、上身直立 |
| 适用场景 | 长途巡航、高速公路 |
| 不适用 | 山路（太重）、越野（太低） |

**代表车型**：

| 车型 | 品牌 | 排量 | 特点 |
|------|------|------|------|
| Street Bob 114 | 哈雷 | 1868cc | Milwaukee-Eight，软尾 |
| Fat Boy 114 | 哈雷 | 1868cc | Milwaukee-Eight，经典车型 |
| Sportster S | 哈雷 | 1252cc | Revolution Max动力 |
| Scout Bobber | 印第安 | 1133cc | 小巧灵活 |
| Vulcan 1700 | 川崎 | 1700cc | 大V双 |
| Bolt | 雅马哈 | 942cc | 小排量入门 |

【维修】 **维修场景**：
- V型双缸气门调整复杂，需要专用工具
- 部分有皮带或轴传动
- 镀铬件需要特别保护（防止锈蚀）
- 哈雷Twin Cam的链条张紧器容易出问题（详见第23章）
- 整备重量大，举升需要专门设备

【注意】 **常见误解**：
- "哈雷容易坏" — 部分对。Twin Cam时代确实有些问题，但新款已改善
- "巡航车都贵" — 部分对。但也有低价位的Vulcan S

【数据】 **数据举例**（哈雷Twin Cam 103 vs Milwaukee-Eight 114）：

| 项目 | Twin Cam 103 | M8 114 |
|------|--------------|--------|
| 年代 | 1999-2017 | 2017+ |

| 气门数 | 4（每缸2气门） | 8 |
| 平衡轴 | 无 | 有 |
| 火花塞 | 1个/缸 | 2个/缸（共4个） |
| 张紧器问题 | 频繁 | 已改善 |
| 配件丰富度 | 高 | 高 |

#### Scrambler（攀爬者）

**是什么**：一种融合街车和越野车的车型，高位排气、高位脚踏、升高把手。

**为什么长这样**：
- 起源于英国1960年代，玩家把街车升高改装
- 高位排气避免涉水
- 高位脚踏避免碰石头
- 升高把手获得更大杠杆

**详细特点**：

| 项目 | 数据/说明 |
|------|-----------|
| 重量 | 190-230kg |
| 油箱 | 12-18L |
| 座椅高 | 820-880mm |
| 骑行姿势 | 直立、把高、腿略弯 |
| 适用场景 | 公路+轻度越野 |
| 不适用 | 极限越野 |

**代表车型**：

| 车型 | 品牌 | 排量 | 特点 |
|------|------|------|------|
| Scrambler 1200 X | 凯旋 | 1200cc | 双缸高扭矩 |
| Scrambler Icon | 杜卡迪 | 803cc | 风冷L双 |
| R nineT Scrambler | 宝马 | 1170cc | Boxer发动机 |
| Griso 1100 | 摩托古兹 | 1064cc | 横V双 |

【维修】 **维修场景**：
- 高位排气管内部冷凝水积聚处容易锈蚀
- 长行程减震需要更细致维护
- 部分车型（凯旋1200）链条磨损较快
- 部分车型化油器需要调整

【口诀】 **记忆口诀**：Scrambler = "高位排、高脚踏、升高把、能越野"

#### ADV/冒险车型（Adventure）

**是什么**：可以"周游世界"的多功能车型，离地间隙高、油箱大、续航长。

**为什么长这样**：

**详细特点**：

|------|-----------|
| 重量 | 200-260kg |
| 油箱 | 20-30L（大） |
| 座椅高 | 820-900mm（高） |
| 骑行姿势 | 直立、长途舒适 |
| 适用场景 | 长途、铺装路面、烂路 |
| 不适用 | 极限越野、赛道 |

**代表车型**：

| 车型 | 品牌 | 排量 | 特点 |
|------|------|------|------|
| R1250GS | 宝马 | 1254cc | Boxer+轴传动 |
| Africa Twin | 本田 | 1084cc | DCT可选 |
| Ténéré 700 | 雅马哈 | 689cc | 跨平面双缸 |
| KTM 890 Adventure | KTM | 889cc | 高性能 |
| Multistrada V4 | 杜卡迪 | 1158cc | 顶级ADV |
| TRK 502 | 贝纳利 | 500cc | 入门ADV |

【维修】 **维修场景**：
- 链条磨损快（越野环境）
- 长行程减震维护难度高

- 宝马的轴传动需要定期换齿轮油

### 1.1.2 按发动机布局分类

#### 气缸数详解

新手经常问："单缸和双缸到底有什么区别？" 这里详细讲。

---

##### 单缸发动机

**是什么**：只有一个气缸。

**详细结构**：
```
想象一个汽水罐（气缸）里塞一个活塞（活塞）。
活塞上下往复运动，通过连杆带动曲轴旋转。
```

**真实例子**：本田CRF450L（越野车）

**详细特点**：

| 项目 | 说明 |
|------|------|
| 结构 | 简单（最少部件） |
| 重量 | 轻 |
| 成本 | 低 |
| 功率 | 同排量下相对较低 |
| 扭矩 | 同排量下相对较大 |
| 震动 | 大（无平衡抵消） |
| 声浪 | "砰-砰-砰" 节奏感强 |
| 油耗 | 中等 |
| 维护 | 简单 |

**为什么震动大**：
- 双缸、四缸有多个气缸交替做功，互相抵消震动
- 单缸没有抵消，每转一圈做功一次，震动最明显
- 现代单缸用平衡轴来减少震动

**维修角度**：
- 气门机构最简单（多数单缸是SOHC 4气门或2气门）
- 化油器/喷油嘴只有一套
- 点火线圈一个，火花塞一个
- **维修新手最适合从单缸开始学**

**代表车型**：
- 本田CRF450系列、雅马哈WR450F、KTM 690 Duke
- 几乎所有越野车（重量考虑）

---

##### 双缸发动机

**是什么**：两个气缸。

**双缸还有细分**：

| 类型 | 英文 | 缸夹角 | 特点 |
|------|------|--------|------|
| 并列双缸 | Parallel Twin | 0° | 简单、平衡性好 |
| V型双缸 | V-Twin | 60°-90° | 紧凑、独特声浪 |
| 横V双缸 | Transverse V-Twin | 90° | 低重心（摩托古兹） |
| 跨平面双缸 | Crossplane | 270° | 不规则点火（雅马特色） |

**并列双缸详解**：

```
两个气缸并排站立（像两兄弟肩并肩）。

曲轴相位：180°、270° 或 360°
点火顺序：1-2
```

代表：雅马哈MT-07（跨平面特殊）、凯旋T120、川崎Z650

**V型双缸详解**：

```
两个气缸呈V字形分开。
常见夹角：45°（哈雷）、60°（部分）、90°（杜卡迪L双）

夹角影响：
- 45°：震动大（不均匀点火）
- 90°：震动小（均匀点火）
- 90°+：可省去平衡轴
```

代表：哈雷Twin Cam（45°）、杜卡迪L双（90°）

**跨平面双缸详解**（特别说明）：

```
普通双缸曲轴相位：0°-360°-0°-360°（两个活塞同步运动）
270° 曲轴双缸点火间隔：270°/450°（合计 720°）（两个活塞不同步）

不规则点火顺序产生不规则震动，
这种震动反而成为雅马哈的"特色"，
让车有"扭力充沛"的感觉。
```

代表：雅马哈MT-07、MT-09（实际上是三缸）、Ténéré 700

【维修】 **维修场景**：
- 双缸维修工作比单缸多一倍（两套气门、两套活塞环...）
- 跨平面发动机点火顺序特殊，需要专用工具
- V型双缸的气门调整取决于气门机构类型

---

##### 三缸发动机

**是什么**：三个气缸。

**详细结构**：
```
三个气缸并排站立。
曲轴相位：120°（均匀）
点火顺序：1-3-2（常见）或1-2-3
```

**详细特点**：

| 项目 | 说明 |
|------|------|
| 平衡性 | 极佳（奇数缸一阶平衡好） |
| 声浪 | 独特（介于双缸和四缸之间） |
| 功率 | 高 |
| 扭矩 | 大 |
| 重量 | 中等 |
| 成本 | 中等 |

**代表车型**：
- 雅马哈MT-09、Tracer 9
- 凯旋Street Triple 765、Tiger 900、Sprint

【维修】 **维修场景**：
- 三个气缸的气门调整工作量大
- 需要更精细的同步调整
- 化油器车型需要同步三缸

---

##### 四缸发动机

**是什么**：四个气缸。

**详细结构**：
```
四个气缸并排站立。
曲轴相位：180°（对置两缸做功）
点火顺序：1-2-4-3或1-3-4-2（多种）
```

**为什么点火顺序不同**：
- 让做功冲程间隔均匀
- 避免相邻气缸连续做功造成局部震动

**详细特点**：

| 项目 | 说明 |
|------|------|
| 平衡性 | 极好（一阶二阶都平衡） |
| 声浪 | 高亢（赛车声） |
| 功率 | 同排量最高 |
| 扭矩 | 中等（高转速取向） |
| 重量 | 重 |
| 成本 | 高 |

**代表车型**：
- 雅马哈R1、R6
- 本田CBR1000RR、CB650R
- 川崎Ninja ZX-10R、Z900
- 铃木GSX-R1000、GSX-S750

【维修】 **维修场景**：
- 四个气缸的气门调整工作量大（建议分两次调，每次调两个）
- 火花塞需要逐个更换
- 化油器/喷油嘴四套
- 部分四缸机的第3缸工作温度高（中间位置）
- 拆解时需要详细记录

【口诀】 **记忆口诀**：四缸 = "平顺、高转、贵、维修量大"

---

##### V型四缸（特殊）

**是什么**：四个气缸呈V字排列。

**代表**：杜卡迪Panigale V4、MV Agusta F4

**特点**：极致紧凑、功率大、维修复杂度高

#### 常见发动机布局对比总表

上面按"气缸数"讲了单缸到四缸。这里换个角度——按**气缸排列布局**看。气缸数相同，布局不同，车宽、重心、维修难度都不一样。

| 布局 | 震动特性 | 宽度/重心 | 代表车型类别 | 维修特点 |
|------|----------|-----------|--------------|----------|
| 单缸（直立/前倾） | 大，靠平衡轴抑制 | 最窄、重心集中 | 越野、小排量街车、踏板车 | 部件最少，拆装最容易 |
| 直列双缸 | 中等，取决于曲轴相位 | 较窄、重心较集中 | 中排量街车、ADV | 两套气门，需注意两缸同步 |
| 直列四缸 | 最平顺 | 最宽、重心偏高偏前 | 运动跑车、大型街车 | 缸盖宽，调气门工作量大 |
| V型双缸 | 夹角越小越不均匀，90°较平顺 | 窄、重心低 | 巡航车、复古车、部分ADV | 后缸位置深，调整空间小 |
| V型四缸 | 平顺且紧凑 | 窄、重心低 | 高性能跑车 | 结构紧凑，维修空间最紧张 |
| 水平对置（Boxer） | 两侧活塞对冲，平顺性好 | 极宽、重心极低 | 旅行车、ADV | 气缸外露便于拆装，倒车易磕缸头 |

**两条结论**：宽度决定"能不能下手"——直列四缸与V4的缸盖中部最难触及；气缸位置决定"要不要先拆东西"——V型车的后缸、Boxer的侧缸往往要先拆油箱或护板。

【注意】 **常见误解**："V缸就是大排量" — 错，也有小排量V缸；"水平对置只有宝马" — 部分对（来源：⭐；具体以车主手册为准）。

### 1.1.3 按气门机构分类

气门机构决定气门如何打开和关闭。

#### 顶置气门 OHV（Over Head Valve）

**是什么**：凸轮轴在缸体/曲轴箱内部（V型布置的发动机可能在两列气缸的V型夹角里），通过挺柱、推杆和摇臂驱动气门。

```
[凸轮轴] → [挺柱/液压挺柱] → [推杆] → [摇臂] → [气门]
（在缸体/曲轴箱内）（tappet/lifter）（pushrod）（rocker arm）
```

**特点**：
- 结构简单
- 配气运动件多（挺柱、推杆、摇臂），高转速气门控制受限（来源：⭐）
- 维护简单
- 噪音较大

**代表**：哈雷大部分车型、部分复古车

#### 顶置凸轮 SOHC（Single Over Head Cam）

**是什么**：凸轮轴在气门上方，直接通过摇臂驱动气门。

```
[凸轮轴] → [摇臂] → [气门]
（在缸盖上）
```

**特点**：
- 高转速气门控制比OHV更好，但缸盖内有凸轮轴，结构更复杂（来源：⭐）
- 比DOHC简单
- 维护中等

**代表**：雅马哈MT-03、川崎部分车型

#### 双顶置凸轮 DOHC（Double Over Head Cam）

**是什么**：两个凸轮轴在气门上方（通常一个控制进气门、一个控制排气门），用于更精确地控制高转速下的气门运动，也更容易实现每缸4气门布置。

```
[进气凸轮轴] → [摇臂] → [进气门]
[排气凸轮轴] → [摇臂] → [排气门]
（都在缸盖上）
```

**特点**：
- 高转速气门控制精度好
- 容易实现4气门/缸
- 缸盖通常更复杂、更宽/更高
- 成本更高，整机可能略重
- 维护工作量大（两根凸轮轴、更多气门相关部件）

**代表**：几乎所有现代高性能车（雅马哈R1、本田CBR1000RR、川崎Ninja等）

#### Desmo气门（杜卡迪特殊）

**是什么**：Desmodromic气门机构中，每个气门（进气和排气）都有独立的机械开启和机械关闭机构，没有气门弹簧。

```
传统：凸轮推开 → 弹簧关闭
Desmo：机械开启 → 机械关闭
```

**详细原理**：
- 每个进气门都有机械开启机构和机械关闭机构
- 每个排气门也有机械开启机构和机械关闭机构
- 本质不是"进气负责开、排气负责关"，而是每个气门都有机械开+机械关

**优点**：
- 无弹簧失效问题
- 可以更精确控制气门正时，尤其高转速

**缺点**：
- 结构复杂
- 重量大
- 维护要求极高
- 需要专用工具
- 调整精度要求高

**代表**：杜卡迪大部分车型；其他品牌的某些老式赛车也使用过类似机构

【注意】 **常见误解**：
- "Desmo气门不会坏" — 错。调整不当会损坏
- "Desmo气门不用维护" — 错。每12000-24000km需要专业调整

【维修】 **维修场景**：
- 需要Desmo专用工具
- 调整精度要求极高
- 很多独立维修店不会修
- 必须按杜卡迪手册调整

【口诀】 **记忆口诀**：
- OHV = 推杆长、便宜
- SOHC = 一根轴、中间
- DOHC = 两根轴、高性能
- Desmo = 无弹簧、要专业

### 1.1.4 按冷却方式分类

#### 风冷（Air-cooled）

**是什么**：靠气流经过散热片直接散热。

**为什么长这样**：
- 结构最简单
- 没有水泵、散热器、冷却液
- 重量轻
- 维护少

**详细原理**：
```
气缸外壁有散热片（增加散热面积）。
当车前进时，气流经过散热片，带走热量。
部分车型有风扇辅助（如哈雷部分）。
```

**详细特点**：

| 项目 | 说明 |
|------|------|
| 散热能力 | 有限 |
| 适用场景 | 小排量、复古、慢速骑行 |
| 优点 | 简单、轻、便宜 |
| 缺点 | 散热效率低、夏天易过热 |
| 寿命 | 长（少部件） |

**散热片故障**：
- 散热片弯曲 → 影响散热
- 散热片堵塞（油泥、泥沙） → 影响散热
- 散热片破损 → 影响散热

【维修】 **维修场景**：
- 用压缩空气吹散热片
- 用专用工具梳直弯曲的散热片
- 经常检查散热片状态

**代表车型**：
- 哈雷大部分（特别是旧款）
- 本田CB1100（部分）
- 杜卡迪Scrambler Icon（部分）
- 皇家恩菲尔德Classic 350

---

#### 油冷（Oil-cooled）

**是什么**：用机油循环带走热量。

**详细原理**：
```
机油在发动机内循环，
同时润滑+冷却。
机油经过机油冷却器（散热器）散热。
```

**特点**：
- 比风冷效率高
- 比水冷简单
- 没有水泵、冷却液
- 但机油消耗较大

**代表**：宝马R1200GS（早期）、部分复古车

---

#### 水冷（Water-cooled）

**是什么**：用冷却液（水+乙二醇）循环散热。

**详细原理**：
```
[水泵] → 推动冷却液
[冷却液] → 经过发动机（吸热）
[冷却液] → 经过散热器（散热）
[冷却液] → 经过节温器（控制流量）
[冷却液] → 回到水泵
```

**详细部件**：

| 部件 | 功能 |
|------|------|
| 水箱（散热器） | 散热 |
| 水泵 | 推动冷却液 |
| 节温器 | 控制大小循环 |
| 风扇 | 辅助散热 |
| 副水箱 | 容纳膨胀的冷却液 |
| 温度传感器 | 监测温度 |

**特点**：
- 散热效率最高
- 温度稳定
- 结构复杂
- 重量大

**冷却系统类型**：

| 类型 | 原理 |
|------|------|
| 小循环 | 冷却液只在发动机内循环，节温器关闭 |
| 大循环 | 冷却液经过散热器，节温器打开 |

**节温器作用**：
- 冷车时：节温器关闭，冷却液走小循环，让发动机快速升温
- 热车时：节温器打开，冷却液走大循环，保持温度

【维修】 **维修场景**：
- 冷却液每2年更换
- 水泵检查（漏水）
- 节温器检查（开启温度）
- 散热器清洁（散热片）

**代表车型**：
- 凯旋Scrambler 1200X（用户的车！）
- 意塔杰特Dragster 300（用户的车！）
- 大多数现代中大排量车

【口诀】 **记忆口诀**：
- 风冷 = 散热片、简单
- 油冷 = 机油兼散热
- 水冷 = 冷却液、效率高

### 1.1.5 按最终传动分类

#### 链条传动（Chain Drive）

**是什么**：用链条将动力从变速箱传递到后轮。

**详细结构**：
```
[变速箱] → [前链轮（小）]
                ↓
              [链条]
                ↓
[后轮] ← [后链轮（大）]
```

**详细特点**：

| 项目 | 说明 |
|------|------|
| 效率 | 高（98%） |
| 成本 | 低 |
| 噪音 | 有 |
| 维护 | 需定期清洁润滑调整 |
| 寿命 | 链条约 30000 km，链轮通常与链条成组更换（磨损同步） |

**链条规格**：

| 型号 | 节距 | 应用 |
|------|------|------|
| 420 | 12.7mm | 小排量 |
| 428 | 12.7mm | 中小排量 |
| 520 | 15.875mm | 中大排量（主流） |
| 525 | 15.875mm | 大排量 |
| 530 | 15.875mm | 大排量 |

【维修】 **维修场景**：
- 每500km清洁润滑（雨后立即润滑）
- 每5000km检查张力
- 每30000km更换链条链轮
- 配套更换（不要新旧混用）

---

#### 皮带传动（Belt Drive）

**是什么**：用皮带传递动力。

**特点**：
- 静音
- 寿命长（50000km+）
- 效率略低（95%）
- 维护少
- 张紧度需要检查

**代表**：哈雷大部分、踏板车（CVT）

---

#### 轴传动（Shaft Drive）

**是什么**：用轴传递动力。

**详细原理**：
```
[变速箱] → [伞齿轮1]（改变方向）
              ↓
            [传动轴]
              ↓
[后轮] ← [伞齿轮2]
```

**特点**：
- 少维护，不用像链条那样清洁、润滑和调张力（来源：⭐）
- 寿命长
- 效率略低于链条（齿轮啮合损失）
- 重量大
- 价格高

**代表**：
- 宝马R系列（Boxer）
- 本田Gold Wing
- 部分ADV车型

【维修】 **维修场景**：
- 定期更换齿轮油（每20000km）
- 检查油封
- 检查万向节

---

### 1.1.7 按排量分级（维修视角）

1.1.6 给的是"小/中/大/超大"的粗分法，便于记忆。这里再给一套更细的分级口径，重点不是背数字，而是让你知道**排量档位会影响哪些维修决策**。

| 分级 | 典型用途 | 动力取向 | 维修与持有成本倾向 |
|------|----------|----------|--------------------|
| <125cc | 踏板代步、入门练习 | 以省油为主 | 单缸为主，配件便宜 |
| 125-250cc | 城市通勤、入门跨骑 | 够用但不富裕 | 单缸/双缸，门槛低 |
| 250-400cc | 通勤+周末短途 | 有高速余量 | 双缸增多，出现水冷、ABS |
| 400-600cc | 中排量主流 | 高速巡航轻松 | 保养项目增多 |
| >600cc | 长途、运动、巡航 | 动力冗余大 | 多缸/大V缸，耗材成本上升 |

**对维修的三个意义**：
1. **法规门槛不同**：部分国家和地区按排量划分准驾车型与保险费率，分界线各地不同（❓），以当地法规和保险公司为准。
2. **动力不等于排量**：同排量下缸数、气门机构、调校不同，动力差别很大。
3. **成本与难度随排量跳档**：机油用量、轮胎规格、刹车片数量同步加大；维修大致沿"单缸 → 小双缸 → 四缸/大V缸"变难。

【注意】 **常见误解**："排量大就一定难修" — 部分对。大排量单缸反而简单；真正决定难度的是**缸数与布局**。（本节细分口径与 1.1.6 粗分口径并存，用途不同。）

## 1.2 整车架构（详细工作原理）

这一节是核心——讲清楚摩托车到底是怎么工作的。

### 1.2.1 动力系统（发动机）详解

#### 四冲程发动机完整工作循环（重点）

四冲程发动机，曲轴转两圈（720°），完成一个工作循环。

想象一个气缸：
```
        [气门]
         ↑
    [活塞] ——→ [连杆]
         ↓
      [曲轴]
```

活塞在气缸内上下运动，通过连杆带动曲轴旋转。曲轴每转一圈，活塞往复一次（上行+下行）。

**四个冲程**：

---

**第一冲程：进气冲程（Intake Stroke）**

```
位置：活塞从上止点向下运动
曲轴转角：0° → 180°
气门状态：进气门开，排气门关
活塞运动：从上向下
```

**详细过程**：
1. 活塞从上止点开始向下运动
2. 气缸内空间增大
3. 压力下降（形成部分真空）
4. 进气门打开（提前打开，不是TDC才开）
5. 新鲜混合气被吸入气缸
6. 活塞到达下止点
7. 进气门关闭（延后关闭，不是BDC就关）

**为什么进气门提前开**：
- 利用进气惯性
- 让更多混合气进入
- 增加功率

**为什么进气门延后关**：
- 利用高速气流的惯性
- 继续"泵入"更多混合气
- 增加充量

**【数据】 数据举例**（某四缸发动机）：
- 进气提前角：12° BTDC（活塞到TDC前12°）
- 进气迟后角：48° ABDC（活塞到BDC后48°）
- 总进气持续角：240°

**【维修】 维修相关**：
- 进气门漏气 → 动力下降
- 进气门积碳 → 影响进气量
- 进气门烧蚀 → 严重故障

【口诀】 **新手问答**：为什么气门不是正好在TDC开，BDC关？

答：实际气门开闭时间比理论时间要长，这样做能增加进排气量。这就是"配气相位"。

---

**第二冲程：压缩冲程（Compression Stroke）**

```
位置：活塞从下止点向上运动
曲轴转角：180° → 360°
气门状态：所有气门关闭
活塞运动：从下向上
```

**详细过程**：
1. 活塞从下止点开始向上运动
2. 所有气门关闭
3. 混合气被压缩
4. 体积变小
5. 温度升高
6. 接近上止点时点火

**压缩比**：
- 定义：气缸总容积 ÷ 燃烧室容积
- 例如：10:1 表示压缩后体积是原来的 1/10
- 摩托车常见：8:1 - 13:1

**压缩比影响**：

| 压缩比 | 特点 |
|--------|------|
| 低（8:1） | 抗爆性好、动力小、省油、便宜 |
| 中（10:1） | 平衡 |
| 高（12:1） | 动力大、易爆震、需要高辛烷值油 |

**爆震（Knock）**：
- 高压缩比容易发生的异常燃烧
- 不是被火花塞点燃
- 是混合气自己燃烧
- 产生敲击声
- 长期爆震会损坏发动机

**【维修】 维修相关**：
- 压缩比下降（气缸磨损）→ 动力下降
- 压缩比过高（积碳）→ 爆震
- 气缸压力测试 → 检查密封

---

**第三冲程：做功冲程（Power Stroke）**

```
位置：活塞从上止点向下运动
曲轴转角：360° → 540°
气门状态：所有气门关闭
活塞运动：从上向下（被推）
```

**详细过程**：
1. 接近上止点时
2. 火花塞跳火
3. 混合气燃烧
4. 气体急剧膨胀
5. 推动活塞向下
6. 通过连杆带动曲轴
7. 曲轴输出动力

**点火时间**：
- 不是正好在上止点点火
- 一般提前 10-40°
- 称为"点火提前角"
- 太小：动力不足
- 太大：爆震、动力下降

**点火提前角的影响**：

| 提前角 | 效果 |
|--------|------|
| 0° | 太晚，动力小 |
| 10° | 适合怠速 |
| 20° | 适合中转速 |
| 30° | 适合高转速 |
| 太大 | 爆震、动力小 |

**【数据】 数据举例**：
- 怠速：10° BTDC
- 3000rpm：25° BTDC
- 6000rpm：35° BTDC
- 现代电喷根据转速自动调整

**【维修】 维修相关**：
- 点火时间不对 → 各种问题
- 火花塞不点火 → 不工作
- 燃油不燃烧 → 排放异常

---

**第四冲程：排气冲程（Exhaust Stroke）**

```
位置：活塞从下止点向上运动
曲轴转角：540° → 720°
气门状态：排气门开，进气门关
活塞运动：从下向上
```

**详细过程**：
1. 活塞从下止点开始向上运动
2. 排气门提前打开（活塞到BDC前）
3. 废气开始流出
4. 活塞上行推废气
5. 接近上止点时
6. 排气门延后关闭

**为什么排气门提前开**：
- 利用废气压力
- 让废气自己流出
- 减少活塞推废气的消耗

**为什么排气门延后关**：
- 利用废气流的惯性
- 清除更多废气
- 为下一个进气冲程做准备

**【数据】 数据举例**：
- 排气提前角：50° BBDC
- 排气迟后角：10° ATDC
- 总排气持续角：240°

**【维修】 维修相关**：
- 排气门漏气 → 动力下降、异响
- 排气门积碳 → 影响排气
- 排气不畅 → 动力下降、过热

---

**完整循环总结**：

```
0°     : 进气开始（提前）
0°-180°: 进气冲程
180°   : 进气冲程结束
180°-360°: 压缩冲程
~350° : 点火
360°   : 上止点，做功开始
360°-540°: 做功冲程
540°   : 下止点，做功结束
540°   : 排气开始（提前）
540°-720°: 排气冲程
720°   : 回到上止点
```

**新手疑问解答**：

【问答】 **四个冲程中只有一个做功，那其他三个冲程呢？**

答：其他三个冲程是"辅助"——它们消耗能量但不做功。所以四冲程发动机需要飞轮（重的圆盘）储存能量，确保其他三个冲程也能转动。这就是为什么摩托车有飞轮，而且飞轮很重。

【问答】 **为什么四冲程比二冲程省油？**

答：四冲程有独立的进气和排气，燃烧更完全。二冲程有"扫气"过程，新鲜混合气和废气会混合，部分燃油直接被排出。

---

#### 二冲程发动机工作循环

**是什么**：两个冲程完成一个工作循环，曲轴转一圈（360°）。

**详细过程**：

```
第一冲程（活塞上行）：
- 活塞从下止点向上
- 先关闭排气口，再关闭扫气口
- 压缩燃烧室内的混合气
- 同时，曲轴箱吸入新的新鲜混合气
- 上止点前点火

第二冲程（活塞下行）：
- 点火后燃烧膨胀，做功
- 活塞下行，曲轴箱内的新鲜混合气被压缩
- 排气口打开，废气排出
- 扫气口打开，曲轴箱内被压缩的新鲜混合气经扫气道进入气缸，把残余废气推出
- "扫气"方向是曲轴箱 → 扫气道 → 气缸，不是反过来进入曲轴箱
```

**详细结构示意**：
```
    [排气口]
        ↑
    [气缸]
    [活塞]
        ↓
    [扫气口]
        ↓
    [曲轴箱]
        ↑
    [进气口]
```

**特点对比**：

| 项目 | 二冲程 | 四冲程 |
|------|--------|--------|
| 功率 | 同排量功率大（每圈做功一次） | 同排量功率较小 |
| 重量 | 轻 | 重 |
| 结构 | 简单（无气门机构） | 复杂 |
| 油耗 | 高（部分新鲜混合气会短路流失，比例取决于扫气方式和工况；不写固定比例，来源：⭐） | 低 |
| 排放 | 差（蓝烟+未燃尽HC） | 好 |
| 寿命 | 短（高转速磨损大） | 长 |
| 噪音 | 大 | 中等 |
| 扭矩 | 中等 | 大 |
| 维护 | 简单（部件少） | 复杂 |

**为什么二冲程功率大**：
- 曲轴转一圈做功一次，理论做功频率更高（来源：⭐⭐⭐）
- 四冲程转两圈才做功一次
- 实际功率密度通常更高，但受扫气损失、充气效率、排放和热负荷限制，不是简单翻倍（来源：⭐）

**为什么二冲程逐渐淘汰**：
- 排放法规严格（达不到欧4/国4）
- 油耗高（经济性差）
- 烧机油（需要预混燃油）
- 噪音大

**现在还在用二冲程的**：
- 部分越野车（KTM 300 EXC）
- 部分卡丁车
- 部分踏板车（少数）
- 部分船外机

**代表车型**：
- KTM 300 EXC（二冲程越野）
- 雅马哈YZ250（二冲程越野）

【口诀】 **新手问答**：我应该学二冲程吗？

答：如果你是新手，建议先学四冲程。大多数现代摩托车都是四冲程。等你掌握四冲程后，可以再学二冲程（其实很简单）。

---

#### 配气相位详解

**是什么**：气门开闭的具体时间安排。

**关键术语**：

```
进气提前角（IVO, Intake Valve Open）：
- 活塞到上止点前多少度进气门打开
- 一般 5-25° BTDC

进气迟后角（IVC, Intake Valve Close）：
- 活塞到下止点后多少度进气门关闭
- 一般 30-70° ABDC

排气提前角（EVO, Exhaust Valve Open）：
- 活塞到下止点前多少度排气门打开
- 一般 30-70° BBDC

排气迟后角（EVC, Exhaust Valve Close）：
- 活塞到上止点后多少度排气门关闭
- 一般 5-25° ATDC
```

**【数据】 数据举例**（雅马哈R1）：

| 项目 | 数值 |
|------|------|
| 进气提前角 | 10° BTDC |
| 进气迟后角 | 53° ABDC |
| 排气提前角 | 53° BBDC |
| 排气迟后角 | 10° ATDC |

**重叠角**：
- 进气门和排气门同时打开的时间
- 上止点附近，进气门刚开，排气门还没关
- 这个角度就是重叠角

**重叠角的作用**：
- 利用废气的惯性"扫气"
- 让新鲜混合气更顺利进入
- 高转速时更重要

**重叠角过大**：
- 低转速不稳
- 怠速不稳
- 易熄火

**重叠角过小**：
- 高转速功率不足
- 排气不彻底

**可变气门正时（VVT）**：
- 现代发动机可以根据转速调整配气相位
- 低转速用小重叠角（稳定）
- 高转速用大重叠角（功率）
- 宝马ShiftCam、雅马哈VVA、本田VTEC等都是这个原理

【维修】 **维修相关**：
- 配气相位错误 → 各种故障
- 正时链条磨损 → 配气相位漂移
- 正时皮带跳齿 → 严重故障

---

#### 点火顺序详解

**是什么**：多缸发动机的点火次序。

**为什么需要点火顺序**：
- 让做功冲程间隔均匀
- 避免相邻气缸连续做功造成局部震动
- 减少主轴承负荷

**常见点火顺序**：

**直列双缸**：
```
0° - 360° - 720°（每360°一次）
```

**直列三缸**：
```
0° - 240° - 480° - 720°
（如雅马哈MT-09：1-3-2）
```

**直列四缸**：
```
1-2-4-3（最常见）：
0° - 180° - 540° - 360°
或简化为：
1缸：0°
2缸：180°
4缸：360°
3缸：540°

1-3-4-2：
1缸：0°
3缸：180°
4缸：360°
2缸：540°
```

**V型双缸**：

```
Twin Cam 45°（哈雷）：
每个气缸曲轴转两圈（720°）各点火一次（共两次/两圈），
点火间隔为 315° 和 405°（315° + 405° = 720°）
```

```
L双 90°（杜卡迪）：
每个气缸曲轴转两圈（720°）各点火一次（共两次/两圈），
点火间隔为 270° 和 450°（270° + 450° = 720°）
```

【维修】 **维修相关**：
- 调整气门时需要按点火顺序
- 一个气缸做功上止点时，调整另一个气门的气门间隙
- 火花塞需要按顺序点火

【口诀】 **新手问答**：点火顺序错了会怎样？

答：发动机可能还能工作，但震动巨大，动力下降，长期会损坏曲轴。所以正时很重要。

### 1.2.2 燃油供给系统详解

#### 化油器详解

**是什么**：利用文丘里效应的机械式供油装置。

**核心原理 - 文丘里效应**：

```
想象一个管道，中间有个狭窄的地方（喉管）。
气流通过时：
- 在喉管处流速变快
- 压力下降
- 形成低压区
- 燃油被这个低压"吸"出来
- 与空气混合
```

**完整结构**：
```
[进油管] → [针阀] → [浮子室]
                        ↓
                   [浮子控制油面]
                        ↓
                   [主喷嘴] ←── [主油针]
                        ↑
                   [喉管（高速气流）]
                        ↑
                   [节气门（控制进气量）]
                        ↓
                   [怠速油路]
                        ↓
                   [怠速调整螺钉]
                        ↓
                   [混合气出气缸]
```

**主要部件详解**：

| 部件 | 功能 | 调整影响 |
|------|------|----------|
| 浮子 | 控制油面高度 | 影响供油量 |
| 针阀 | 进油阀门 | 控制进油 |
| 主油针 | 控制中速供油 | 影响中速性能 |
| 主喷嘴 | 控制高速供油 | 影响高速性能 |
| 怠速喷嘴 | 怠速供油 | 影响怠速 |
| 怠速调整螺钉 | 怠速混合比 | 影响怠速稳定性 |
| 节气门 | 控制进气量 | 控制动力输出 |
| 启动加浓器 | 冷车加浓 | 影响启动 |

**化油器类型**：

| 类型 | 英文 | 特点 |
|------|------|------|
| 浮子式 | Float-type | 主流 |
| CV式（恒速式） | Constant Velocity | 真空控制滑阀 |
| 真空式 | Vacuum-type | 真空膜片控制 |
| 滑阀式 | Slide-type | 高转速 |

**CV式化油器原理**：
```
[节气门拉线] → [蝶阀开度变化]（粗调进气量）
[喉管真空度] → [真空膜片] → [滑阀/油针升降]（细调供油量）
```

为什么CV式更平顺：
- 拉线控制蝶阀开度，真空膜片控制滑阀/油针升降
- 真空膜片会根据发动机负荷改变滑阀和油针位置，让供油量更合适
- CV是Constant Velocity（等速/恒速），不是Constant Vacuum（等真空）
- 它的目标是让喉管真空度相对恒定，所以油门响应更平顺

**化油器常见问题**：

| 问题 | 症状 | 原因 |
|------|------|------|
| 漏油 | 浮子室溢油 | 针阀磨损、浮子破损 |
| 启动困难 | 启动困难 | 启动加浓器失效 |
| 怠速不稳 | 怠速波动 | 怠速油路堵塞 |
| 加速不顺 | 加速顿挫 | 主油针磨损 |
| 动力下降 | 加速无力 | 喷嘴堵塞 |

---

#### 电喷系统详解

**是什么**：用ECU电子控制喷油的系统。

**完整系统**：
```
[传感器] → [ECU] → [执行器]
   ↓                  ↓
采集数据          控制喷油/点火
```

**主要传感器详解**：

| 传感器 | 英文 | 监测内容 | 影响 |
|--------|------|----------|------|
| 进气压力 | MAP | 进气歧管压力 | 喷油量 |
| 进气温度 | IAT | 进气温度 | 喷油量修正 |
| 冷却液温度 | ECT | 水温 | 喷油量、点火 |
| 曲轴位置 | CKP | 曲轴转角 | 点火时刻 |
| 凸轮轴位置 | CMP | 凸轮轴位置 | 配气、喷油 |
| 节气门位置 | TPS | 节气门开度 | 喷油量 |
| 氧传感器 | O2 | 排气氧含量 | 空燃比修正 |
| 倾倒传感器 | Tip-over | 车的倾倒 | 摔倒时断油 |
| 大气压力 | BARO | 海拔 | 喷油量修正 |

**ECU工作流程**：
```
1. 采集所有传感器数据
2. 根据内置MAP（映射表）查目标值
3. 计算喷油脉宽（喷油嘴开启时间）
4. 控制喷油嘴喷油
5. 监测氧传感器
6. 修正喷油量
7. 形成闭环控制
```

**为什么需要这么多传感器**：
- 不同工况需要不同喷油量
- 冷车需要加浓
- 热车需要减稀
- 加速需要临时加浓
- 海拔变化需要调整
- 各种情况都要考虑

**优点**：
- 精准控制
- 燃油经济性好
- 排放低
- 各种工况最优

**缺点**：
- 复杂
- 维修需要诊断仪
- 传感器故障影响大

### 1.2.3 传动系统详解

#### 离合器详解

**是什么**：连接和断开发动机与变速箱的部件。

**为什么要离合器**：
- 起步时需要半联动
- 换挡时需要切断动力
- 防止发动机熄火

**湿式多片离合器详解**：
```
[发动机曲轴]
     ↓
[一次减速齿轮]
     ↓
[离合器外壳]（主动件）
     ↓
[摩擦片]（外齿挂外壳）/ [钢片]（内齿挂内毂）
     ↓
[离合器内毂]
     ↓
[变速箱输入轴]
```

**工作原理**：

**结合状态（传递动力）**：
```
弹簧压紧压盘
   ↓
压盘压紧摩擦片和钢片
   ↓
摩擦片和钢片摩擦（贴合）
   ↓
动力从曲轴 → 一次减速齿轮 → 离合器外壳（主动件） → 摩擦片 → 钢片 → 离合器内毂 → 变速箱输入轴
```

主动件通常是离合器外壳，不是离合器内毂。

**分离状态（切断动力）**：
```
捏离合器手柄
   ↓
拉线拉动分离轴承
   ↓
分离轴承推动压盘
   ↓
弹簧被压缩
   ↓
摩擦片和钢片分离
   ↓
动力切断
```

**摩擦片和钢片怎么排列**：

```
最常见的排列（5片摩擦+5片钢）：
[摩擦片] ← 外齿挂离合器外壳（主动件）
[钢片]   ← 内齿挂离合器内毂（从动件）
[摩擦片]
[钢片]
[摩擦片]
[钢片]
[摩擦片]
[钢片]
[摩擦片]

摩擦片外齿 ↔ 离合器外壳（主动件）；钢片内齿 ↔ 离合器内毂（从动件）。
外齿/内齿哪个挂哪个，不同车型可能不同；但最常见是摩擦片外齿+钢片内齿。
```

**湿式 vs 干式**：

| 项目 | 湿式 | 干式 |
|------|------|------|
| 位置 | 在机油中 | 不在油中 |
| 散热 | 好（油冷） | 一般 |
| 寿命 | 长 | 短 |
| 应用 | 主流 | 部分杜卡迪老款、赛车或特定车型；以车型结构为准（来源：⭐） |

**离合器调整（拉线式）**：
```
1. 找到离合器拉线调整螺栓（发动机侧或拉线中段）
2. 松开锁紧螺母
3. 调整调节螺母
4. 测量自由行程（手柄末端的空行程：从静止位置捏到阻力开始增加时的位移量）
5. 标准：手柄端自由行程常见 10-20mm（不同车型差异大，以维修手册为准）
6. 紧固锁紧螺母
```

**离合器打滑**：
- 现象：加油时发动机转速上升但车速不增
- 原因：摩擦片磨损
- 解决：更换摩擦片

**离合器分离不彻底**：
- 现象：捏离合器仍能行走
- 原因：调整不当
- 解决：调整自由行程

---

#### 变速箱详解

**是什么**：改变传动比的装置。

**为什么需要变速箱**：
- 起步需要大减速比
- 高速需要小减速比
- 倒车需要反转（部分车型）

**档位详解**：

| 档位 | 速比特点 | 用途 |
|------|----------|------|
| 1档 | 减速比最大 | 起步、爬陡坡 |
| 2档 | 减速比大 | 低速、上坡 |
| 3档 | 减速比中等 | 中速 |
| 4档 | 减速比小 | 中高速 |
| 5档 | 减速比小 | 高速 |
| 6档 | 减速比最小 | 极速 |

**档位排列**：

国际档（最常见）：
```
1 - N - 2 - 3 - 4 - 5 - 6
```

踩一挡，轻挑空挡（在中立位置），再挑二挡。停车时退到空挡（在1挡和2挡之间）。

新手常见误解：空挡不在1挡前，而是在1挡和2挡之间。

循环档：
```
N → 1 → 2 → 3 → 4 → 5 → N（循环）
```

**变速箱结构**：
```
[主轴（输入轴）] ← 连接离合器
   ↓
[1档齿轮] [2档齿轮] [3档齿轮] [4档齿轮] [5档齿轮]
   ↓
[副轴（输出轴）] ← 连接链条
   ↓
[连接后轮]
```

**换挡过程**：
```
1. 捏离合器（切断动力）
2. 脚踩换挡杆
3. 换挡轴转动
4. 换挡凸轮旋转
5. 拨叉推动齿轮
6. 齿轮啮合
7. 释放离合器
8. 动力传递到新档位
```

【维修】 **维修相关**：
- 换挡困难 → 调整离合器或换挡轴
- 跳档 → 拨叉磨损或弹簧损坏
- 异响 → 齿轮磨损

### 1.2.4 制动系统详解

#### 盘式制动详解

**是什么**：用刹车片夹紧刹车盘产生摩擦制动的系统。

**完整结构**：
```
[刹车手柄] → [上泵] → [刹车油管] → [卡钳活塞] → [刹车片] → [刹车盘]
                                                              ↓
                                                          [摩擦力]
                                                              ↓
                                                          [制动力]
```

**详细工作过程**：

```
1. 捏刹车手柄
2. 上泵中的活塞被推动
3. 刹车油被加压
4. 压力通过刹车油管传递
5. 压力到达卡钳活塞
6. 活塞推动刹车片
7. 刹车片夹紧刹车盘
8. 摩擦产生制动力
9. 车辆减速
```

**盘式制动关键部件**：

| 部件 | 功能 |
|------|------|
| 刹车盘 | 旋转制动面 |
| 卡钳 | 夹紧刹车盘 |
| 刹车片 | 摩擦材料 |
| 上泵 | 产生液压 |
| 刹车油 | 传递压力 |
| 油管 | 传输液压 |

**卡钳类型**：

| 类型 | 特点 |
|------|------|
| 单活塞 | 简单、便宜 |
| 双活塞 | 平衡、性能好 |
| 四活塞 | 高性能 |
| 对置四活塞 | 顶级 |
| 浮动卡钳 | 主流 |

**浮动卡钳原理**：
```
[刹车盘]
 ↑
[刹车片] ← [卡钳本体]
 ↑
[刹车片] ← [支架]（固定到车架）
```

当一侧活塞推动刹车片，另一侧通过卡钳本体滑动反向移动夹紧。

【维修】 **维修相关**：
- 更换刹车片后需要压回活塞
- 排气是关键（不能有空气）
- 刹车盘和片需要磨合

#### 鼓式制动详解（构造级）

碟刹普及前，鼓刹是主流；今天仍保留在小排量车与后轮上。

**结构与工作过程**：
```
[制动鼓]（随车轮旋转，在轮毂内侧）
   ↓
[制动蹄 ×2]（带摩擦材料的弧形块，装在制动底板）
   ↑
[凸轮 或 液压活塞] → 蹄片外张 → 压紧鼓内壁 → 制动
```

操纵刹车后，凸轮（拉线式）或活塞（液压式）把两片蹄片外张，摩擦片压紧旋转的鼓内壁；松开后由**回位弹簧**拉回。

**自增力效应**：鼓旋转时会"拖着"摩擦片同向移动，顺着旋转方向的一片（**领蹄**）被带动进一步压紧，形成**自增力**，操纵力很小就能出大力；另一片（**从蹄**）出力较小。结果是**初段来力快但不线性、不易精细控制**，这是性能车改用碟刹的主因。

**与碟刹的构造级对比**：

| 项目 | 鼓刹 | 碟刹 |
|------|------|------|
| 散热 | 封闭，连续制动易热衰退 | 开放，散热好 |
| 线性度 | 有自增力，初段来力突然 | 更线性、可控 |
| 涉水后 | 进水不易排出，需摩擦一段才恢复 | 排水快 |
| 维护 | 蹄片磨损慢，但间隙调整繁琐 | 换片快，但需排气 |

**为什么只在小排量/后轮保留**：车速低、整车轻，鼓刹已够用；后轮制动比例低，对散热与线性度要求不高；成本低、封闭性好，适合踏板车与复古车。

**维修要点（细节归 CH12）**：检查蹄片厚度与制动鼓内径，超标即更换；清理鼓内粉尘；检查回位弹簧与凸轮是否卡滞；拉线式按手册调自由行程。

【经验】 鼓刹"拖滞"多来自拉线过紧或回位弹簧疲劳，先查这两项。

---

#### ABS详解

**是什么**：防抱死制动系统，防止刹车时轮胎抱死。

**为什么需要ABS**：
- 紧急制动时轮胎抱死
- 抱死后无法转向
- 抱死后车辆失控
- ABS可以让轮胎保持滚动，同时减速

**ABS工作原理**：

```
1. 监测轮速传感器
2. 检测到轮速急剧下降（即将抱死）
3. ABS泵释放压力
4. 轮胎恢复滚动
5. 重新加压
6. 循环（每秒多次）
```

**驾驶员感觉**：
- 刹车手柄/踏板震动
- "哒哒哒"的声音
- 这是正常的！

【注意】 **常见误解**：
- "ABS震动是故障" — 错。这是ABS工作的表现
- "ABS会延长制动距离" — 部分对。在松散路面ABS会更长，但更安全

### 1.2.5 电气系统详解

#### 充电系统详解

**完整过程**：

```
[磁电机] → [三相交流电] → [整流器] → [直流电] → [稳压器] → [电瓶]
                                                          ↓
                                                       [用电器]
```

**磁电机详解**：
- 永磁式：磁铁旋转，在定子线圈中产生电流
- 输出三相交流电

**整流器详解**：
- 将AC（交流）转DC（直流）
- 内部是二极管桥
- 部分集成稳压功能（整流稳压器）

**稳压原理**：
- 当电压过高时，稳压器在交流侧或整流侧分流多余能量并转为热（来源：⭐⭐）
- 具体拓扑看调压器类型（并联式、串联式、SCR/MOSFET等），以维修手册为准（来源：⭐）
- 当电压回到目标范围时，调压器恢复正常输出控制

**充电电压标准**：

| 状态 | 电压 |
|------|------|
| 静态电瓶 | ≥12.6V 满电；12.4-12.6V 需补电；<12.4V 该充电（来源：⭐⭐；不同电瓶类型略有差异） |
| 怠速充电 | 13.5-14.0V |
| 3000rpm充电 | 14.0-14.5V |
| 过高（>15V） | 整流器故障 |

【维修】 **维修场景**：
- 用万用表测量电瓶电压
- 启动后测量充电电压
- 高于15V：整流器损坏
- 低于13V：充电系统故障

---

#### 点火系统详解

**CDI工作原理**（传统）：

```
[触发线圈] → [产生触发信号]
                  ↓
[CDI电容器] ← [充电]
                  ↓
[触发信号到达] → [CDI放电]
                  ↓
[点火线圈初级] → [电流突变]
                  ↓
[次级感应高压] → [数万伏]
                  ↓
[火花塞跳火]
```

**TCI工作原理**（现代）：

```
[曲轴位置传感器] → [ECU计算点火时间]
                          ↓
[ECU控制点火线圈初级通断]
                          ↓
[次级感应高压]
                          ↓
[火花塞跳火]
```

**ECU控制更精确的原因**：
- 可以根据转速调整点火时间
- 可以根据进气压力调整
- 可以根据温度调整
- 可以根据各种工况最优化

---

#### 启动系统详解

**完整启动过程**：

```
1. 满足启动条件：
   - 钥匙开启
   - 空挡 或 捏离合
   - 边撑收起（部分车型）
   - 紧急熄火开关：处于 RUN 位

2. 按下启动按钮
3. 小电流到启动继电器
4. 继电器吸合（开关接通）
5. 大电流从电瓶到启动电机
6. 启动电机转动
7. 启动电机带动曲轴
8. 发动机开始旋转
9. 活塞开始往复运动
10. 产生压缩
11. 火花塞点火
12. 发动机启动
13. 松开启动按钮
14. 继电器断开
15. 启动电机停止
```

**启动条件**：
- 钥匙开启
- 空挡开关：检测是否在空挡
- 离合器开关：检测是否捏离合
- 边撑开关：检测边撑是否收起（部分车型）
- 紧急熄火开关：必须处于 RUN（运行）位

**如果启动不了，按这个顺序检查**：
1. 检查电瓶电压
2. 检查启动按钮
3. 检查各开关（空挡、离合、边撑）
4. 检查启动继电器
5. 检查启动电机

### 1.2.6 车架详解

#### 车架类型详解

**摇篮式车架**：
```
        [前部]
          ↑
       [车架主管]
       ↑         ↑
    [发动机]   [后摇臂]
       ↑
       [底板摇篮]
```

特点：
- 发动机作为受力部件
- 简单
- 维护方便
- 应用：复古车、部分街车

**双摇篮式车架**：
```
类似摇篮，但有两层
更稳固
```

**钢管空间车架**：
```
[Trellis Frame]
钢管制成空间结构
像编织的网格
```

特点：
- 轻量化
- 刚性好
- 现代运动车主流
- 代表：杜卡迪Monster、雅马哈MT系列

**铝合金车架**：
```
铸造成型
或挤压成型
```

特点：
- 轻量化
- 高端
- 价格高
- 维修困难（铝合金焊接特殊）

**碳纤维车架**：
- 顶级
- 极轻
- 极贵
- 维修几乎不可能

---

#### 车架类型对比总表

前面逐个介绍了主要车架形式，这里做横向对比，重点是"刚性—重量—维修性"三者的取舍。

| 车架类型 | 刚性特征 | 重量 | 维修性 | 代表车型类别 |
|----------|----------|------|--------|--------------|
| 钢管摇篮式 | 中低 | 中 | 好：管件外露，焊修校正门槛低 | 复古车、小排量通勤车 |
| 铝合金双翼梁 | 高，刚性好且可控 | 中偏轻 | 差：焊接与热处理要求高 | 运动跑车、高性能街车 |
| 单体壳（Monocoque） | 高，车架与车身部分合一 | 视材料而定 | 差：一体化结构，局部损伤常需大范围处理 | 部分旅行车、大踏板 |
| 钢管编织（Trellis） | 中高，靠三角结构抗扭 | 中偏轻 | 中：节点可焊接，需控制变形 | 运动街车、部分ADV |
| 冲压钢板 | 中低 | 偏重 | 中：局部变形可校正，大面积锈蚀难处理 | 踏板车、小排量通勤车 |

**维修角度的两条提醒**：车架损伤先判断"是否影响几何"——轴距、前后轮对齐、方向柱角度，比外观更重要；铝合金车架不建议无资质施焊，钢管车架焊接后也要留意应力集中区（来源：⭐；以车主手册/维修手册为准）。

【经验】 车架受损后先做几何测量再决定修不修——很多"看着只是掉漆"的位置其实是主要受力节点。

### 1.2.7 悬挂系统详解（构造级总览）

悬挂决定车轮能不能"贴住地面"。前面只在术语表里零散提过前后减震，这里做总览。

#### 前叉：正立与倒置

| 项目 | 正立前叉（Conventional） | 倒置前叉（Inverted/USD） |
|------|--------------------------|---------------------------|
| 结构 | 细管在上、粗管在下 | 粗管在上、细管在下 |
| 抗弯刚性 | 较低 | 较高（粗管固定于联板） |
| 代表车型类别 | 通勤车、复古车、小排量 | 运动车、ADV、大排量 |
| 维修特点 | 拆装简单，油封更换容易 | 需注意上下管顺序，内管易磕伤 |

#### 后悬挂：双枪、单枪与多连杆

| 类型 | 结构特征 | 特点 | 代表车型类别 |
|------|----------|------|--------------|
| 双枪（Twin Shock） | 左右各一支，直连摇臂 | 结构简单、维修方便 | 复古车、巡航车、小排量 |
| 单枪（Mono Shock） | 单支位于车体中轴附近 | 重量集中、便于调校 | 街车、运动车 |
| 多连杆（Linkage） | 单枪 + 连杆机构 | 行程特性可设计 | 越野、ADV、运动车 |

【注意】 多连杆车型的连杆轴承与密封件是易损点，忽略后常表现为"后轮发涩或异响"。

#### 弹簧与阻尼的分工

- **弹簧**：承担车重与冲击，决定车身"沉多少"，但不能抑制弹跳。
- **阻尼**：控制弹簧伸缩的**速度**，把能量转成热消耗掉；没有阻尼，车会连续上下晃。

【经验】 只加预载、不动阻尼，常出现"更硬但更晃"——支撑变强了，摆动仍未被控制。

#### 三个调节维度

| 维度 | 作用 | 调节效果 |
|------|------|----------|
| 预载（Preload） | 改变弹簧初始压缩量 | 调整车身高度与SAG |
| 压缩阻尼 | 控制被压缩时的速度 | 影响过坎、急刹时的下沉 |
| 回弹阻尼 | 控制回伸时的速度 | 影响过坎后车身回位的快慢 |

**入门第一件事**：按车主手册测量并设定 **SAG（静态下沉量）**，它是所有调节的基准（来源：⭐）。

### 1.2.8 轮胎类型详解（构造级）

轮胎是唯一接触地面的部件。本节只讲类型差异**对维修的影响**，不做选购建议。

#### 斜交胎与子午胎

| 项目 | 斜交胎（Bias） | 子午胎（Radial） |
|------|----------------|------------------|
| 胎侧刚性 | 较硬 | 较软，侧壁可变形 |
| 磨损特征 | 较均匀，发热略高 | 磨耗较均匀，寿命通常更长 |
| 补胎 | 相对容易，局部修补接受度高 | 胎侧损伤一般不建议修补 |

#### 有内胎与无内胎

| 项目 | 有内胎（Tube Type） | 无内胎（Tubeless） |
|------|---------------------|--------------------|
| 漏气速度 | 扎钉后通常较慢 | 可能快速漏气，也偶有慢漏 |
| 补胎方式 | 拆轮拆胎，换或补内胎 | 可塞条应急，正规做法是拆胎内补 |

#### 不同用途轮胎的维修要点

| 用途 | 磨损特征 | 胎压管理 | 维修注意 |
|------|----------|----------|----------|
| 街车胎 | 中部磨平为主 | 按手册定期检查 | 换胎时留意前后磨损差 |
| 运动胎 | 两侧胎肩磨损快于中部 | 对气压变化更敏感 | 气压不足易致胎肩异常磨损 |
| 越野胎 | 大花纹块，易崩块 | 按路况调整（砂石/公路不同） | 花纹深度直接影响抓地 |
| 巡航胎 | 寿命长，高载易老化 | 载重/双人需调整 | 注意胎侧裂纹与年限老化 |

【注意】 辐条轮不都是"必须有内胎"，密封辐条轮可装无内胎；以轮胎与轮辋标注为准（来源：⭐）。拆装别夹伤内胎；无内胎轮检查轮辋密封面与气门嘴。

**两条原则**：胎压以**车主手册/车身标签**为准，冷胎测量（来源：⭐）；磨到磨耗标记，或出现鼓包、裂纹、胎侧扎穿应更换。

【经验】 前后胎磨损速度常不同，不必强行同时更换；混用取向不同的胎会让操控变难预测。

### 1.4.2 各系统维修重点（详细）

#### 发动机：6大重点

**重点1：气门间隙**

为什么重要：
- 间隙过小 → 气门关闭不严 → 烧气门
- 间隙过大 → 异响、动力下降

检查频率：5000-10000km

**重点2：火花塞**

为什么重要：
- 直接影响点火
- 积碳会降低点火能量

更换周期：10000-20000km

**重点3：机油**

为什么重要：
- 润滑、冷却、清洁、密封、防锈
- 失效会损坏发动机

更换周期：5000-7500km（按油品）

**重点4：冷却液**（水冷车型）

为什么重要：
- 防止过热
- 防腐蚀
- 防冻

更换周期：2年

**重点5：正时系统**

为什么重要：
- 链条断裂 → 严重损坏
- 皮带跳齿 → 严重损坏

检查/更换周期：链条长期、皮带30000-60000km

**重点6：缸盖扭矩**

为什么重要：
- 缸盖松动 → 漏气、漏水
- 缸盖过紧 → 变形

定期复紧：按厂家规定

#### 燃油系统：4大重点

**重点1：燃油滤芯**

为什么重要：
- 堵塞会影响供油

更换周期：20000-50000km

**重点2：燃油泵**

为什么重要：
- 损坏无法供油
- 寿命长但有终点

更换周期：100000km+

**重点3：喷油嘴**

为什么重要：
- 堵塞会导致动力下降

清洗周期：30000-50000km

**重点4：燃油管**

为什么重要：
- 老化会漏油
- 漏油可能引发火灾

更换周期：5年

#### 传动系统：3大重点

**重点1：离合器片**

磨损症状：打滑、分离不彻底

**重点2：链条**

维护频率：
- 清洁润滑：每500km
- 张力检查：每5000km
- 更换：每30000km

**重点3：变速箱油**

更换周期：5000-10000km

#### 制动系统：3大重点

**重点1：刹车片**

检查：每5000km或每月

**重点2：刹车油**

为什么重要：
- 吸湿性 → 含水量高 → 沸点低
- 含水率/沸点检测异常或到手册周期即更换（来源：⭐⭐；具体阈值看检测工具和手册）

更换周期：2年

**重点3：刹车盘**

更换时机：厚度到极限

#### 行走系统：4大重点

**重点1：轮胎**

检查项：压力、磨损、损伤

**重点2：前叉油**

更换周期：1-2年

**重点3：链条轴承**

更换时机：异响、松动

**重点4：方向柱轴承**

检查：每年

#### 电气系统：5大重点

**重点1：电瓶**

为什么重要：
- 全车电气依赖它
- 老化无征兆

更换周期：3-5年

**重点2：整流器**

故障表现：充电异常

**重点3：火花塞**

按周期更换

**重点4：灯泡**

按需更换

**重点5：线路**

检查老化、磨损

### 1.4.3 新手常见错误（详细版）

| 错误 | 后果 | 严重度 | 正确做法 |
|------|------|--------|----------|
| 不拧紧螺丝 | 部件脱落 | 严重 | 使用扭力扳手 |
| 螺栓拧得太紧 | 螺纹损坏 | 严重 | 按扭矩拧紧 |
| 机油加太多 | 烧机油、动力下降 | 中等 | 按量加注 |
| 机油加太少 | 发动机损坏 | 严重 | 检查液位 |
| 螺丝拧错顺序 | 缸盖变形 | 严重 | 按对角顺序 |
| 混用不同型号油液 | 化学反应 | 中等 | 使用规定型号 |
| 不放气就加油液 | 部件失效 | 中等 | 排出空气 |
| 工具不合适 | 螺丝滑扣 | 中等 | 用合适工具 |
| 不记录拆装步骤 | 装不回去 | 轻 | 拍照记录 |
| 急着一次性完成 | 遗漏步骤 | 中等 | 分步骤进行 |
| 漏装垫片 | 漏油、漏气 | 中等 | 注意垫片 |
| 不戴手套 | 烫伤、划伤 | 轻 | 戴手套 |
| 在不通风处作业 | 中毒 | 严重 | 通风环境 |

### 1.4.4 学习路径建议（详细版）

#### 第1阶段：认识阶段（1-2月）

**学习目标**：
- 认识自己车的所有部件
- 知道每个部件叫什么
- 学会基本工具使用

**实操任务**：
- 检查机油液位（每天）
- 检查胎压（每周）
- 清洁链条（每周）
- 更换火花塞（学习）
- 认识电路、保险丝

**推荐阅读**：
- 本章
- 自己车的车主手册
- 简单维修视频

#### 第2阶段：基础保养（2-3月）

**学习目标**：
- 掌握基础保养项目
- 学会使用扭力扳手
- 学会基本故障判断

**实操任务**：
- 更换机油+滤芯
- 调整链条
- 更换刹车片
- 调整离合器
- 更换刹车油
- 检查气门间隙（仅检查）

#### 第3阶段：中级维修（3-6月）

**学习目标**：
- 掌握各系统工作原理
- 学会使用诊断仪
- 掌握拆装基本功

**实操任务**：
- 调整气门间隙
- 拆装化油器
- 拆装前叉
- 拆装卡钳
- 简单电气故障诊断
- 更换电瓶

#### 第4阶段：高级维修（6月-1年）

**学习目标**：
- 掌握发动机内部结构
- 掌握ECU诊断
- 掌握复杂故障排除

**实操任务**：
- 发动机大修
- 悬挂升级
- ECU重新映射
- 复杂改装
- 轴传动维护（如有）

#### 第5阶段：专业维修（1年+）

**学习目标**：
- 各品牌细节差异
- 比赛级调校
- 定制改装

**实操任务**：
- 自由操作各种车型
- 解决疑难故障
- 性能改装
- 指导他人
