## 2.1 工具总览（先建立全局认知）

### 2.1.1 为什么工具这么重要

【问答】 **新手问答**：工具便宜的有，贵的也有，差很多吗？

答：**差非常多**。差的工具不仅难用，还会把螺丝拧花、把零件刮花。

**真实案例**：

场景1：用劣质螺丝刀拧紧螺丝
- 螺丝刀头打滑
- 螺丝槽被拧花（叫"螺丝滑丝"）
- 螺丝报废
- 可能还要钻出来重攻丝

场景2：用劣质扳手拧螺母
- 扳手打滑
- 螺母圆角
- 螺母报废
- 可能还要切割下来

**所以**：工具是值得投资的。买质量好的工具，能用十几年甚至一辈子。

### 2.1.2 工具等级（关键认知）

工具按用途和价格分三个等级。每个新手都应该按这个顺序升级：

```
★ 新手必备级（每个新手都要有）
├── 螺丝刀套装
├── 扳手套装
├── 内六角套装
├── 钳子3件套
├── 锤子（橡胶+铁）
└── 基础工具包

★★ 进阶必备级（开始自己修车就要有）
├── 扭力扳手 ★ 最重要
├── 数字万用表
├── 卡尺
├── 套筒套装
├── 拉马（拉拔器）
└── 链条工具

★★★ 专业工具级（高级维修才需要）
├── OBD诊断仪
├── 气缸压力表
├── 燃油压力表
├── 示波器
├── 专用发动机工具
└── 各种拉拔器
```

【注意】 **常见误解**："工具多就是好" — 错。新手工具多反而乱。先有核心工具，需要时再补充。

## 2.2 手动工具详解

### 2.2.1 螺丝刀

#### 螺丝刀是什么

最基础的工具，用来拧十字或一字螺丝。

#### 螺丝刀种类

**按头部形状**：
- 一字（Slot/Flat）
- 十字 Phillips（PH，十字槽）
- 十字 Pozidriv（PZ，带小斜线槽）
- Torx / 六角星（T，六角星形）
- Hex / 内六角（H，正六边形）
- JIS（日本工业标准，摩托车日系车常见）
- 特种（如摩托车气门调整螺丝的"花键"）

【注意】 **日系车螺丝刀**：摩托车尤其日系车常用 **JIS 螺丝刀**，看起来像 Phillips 但**角度更钝**，**不能用 Phillips 螺丝刀硬拧 JIS**（会滑丝）。

**按规格**：

十字螺丝刀规格：

| 规格 | 应用 |
|------|------|
| PH0 | 小螺丝（仪表内） |
| PH1 | 中等螺丝（覆盖件） |
| PH2 | 大螺丝（多用途） |
| PH3 | 大螺丝（少见） |

一字螺丝刀规格：

| 规格 | 应用 |
|------|------|
| 3mm | 小螺丝 |
| 5mm | 中等螺丝 |
| 6mm | 大螺丝 |
| 8mm | 极大螺丝 |

Torx螺丝刀规格：

| 规格 | 应用 |
|------|------|
| T8 | 小 |
| T10 | 小中 |
| T15 | 中 |
| T20 | 中大 |
| T25 | 大 |
| T30 | 极大 |
| T40 | 巨型 |

#### 为什么摩托车常用十字螺丝

- 早期摩托车多用十字螺丝（标准化）
- 现代部分车型用Torx（强度更高、不易滑）
- 高端车型（杜卡迪）部分用内六角或特殊头

#### 螺丝刀品牌选择

| 品牌 | 定位 | 价格 | 推荐度 |
|------|------|------|--------|
| Wera | 高端 | 贵 | ★★★★★ |
| Wiha | 高端 | 贵 | ★★★★★ |
| PB Swiss | 高端 | 贵 | ★★★★ |
| 世达（Sata） | 中端 | 中 | ★★★★ |
| 史丹利（Stanley） | 中端 | 中 | ★★★ |
| 田岛（TAJIMA） | 中端 | 中 | ★★★ |
| 淘宝廉价 | 低端 | 便宜 | ★ |

【问答】 **新手问答**：便宜螺丝刀能用吗？

答：短期能用，但容易出问题。建议至少买中等质量的。高端品牌一套螺丝刀500-1000元，能用几十年。

【维修】 **维修场景**：
- 拆覆盖件：PH2 螺丝刀（最常用）
- 拆电池盒：PH1 或 PH2
- 拆仪表：PH0 或 PH1
- 拆发动机边盖：特殊规格

#### 螺丝刀使用技巧

**正确握法**：
- 拇指压顶部
- 食指、中指扶杆部
- 手掌压柄部
- 保持螺丝刀与螺丝垂直

**拧紧技巧**：
- 先正手拧紧（顺时针）
- 接近到底时放慢
- 最后一点用力

**拧松技巧**：
- 反手（逆时针）施加压力
- 听到"咔哒"声时用力
- 别急，慢慢来

【注意】 **常见错误**：
- 螺丝刀头不匹配螺丝 → 滑丝
- 螺丝刀与螺丝不垂直 → 滑丝
- 用力过猛 → 螺丝刀头磨损
- 不检查就硬拧 → 螺丝滑丝报废

### 2.2.2 扳手

#### 扳手是什么

用来拧螺母和螺栓的工具。

#### 扳手种类

**开口扳手**：
- 两端开口
- 适合空间大的位置
- 价格便宜

**梅花扳手**：
- 环形封闭
- 包裹螺母
- 不易滑脱
- 推荐优先使用

**两用扳手**：
- 一端开口、一端梅花
- 主流扳手样式

**活动扳手**：
- 开口可调
- 不推荐用于精密维修
- 应急使用

**扭力扳手**（后面单独讲）

#### 公制扳手规格

摩托车最常用的规格：

| 规格 | 应用 |
|------|------|
| 8mm | 小零件 |
| 10mm | 最常用 |
| 12mm | 最常用 |
| 13mm | 通用 |
| 14mm | 通用 |
| 17mm | 大螺母 |
| 19mm | 很大螺母 |
| 22mm | 极大螺母 |
| 24mm | 顶级大螺母 |

【数据】 **数据举例**（凯旋Scrambler 1200X常用规格）：

| 部位 | 规格 |
|------|------|
| 火花塞 | 16mm |
| 机油放油螺丝 | 17mm |
| 缸盖螺丝 | 12mm |
| 后轴螺母 | 24mm |
| 前轴螺母 | 22mm |
| 链条调节螺母 | 14mm |

#### 英制扳手

部分美规车型（哈雷、印第安、部分国产）用英制：

| 规格 | 用途 |
|------|------|
| 3/8" | 常见 |
| 1/2" | 常见 |
| 9/16" | 常见 |
| 5/8" | 较大 |
| 3/4" | 大 |

【注意】 **常见误解**："英制和公制差不多" — 错！1/2" = 12.7mm，而 13mm 扳手是近似的公制规格。如果用公制 13mm 扳手拧英制 1/2" 螺丝，会偏大滑脱。

【问答】 **新手问答**：买扳手买公制还是英制？

答：先按车型买。日系、国产、多数欧系以**公制**为主；哈雷、印第安、部分老美系或改装件，再备**英制**。⭐

#### 扳手使用技巧

**正确握法**：
- 虎口握住扳手柄部
- 拇指压顶部
- 食指、中指辅助
- 拉动而非推动

**为什么拉不推**：
- 推动时手部肌肉别扭
- 万一打滑手部受伤
- 拉动更稳更安全

【维修】 **维修场景**：
- 拧火花塞：专用火花塞套筒（14/16/18/21mm）
- 换机油放油螺丝：17mm 开口或梅花
- 拆轮毂：专用扳手或套筒
- 调整链条：14mm 梅花

【注意】 **火花塞工具**：火花塞拆装要用**专用火花塞套筒**（深套筒，内含橡胶垫圈）。普通套筒/梅花扳手大多数场景**不能用**于火花塞，容易损伤火花塞陶瓷体。

【注意】 **常见错误**：
- 用错规格 → 螺母滑角
- 用开口扳手拧紧 → 螺母滑角
- 用活动扳手拧精密螺丝 → 螺丝滑角
- 用力过猛 → 螺丝断

### 2.2.3 套筒

#### 套筒是什么

套筒是封闭的扳手，配合棘轮扳手（扳手柄）使用。

#### 为什么套筒很重要

- 空间小的地方只能用套筒
- 速度快（棘轮不用每次取下）
- 不易滑脱

#### 套筒规格

**驱动尺寸**（套筒的方榫尺寸）：

| 驱动尺寸 | 适用扭矩 |
|----------|----------|
| 1/4" | 小扭矩（精密） |
| 3/8" | 中扭矩（主流） |
| 1/2" | 大扭矩（重负载） |

**螺栓六角规格**：

| 规格 | 应用 |
|------|------|
| 8mm | 小螺丝 |
| 10mm | 通用 |
| 12mm | 通用 |
| 14mm | 大螺丝 |
| 17mm | 大螺母 |
| 19mm | 极大 |

#### 套筒套装

**入门套装**（推荐新手）：
- 3/8" 棘轮扳手
- 套筒：8, 10, 12, 13, 14, 15, 17, 19mm
- 加长杆
- 万向接头
- 数量：20件左右
- 价格：200-500元

**进阶套装**：
- 1/2" 棘轮扳手（用于大螺丝）
- 3/8" 棘轮扳手
- 1/4" 棘轮扳手（精密）
- 套筒覆盖 6-32mm
- 加长杆、万向、转换接头
- 数量：50-100件
- 价格：500-2000元

【问答】 **新手问答**：先买1/2"还是3/8"？

答：**先买3/8"**。3/8" 是主流规格，摩托车大部分螺丝都用3/8"套筒。

【维修】 **维修场景**：
- 拆发动机外壳：8/10mm 套筒
- 拆气门室盖：10mm 套筒
- 拆缸盖：12mm 套筒
- 拧后轴螺母：1/2" 套筒 + 24mm

#### 套筒使用技巧

**加长杆作用**：
- 节省力气
- 接触不到的地方用加长杆
- 直线加长杆**不改变扭矩**，扭力扳手显示的力矩就是真实施加力矩
- 偏置工具（crowfoot 开口扳手头）**需要换算**，因为力臂改变

【注意】 **扭矩换算**：直线加长接杆是 OK 的；**只有 crowfoot 偏置头才需要做力矩换算**。

**万向接头作用**：
- 角度不对的地方用万向
- 灵活方便
- 但**万向不能用于大扭矩**（容易损坏）

### 2.2.4 内六角

#### 内六角是什么

头部是六角孔的螺丝（也叫"阿伦螺丝"或"艾伦螺丝"）。

#### 为什么摩托车爱用内六角

- 占用空间小
- 强度高
- 美观
- 不易滑脱

#### 内六角规格

公制（主流）：

| 规格 | 应用 |
|------|------|
| 2mm | 极小（仪表） |
| 2.5mm | 小 |
| 3mm | 通用 |
| 4mm | 通用 |
| 5mm | 通用 |
| 6mm | 大 |
| 8mm | 极大 |
| 10mm | 顶级大 |

英制（部分美规）：

| 规格 | 应用 |
|------|------|
| 1/16" | 小 |
| 5/64" | 小 |
| 3/32" | 小中 |
| 1/8" | 中 |
| 5/32" | 大 |
| 3/16" | 大 |
| 1/4" | 极大 |

#### 内六角套装

**L型内六角**（最常用）：
- 短端：力矩大
- 长端：能进深孔
- 套装：2-10mm
- 价格：30-200元

**T型内六角**（更省力）：
- 手柄长
- 力矩大
- 适合拧紧大螺丝

**折叠式内六角**（便携）：
- 多规格一体
- 便携
- 力矩不如L型

**带球头的内六角**（可倾斜）：
- 可以斜着拧
- 适合空间受限

【口诀】 **记忆口诀**：3、4、5、6 内六角最常用；2、2.5 小螺丝；8、10 大螺丝。

【维修】 **维修场景**：
- 拆覆盖件：4mm、5mm 内六角
- 拆脚踏：6mm 内六角
- 拆车把夹：4mm、5mm 内六角
- 拆座椅：4mm、5mm 内六角

【注意】 **常见错误**：
- 用错规格 → 内六角螺丝滑角（很难修复）
- 用便宜的内六角 → 容易断头
- 用力过猛 → 内六角螺丝头部滑角

【问答】 **新手问答**：内六角螺丝滑角了怎么办？

答：这是非常麻烦的情况。常见处理方法：
1. 用橡皮垫在螺丝头上再加力
2. 用专用螺丝取出工具
3. 用电钻打掉，重新攻丝
4. 实在不行，整个部件更换

**所以**：选对规格 + 不要用便宜货 + 不要硬拧。

### 2.2.5 钳子

#### 钳子种类

**尖嘴钳**：
- 头部尖细
- 夹持小物件
- 弯折电线

**斜嘴钳（剪钳）**：
- 用于剪断电线
- 剪铁丝
- 不要用于拧螺丝（会损坏）

**鲤鱼钳**：
- 钳口可调
- 夹持较大物件
- 通用

**卡簧钳**：
- 拆装卡簧
- 内外卡簧不同
- 摩托车维修必备

**大力钳**：
- 锁定式
- 夹持力大
- 焊接时夹持工件

【维修】 **维修场景**：
- 尖嘴钳：夹持小螺丝、弯折线束
- 斜嘴钳：剪电线、剪扎带
- 鲤鱼钳：拆火花塞帽（应急）、拔钉子
- 卡簧钳：拆气门卡簧、拆刹车卡钳销

#### 钳子品牌选择

| 品牌 | 定位 | 推荐 |
|------|------|------|
| Knipex | 高端 | ★★★★★ |
| 世达 | 中端 | ★★★★ |
| 田岛 | 中端 | ★★★★ |
| 宝工（Pro'sKit） | 中端 | ★★★ |

【注意】 **常见错误**：
- 用钳子代替扳手 → 螺母滑角
- 用斜嘴钳拧螺丝 → 钳口损坏
- 用便宜钳子剪钢丝 → 钳口崩

### 2.2.6 锤子

#### 锤子种类

**橡胶锤**：
- 软头
- 不损伤表面
- 摩托车维修必备

**塑料锤**：
- 比橡胶硬
- 适合中等敲击

**铁锤**：
- 硬头
- 大力敲击
- 必须配合垫木块使用

**铜锤**：
- 不产生火花
- 适合易燃环境

【维修】 **维修场景**：
- 拆下轴承：用铁锤+垫木
- 安装轮胎：用橡胶锤
- 校正变形零件：用橡胶锤
- 安装销钉：用塑料锤

【注意】 **常见错误**：
- 用铁锤直接敲击零件 → 零件损坏
- 用力过猛 → 零件变形
- 锤头松动 → 飞出伤人

## 2.3 测量工具详解

### 2.3.1 量具

#### 卷尺

- 测量长度
- 一般5m够用
- 摩托车维修不常用

#### 钢尺

- 精确测量
- 30cm 够用
- 检查间隙时用

#### 游标卡尺（重要★★★）

**是什么**：测量内外径、深度、台阶的高精度工具。

**精度**：0.02mm 或 0.05mm

**应用**：
- 外径测量（活塞、轴、销）
- 浅深度测量
- 台阶测量
- 内径粗测
- 测量刹车片厚度

【注意】 **精密间隙工具**：气门间隙 → **塞尺**；轴瓦间隙 → **Plastigauge（塑料线规）+ 千分尺 + 内径表**。新手买工具：游标卡尺是基础测量工具，但**测量气门/轴瓦这种精密间隙，要用更专业的工具**。

**使用方法**：

测量外径：
1. 物体夹在卡尺外爪
2. 轻轻合拢
3. 读数

测量内径：
1. 物体放在卡尺内爪
2. 轻轻张开
3. 读数

测量深度：
1. 深度尺伸入孔
2. 到底
3. 读数

【数据】 **数据举例**：

摩托车维修常用游标卡尺测量：

| 项目 | 测量什么 | 标准值 |
|------|----------|--------|
| 链条厚度 | 节厚度 | 见标准 |
| 链轮齿厚 | 齿厚 | 见标准 |
| 活塞直径 | 直径 | 见标准 |
| 刹车盘厚度 | 盘厚度 | 见标准 |

**游标卡尺品牌**：

| 品牌 | 精度 | 价格 |
|------|------|------|
| 三丰（Mitutoyo） | 0.02mm | 500-2000元 |

| 国产中端 | 0.02mm | 100-200元 |

【问答】 **新手问答**：游标卡尺便宜能用吗？

答：能。但要选金属的、刻度清晰的。塑料的、刻度模糊的不要买。

### 2.3.2 塞尺（间隙尺）

#### 塞尺是什么

一组长薄金属片，每片有固定厚度。

#### 应用

- 气门间隙

### 2.3.3 扭力扳手（重要★★★★★）

#### 扭力扳手是什么

显示扭矩的扳手，拧到设定扭矩会发出"咔哒"声或手感变化。

#### 为什么扭力扳手最重要

**没有扭力扳手会出现的问题**：

| 拧紧程度 | 后果 |
|----------|------|
| 过松 | 螺丝松动、脱落 |
| 略松 | 振动、漏气、漏油 |
| 正好 | 正常 |
| 略紧 | 螺丝变形、可能断 |
| 过紧 | 螺丝断、螺纹滑丝 |

**结论**：发动机、刹车、悬挂等关键部位的螺丝，必须用扭力扳手。

#### 扭力扳手类型

**指针式**：
- 指针显示扭矩
- 便宜
- 不易读准

**预置式（咔哒式）**：
- 设定扭矩
- 到达扭矩"咔哒"响
- 最常用

**数显式**：
- 数字显示
- 精确
- 较贵

#### 扭力扳手规格

按扭矩范围：

| 范围 | 应用 |
|------|------|
| 1/4" 驱动 5-25Nm | 精密（小螺丝） |
| 3/8" 驱动 5-50Nm | 中等（主流） |
| 1/2" 驱动 20-200Nm | 大螺丝（后轴等） |
| 3/4" 驱动 50-300Nm | 极大螺丝 |

#### 摩托车维修需要的扭力范围

| 应用 | 扭矩范围 |
|------|----------|
| 火花塞 | 15-25Nm |
| 缸盖螺丝 | 30-50Nm |
| 油底壳螺丝 | 8-15Nm |
| 主轴瓦盖 | 50-80Nm |
| 连杆螺栓 | 30-50Nm |
| 飞轮 | 40-100Nm |
| 前轴螺母 | 60-100Nm |
| 后轴螺母 | 80-120Nm |
| 卡钳螺栓 | 30-50Nm |
| 方向柱锁紧 | 40-80Nm |

#### 推荐配置

**新手配置**（1个扭力扳手）：
- 3/8" 驱动 5-50Nm（覆盖80%维修）
- 价格：200-500元

**进阶配置**（2个扭力扳手）：
- 3/8" 驱动 5-50Nm（精密）

- 价格：500-1500元

| 品牌 | 定位 | 价格 | 推荐 |
|------|------|------|------|
| Snap-on | 顶级 | 2000+ | ★★★★★ |
| Stahlwille | 顶级 | 2000+ | ★★★★★ |
| 世达 | 中端 | 200-500 | ★★★★ |
| 力易得 | 中端 | 200-500 | ★★★ |
| 淘宝 | 低端 | 50-200 | ★★ |

【问答】 **新手问答**：扭力扳手便宜的能用吗？

答：能用，但要每年校准一次（专业机构校准费用50-100元）。便宜扭力扳手偏差可能 5-10%，对一般维修影响不大。

#### 扭力扳手使用注意事项

**使用前**：
- 检查是否归零
- 检查外观

**使用中**：
- 缓慢用力
- 听到"咔哒"立即停止
- 不要冲击式用力

**使用后**：
- 归零（释放弹簧张力）
- 放回盒中
- 避免跌落

【注意】 **常见错误**：
- 不归零存放 → 弹簧疲劳，精度下降
- 超过量程使用 → 损坏
- 用作普通扳手 → 精度下降
- 不校准 → 数据不准

### 2.4.2 制动系统专用工具

#### 刹车卡钳压具

**是什么**：压回卡钳活塞的工具。

**用法**：
1. 卡钳活塞伸出（磨损后）
2. 用压具压回
3. 同时观察刹车油壶（不能溢出）

【维修】 **维修场景**：

【经验⭐】 **试灯不是万能工具**：遇到 ECU、传感器、CAN 总线，不要用“试灯一碰就知道”的老办法，必须改用高阻表或示波器。

## 2.5 诊断设备详解

### 2.5.1 OBD诊断仪

#### 什么是OBD

OBD（On-Board Diagnostics，车载诊断系统）能读取车辆故障码。

#### OBD接口位置

【经验⭐】 **位置原则**：**OBD 接口位置以你车主维修手册为准**。摩托车 OBD 接口位置多样，不能按街车、跑车、踏板车固定判断。

常见位置（参考）：
- 座垫下
- 侧盖内
- 头罩内
- 电池附近
- ECU 旁

#### OBD设备类型

**蓝牙OBD（最便宜）**：
- 价格：50-150元
- 配合手机APP使用
- 读取基本故障码

**手持OBD**：
- 价格：200-1000元
- 独立使用
- 显示直观

**专业诊断仪**：
- 价格：1000-5000元
- 全面诊断
- 厂家级

#### OBD能做什么

- 读取故障码
- 清除故障码
- 读实时数据
- 部分能做基本设定

#### OBD不能做什么

- 不能修车
- 不能做高级编程
- 不能替代专业诊断

【数据】 **数据举例**（常见故障码）：

| 故障码 | 含义 |
|--------|------|
| P0300 | 随机失火 |
| P0301 | 1缸失火 |
| P0171 | 系统过稀 |
| P0420 | 催化器效率低 |
| P0562 | 系统电压低 |

【注意】 **通用码边界**：P0xxx 是 OBD-II 通用码，所有支持 OBD-II 的车都支持；但**厂家专用码**（P1xxx / B / C / U）需要**专用诊断仪**。常见厂家工具包括本田 HDS、雅马哈 YDT、川崎 KDS / KHI、KTM 专用诊断仪，以及哈雷 / 杜卡迪 / BMW 各自专用诊断系统。很多摩托车的**重要故障码在专用码区**，通用 OBD-II **读不出来**。OBD-II 通用码是基础，但**完整诊断需要厂家专用诊断仪**。

【维修】 **维修场景**：
- 仪表故障灯亮
- 性能下降但找不到原因
- 维修后清除故障码

#### 气缸压力表

**是什么**：测量气缸压缩压力的工具。

**应用**：
- 检查气缸密封
- 判断气门、活塞环状态

**用法**：
1. 拆下火花塞
2. 安装压力表
3. 启动电机几秒
4. 读数

【原理⭐⭐⭐】 **压缩压力不是按缸数定**：压缩压力以你车主维修手册为准。它取决于发动机设计、凸轮正时、海拔、测试条件和气缸密封状态，不能用“四缸/双缸/单缸”直接给标准值。

【原理⭐⭐⭐】 **粗略关系**：一般摩托车压缩比约 9-13:1（经验值⭐）。压缩压力与压缩比有关，但实际压缩过程受气门正时、起动转速、温度、海拔、活塞环和气门密封影响；“大气压力 × 压缩比”只能帮助理解量级，不能用于判定。最终看维修手册给出的压缩压力范围和缸间差。⭐

【经验⭐】 **环境影响**：海拔每升高 1000m，气压约下降 12%，压缩压力读数也会随之降低。

【注意】 **测试条件**：测试时油门全开（WOT）、电池充足、发动机热态。最终判断必须**以你车主维修手册为准**。

#### 燃油压力表

**是什么**：测量燃油系统压力的工具。

**应用**：
- 检查燃油泵
- 检查压力调节器

#### 真空表

**是什么**：测量进气真空度的工具。

**应用**：
- 进气真空度测量（诊断进气系统）
- 化油器同步（多缸化油器同步平衡）
- 进气泄漏检查
- 怠速稳定性诊断

【注意】 **气门密封**：**真空表 ≠ 气门密封检查**；气门密封问题用**压缩测试 + 泄漏测试**。泄漏测试是向气缸灌压缩空气，再听进气、排气、曲轴箱位置是否漏气。

#### 冷却系统压力测试仪

**是什么**：测试冷却系统密封的工具。

**用法**：
1. 加压到标准值
2. 观察压力下降
3. 找出泄漏点

#### 烟雾检测仪

**是什么**：检测进气系统泄漏的工具。

**用法**：
1. 把烟雾注入进气系统
2. 观察哪里冒烟
3. 找出泄漏点

## 2.7 工具使用技巧（实战场景）

### 2.7.1 螺丝拆装技巧

#### 螺丝滑丝怎么办

**预防**：
- 用合适规格
- 不要硬拧
- 用质量好的工具

**补救方法**：

方法1：橡皮法
- 把橡皮放在螺丝头上
- 用螺丝刀压橡皮
- 增加摩擦

方法2：缝衣针法
- 用针尖插入十字缝
- 增加接触面积

方法3：橡胶垫法
- 在螺丝刀头上包橡胶
- 增加摩擦

方法4：专业工具
- 螺丝取出器
- 钻出后重新攻丝

方法5：焊接法
- 在螺丝头上焊螺母
- 用螺母拧出

方法6：冲击法
- 用锤击螺丝刀
- 利用震动

方法7：终极方法
- 钻掉螺丝
- 重新攻丝或焊接修复

### 2.7.2 螺丝拧紧技巧

#### 扭矩法（推荐）

```
步骤：
1. 设定扭力扳手扭矩
2. 缓慢用力
3. 听到"咔哒"立即停止
4. 多次紧固时按对角顺序
```

#### 多螺丝拧紧顺序

**对角顺序**（最常用）：
```
4个螺丝：1→3→2→4
6个螺丝：1→4→2→5→3→6
8个螺丝：1→5→3→7→2→6→4→8
```

**螺旋顺序**：
从中心向外，逐步扩散。

#### 不同螺丝拧紧方式

**缸盖螺丝**（重要）：
1. 分多次拧紧（不要一次到位）
2. 纯示意：例如分级递增，具体数值不可照抄
3. 按对角顺序
4. 按车型维修手册确认扭矩、顺序、是否使用角度规、螺栓是否可重复使用、螺纹/垫面是否润滑 ⭐

**油底壳螺丝**：
1. 对角顺序
2. 不要一次拧紧
3. 拧到规定扭矩即可

### 2.7.3 螺纹修复

#### 螺纹滑丝

**处理方法**：

方法1：丝攻修复
- 用相同规格丝攻
- 重新攻丝
- 适合轻微损坏

方法2：螺纹修复套件
- 钻孔
- 攻丝
- 安装螺纹套
- 适合中等损坏

方法3：焊接修复
- 焊接填满
- 重新钻孔攻丝
- 适合严重损坏

方法4：更换部件
- 整个部件换掉
- 适合无法修复

#### 螺纹咬死（不锈钢螺丝常见）

**预防**：
- 不锈钢螺丝容易咬死
- 是否涂防咬合剂按维修手册或部位要求；未要求处不要自行改变润滑条件，因为润滑/防咬合剂会改变扭矩-预紧力关系 ⭐

**处理方法**：

方法1：渗透油
- 喷渗透油
- 等待10-30分钟
- 慢慢拧

方法2：加热
- 用气焊枪加热
- 让金属膨胀
- 趁热拧

方法3：冲击
- 用锤击螺丝刀
- 利用震动

方法4：暴力破坏
- 实在不行，破坏螺丝
- 取出后换新的

### 2.7.4 拉拔技巧

#### 轴承拉拔

**正确方法**：
1. 使用专用拉马
2. 钩住轴承
3. 旋转中心螺栓
4. 缓慢拉出

**错误方法**：
- 用螺丝刀撬 → 损坏轴承位
- 用锤子敲 → 损坏轴承
- 火焰切割 → 损坏部件

#### 齿轮拉拔

类似轴承，用专用拉马。

### 2.7.5 密封件处理

#### O型圈安装

**正确方法**：
1. 涂抹润滑脂
2. 不要拉伸
3. 不要扭曲
4. 放入密封槽

**错误方法**：
- 拉伸O型圈 → 永久变形
- 不润滑 → 装配时切伤
- 扭曲、夹伤、规格不对 → 漏油
- 有方向的油封、唇形密封、异形密封 → 按标记和手册安装 ⭐

#### 油封安装

**正确方法**：
1. 用专用工具
2. 水平压入
3. 涂抹润滑油
4. 注意方向（有的油封有方向）

**错误方法**：
- 用锤子敲 → 变形
- 倾斜压入 → 漏油
- 装反 → 漏油

## 2.8 工具维护与保养

### 2.8.1 日常维护

**每次用完**：
- 清洁工具
- 归位

**每周**：
- 检查工具状态
- 润滑运动部件

### 2.8.2 扭力扳手维护（特别重要）

**每月**：
- 检查精度（如果有校准件）
- 检查外观

**每年**：
- 专业校准（50-100元）

**存放**：
- 归零后存放
- 放回原盒
- 干燥环境
- 避免跌落

【注意】 **常见错误**：
- 不归零存放 → 弹簧疲劳
- 跌落 → 精度丧失
- 用作普通扳手 → 精度丧失
- 不校准 → 数据不准

### 2.8.3 电动工具维护

**锂电池**：
- 不要完全放电
- 不要过充
- 长期不用时50%电量存放

**碳刷**：
- 定期检查
- 磨损后更换

### 2.8.4 精密工具存放

**游标卡尺**：
- 清洁后存放
- 防锈油
- 专用盒

**塞尺**：
- 清洁
- 防锈

**万用表**：
- 关闭电源
- 取出电池（长期不用）
- 干燥环境
