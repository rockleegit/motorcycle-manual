# 第3章 安全规范

> 这一章是**最重要的一章**。你学了怎么修车，工具也好，但安全不规范，可能没修好车反而被车"修"了——受伤、中毒、火灾、爆炸。

## 3.1 维修工作的一般安全原则

### 3.1.1 三个核心原则

```
原则1：预防为主
原则2：保护到位
原则3：应急有备
```

#### 原则1：预防为主

**为什么预防比治疗重要**：

| 项目 | 数据 |
|------|------|
| 因维修受伤的技师 | 每年全球数千人 |
| 因维修死亡的技师 | 每年全球数十人 |
| 其中可预防的比例 | 80%以上 |

**具体含义**：
- 不要想着"应该没事"
- 不要为了"快点"跳过步骤
- 不要在疲劳/分心时操作

#### 原则2：保护到位

**个人防护装备（PPE）**：
- 手套
- 护目镜
- 工作服
- 鞋
- 呼吸保护（必要时）

#### 原则3：应急有备

**必备**：
- 急救箱
- 灭火器
- 紧急联系方式
- 知道最近的医院

### 3.1.2 维修前的安全检查清单

每次维修前，**必须**检查：

| 检查项 | 检查什么 | 状态 |
|--------|----------|------|
| 通风 | 空气流通 | [ ] |
| 灭火器 | 在手边 | [ ] |
| 急救箱 | 在手边 | [ ] |
| 电瓶 | 已断电（如需要） | [ ] |
| 油液 | 已收集 | [ ] |
| 工具 | 已准备 | [ ] |
| 说明书 | 在手边 | [ ] |
| 拍摄 | 已拍照记录 | [ ] |

【问答】 **新手问答**：每次都要做这个清单吗？

答：**是的**。这是习惯。开始时觉得麻烦，养成后变成本能。

## 3.2 个人防护装备（PPE）详解

### 3.2.1 护目镜 ●●●●●（最重要）

#### 为什么要戴护目镜

**真实伤害**：
- 清洁剂溅入眼睛 → 失明
- 金属碎屑飞入 → 眼球损伤
- 油液飞溅 → 角膜损伤
- 高压油液喷射 → 眼球穿孔

【注意】 **严重警告**：眼睛伤害是不可逆的。一旦受伤，即使治好视力也下降。

#### 护目镜类型

**普通护目镜**：
- 包住眼睛
- 防飞溅
- 价格：20-100元

**侧面防护型**：
- 侧面也保护
- 推荐

**化学防护型**：
- 防化学物质
- 操作油液时使用

【维修】 **维修场景**：
- 清洁刹车：必须戴护目镜
- 操作清洁剂：必须戴
- 拆链条：必须戴
- 任何喷洒操作：必须戴

【注意】 **常见错误**：
- 用普通眼镜代替护目镜 → 侧面无保护
- 戴护目镜但镜片脏 → 影响视野
- 不戴护目镜"小心点就行" → 一滴油就失明

【问答】 **新手问答**：我有近视眼镜怎么办？

答：戴在护目镜里面，或购买带度数的护目镜。

#### 护目镜品牌

| 品牌 | 特点 | 价格 |
|------|------|------|
| 3M | 高端 | 50-200元 |
| Uvex | 高端 | 80-300元 |
| 霍尼韦尔 | 中高端 | 50-200元 |
| 国产中端 | 性价比 | 20-50元 |
| 淘宝廉价 | 凑合用 | 10-30元 |

### 3.2.2 手套 ●●●●

#### 为什么要戴手套

**主要防护**：
- 切伤
- 烫伤
- 化学伤害
- 油液接触
- 划伤

#### 手套类型

**一次性丁腈手套**：
- 处理油液
- 一次性
- 价格：20-50元/盒

**橡胶手套**：
- 清洁用
- 不适合精密操作

**皮革手套**：
- 防止切伤
- 机械操作
- 焊接等高温工作

**丁腈涂层手套**：
- 防滑
- 防油
- 机械操作
- 推荐

**耐高温手套**：
- 操作热部件
- 拆消音器
- 操作气缸

【维修】 **维修场景**：
- 换机油：丁腈一次性手套
- 拆火花塞：丁腈涂层手套
- 拆消音器：耐高温手套
- 焊接：皮手套
- 清洁：橡胶手套

【注意】 **常见错误**：
- 用不防油的手套 → 油液渗入
- 戴手套操作细小螺丝 → 不好操作
- 一次性手套重复用 → 破损

【问答】 **新手问答**：戴手套操作细小螺丝会不会不方便？

答：会。所以**精密操作时不戴手套**。但大操作（油液、重零件）必须戴。

### 3.2.3 工作服 ●●●

#### 为什么要穿工作服

**主要防护**：
- 油液污染衣服
- 高温烫伤
- 划伤

#### 工作服类型

**连体工服**：
- 整体保护
- 机械师常用
- 推荐

**分体工服**：
- 上下分
- 实用

**旧衣服**：
- 应急用
- 容易破

【注意】 **注意**：
- 工作服应合身
- 袖口不应过宽（避免卷进旋转部件）
- 不要穿宽松衣服

【维修】 **维修场景**：
- 换机油：必穿（油液会溅）
- 拆发动机：必穿
- 任何维修：必穿

### 3.2.4 鞋 ●●●●

#### 为什么要穿工作鞋

**主要防护**：
- 重物砸脚
- 油液滑倒
- 钉子扎脚
- 高温烫伤

#### 工作鞋类型

**安全鞋（推荐）**：
- 钢头防砸
- 防滑
- 防刺穿
- 价格：100-500元

**防滑鞋**：
- 防油液
- 一般防护

**拖鞋/凉鞋**：
- 严禁穿！
- 绝对危险

【注意】 **严重警告**：摩托车维修**严禁穿拖鞋、凉鞋、网面鞋**。重物落下或油液滑倒可能导致严重伤害。

【维修】 **维修场景**：
- 换胎：必穿安全鞋
- 拆发动机：必穿
- 任何情况：必穿

### 3.2.5 呼吸保护 ●●●●（重要）

#### 为什么要戴呼吸保护

**真实风险**：
- 汽油蒸气
- 清洁剂蒸气
- 粉尘
- 焊接烟气

#### 呼吸保护类型

**防尘口罩**：
- 过滤粉尘、研磨颗粒（无油雾）
- 处理打磨粉尘
- 价格：1-5元/个

**有机蒸气滤盒（褐色）**：
- 过滤化油器清洗剂、油漆、汽油蒸气
- 必须密合，滤盒到期或闻到异味就更换
- 价格：50-200元

**酸性气体滤盒（白色）**：
- 过滤电瓶酸雾
- 必须按滤盒标识和说明书选型

**颗粒物/烟尘防护（P100/FFP3）**：
- 过滤焊接烟尘、打磨粉尘
- 焊接还必须配合局部排风

**供气式呼吸器**：
- 长时间喷漆、专业涂装
- 专业场合

【维修】 **维修场景**：
- 清洁化油器：有机蒸气滤盒
- 处理粉尘：防尘口罩或P100/FFP3
- 电瓶酸雾：酸性气体滤盒
- 焊接：局部排风 + 颗粒物/烟尘防护 + 防火花衣服

【注意】 **常见错误**：
- "闻一下没事" → 长期会损伤
- 用医用口罩代替滤盒式呼吸防护 → 不能过滤化学蒸气
- 滤盒过期继续用 → 防护失效
- 不戴 → 长期损伤

【问答】 **新手问答**：操作油液需要呼吸防护吗？

答：**需要合适滤盒**。汽油蒸气、清洁剂蒸气要用有机蒸气滤盒；滤盒必须密合、有寿命，到期要换。

### 3.2.6 头部保护

#### 头灯

**应用**：
- 照明不足时
- 解放双手

**价格**：30-200元

#### 安全帽

**应用**：
- 举升重物
- 车间内
- 偶尔必要

**价格**：50-300元

## 3.3 维修环境安全

### 3.3.1 通风 ●●●●●（最重要）

#### 为什么通风最重要

**真实风险**：
- 汽油蒸气 → 爆炸、火灾、吸入
- 清洁剂蒸气 → 中毒
- 焊接烟气 → 肺损伤
- 一氧化碳 → 死亡

【注意】 **严重警告**：通风不良是**最常见的严重事故原因**。

#### 通风要求

**绝对禁止**：
- 封闭空间操作汽油
- 密闭空间清洁化油器
- 通风不良时使用溶剂

**必须**：
- 开窗开门
- 风扇强制通风
- 户外作业

【维修】 **维修场景**：
- 化油器清洁：户外或强通风
- 燃油系统操作：户外
- 焊接：通风良好
- 喷涂：户外

【注意】 **常见错误**：
- "就一点点汽油" → 蒸气足够引燃
- "在车库里没事" → 容易中毒
- 通风但用明火 → 火灾

### 3.3.2 防火 ●●●●●

#### 真实火灾案例

**场景**：在车库里操作汽油

```
操作：拆化油器
意外：汽油洒出
火源：明火（电暖器）
结果：车毁，可能人亡
```

#### 防火措施

**禁止明火**：
- 维修区禁止吸烟
- 禁止明火作业
- 禁止明火取暖

**禁止火源**：
- 静电
- 火花
- 热表面
- 电火花

**必备器材**：
- 灭火器（必备）
- 防火毯
- 砂土（少量油火）

#### 灭火器

**类型**：

| 类型 | 适用 | 摩托车维修 |
|------|------|------------|
| 干粉 | 通用 | ●●●●●推荐 |
| 二氧化碳 | 电器 | ●●●● |
| 泡沫 | 油火 | ●●● |
| 水基 | 通用 | ● |

**配置**：
- 至少1个干粉灭火器
- 容量：1-4kg
- 位置：手边

**使用**：

```
拔销 → 握管 → 压把 → 瞄准火源根部 → 扫射
```

**检查**：
- 压力表正常（绿色）
- 销子完好
- 软管完好
- 1年至少检查1次

【注意】 **严重警告**：灭火器过期或压力不足等于没有。每月检查一次。

### 3.3.3 整理 ●●●●

#### 为什么要整理

**真实风险**：
- 工具乱放 → 找不到 → 浪费时间
- 工具乱放 → 绊倒 → 受伤
- 油液乱洒 → 滑倒 → 摔倒
- 零件乱放 → 丢失 → 维修失败

#### 5S管理

| 步骤 | 中文 | 含义 |
|------|------|------|
| 1 | 整理 | 不要的清掉 |
| 2 | 整顿 | 要的有定位 |
| 3 | 清扫 | 保持干净 |
| 4 | 清洁 | 标准化 |
| 5 | 素养 | 习惯 |

#### 实际操作

**整理**：
- 报废零件扔掉
- 旧纸箱清掉
- 不用的工具收起

**整顿**：
- 工具按位置摆放
- 工具车分层
- 常用工具在手边

**清扫**：
- 工作后清洁
- 油液立刻清理
- 工作台保持干净

【维修】 **维修场景**：
- 拆机前：铺工作布
- 拆机中：零件按顺序放
- 拆机后：清洁工作区

### 3.3.4 照明

#### 照明不足的风险

- 看不清 → 装错零件
- 看不清 → 螺丝拧错
- 看不清 → 漏装垫片
- 看不清 → 受伤

#### 照明要求

**最低要求**：
- 工作区明亮
- 重点部位有专门照明
- 必要时用头灯

**常见照明**：
- 车间大灯
- 工作灯
- 头灯
- 手电

【维修】 **维修场景**：
- 拆发动机：工作灯+头灯
- 检查暗处：手电
- 整体照明：车间灯

## 3.4 油液安全详解

### 3.4.1 燃油安全 ●●●●●（最高危）

#### 燃油的真实危险

| 性质 | 数值 |
|------|------|
| 闪点 | 汽油-43°C |
| 爆炸极限 | 1.4-7.6% |
| 自燃温度 | 280°C |
| 蒸气密度 | 比空气重3倍 |

【问答】 **新手问答**：闪点是什么？

答：液体蒸气能**瞬间被点燃的最低温度**。汽油-43°C意味着**几乎所有情况下**汽油蒸气都能被点燃。

#### 操作燃油的原则

**绝对禁止**：
- 在密闭空间操作
- 附近有明火
- 边操作边吸烟
- 靠近可能产生火花的设备（开关、维修灯、未接地电气设备）
- 靠近热源
- 边操作边用手机（额外注意）

**必须**：
- 户外或强通风
- 准备灭火器
- 穿工作服
- 戴护目镜
- 准备吸附材料（砂、吸液棉）

#### 加油安全

**加油前**：
- 关闭发动机
- 远离任何非防爆电器、电火花和热源
- 关闭手机（额外注意）
- 准备灭火器

**加油中**：
- 慢加
- 不要加太满（留膨胀空间）
- 不要溢出
- 接地放电（部分情况）

**加油后**：
- 拧紧油箱盖
- 擦干溢出
- 检查漏油

#### 燃油泄漏处理

**处理流程**：
```
1. 停止所有火源
2. 通风
3. 准备吸附材料
4. 不要用水冲
5. 用吸附材料清理
6. 报告问题
7. 维修后再使用
```

【注意】 **严重警告**：燃油泄漏 + 明火 = 爆炸火灾。绝不能马虎。

【维修】 **维修场景**：
- 拆油管：用容器接油
- 清洗油箱：户外，通风，远离明火
- 检修化油器：户外，强通风

### 3.4.2 机油安全 ●●●

#### 机油的真实风险

**主要风险**：
- 滑倒
- 长期接触皮肤
- 误食
- 吸入雾化油

#### 操作机油的原则

**必须**：
- 戴手套
- 戴护目镜
- 穿工作服
- 通风良好

**禁止**：
- 皮肤直接接触
- 长期吸入
- 误食
- 用口吸油

#### 废机油处理

**绝对禁止**：
- 倒入下水道
- 倒入土壤
- 倒入垃圾桶

**正确处理**：
- 收集到专用容器
- 送废油回收点
- 4S店可回收
- 关注当地法规

【注意】 **常见错误**：
- "废油又不多" → 累积起来污染大
- "倒厕所没事" → 严重污染水源
- 乱放废油 → 容易引发火灾

【问答】 **新手问答**：废机油怎么处理？

答：收集起来（用废油桶），送到当地**废油回收站**。也可以交给4S店或修理店处理。**绝不**倒入下水道或地面。

### 3.4.3 冷却液安全 ●●●●

#### 冷却液的真实风险

**乙二醇冷却液**：
- 有毒
- 误饮致命
- 引起皮肤过敏
- 蒸气有害

**重要**：乙二醇**有甜味**（导致动物和小孩误食）。

#### 操作冷却液的原则

**必须**：
- 戴手套
- 戴护目镜
- 远离食物饮料
- 标记容器

**禁止**：
- 误饮
- 长时间接触皮肤
- 倒入土壤

#### 冷却液烫伤

**风险场景**：
- 热车开散热器盖
- 喷出沸水/蒸汽

**预防**：
- 冷车操作
- 用布包盖慢开
- 戴护目镜

【维修】 **维修场景**：
- 更换冷却液：冷车操作
- 添加冷却液：开盖慢开
- 漏水：检查软管、卡箍

【注意】 **严重警告**：开盖时**绝对不能**对人。哪怕冷车，冷却液也可能喷出。

#### 冷却液处理

**禁止**：
- 倒入下水道
- 倒入土壤
- 倒入垃圾

**正确**：
- 收集容器
- 送回收点
- 注意环保

### 3.4.4 刹车油安全 ●●●●

#### 刹车油的真实风险

| 性质 | 数值 |
|------|------|
| DOT3/4 | 沸点 205-230°C |
| DOT5.1 | 沸点 260°C |
| 腐蚀性 | 强 |
| 毒性 | 中等 |

**主要风险**：
- 误饮
- 接触皮肤
- 损伤车漆
- 失效（吸水后）

#### 操作刹车油的原则

**必须**：
- 戴手套
- 戴护目镜
- 避免接触车漆
- 使用规定的DOT等级

**禁止**：
- 按主缸盖/手册选用；禁止 DOT 5 与 DOT 3/4/5.1 混用；DOT 3/4/5.1 之间不要随意降级或长期混用，必要时按手册彻底更换（来源：⭐⭐⭐）
- 接触皮肤
- 误饮
- 接触车漆

#### 刹车油泄漏

**处理**：
1. 立即擦干
2. 用水冲洗接触部位
3. 严重时立即就医
4. 漏到车漆上立即清洗（会损伤车漆）

【维修】 **维修场景**：
- 换刹车片：避免刹车油溢出
- 排气：开盖排气
- 漏油：检查管路

### 3.4.5 电池液安全 ●●●●

#### 电池液的真实风险

**硫酸**：
- 强腐蚀
- 接触皮肤 → 灼伤
- 接触眼睛 → 失明
- 误饮 → 致命

#### 操作电池的原则

**必须**：
- 戴护目镜
- 戴耐酸手套
- 穿工作服
- 准备中和剂（小苏打水）

**禁止**：
- 倾斜电池
- 接触电池液
- 靠近明火或火花（铅酸电瓶在充电、过充、大电流放电时可能析氢；通风不良遇火花，如电瓶桩头短路、插钥匙、开大灯，可爆炸）

【注意】 **严重警告**：任何电瓶操作前，关掉所有电气负载，先拆负极。

#### 电池液接触处理

**皮肤**：
1. 立即用清水冲洗15分钟
2. 严重时就医

**眼睛**：
1. 立即用清水冲洗15分钟
2. **立即就医**

**误饮**：
1. 立即就医
2. 不要催吐（可能二次伤害）

【注意】 **严重警告**：电池液进入眼睛，可能失明。**必须立即**用大量清水冲洗。

【维修】 **维修场景**：
- 检查电瓶：戴护目镜
- 加电池液：戴手套护目镜
- 处理漏液：戴护目镜手套

### 3.4.6 清洁剂安全 ●●●

#### 清洁剂种类

**化油器清洁剂**：
- 易燃
- 蒸气有毒
- 操作要通风

**刹车清洁剂**：
- 按 SDS 区分：非氯多为易燃，含氯重点防高毒分解气体
- 通风/远离热源
- 完全挥发后再加热或焊接（来源：⭐⭐⭐）

**机件清洁剂**：
- 毒性低
- 仍要通风

**WD-40**：
- 易燃
- 蒸气刺激

#### 操作清洁剂的原则

**先看SDS（Safety Data Sheet，安全数据表）/标签**：
- 看成分、危险、个人防护要求
- 不确定成分时，按更高风险处理

**必须**：
- 通风
- 戴手套
- 戴护目镜
- 远离热源、明火和电火花
- 使用有机蒸气防护

**禁止**：
- 在封闭空间使用
- 喷向人
- 对着明火喷
- 喷过清洗剂的部件未完全挥发就加热或焊接
- 刚喷过化油器清洗剂就点火

【注意】 **严重警告**：刹车清洗剂、化油器清洗剂受热或焊接可能产生高毒性分解气体；含氯溶剂受热可产生光气。必须等清洗剂完全挥发并通风后，才能点火、加热或焊接。

### 3.4.7 油液通用安全原则

**通用规则**：

```
原则1：通风第一
原则2：远离火源
原则3：戴好防护
原则4：废油回收
原则5：标记清楚
```

## 3.5 电气安全

### 3.5.1 触电风险

#### 摩托车电气系统电压

| 部位 | 电压 |
|------|------|
| 12V电气 | 12-14V |
| 高压点火 | 约 10,000-40,000V，常见 15,000-40,000V |

【注意】 **严重警告**：点火系统**高压电**会击穿人体，通常电流/能量有限，不会像家用220V那样直接致命，但可能导致剧痛、烧伤、跌倒（二次伤害），**对心脏病、植入心脏起搏器人群风险更高**；**严禁带电触碰**。

#### 触电风险场景

| 场景 | 风险 | 程度 |
|------|------|------|
| 操作12V | 触电 | 极低 |
| 操作点火 | 触电 | 中等（剧痛） |
| 充电系统 | 触电 | 电瓶直流侧 12-14V 触电风险低；发电机三相交流端、点火线圈、运行中的裸露端子不可手触 |
| 电瓶短路 | 火花+燃烧 | 中等 |

#### 触电预防

**操作前**：
- 任何电路工作前，先断开电瓶负极
- 等待电容放电

**操作中**：
- 不要触碰点火高压线
- 不要带电操作
- 测量发电机三相交流端、点火线圈或运行中裸露端子，必须按维修手册用绝缘表笔（来源：⭐⭐⭐）

**操作后**：
- 检查接插件
- 恢复供电前检查

【维修】 **维修场景**：
- 拆电瓶：先负极后正极
- 装电瓶：先正极后负极
- 测电压：万用表
- 测电流：钳形表

### 3.5.2 短路风险 ●●●●

#### 短路的真实危险

**场景**：电瓶正极搭铁
```
正极 → 金属部件（搭铁）
电阻极小
电流极大
火花 + 燃烧
```

**结果**：
- 火花引燃汽油
- 烧毁电瓶
- 烧毁线束
- 可能引发火灾

#### 短路预防

**工具**：
- 工具绝缘（如扳手包胶）
- 避免金属工具接触两极

**操作**：
- 拆电瓶先负极
- 装电瓶先正极
- 测量时不要短路
- 检查正极绝缘

【维修】 **维修场景**：
- 拆电瓶：先负极后正极
- 装电瓶：先正极后负极
- 拆线束：标记每个接头

【注意】 **严重警告**：电瓶正极 + 扳手 = 火花。**绝对避免**。

### 3.5.3 火灾风险

#### 电气火灾场景

| 场景 | 原因 | 后果 |
|------|------|------|
| 电瓶短路 | 工具搭接 | 火花 |
| 线路老化 | 绝缘破损 | 短路 |
| 改装不当 | 负载过大 | 发热 |
| 接插件松 | 接触电阻 | 发热 |

#### 电气火灾预防

**检查**：
- 线路绝缘
- 接插件
- 保险丝规格
- 不要超载

**禁止**：
- 不按规定改装
- 跨接保险丝
- 私自加大功率

【注意】 **常见错误**：
- "保险丝烧了加大一号" → 严重错误
- "线路发热没事" → 火灾隐患
- "改装后不检查" → 隐患

【问答】 **新手问答**：保险丝烧了用什么代替？

答：**绝对不能**用其他东西代替。**必须用相同规格的保险丝**。如果反复烧保险丝，说明线路有问题，要查清原因。

### 3.5.4 电瓶安全

#### 电瓶的危险

| 风险 | 程度 | 后果 |
|------|------|------|
| 短路 | 高 | 火灾 |
| 漏液 | 中 | 灼伤 |
| 爆炸 | 高后果 | 面部酸灼伤、失明、听力损伤 |
| 电击 | 极低 | 刺痛 |

#### 电瓶操作安全

**拆电瓶**：
1. 关闭所有用电器
2. 关闭发动机
3. 拆负极（-）先
4. 拆正极（+）
5. 拆固定件
6. 取出电瓶

**装电瓶**：
1. 装入电瓶
2. 装固定件
3. 接正极（+）先
4. 接负极（-）
5. 启动测试

**充电安全**：
- 通风
- 远离明火
- 不在车上充电
- 用专业充电器

【注意】 **严重警告**：电瓶爆炸不常发生，但一旦发生，后果是面部酸灼伤、失明、听力损伤；操作电瓶时**戴护目镜 + 通风 + 关负载**。

【维修】 **维修场景**：
- 更换电瓶：先负后正
- 充电：专用充电器
- 储存：定期充电

### 3.5.5 电焊安全

#### 电焊的真实危险

| 风险 | 程度 |
|------|------|
| 触电 | 中等 |
| 紫外线伤眼 | 高 |
| 烟气 | 中等 |
| 火灾 | 中等 |
| 烧伤 | 中等 |

#### 电焊安全装备

**必备**：
- 焊接面罩
- 焊接手套
- 焊接围裙
- 焊接鞋
- 通风设备

**禁止**：
- 没有面罩焊接
- 周围有可燃物
- 通风不良
- 周围有汽油
- 对喷过刹车清洗剂、化油器清洗剂且未完全挥发的部件加热或焊接

【注意】 **严重警告**：焊接时电弧**会损伤眼睛**。必须戴焊接面罩，并警告周围人不要直视。焊接前确认工件没有清洗剂残留；溶剂受热分解可能产生剧毒气体。

## 3.6 高温部件安全

### 3.6.1 高温部件清单

| 部件 | 工作温度 | 烫伤风险 |
|------|----------|----------|
| 消音器 | 200-500°C | 极高 |
| 排气管 | 200-600°C | 极高 |
| 气缸盖 | 100-250°C | 高 |
| 油底壳 | 80-150°C | 中等 |
| 发动机外壳 | 80-150°C | 中等 |
| 制动盘（刚刹完车） | 100-200°C | 高 |
| 散热器 | 80-110°C | 高 |

### 3.6.2 烫伤预防

**操作前**：
- 让车冷却（至少30分钟）
- 测试温度（用手靠近，不直接接触）

**操作中**：
- 戴耐高温手套
- 用工具而非手
- 标记高温部件

**操作后**：
- 提醒其他人不碰
- 等待冷却

【维修】 **维修场景**：
- 拆消音器：戴耐高温手套
- 拆火花塞：等气缸冷却
- 放冷却液：等冷却

【注意】 **严重警告**：消音器即使**熄火1小时**仍可能很烫。接触前**必须**测试温度。

### 3.6.3 烧伤处理

**轻度（一度/浅二度，面积小）**：
- 红肿
- 疼痛
- 处理：冷水冲15-20分钟，不涂牙膏、酱油等，不刺破水泡，保持清洁，送医评估

**按面积/深度/部位判定**：
- 小面积浅二度可有水泡：冷水冲15-20分钟，不刺破水泡，覆盖清洁敷料，就医评估
- 面部/手/关节/会阴、大面积、焦痂、感觉迟钝或深二度以上：**立即120**，冷水冲15-20分钟同时叫人，不脱粘连衣物，不涂任何药膏，用清洁布覆盖（来源：⭐⭐⭐）

【注意】 **严重警告**：严重或较大面积烧伤**必须立即120**，不要自行涂药后拖延就医。烧伤分级和急救流程来源等级：⭐⭐⭐；**以急救中心/医生指导为准**。

## 3.7 机械伤害预防

### 3.7.1 旋转部件伤害 ●●●●●

#### 旋转部件清单

| 部件 | 转速 | 危险 |
|------|------|------|
| 飞轮 | 1000-10000 rpm | 极高 |
| 链条 | 1000-5000 rpm | 极高 |
| 链轮 | 同步 | 高 |
| 齿轮 | 同步 | 中等 |
| 风扇 | 1000-3000 rpm | 中等 |

【注意】 **严重警告**：旋转部件**会卷住衣物、手、手指**。可能撕脱皮肤、骨折、截肢。

#### 旋转伤害预防

**绝对禁止**：
- 发动机运行、链条/风扇/飞轮可能转动时戴手套或接近
- 操作时穿宽松衣服
- 操作时长发未扎起
- 接近旋转部件

**必须**：
- 关闭发动机
- 等待停止
- 停机静止处理链条、刹车片或锋利边缘时，可戴贴手防割或耐油手套（来源：⭐⭐⭐）

【维修】 **维修场景**：
- 拆链条：关闭发动机
- 检查飞轮：拆下启动
- 测链条张力：停车状态

【口诀】 **记忆口诀**：旋转不停我不碰，宽松衣服禁止穿。

### 3.7.2 重物伤害 ●●●●

#### 重物伤害清单

| 部件 | 重量 | 风险 |
|------|------|------|
| 整车 | 200-300kg | 高 |
| 发动机 | 30-80kg | 高 |
| 油箱（满） | 15-30kg | 中等 |
| 轮毂 | 10-20kg | 中等 |
| 消音器 | 5-10kg | 低 |

#### 重物伤害预防

**操作前**：
- 评估重量
- 准备举升设备
- 准备支撑

**操作中**：
- 用正确姿势
- 腰背挺直
- 腿发力
- 不要突然发力

**操作后**：
- 放置稳固
- 不压在手上

【维修】 **维修场景**：
- 拆发动机：举升机+支撑
- 抬车：两人或举升机
- 放电池：双手

【注意】 **常见错误**：
- 一个人抬重物 → 腰伤
- 抬物弯腰 → 腰伤
- 突然放下 → 砸脚

【问答】 **新手问答**：一个人能抬发动机吗？

答：**不推荐**。发动机30-80kg，**必须**用举升设备或有人帮忙。

#### 正确抬重物姿势

```
1. 站到重物前
2. 蹲下，背部挺直
3. 双手抓稳
4. 腿发力站起
5. 保持背部挺直
6. 不要扭转身体
7. 到达位置再放下
```

## 3.8 举升和支撑安全

### 3.8.1 举升机安全

#### 举升机类型

| 类型 | 适用 | 安全性 |
|------|------|--------|
| 液压举升机 | 整车 | ●●●●● |
| 千斤顶 | 局部 | ●●● |
| 中撑 | 维修 | ●●● |
| 边撑 | 短停 | ● |

【注意】 **严重警告**：**严禁**在边撑状态下进行维修。边撑会下沉、弹回、滑倒。

#### 举升机操作

**使用前**：
- 检查液压油
- 检查锁止机构
- 检查地面平整

**使用中**：
- 缓慢举升
- 听声音
- 观察是否平衡

**举升后**：
- **必须锁止**
- 不要摇晃
- 确认稳固

【维修】 **维修场景**：
- 举整车：液压举升机
- 举局部：千斤顶
- 维修支撑：举升机+支撑

【注意】 **严重警告**：举升机**必须**锁止。**未锁止的举升机砸人致死**的真实案例很多。

### 3.8.2 千斤顶安全

#### 千斤顶操作

**使用前**：
- 检查液压油
- 检查地面
- 检查负载

**使用中**：
- 放在坚固地面
- 不要用软地面
- 缓慢举升

**举升后**：
- **必须用支撑架**
- 不要只用千斤顶

【注意】 **严重警告**：千斤顶**不能长时间支撑**。举升后**必须**用支撑架（安全支架）。

### 3.8.3 支撑架

#### 支撑架种类

- 千斤顶支撑架
- 各种专用支撑
- 木块（应急）

【维修】 **维修场景**：
- 换胎：千斤顶+支撑
- 修发动机：举升机
- 修链条：千斤顶+支撑

## 3.9 应急处理

### 3.9.1 急救箱配置

**必备物品**：

| 物品 | 数量 | 用途 |
|------|------|------|
| 创可贴 | 多种 | 小伤口 |
| 纱布 | 1包 | 包扎 |
| 医用胶带 | 1卷 | 固定 |
| 消毒酒精 | 1瓶 | 消毒 |
| 碘伏 | 1瓶 | 消毒 |
| 烫伤膏 | 1支 | 烫伤 |
| 生理盐水 | 1瓶 | 冲洗眼部/伤口 |
| 一次性手套 | 1盒 | 防护 |
| 三角巾 | 1条 | 固定 |
| 镊子 | 1个 | 取出异物 |
| 剪刀 | 1把 | 剪开 |
| 急救手册 | 1本 | 参考 |
| 紧急电话 | 1张 | 联系 |

**位置**：
- 工作区附近
- 显眼位置
- 所有人都知道

### 3.9.2 常见事故应急

#### 烫伤

**轻度**：
- 冷水冲15-20分钟
- 不刺破水泡
- 不涂牙膏、酱油等
- 保持清洁，送医评估

**严重**：
- **立即120**
- 冷水冲15-20分钟同时叫人
- 不脱粘连衣物
- 不涂任何药膏
- 用清洁布覆盖

【注意】 烧伤分级和急救流程来源等级：⭐⭐⭐；**以急救中心/医生指导为准**。

#### 切伤

**轻度**：
- 止血
- 消毒
- 包扎

**深度**：
- 止血
- 就医

**动脉出血**：
- 立即压住
- **立即就医**
- 拨打120

#### 眼睛伤害

**异物**：
- 不要揉
- 流水冲洗
- 就医

**化学物质**：
- **立即用大量清洁流动清水或生理盐水持续冲洗至少15-30分钟**
- 水要足、时间要够；冲水量比冲洗时间更重要
- 不用眼药水代替冲洗
- **立即送医或打120，带着化学品SDS/包装**

**撞击**：
- 不动眼睛
- 就医

【注意】 **严重警告**：眼睛受伤**必须**就医，不要自行处理。化学入眼急救流程来源等级：⭐⭐⭐；**以急救中心/医生指导为准**。

#### 触电

**轻度**（刺痛）：
- 切断电源
- 观察

**中度**（灼伤）：
- 切断电源
- 冷冲
- 就医

**重度**（昏迷）：
- 切断电源后再接触伤者
- 呼叫120
- 检查意识/呼吸
- 无正常呼吸时，由受训者 CPR/AED（来源：⭐⭐⭐）

#### 中毒

**蒸气吸入**：
- 立即通风
- 移出现场
- 就医

**误饮**：
- **不要催吐**（可能二次伤害）
- 就医
- 携带毒物样本

**误食电池液**：
- **立即就医**
- 不要催吐
- 拨打120

#### 骨折

**开放性骨折**：
- 不复位
- 止血
- 固定
- **立即就医**

**闭合性骨折**：
- 固定
- 不动
- 就医

#### 火灾

**小火**：
- 灭火器
- 报警

**大火**：
- 撤离
- 报警
- 不抢救财物

### 3.9.3 紧急联系方式

**必备**：
- 120（急救）
- 119（火警）
- 110（报警）
- 医院电话
- 毒物中心

**位置**：
- 工作区张贴
- 急救箱旁

### 3.9.4 灭火器使用

**使用步骤**：
1. 拔销
2. 握管
3. 压把
4. 瞄准火源根部
5. 左右扫射

**注意事项**：
- 对准根部
- 不要对火焰
- 多次喷射
- 注意复燃

```
- 准备灭火器
```

```
重点：
- 拆电瓶先负极
- 操作前断电
- 避免短路
- 工具绝缘
- 远离电瓶正极
```

```
重点：
- 等待冷却
- 戴耐高温手套
- 准备重物支撑
- 戴护目镜
- 弹簧操作小心
```

### 3.10.5 制动系统维修安全重点

```
重点：
- 戴护目镜
- 戴手套
- 远离车漆
- 排气
- 操作后测试
```

### 3.10.6 链条维修安全重点

```
重点：
- 戴手套
- 戴护目镜
- 戴工具清理
- 链条工具使用
- 链条接扣小心
```

### 3.10.7 轮胎维修安全重点

```
重点：

- 戴手套
- 举升机+支撑
- 不要用裸手
- 气压安全
```

### 3.10.8 焊接安全重点

```
重点：
- 焊接面罩
- 焊接手套
- 通风
- 远离可燃物
- 防火设备
```
