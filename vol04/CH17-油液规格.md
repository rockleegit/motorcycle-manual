### 17.0.3 速查表（30 秒找到你要的油）

**车型/系统 → 用什么油**：

| 项目 | 主流规格 |
|------|---------|
| **发动机机油** | 按说明书粘度，湿式离合车型（大多数摩托车）通常要求 JASO MA/MA1/MA2。大多数摩托车发动机与变速箱共用机油，无需另加齿轮油 |
| **终传/齿轮油** | **仅轴传动车型（如宝马R系列）或部分踏板车**需要单独更换。规格按说明书，常见为 SAE 80W-90、75W-90 等齿轮油规格 |
| **冷却液** | 乙二醇或丙二醇基，适合铝合金发动机，按说明书选类型和冰点 |
| **刹车油** | 按主缸盖/说明书，现代车型常见 DOT 4，部分允许 DOT 5.1 |
| **燃油稳定剂** | 长期存放时加，乙醇汽油要注意 |
| **链条油** | 摩托车专用，O 形链条用 O 形链条油 |
| **化油器清洗剂** | 摩托车专用，不要用汽油 |
| **节气门清洗剂** | 摩托车专用，不要用 WD-40 |

【严重警告】 **严重警告**：油液先看说明书。湿式离合车型通常要用 JASO MA/MA1/MA2 机油；踏板终传齿轮油、轴传动齿轮油、液压离合油、刹车油是不同系统，不能按名字相近就混用。

## 17.1 发动机机油（核心）★★★

### 17.1.1 机油干什么的 ★★★

**摩托车的"血液"**——同时承担：
- **润滑**（减少摩擦）
- **散热**（带走热量）
- **清洁**（带走磨屑）
- **密封**（活塞环密封辅助）
- **防锈**（保护金属）

**没有机油**，**发动机几分钟就报废**。

### 17.1.2 机油规格（如何看懂标签）★★★

**机油瓶上写的都是什么**：

**粘度等级 SAE**（最重要）：
```
10W-40

前半部分（W 之前）：低温粘度
  数字越小，低温流动性越好
  0W = -35°C 以下能用
  5W = -30°C 能用
  10W = -25°C 能用
  15W = -20°C 能用
  20W = -15°C 能用

后半部分（W 之后）：高温粘度
  数字越大，高温下油膜越厚
  30 = 较稀
  40 = 中等
  50 = 较稠
  60 = 很稠

常见组合：
  10W-40：通用（-25~40°C）
  0W-40：冬季用（-35~40°C）
  15W-50：高温/激烈驾驶
  20W-50：老车、热带
```

【来源】 **数据来源等级**：★★（基于 SAE J300 工业标准）。

**质量等级 API**（美国标准）：
```
API SJ / SL / SM / SN / SP

字母越靠后 = 等级越高
  SF = 1980 年（老车用）
  SG = 1989 年（老车用）
  SH = 1993 年
  SJ = 1996 年
  SL = 2001 年
  SM = 2004 年
  SN = 2010 年（**常用**）
  SP = 2020 年（**目前最新**）

摩托车主要看 SJ/SL/SM/SN/SP；现代车型最常用 SN/SP。具体以说明书和最新 API 公告为准。
```

【来源】 **数据来源等级**：★★（基于 API 1509/API 最新服务分类公告；以最新 API 公告为准）。

**质量等级 ACEA**（欧洲标准）：
```
ACEA A3/B3 = 主流
ACEA A3/B4 = 高性能
ACEA A5/B5 = 节能
```

【来源】 **数据来源等级**：★★（基于 ACEA 标准）。

**JASO 等级（**摩托车关键**）** ★★★：

```
JASO T 903 湿式离合器分类：
  MA  = 通用，摩擦系数适中
  MA1 = MA 子分类，低摩擦，适合节能型车
  MA2 = MA 子分类，高摩擦，适合运动车/重载车
  MB  = 机油不接触离合器的车型（踏板/CVT 等）

【注意】 重要：摩托车湿式离合器必须用说明书指定的 JASO MA、MA1 或 MA2
   用 JASO MB 或无 JASO 标志的油 = 离合打滑
```

【来源】 **数据来源等级**：★★（基于 JASO T 903 标准）。

【经验】 **老师傅经验**：**JASO 等级**是湿式离合车型选油的关键。不是所有汽车机油都会立刻导致打滑，但没有 JASO MA/MA1/MA2 标注时，不能当作湿式离合摩托车的稳妥选择。

### 17.1.3 机油类型 ★★

| 类型 | 特点 | 适用 |
|------|------|------|
| **矿物油** | 最便宜、寿命短 | 老车、低预算 |
| **半合成** | 性能中等、性价比高 | **主流** |
| **全合成** | 性能最好、寿命长 | 现代车、性能车 |
| **酯类合成** | 高端、贵 | 赛车、高性能 |

【来源】 **数据来源等级**：★（**你的车用什么油，看说明书**）。

### 17.1.4 基础油与性能指标 ★★

**API 基础油分类 I/II/III/IV/V**：

| 组别 | 常见叫法 | 特点 |
|------|----------|------|
| **I 类** | 溶剂精炼矿物油 | 传统矿物基础油，杂质和硫含量相对高 |
| **II 类** | 加氢裂化矿物油 | 纯净度和抗氧化性能优于 I 类 |
| **III 类** | 高度加氢裂化基础油 | 性能接近合成油，市场上常被标为“全合成” |
| **IV 类** | PAO | 真正化学合成基础油，低温和高温稳定性好 |
| **V 类** | 酯类/其他 | 常用于高端配方或作为调和组分 |

【来源】 **数据来源等级**：★★（基于 API 1509 基础油分类）。

**ILSAC GF-5 / GF-6**：
- ILSAC 是汽油机乘用车机油规范，GF-5、GF-6 强调燃油经济性、排放系统兼容和低速早燃等要求。
- 带 ILSAC “Resource Conserving”取向的汽车机油可能偏低摩擦；湿式离合摩托车仍应优先看 JASO T 903 和说明书。

【来源】 **数据来源等级**：★★（基于 ILSAC GF-5/GF-6 规范）。

**VI（粘度指数）**：
- VI 表示机油粘度随温度变化的程度，数值越高，温度变化时粘度变化越小。
- VI 只能辅助判断温度稳定性，不能单独替代 SAE 粘度、API/JASO 等级或厂家规格。

【来源】 **数据来源等级**：★★（基于 ASTM D2270 粘度指数定义）。

**HTHS（高温高剪切粘度）**：
- HTHS 反映约 150°C、高剪切条件下油膜保持能力。
- 高负荷、高转速发动机更需要关注 HTHS，但具体下限必须看厂家规范，不能只凭“越高越好”选油。

【来源】 **数据来源等级**：★★（基于 SAE J300/ASTM D4683、D4741、D5481 等 HTHS 测试框架）。

### 17.1.5 机油粘度选择 ★★

| 车型/工况 | 推荐粘度 |
|----------|---------|
| 街车 / 通用 | 10W-40 |
| 运动车 / 高速 | 10W-40 或 10W-50 |
| 冬季 / 寒冷地区 | 0W-40 或 5W-40 |
| 热带 / 夏季 | 15W-50 或 20W-50 |
| 老车（> 20 年） | 20W-50（粘度大保护磨损） |
| 越野 / ADV | 10W-40 |

【来源】 **数据来源等级**：★（**你的车具体粘度看说明书**）。

### 17.1.6 机油容量 ★★

**容量因车型不同**：

| 排量 | 一般容量 |
|------|---------|
| 小排量（125-250cc） | 1.0-1.5 L |
| 中排量（300-650cc） | 2.0-3.5 L |
| 大排量（700+cc） | 3.5-5.0 L |

**容量分两种**：
- **拆解总容量**：发动机完全拆解后系统能容纳的总油量
- **换油容量**：常规放油后需要加入的油量，通常分“换滤芯”和“不换滤芯”两种

【来源】 **数据来源等级**：★（**你的车具体容量看说明书**）。

【注意】 **重要**：**换机油时**：
- **换机油滤芯** → 按说明书“with filter/更换滤芯”容量加注，再用油尺或油窗复核
- **不换机油滤芯** → 按说明书“不更换滤芯”容量加注
- 不要直接按“总容量”倒油，容易加多

### 17.1.7 机油推荐品牌 ★★

**正品机油品牌**（摩托车用）：

| 品牌 | 特点 | 价格 |
|------|------|------|
| **壳牌 Shell**（Advance 系列） | 主流 | 中 |
| **美孚 Mobil**（Super 系列） | 高端 | 高 |
| **嘉实多 Castrol**（Power 系列） | 主流 | 中 |
| **长城**（中国） | 性价比 | 低 |
| **昆仑**（中国） | 性价比 | 低 |
| **Motul**（法国） | 高端 | 高 |
| **Liqui Moly**（德国） | 高端 | 高 |
| **Silkolene**（英国） | 高端 | 高 |
| **Repsol**（西班牙） | 中端 | 中 |

【来源】 **数据来源等级**：★（行业口碑排序）。

【费用】 **省钱贴士**：机油不要只看品牌和价格，优先看粘度、JASO/API 等级、购买渠道和生产日期。假油、错油比贵油更伤车。

### 17.1.8 机油选择建议 ★★

**普通车主建议**：
- **街车通勤**：壳牌/美孚 **10W-40 半合成**（SN 级、JASO MA/MA1/MA2）
- **预算紧**：选择符合说明书最低 API/JASO 要求的正品油，不用盲目追高端
- **性能车/赛道**：Motul 全合成 10W-50

**老车建议**：
- 20W-50 半合成（**粘度大保护磨损**）

【经验】 **老师傅经验**：**机油没有最好的，只有最合适的**。**说明书说用什么就用什么**。**别听商家忽悠**——**"高级油""赛车油"**对你的车没意义。

## 17.2 终传/齿轮油 ★★

### 17.2.1 齿轮油干什么的 ★★

很多挡车的发动机、变速箱、湿式离合器共用同一份发动机机油，**没有单独的变速箱齿轮油**。这里说的齿轮油，主要指：
- 踏板车/CVT 的最终减速齿轮箱油
- 轴传动车型的后牙包/终传油
- 少数车型说明书明确要求的独立齿轮箱油

### 17.2.2 什么时候需要齿轮油 ★★★

**第一原则**：说明书没有写“final gear oil / transmission oil / gear oil”单独更换项目，就不要自己额外加齿轮油。

**常见场景**：
- 踏板车终传：常见 SAE 80W-90、75W-90 或厂家专用油
- 轴传动后牙包：常见 hypoid gear oil，API GL-5 等级按说明书
- 两冲程独立变速箱：可能使用专用 transmission oil 或指定机油

【严重警告】 **严重警告**：不要把汽车 GL-5 齿轮油倒进需要 JASO MA/MA1/MA2 发动机机油的湿式离合发动机里。齿轮油和发动机机油不是同一种东西。

### 17.2.3 齿轮油规格

**粘度**：
- SAE 80W-90、75W-90、85W-90 等是常见齿轮油粘度
- 少数车型会指定 10W-30/10W-40 发动机油作为独立变速箱油

**API 等级**：GL-4 或 GL-5，按说明书选择。GL-5 常用于双曲面齿轮/后牙包，含高剂量极压添加剂，可能腐蚀黄铜/铜合金同步器或软金属；GL-4 兼容性好，GL-5 极压性能高但有材料兼容风险。严格按手册选，不代表能放进湿式离合发动机。

【来源】 **数据来源等级**：★★（基于 API GL 分类和车型说明书用油逻辑）。

### 17.2.4 齿轮油容量

**容量因车型不同**：

| 传动形式 | 常见容量 |
|------|---------|
| 踏板车终传齿轮箱 | 约 80-150 mL（如 GY6 机型约 100-110 mL） |
| 轴传动后牙包 | 通常仅数百 mL（车型差异大，**以说明书为准**） |

【来源】 **数据来源等级**：★（**你的车具体容量看说明书**）。

### 17.2.5 齿轮油推荐品牌

**正品摩托车齿轮油**：
- 壳牌 Advance
- 美孚
- 嘉实多
- Motul
- 长城

【费用】 **省钱贴士**：**齿轮油**比**机油便宜**——**500ml 几十元**——**踏板终传一次只换一百多毫升**——**每次十几到几十元**。

## 17.3 冷却液 ★★★

### 17.3.1 冷却液干什么的

- 散热
- 防冻
- 防腐蚀
- 防沸

### 17.3.2 冷却液类型

**按配方/标准/厂家规格判断，不按颜色判断**：

| 类型 | 判断依据 | 特点 |
|------|----------|------|
| IAT（传统无机添加剂） | 产品配方/标准/厂家规格 | 传统绿/黄较常见，但颜色不可靠 |
| OAT（有机酸） | 产品配方/标准/厂家规格 | 橙/红较常见，长效取向 |
| HOAT（混合） | 产品配方/标准/厂家规格 | 混合配方，部分车专用 |
| 丙二醇 | 产品配方/标准/厂家规格 | 毒性相对低，仍需按手册确认 |

【来源】 **数据来源等级**：★（基于冷却液配方分类和厂家规格逻辑）。

【严重警告】 **严重警告**：**不要混用不同类型冷却液**！颜色不是可靠标准，同色不同配方也不可混用，以厂家规格为准。

### 17.3.3 冷却液浓度

**标准 50%**：50% 乙二醇水溶液常压下沸点约 108-110°C，冰点约 -35°C；加压冷却系统（约 1.0-1.1 bar）沸点可升至约 120°C。沸点取决于常压/系统表压/产品配方，以上为典型值，具体看产品数据表和车主手册。

【来源】 **数据来源等级**：★★（基于乙二醇水溶液典型冰点/沸点数据；具体以产品数据表为准）。

**配比方法**：
- 用**预混好的**（最简单）
- 用**浓缩液 + 蒸馏水** 1:1 混合

**不要用**：
- 自来水（**矿物质腐蚀水道**）
- 纯净水（勉强可用）
- 矿泉水（**矿物质高**）

### 17.3.4 冷却液推荐品牌 ★★

**正品品牌**：
- 长城（中国）
- 壳牌（中国）
- 蓝星（中国）
- Peak（美国）
- Prestone（美国）
- BASF（德国）

【来源】 **数据来源等级**：★（行业口碑）。

【费用】 **省钱贴士**：**预混冷却液 50 元/L**——**一次加 2-3L**——**成本 100-150 元**。

## 17.4 刹车油 ★★★

### 17.4.1 刹车油干什么的

**液压系统的传力介质**——在制动压力下**近似不可压缩**；空气/蒸汽泡才是手感变软的主要问题。

### 17.4.2 刹车油规格 ★★★

**DOT 等级**：

| 等级 | 干沸点 | 湿沸点 | 应用 |
|------|--------|--------|------|
| DOT 3 | 205°C | 140°C | 老车 |
| DOT 4 | 230°C | 155°C | **主流** |
| DOT 5.1 | 260°C | 180°C | 高端/性能 |
| DOT 5 | 260°C | 180°C | **硅油基，特殊** |

【来源】 **数据来源等级**：★★（基于 FMVSS 116 DOT 标准）。

【严重警告】 **严重警告**：
- **DOT 5 是硅油基**，只用于明确要求 DOT 5 的系统
- **DOT 5.1 不是 DOT 5 的升级版**；是否能替代 DOT 4 要看说明书
- 不要混用 DOT 5 与 DOT 3/4/5.1

### 17.4.3 刹车油推荐品牌

**正品品牌**：
- 博世 Bosch
- 菲罗多 Ferodo
- 布雷博 Brembo
- ATE（德国）
- 长城
- 壳牌

【费用】 **省钱贴士**：**DOT 4 刹车油 50-150 元/L**——**一次用 0.3-0.5L**——**成本 30-80 元**。

### 17.4.4 离合液压油（液压离合车）

很多液压离合使用 DOT 4 刹车油，但也有车型使用矿物油或厂家专用液压油。

【严重警告】 **严重警告**：
- **必须看主缸盖或说明书**：写 DOT 4 就用 DOT 4，写 mineral oil 就用矿物液压油
- DOT 制动液和矿物油系统不能混用，混用会损坏密封件
- 不要用发动机机油、链条油等代替液压离合油

## 17.5 燃油及燃油添加剂

### 17.5.1 燃油标号 ★★★

**汽油标号**：
- **92/95/98 号**：按说明书指定标号选择；压缩比只作爆震风险提示，不直接决定标号

【来源】 **数据来源等级**：★★（基于 RON 研究法辛烷值标准）。

**如何选标号**：
- 看说明书
- 压缩比只作风险提示，不替代厂家要求
- 不要用听声音替代厂家要求；怀疑爆震时先停用不符合手册的燃油并检查工况

【严重警告】 **严重警告**：
- **高标号车加低标号油** = **爆震**（见第 6 章）
- **低标号车加高标号油** = **浪费钱**（没必要）

### 17.5.2 乙醇汽油

**乙醇汽油**（E10 = 10% 乙醇）：
- 越来越普及
- 优点：环保、可再生
- 缺点：**容易吸水**、**动力略低**；老车/非耐醇材料可能膨胀、硬化或老化加速，现代兼容 E10 的燃油系统通常没事

**对老车的影响**：
- 非耐醇橡胶油管、密封件可能膨胀、硬化或老化加速
- 不兼容或老化的燃油泵部件可能出问题
- 化油器可能堵

**应对**：
- 加**燃油稳定剂**（长期）
- 定期**跑长途**（避免长期存放）
- 必要时**换耐乙醇零件**

### 17.5.3 燃油添加剂

**常见类型**：

| 类型 | 作用 | 是否需要 |
|------|------|---------|
| **燃油宝**（清洁剂） | 清洗喷油嘴 | **不推荐长期** |
| **燃油稳定剂** | 防止汽油变质 | **长期存放时必加** |
| **辛烷值提升剂** | 提高辛烷值 | **应急用** |
| **排气管清洁剂** | 减少积碳 | **不推荐** |

【经验】 **老师傅经验**：燃油添加剂不要长期、盲目使用。长期存放时燃油稳定剂有明确用途；喷油嘴清洁剂、辛烷值提升剂等只在说明书允许且有明确症状/用途时考虑，不要把它们当成保养替代品。

### 17.5.4 燃油选择

**推荐**：
- **正规加油站**（中石化、中石油、Shell 等）
- **加合适的标号**（说明书规定）

**避免**：
- 私人小加油站（**油品差**）
- 加油机数字跳得太快（**可能是劣质**）
- 长期加同一家油（**避免单点故障**）

## 17.7 【经验】 老师傅经验沉淀（应写尽写）

### 17.7.1 新手必踩的 12 个油液坑 ★★★

**机油类**：
1. **用汽车机油代替摩托车机油** —— **离合打滑**
2. **机油粘度选错** —— **发动机磨损**
3. **机油加多/加少** —— **烧机油/烧瓦**
4. **不按周期换** —— 机油失效

**齿轮油类**：
5. **把齿轮油倒进湿式离合发动机** —— **可能离合打滑或润滑异常**
6. **GL-4/GL-5 不看说明书** —— **GL-5 极压添加剂性能高，但可能腐蚀黄铜/铜合金同步器或软金属；GL-4 兼容性好，必须按手册选**

**冷却液类**：
7. **用自来水代替** —— **水道腐蚀、水垢**
8. **混用不同类型** —— **生成胶状物**
9. **浓度不够** —— **冬天冻裂**

**刹车油类**：
10. **普通 DOT 4 系统误用 DOT 5** —— **不兼容，必须彻底处理**
11. **DOT 制动液和矿物油系统混用** —— **密封件损坏**
12. **超过 3 年不换** —— **刹车失灵风险**

【经验】 **老师傅经验**：**油液选择**第一原则：**说明书怎么说就怎么用**。**说明书是工程师写的**——**比任何商家、AI、老师傅都准**。

### 17.7.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 机油选 JASO MA/MA1/MA2**：摩托车湿式离合器专用
2. **【维修】 齿轮油看说明书**：踏板终传、轴传动后牙包和独立变速箱要求不同
3. **【维修】 冷却液不要混用**：不同类型会反应
4. **【维修】 冷却液不要用自来水**：矿物质腐蚀水道
5. **【维修】 刹车油看主缸盖**：DOT 5 和 DOT 5.1 不是一回事
6. **【维修】 燃油标号看说明书**：不要想当然
7. **【维修】 长期存放加燃油稳定剂**：防止汽油变质
8. **【维修】 燃油添加剂按用途用**：长期存放、积碳清洁、辛烷值应急是不同场景

### 17.7.3 油液选择决策树 ★★★

**机油选择**：
```
1. 车主手册允许哪些 SAE 粘度？
   - 只在手册允许范围内选
2. 你的环境温度和使用工况？
   - 冬季寒冷 = 选手册允许的低温粘度
   - 高温/重载/长途 = 选手册允许的高温粘度
3. API/JASO 和厂家规范是否符合？
   - 湿式离合 = 按说明书选 JASO MA/MA1/MA2
   - API 等级不得低于说明书要求
4. 你的车什么车龄？
   - > 20 年 = 考虑 20W-50（保护磨损）
   - 新车 = 按说明书推荐粘度和厂家规范

压缩比不是机油粘度的直接决定因素。
```

【来源】 **数据来源等级**：★（机油粘度选择以车主手册、环境温度、API/JASO 等级和厂家规范为准）。

**冷却液选择**：
```
1. 你的车什么类型？
   - 看说明书
2. 你的当地最低温、厂家推荐配比和产品数据表是什么？
   - 50/50 是常见默认配比
   - 极寒可按手册提高到约 60%
   - 热带重点是防腐、散热、压力盖和系统健康，不是追求更低冰点
3. 你用什么水源？
   - 必须蒸馏水或预混
   - 不要自来水
```

### 17.7.4 油液品牌真伪识别 ★★

**正品机油识别**：
- 包装完整、印刷清晰
- 防伪码（官网可查）
- 正规渠道购买
- 价格合理（**太便宜可能是假的**）

**假的机油危害**：
- 保护差 → 发动机磨损
- 杂质多 → 油道堵
- 寿命短 → 频繁换油

【费用】 **省钱贴士**：机油要买来源可靠、规格正确的正品。价格异常低、包装信息不全、渠道不明时风险很高，不要只看“全合成”三个字。

### 17.7.5 油液兼容速查表 ★★

| 油液 | 可混用 | 不可混用 |
|------|--------|---------|
| **不同粘度机油** | 应急补加可同品牌同系列 | 长期/完整换油不建议主动混配 |
| **不同品牌机油** | 应急补加可以同等级不同品牌 | 长期/完整换油不建议主动混配，基础油类型、添加剂体系可能不同 |
| **不同等级机油** | 【注意】 应急谨慎补加 | 长期混用可能影响性能或产生沉淀 |
| **机油 + 齿轮油** | ✗ | ✓ 不能混 |
| **DOT 3 + DOT 4** | 应急可兼容 | 长期按说明书完整更换 |
| **DOT 4 + DOT 5.1** | 说明书允许时可兼容 | 长期按说明书完整更换 |
| **DOT 4 + DOT 5** | ✗ | ✓ 硅油和乙二醇不能混 |
| **IAT + OAT** | ✗ | ✓ 不能混 |
| **不同冷却液** | ✗ | ✓ 不能混 |

【来源】 **数据来源等级**：★（基于润滑油基础油和添加剂体系兼容性通用原则；长期使用以厂家规格为准）。

下表是常见经验范围，只用于规划检查，不作为换油依据；实际更换周期以车主手册、维修手册、产品数据表和使用工况为准。

| 冷却液 | 常见约 2-5 年；以手册和产品数据表为准 | 变色、变酸 |

## 17.8 网络实战案例汇编（来自论坛、技师分享）★★

**这是按论坛和技师分享整理的匿名/教学化场景**，用于训练排查思路；车型名只作示例，不代表该车型通病，具体车型仍以说明书和实际检测为准。

### 案例 A：湿式离合挡车误用低摩擦机油

**症状**：换油后大油门转速上升，车速不上去。
**踩坑过程**：只看粘度，没有看 JASO 等级。
**可能原因**：湿式离合车型使用了不适合湿式离合器的低摩擦油。
**处理**：按说明书换回 JASO MA/MA1/MA2 机油；如仍打滑，检查离合器片。
**教训**：湿式离合车型选机油必须看 JASO。

### 案例 B：只看 DOT 4 没看厂家参数

**症状**：换油后刹车手感变差。
**踩坑过程**：只看 DOT 4，没看低粘度、ABS 或厂家要求。
**可能原因**：同为 DOT 4，不同产品的粘度、干/湿沸点和适用系统可能不同。
**处理**：按主缸盖和说明书选择符合要求的制动液，彻底排气。
**教训**：刹车油先看说明书，不只看 DOT 数字。

### 案例 C：雅马哈 MT-07 混用冷却液

**症状**：混了不同颜色冷却液
**踩坑过程**：以为没事
**可能原因**：不同配方冷却液不兼容，可能产生沉淀、胶状物或降低防腐能力。
**处理建议**：按手册彻底排放、冲洗并换回指定冷却液。
**教训**：冷却液看配方和手册，不靠颜色混用。

### 案例 D：哈雷 Sportster 用低价机油

**症状**：用了 50 元的机油
**踩坑过程**：以为便宜
**可能原因**：低价油来源不明，可能是假油、过期油或规格不符。
**处理建议**：停止使用，换正规渠道、符合手册规格的机油；如出现异响或压力报警，进一步检查。
**教训**：机油优先看规格和渠道，不只看价格。

### 案例 E：川崎 Ninja 400 用半合成当全合成

**症状**：买的是半合成
**踩坑过程**：以为是全合成
**可能原因**：产品标称、基础油类型和车型要求没有核对清楚。
**处理建议**：按说明书确认 SAE 粘度、API/JASO 等级和换油周期；VI 只能作为参考指标，不能单独判断全合成。
**教训**：机油选择看手册规格和认证，不靠单一 VI 值。

### 案例 F：杜卡迪 Monster 用错机油规格

**症状**：用了低规格机油
**踩坑过程**：以为够
**可能原因**：粘度、API/JASO 等级或湿式离合兼容性不符合手册。
**处理建议**：按说明书换回指定规格；如已出现打滑、异响或压力报警，进一步检查。
**教训**：机油规格以说明书为准。

### 案例 G：凯旋 Tiger 900 冬季用夏季油

**症状**：冬季 10W-40
**踩坑过程**：以为没事
**可能原因**：低温下机油粘度、电瓶容量、启动机状态都会影响启动。
**处理建议**：按说明书允许的低温粘度选择机油，同时检查电瓶健康和充电状态；不要擅自改成手册不允许的粘度。
**教训**：冬季难启动要同时看机油粘度、电瓶和启动系统。

### 案例 H：终传齿轮油粘度用错

**症状**：用了 80W-90
**踩坑过程**：以为是越野车
**可能原因**：粘度和 API 等级没有按说明书选
**处理**：按说明书换回指定齿轮油
**教训**：**齿轮油粘度** = **看车型**

### 案例 I：铃木 SV650 误用 DOT 5

**症状**：误买 DOT 5 硅油
**踩坑过程**：以为是 DOT 5.1
**可能原因**：**DOT 5 是硅油**——**不能和 DOT 4 混**
**处理建议**：未加注时直接退换符合手册的制动液；若已加入系统，需按维修手册彻底处理，必要时送修。
**教训**：**DOT 5 vs 5.1** = **不同**

### 案例 J：本田 NC750X 用自来水当冷却液

**症状**：应急加了自来水
**踩坑过程**：以为没事
**可能原因**：**水垢+腐蚀**——**水箱堵**
**处理建议**：**彻底清洗 + 换冷却液**
**教训**：**冷却液** = **不要用自来水**

### 这些案例的共同教训 ★★

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **用错 JASO** = **离合打滑**
2. **用错 DOT** = **刹车失灵**
3. **混用冷却液** = **化学反应**
4. **用便宜假油** = **发动机磨损**
5. **不按季节** = **难启动**

【经验】 **老师傅总结**：**油液规格** = **严格按说明书**——**混错=损坏**——**假油=磨损**——**必看**。
