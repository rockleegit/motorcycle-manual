## 16.1 骑前 5 分钟检查（必做）★★★

### 16.1.1 为什么骑前检查

**骑前 5 分钟检查 = 减少 90% 的故障**。

**真实案例**：
- 胎压低 0.3 bar 没发现 → 高速爆胎
- 刹车片磨光没发现 → 刹不住
- 链条松没发现 → 链条脱落
- 灯泡烧没发现 → 被交警拦/夜间看不清
- 机油缺没发现 → 发动机烧瓦

**这些事故，骑前 5 分钟检查都能避免**。

### 16.1.2 骑前检查清单 ★★★

**按这个顺序检查**（**最有效率**）：

```
1. 轮胎（30 秒）
   - 胎压（用手按一下，看软硬）
   - 看有无鼓包、扎钉
   - 看胎面磨损
   
2. 刹车（30 秒）
   - 捏前刹、看后刹踏板行程
   - 听有无异响
   - 看刹车片（通过轮辐看）

3. 灯光（30 秒）
   - 大灯（远近光）
   - 转向灯（前/后都试）
   - 尾灯/刹车灯（捏刹看一下）
   - 喇叭

4. 油液（1 分钟）
   - 机油（看机油窗）
   - 刹车油（看主缸液位）
   - 冷却液（看副水箱）
   - 燃油（看油表）

5. 链条（30 秒）
   - 看松紧（20-30 mm 上下活动）
   - 看有无油
   - 看链轮齿形

6. 仪表（30 秒）
   - 看仪表显示
   - 看故障灯
   - 看里程数

7. 整体（1 分钟）
   - 试启动
   - 听发动机声音
   - 看有无漏油/水
```

⏱ **总用时**：**5 分钟以内**

【经验】 **老师傅经验**：**骑前 5 分钟检查**是老司机的标志——**看一眼、摸一下、转一下**。**新手觉得"我骑了 1 万 km 都没事"**——**真出事了一次就够**。

### 16.1.3 异常情况处理

| 检查发现 | 怎么办 |
|----------|--------|
| 胎压低 | 立即打气 |
| 胎压高 | 放气到规定值 |
| 刹车软/有空气感 | **不能骑**！排气/送修 |
| 刹车异响 | 检查刹车片 |
| 灯泡烧 | 换灯泡（应急可以骑，但要尽快换） |
| 机油少 | 加机油（同规格） |
| 机油多 | **不能骑**——会烧机油、积碳 |
| 冷却液少 | 加冷却液（同规格） |
| 燃油少 | 加油 |
| 链条松 | 调整 |
| 链条干 | 上油 |
| 链条断/跳齿 | **不能骑**！送修 |
| 故障灯亮 | 查说明书（部分灯可以骑，部分不行） |
| 漏油/水 | **不能骑**！送修 |

## 16.2 每周检查（30 分钟）

### 16.2.1 洗车

**为什么**：**洗车时顺便检查**——比专门检查省一半时间。

**步骤**：
```
1. 整车冲洗（先水冲，再抹布）
2. 用洗车液洗
3. 重点检查：
   - 看轮胎磨损
   - 看漆面损伤
   - 看灯具老化
   - 看是否有漏油痕迹
   - 看螺丝是否松动
4. 擦干
5. 可选：打蜡
```

### 16.2.2 轮胎花纹检查

**检查**：
```
1. 找磨损指示点（一般在胎面沟里有小凸起）
2. 看胎面是否磨到指示点
3. 测胎纹深度（用胎纹尺或硬币）
4. 最低要求：1.6 mm
5. 建议换：2-3 mm（湿地排水）
```

### 16.2.3 链条深度检查

**检查**：
```
1. 看链条有没有干燥、锈蚀
2. 看链轮齿形有没有变尖
3. 测链条松紧（20-30 mm）
4. 看链节卡子是否松动
```

### 16.2.4 漏油检查

**重点查**：
- 发动机底部（曲轴箱垫片）
- 油底壳放油螺丝
- 链条覆盖区（**这里漏油最隐蔽**）
- 前叉底部
- 后避震底部
- 刹车卡钳
- 油泵附近

**漏液颜色**：
- **棕色/黑色**：机油
- **红色/棕色**：齿轮油
- **绿色/橙色/红色**：冷却液
- **黄色（DOT 等级）**：刹车油
- **汽油味**：燃油

## 16.3 每月检查（1-2 小时）

### 16.3.1 全面目视检查

**项目**：
```
1. 轮胎（再仔细查）
   - 胎压（用胎压表测）
   - 磨损
   - 损伤（鼓包、裂纹）

2. 刹车
   - 刹车片厚度
   - 刹车盘厚度（卡尺）
   - 刹车油液位
   - 刹车油颜色

3. 链条
   - 松紧
   - 油量
   - 链轮

4. 灯光
   - 所有灯泡（远近光、转向、刹车、仪表）
   - 灯罩雾化情况

5. 仪表
   - 仪表显示
   - 故障灯
   - 里程数（记录）

6. 电瓶
   - 电压（万用表测）
   - 桩头（清洁、紧固）

7. 油液
   - 机油（液位、颜色）
   - 冷却液
   - 齿轮油
   - 刹车油

8. 螺丝
   - 主要部位螺丝（油箱、座椅、边盖）

9. 紧固件
   - 后视镜
   - 牌照架
   - 脚踏

10. 漏油/漏水
    - 整车检查
```

### 16.3.2 链条调整（每月）★★

**步骤**：
```
1. 架起大撑
2. 检查链条松紧
3. 松后轴螺母
4. 左右对称调整
5. 拧紧后轴螺母
6. 检查松紧度
7. 检查左右对称
```

### 16.3.3 电瓶检查（每月）★★

**步骤**：
```
1. 测静态电压（停车 1 小时以上）
2. 12.6-12.8V = 满电
3. 12.4V = 该充电
4. < 12V = 启动困难
5. 看桩头（清洁、紧固）
6. 看液位（铅酸电瓶）
```

### 16.3.4 月度记录

**记录**：
- 行驶里程
- 燃油消耗
- 异常情况
- 保养项目

**为什么记录**：**保养是连续过程**——**没有记录就没有数据**——**没有数据就无法判断"什么时候该保养"**。

【经验】 **老师傅经验**：**保养记录**是**老司机和新手的分水岭**。**老司机**一本记录册子能用 10 年。**新车卖**的时候，**保养记录完整的车多卖 10-20%**。

## 16.4 季节性检查

### 16.4.1 春季（开春检查）★★★

**开春是保养最关键的时间点**——**车放了整个冬天**。

**检查清单**：
```
1. 电瓶
   - 测电压（冬季可能饿死）
   - 必要时充电或换新

2. 燃油
   - 看油箱是否有水（冬天可能冷凝）
   - 必要时换油

3. 机油
   - 看是否变质（颜色、气味）
   - 必要时换油

4. 冷却液
   - 看液位
   - 看是否变质（颜色）

5. 轮胎
   - 测胎压（冬季可能慢漏）
   - 看老化（冬天橡胶脆）

6. 链条
   - 看锈蚀（冬天湿冷）
   - 上油

7. 刹车
   - 检查（长期不用可能锈）

8. 试骑
   - 短距离试骑
   - 听异常
   - 看仪表
```

### 16.4.2 夏季检查 ★★

**夏季特别注意**：**热、过热、油液蒸发**。

**检查**：
```
1. 冷却液（夏季消耗快）
2. 机油（高温易变质）
3. 胎压（高温胎压上升）
4. 电池液（铅酸电瓶夏天蒸发）
5. 风扇（夏天是主要散热）
6. 启动机（夏季长时间怠速容易过热）
```

### 16.4.3 秋季检查

**秋季准备过冬**——**类似春季但反向**。

**检查**：
```
1. 全面检查
2. 紧螺丝
3. 防锈处理
4. 检查所有灯光（冬天夜长）
5. 换冬季机油（低温流动性好的）
```

### 16.4.4 冬季检查 ★★★

**冬季是最容易出问题的季节**——**电瓶、油液、轮胎、骑手**。

**检查**：
```
1. 电瓶（关键）
   - 测电压（低温容量下降）
   - 必要时换新
   - 长期不骑要拆下

2. 冷却液
   - 检查冰点（必须 -35°C 以下）
   - 浓度不够要换

3. 机油
   - 冬季用低温流动性好的（如 0W-40）

4. 轮胎
   - 看花纹深度（湿地排水重要）
   - 适当提高胎压（低温下降）

5. 链条
   - 冬季干燥要勤上油

6. 启动
   - 冷启动困难时多捏几下离合
   - 热车 1-2 分钟再走
```

【经验】 **老师傅经验**：**冬季**最危险的不是**冷**——**是车主"装硬汉"**。**不戴手套、不穿保暖服、不热车**，**出事**。**冬季骑车** = **防护 + 热车 + 注意**。

### 16.4.5 雨季检查 ★★

**雨季空气湿度大、灰尘被压住**。

**检查**：
```
1. 空气滤芯（**关键**——湿度让滤芯潮）
2. 链条（雨后要上油——雨水的氧气锈链条）
3. 刹车（**关键**——雨水让刹车打滑）
4. 灯光（雨水进入可能雾化）
5. 电瓶桩头（潮气腐蚀）
```

【严重警告】 **严重警告**：**雨后刹车**——**前几脚刹车**几乎**没效果**！**碟刹盘上有水膜**——**要前几脚慢慢点几下**，**把水膜磨掉**。**不点直接用** = **刹不住**！

### 16.4.6 长期存放检查

**长期存放前**：
```
1. 洗车
2. 换机油
3. 加满油箱
4. 加燃油稳定剂
5. 拆电瓶
6. 胎压上限
7. 罩车衣
```

**存放期间**：
```
1. 每月启动 1 次（10-15 分钟）
2. 或每月充电瓶
3. 偶尔挪车
```

## 16.6 【经验】 老师傅经验沉淀（应写尽写）

### 16.6.1 新手必踩的 10 个日常检查坑 ★★★

**骑前类**：
1. **不骑前检查** —— **故障在路上发生**
2. **胎压用手按代替胎压表** —— **误差 0.5+ bar**
3. **不查机油** —— **发动机会烧瓦**

**月度类**：
4. **不查电瓶** —— **冬季最容易出问题**
5. **不查链条** —— **链条断/脱落 = 摔车**
6. **不检查刹车片** —— **磨光继续骑 = 几千元的损失**

**季节类**：
7. **冬季不换冬季机油** —— **冷启动困难**
8. **冬季冷却液浓度低** —— **冻裂缸体**
9. **雨季不点几下刹车** —— **刹不住**
10. **春季不查电瓶** —— **冬季可能饿死**

【经验】 **老师傅经验**：**日常检查是修车师傅口中"老司机"和"新手"的真正分水岭**。**老司机不是技术比新手好**——**是检查比新手勤**。**骑前 5 分钟** + **每月 1 小时** + **季节调整** = **车多骑 5-10 年**。

### 16.6.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 骑前 5 分钟**：胎压 + 刹车 + 灯光 + 油液
2. **【维修】 每月查电瓶**：冬季前特别要查
3. **【维修】 雨后点刹几脚**：磨掉刹车盘水膜
4. **【维修】 春季全车检查**：放了一冬最危险
5. **【维修】 长期存放每月启动**：电瓶不饿死
6. **【维修】 洗车时顺便检查**：省时间
7. **【维修】 记录保养**：不漏项 + 卖车值钱
8. **【维修】 工具齐**：5000 km 紧一次螺丝

### 16.6.3 检查频率的真实建议

**老司机 vs 新手**：

| 频率 | 老司机 | 新手 |
|------|--------|------|
| 骑前检查 | 5 分钟（**形成习惯**） | 跳过 |
| 每周 | 30 分钟（**洗车+检查**） | 不做 |
| 每月 | 1-2 小时（**记录+调整**） | 不做 |
| 季度 | 半天（**深度检查+保养**） | 4S 店 |
| 季节 | 半天（**全车换季保养**） | 4S 店 |

**成本对比**：
- **老司机**：每年 500-1500 元工具和耗材
- **新手**：每年 2000-5000 元 4S 店

### 16.6.4 一眼看出车主是新手还是老司机的标志 ★★

**老司机的车**：
- 链条有油
- 螺丝都紧
- 胎压足
- 灯泡都亮
- 车身干净
- 工具齐全
- 保养记录完整

**新手的车**：
- 链条干涩
- 螺丝松
- 胎压低
- 灯泡有的不亮
- 车身脏
- 没工具
- 没记录

【经验】 **老师傅经验**：**车的状态 = 车主的习惯**。**看车就知道人**。**老司机的车**比**新手的车**骑起来**舒服 10 倍**。

### 16.6.5 容易忽略的检查点 ★★

**车友经常忘记的**：
- 【维修】 **链条松紧**：长期不查，链条会越来越松
- 【维修】 **后避震吊胶**：影响排气管位置
- 【维修】 **脚踏防滑钉**：磨光了脚打滑
- 【维修】 **牌照架螺丝**：掉了被交警拦
- 【维修】 **油箱盖密封圈**：老化漏油
- 【维修】 **气门嘴帽**：丢了漏气
- 【维修】 **仪表线束**：松了仪表不显示

**安全相关的隐藏点**：
- 【维修】 **刹车油管**：老化开裂
- 【维修】 **油门线**：磨损卡住
- 【维修】 **离合线**：磨损卡住
- 【维修】 **排气管吊胶**：烂了排气管会摔下来

### 16.6.6 不同车型检查重点 ★★

**街车**：全车通用
**ADV**：底盘（越野冲击）+ 空气滤芯（灰尘）
**运动车**：轮胎（高速磨损）+ 刹车（激烈使用）
**踏板车**：CVT 皮带 + 后轮轴承
**复古车**：链条 + 化油器
**电动摩托**：电池（衰减）+ 控制器 + 电机
