## 20.1 案例 1：启动困难 + 排气管冒白烟

### 20.1.1 症状

- 早上启动困难
- 启动后排气管冒大量白烟（不是冬天冷启动那种）
- 副水箱液位异常升高
- 机油变白/乳化

### 20.1.2 诊断过程

```
1. 检查副水箱液位（异常升高可能是缸垫漏线索，但不能单独定论）
2. 启动发动机怠速
3. 看副水箱是否有气泡
4. 检查机油（变白 = 冷却液进油道）
5. 检查排气管（大量白烟 = 冷却液进燃烧室）
6. 做冷却系统压力测试、缸压/漏气测试
7. 做尾气测漏/冷却液 CO2 化学检测，确认燃烧废气是否进入冷却系统
```

### 20.1.3 原因

**疑似缸垫漏**——气缸的高压气体（燃烧气体）可能通过破损的缸垫进入冷却水道，但需要压力测试、缸压/漏气测试、尾气测漏或冷却液 CO2 化学检测验证。单一现象不能定论。

【来源 ⭐】 缸垫漏应通过冷却系统压力、缸压/漏气和燃烧废气进入冷却液等证据交叉确认。

### 20.1.4 处理

【送修】 **必须送修**——**要换缸垫**。

**处理步骤**：
1. 拆缸盖
2. 换缸垫
3. 检查缸盖平面度
4. 检查缸盖是否变形
5. 装回（按扭矩，**分多次**）
6. 加冷却液
7. 排气
8. 测试

### 20.1.5 教训

【严重警告】 **严重警告**：**冷却液进燃烧室**会让发动机**严重过热**、**水锤**（液体不可压缩），**可能导致连杆弯曲**。**立即送修**——**不要继续骑**。

【经验】 **老师傅经验**：**缸垫漏**是**摩托车最隐蔽的故障之一**。**早期症状**：副水箱液位轻微升高、偶尔白烟。**晚期症状**：发动机过热、机油变白。**发现一次就要重视**。

## 20.2 案例 2：怠速不稳、发动机抖动

### 20.2.1 症状

- 怠速忽高忽低（800-1500 rpm 来回波动）
- 怠速时车身明显抖动
- 起步闯动

### 20.2.2 诊断过程

```
1. 检查火花塞（拆下看颜色、跳火）
   - 1 个缸不工作 vs 多个缸不工作
2. 检查进气漏气（化油器清洗剂喷接口）
   - 转速变化 = 漏气点
3. 检查燃油压力（电喷车）
4. 检查节气门脏污
5. 检查怠速阀
6. 检查气门间隙（过大/过小）
```

### 20.2.3 常见原因及处理

| 原因 | 处理 |
|------|------|
| **单缸不工作** | 见 6 章火花塞诊断 |
| **进气漏气** | 紧固卡箍/换垫圈 |
| **节气门脏** | 清洗节气门 + 重置 ECU |
| **气门间隙不对** | 调气门间隙 |
| **怠速阀坏** | 送修 |
| **燃油压力低** | 见 7 章 |

### 20.2.4 教学化案例 ❓

**症状**：怠速 1200-1500 rpm 来回波动。

**诊断**：
1. 火花塞颜色：1 缸黑色，2 缸正常
2. 1 缸点火线圈：换到 2 缸，故障转移到 2 缸
3. **结论**：1 缸点火线圈坏

**处理**：**换点火线圈**——**150-500 元**。

**老师傅经验**：多缸车怠速不稳要逐缸判断，但现代点火线圈和电喷系统不建议随意拔火花塞插头，可能造成高压击穿或故障码。更稳妥的方法是读故障码、测排温、检查火花塞和线圈，必要时用诊断仪做断缸测试。❓

## 20.3 案例 3：加速无力 + 油耗飙升

### 20.3.1 症状

- 油门到底但加速迟缓
- 油耗从 4 L/100km 涨到 6 L/100km
- 排气管有时冒黑烟

### 20.3.2 诊断过程

```
1. 检查空气滤芯（堵了）
2. 检查火花塞颜色（黑/白）
3. 检查氧传感器（不能单凭电压不波动判老化）
4. 检查燃油压力
5. 检查进气压力传感器
6. 检查排气管是否堵
7. 检查气缸压力
```

### 20.3.3 教学化案例 ❓

**症状**：本田 CB650R，加速无力，油耗从 4.5 涨到 6 L/100km。

**诊断**：
1. 换空气滤芯：无改善
2. 火花塞：颜色略深
3. 氧传感器：诊断仪读数据，电压不波动（可能原因包括传感器老化、开环工况、加热器/线路问题、混合气持续过浓/过稀、宽带/窄带传感器类型差异）
4. **结论**：查故障码 + 加热器电压 + 跨工况读数后，才可判断是否氧传感器老化

**处理**：**换氧传感器**——**300 元**——**油耗恢复**。

【来源 ⭐】 氧传感器电压不波动不能单独定论；冷启动/大负荷等开环工况、加热器或线路故障、混合气异常、宽带与窄带传感器类型差异都可能影响读数。应查故障码、加热器电压和跨工况数据。

【经验】 **老师傅经验**：油耗飙升要系统排查：胎压、拖刹、空滤、火花塞、故障码、氧传感器和喷油状态都可能相关。不要凭油耗直接换氧传感器。❓

## 20.4 案例 4：高速车把抖

### 20.4.1 症状

- 80 km/h 以下正常
- 100 km/h 以上车把明显抖动
- 速度越高抖动越厉害

### 20.4.2 诊断过程

```
1. 检查胎压（不均或都低）
2. 检查车轮平衡（不平衡）
3. 检查轮胎磨损（不均/鼓包）
4. 检查车轮轴承（旷量）
5. 检查前叉（弯曲/漏油）
6. 检查车架（变形）
```

### 20.4.3 教学化案例 ❓

**症状**：凯旋 Scrambler 1200X，高速 100 km/h 车把抖。

**诊断**：
1. 胎压：正常
2. 车轮平衡：前轮严重不平衡（贴错位置）
3. **结论**：**前轮没做动平衡**

**处理**：**重新做车轮动平衡**——**50 元**。

【经验】 **老师傅经验**：高速车把抖常见原因包括车轮动平衡、轮胎变形、胎压、轮毂跳动、轴承、转向轴承和悬挂设定。换轮胎后一定要做动平衡，但不要把所有抖动都归因于平衡块。❓

## 20.5 案例 5：刹车软、刹车距离变长

### 20.5.1 症状

- 捏刹车手柄到一半才有刹车力
- 刹车距离明显变长
- 紧急情况刹不住

### 20.5.2 诊断过程

```
1. 检查刹车油液位（低 = 漏）
2. 检查是否有漏油痕迹
3. 捏手柄听/感受（"气泡感"只是线索，不能单独定论）
4. 检查刹车片厚度
5. 检查刹车盘厚度
6. ABS 车型按手册/诊断仪要求走排气流程
7. 检查主泵、软管膨胀、卡钳回位和漏油/油位低
```

### 20.5.3 教学化案例 ❓

**症状**：宝马 F750GS，刹车软，捏到底还要再捏几下。

**诊断**：
1. 刹车油液位：正常
2. 无漏油痕迹
3. 捏手柄：明显海绵感/气泡感
4. **结论**：可能有空气，但还要按 CH12 诊断流程先排除 ABS 工作/排气流程、主泵问题、软管膨胀、卡钳问题和漏油

**处理**：**排气**——**专业排气**——**80 元**——**恢复正常**。

【严重警告】 **严重警告**：**刹车软 = 危险**！**不要继续骑**——**立即排气或送修**！
【来源 ⭐】 制动手感异常需按液压系统完整流程诊断；ABS 车型可能需要专用排气流程或诊断仪辅助。
❓

## 20.6 案例 6：过坑"咣当"、操控差

### 20.6.1 症状

- 过坑时车架明显颠簸
- 急刹车时车头下沉太多（"点头"）
- 操控不线性

### 20.6.2 诊断过程

```
1. 按车主手册检查后避震预载/静态下沉（不是判断弹簧硬度）
2. 检查前叉预载（太软）
3. 检查避震油（老化）
4. 检查前叉油（老化）
5. 检查弹簧（损坏/老化）
```

### 20.6.3 教学化案例 ❓

**症状**：雅马哈 MT-07，过坑"咣当"，双人骑特别明显。

**诊断**：
1. 后避震预载：出厂设定（没调过）
2. 双人骑应该加预载
3. **结论**：**预载不足**

**处理**：按车主手册调整后避震预载：有级位调节按级别，螺纹调节用专用扳手，气压调节（部分 ADV）用规定气泵；预载用于调整初始静态下沉，不是改变弹簧硬度，也不替代弹簧/阻尼匹配。

【来源 ⭐】 后避震预载结构和调法因车型不同，必须按车主手册和调节机构执行。
【经验】 **老师傅经验**：后避震预载不合适会影响下沉量和支撑感，但如果过坑触底、回弹异常或载重变化很大，要检查弹簧和阻尼是否匹配，不能只靠预载硬撑。
❓

## 20.7 案例 7：链条响、跳齿

### 20.7.1 症状

- 加速时有金属撞击声
- 链条有"咯噔"声
- 链条明显松弛

### 20.7.2 诊断过程

```
1. 检查链条松紧/自由行程（以车主维修手册为准；常见参考 20-35 mm，视车型）
2. 检查链条油（干燥）
3. 检查链轮齿形（变尖）
4. 测量链条拉伸/磨损（按手册规定节数；常见按 20 节测量，超过原始长度约 1.5-2% 可判报废（ANSI 滚子链口径；部分密封链厂家以 1% 作为预警线，以链条厂家手册为准），❓）
```

【来源 ⭐】 链条自由行程和拉伸极限必须以车型车主手册/维修手册、链条规格和规定测量节数为准；上面数值只作教学参考。

### 20.7.3 教学化案例 ❓

**症状**：本田 CB500F，链条响，跳齿。

**诊断**：
1. 链条松紧：40 mm（相对常见参考偏松；最终以该车型手册为准）
2. 链轮齿形：变尖（"鲨鱼鳍"）
3. 链条拉伸：以 520 链为例，20 节新链基准约 317.5 mm（15.875 mm × 20）；拉紧测量超过厂家给定极限即报废（示例值，以链条厂家手册为准）
4. **结论**：**链条+链轮都报废**

**处理**：**换链条+链轮**——**400 元**。

【经验】 **老师傅经验**：**链条+链轮要同时换**——**单换链条被旧链轮磨坏**——**单换链轮被旧链条磨坏**。
❓

## 20.8 案例 8：电瓶没电、启动没反应

### 20.8.1 症状

- 按启动按钮：完全没反应
- 仪表也不亮
- 喇叭不响

### 20.8.2 诊断过程

```
1. 检查电瓶电压（万用表测）
   - 11.0 V 左右只能说明电压很低，不能直接定论原因
2. 看桩头（腐蚀、松动）
3. 看保险丝（主保险丝）
4. 看电瓶是否能充电
5. 做负载测试（高率放电/CCA 测试）
6. 测发动机运行时充电电压（常见参考 13.5-14.5 V，以手册为准）
7. 查寄生电流（常见参考 < 10-30 mA，以车型为准）
8. 查保险、搭铁和主电源线
```

### 20.8.3 教学化案例 ❓

**症状**：冬天早上，启动没反应。

**诊断**：
1. 电瓶电压：11.0 V（电压很低，但不能直接定论原因）
2. 桩头：正常
3. **结论**：需通过负载测试、充电电压、寄生电流、保险/搭铁检查，定位是电瓶、充电系统还是漏电

**处理**：
- 应急：搭电启动
- 长期：换新电瓶 + 智能充电器

【来源 ⭐】 静态电压只能说明当前状态，不能单独区分电瓶老化、充电不足、寄生漏电或线路问题；需要负载和充电系统测试。

【经验】 **老师傅经验**：**冬季电瓶最容易出问题**——**每年入冬前查电瓶**。0°C 时电瓶可用容量常见约下降 20-30%；更低温可能更明显，具体看电瓶类型、健康状态和 CCA。**夏天 OK 的电瓶冬天可能不行**。
【来源 ⭐】 低温电瓶性能需按电瓶类型、CCA 和车型手册判断；0°C 下降 20-30% 与 CH13 口径一致。

## 20.9 案例 9：异响（按位置分类）

### 20.9.1 缸头异响（"哒哒哒"）

**原因**：
1. 气门间隙大
2. 凸轮轴磨损
3. 摇臂磨损

**诊断**：
1. 冷车响热车消失 = 气门间隙（调整）
2. 一直响 = 凸轮轴/摇臂磨损（送修）

### 20.9.2 缸体异响（"铛铛铛"）

**原因**：
1. 活塞敲缸
2. 活塞销磨损
3. 连杆瓦磨损

**诊断**：
1. 冷车响热车消失也可能是活塞/缸壁/连杆等内部问题（**立即停骑送修**）
2. 一直响 + 加速无力 = 连杆瓦（**立即送修**）

【严重警告】 **发动机内部敲击不要继续骑**：活塞敲缸、缸壁磨损或连杆问题继续骑，可能导致拉缸、抱死、失火甚至后轮瞬间失去牵引。冷车响热车减轻也不等于安全。
【来源 ⭐⭐】 发动机内部规律敲击属于高风险机械故障，需专业检查确认。

### 20.9.3 底部异响（"嗡嗡嗡"）

**原因**：
1. 曲轴轴承磨损
2. 变速箱齿轮磨损

**诊断**：
1. 怠速/空挡也响：先定位曲轴、离合器、一次传动等随发动机转速变化的部位
2. 随车速变化：再查链条、链轮、轮轴轴承、变速箱输出端等传动/行走部位
3. 随负载或某一挡位变化：重点查离合器、变速箱齿轮和相关轴承

【来源 ⭐】 异响诊断应按位置、时机、转速/车速/负载关联综合定位，不能用“怠速响=轴承、高速响=齿轮”直接定论。

【送修】 **该送修了**：**底部异响是大修级别**。

### 20.9.4 传动链条异响（侧后方链条"哗啦哗啦"）

**原因**：
1. 链条松
2. 链条缺油
3. 链轮磨损

【来源 ⭐】 传动链条位于车身侧后方；前部链条异响通常指正时链条，诊断和处理路径不同，不能混写。

**处理**：
- 链条松：调整
- 缺油：上油
- 链轮磨损：换

### 20.9.5 后部异响（排气管"咣当咣当"）

**原因**：
1. 排气管挂钩弹簧断
2. 排气管接口松

**处理**：
- 挂钩断：换挂钩（几元）
- 接口松：紧固

【经验】 **老师傅经验**：**异响的诊断"黄金法"**——**位置 + 时机 + 声音特点**。**位置告诉你哪个部件**，**时机告诉你冷/热工况**，**声音告诉你故障类型**。

## 20.10 案例 10：维修后出新问题

### 20.10.1 案例：换火花塞后启动困难

**症状**：换完火花塞，启动困难，甚至不启动。

**可能原因**：
1. 火花塞型号不对（热值不对、长度不对）
2. 火花塞没拧紧（漏气）
3. 高压线没插好

**处理**：
- 拆火花塞确认型号
- 按扭矩拧紧
- 检查高压线

### 20.10.2 案例：换链条后跑偏

**症状**：换完链条+链轮，车跑偏。

**可能原因**：
1. 链条调整左右不对称
2. 后轴螺丝没拧紧
3. 后轮没对准

**处理**：
- 重新调链条（按车型手册，用后轴刻度/对中基准确认左右调整量）
- 按扭矩拧紧后轴
- 不用两侧张力判断对中；必要时用直尺/激光对链条线或送修复查

【来源 ⭐】 链条调整应按车型手册使用后轴刻度、对中标记或规定工具确认后轮对中，链条张力与左右对中不是同一个测量项目。

### 20.10.3 案例：清洗节气门后怠速异常

**症状**：清洗节气门后怠速 2000 rpm，发动机故障灯亮。

**可能原因**：
1. **没重置 ECU**
2. 节气门线被移动
3. 进气漏气（拆装时没装好）

**处理**：
- **重置 ECU**（按第 7 章方法）
- 检查节气门线
- 检查进气漏气

【经验】 **老师傅经验**：维修后的新问题很常见，优先回看刚拆过的部位：插头、真空管、垫圈、扭矩、卡扣和线束走向。维修前拍照、维修后复查和低速试车，能显著减少返工。

## 20.11 【经验】 老师傅经验沉淀（应写尽写）

### 20.11.1 新手必记的 8 个故障真相 ●●●

**真相 1**：**故障的"简单解释"通常是错的**。
- 启动困难不一定是火花塞——可能是电瓶、油泵、ECU。
- **多查几项再下结论**。

**真相 2**：**异响越规律越严重**。
- 节奏规律的异响往往是磨损（如气门、活塞）。
- **持续恶化不要拖延**。

**真相 3**：**故障前兆比故障本身重要**。
- 油耗高、动力下降——**这些是前兆**。
- **发现前兆就查**——**不要等大故障**。

**真相 4**：**传感器和线路是现代电喷车常见排查方向之一**。
- 动力问题不要直接归因；先读故障码和数据流，再结合燃油压力、进排气和机械状态验证。
- **学会读诊断仪**——**值回票价**。

**真相 5**：**维修后试车最重要**。
- 维修完不试车 = **赌运气**。
- **试车 5 分钟**——**比什么都管用**。

**真相 6**：**"老车常见关注点"是真的**。
- 每个车型都有"常见关注点"。
- **加入车友群**——**问问过来人**。

**真相 7**：**维修前的拍照能救命**。
- 维修前拍 5 张照片 = 装回去省一半时间。
- **新手不拍 = 必然出错**。

**真相 8**：**不知道原因别瞎修**。
- **瞎修** = **小病变大病**。
- **查清楚再动手**。

### 20.11.2 老师傅不外传的 8 个诀窍 ●●●

1. **【维修】 异响诊断三要素**：位置 + 时机 + 声音
2. **【维修】 油耗飙升先系统排查**：胎压、拖刹、空滤、故障码、燃油压力和氧传感器数据都要看
3. **【维修】 高速车把抖先查轮胎和车轮**：动平衡、胎压、轮胎变形、轮毂跳动都要看
4. **【维修】 维修前拍 5 张照片**：装回去省时间
5. **【维修】 维修后试车 5 分钟**：避免装配问题
6. **【维修】 加入车友群**：问过来人
7. **【维修】 备一些应急件**：保险丝、灯泡、链条扣
8. **【维修】 故障诊断从简到繁**：从最容易的开始

### 20.11.3 故障诊断的标准流程

**老师傅推荐的诊断流程**：

```
1. 现象观察（症状、时机、位置）
2. 简单检查（看、听、摸）
3. 排除法（从最可能开始）
4. 用工具测（万用表、压力表、诊断仪）
5. 拆解检查（最后手段）
6. 确认病因
7. 维修
8. 验证
```

【经验】 **老师傅经验**：**诊断比维修重要**。**诊断错误** = **维修错误** = **浪费时间+金钱**。**花 1 小时诊断** = **省 3 小时维修**。

### 20.11.4 不同车型的常见故障

**老师傅经验**：

| 车型 | 常见故障 |
|------|---------|
| **本田 CB/CBR 系列** | 离合器打滑（老车）、链条松 |
| **雅马哈 MT/R 系列** | 油门响应迟钝（节气门脏）、链条松 |
| **川崎 Ninja/Z 系列** | 充电系统、刹车软（老化） |
| **哈雷 Sportster** | 油路老化（橡胶管）、点火线圈 |
| **宝马 R 系列（轴传动）** | ABS 传感器 |
| **宝马 F 系列（链条传动）** | 链条寿命短 |
| **杜卡迪** | 链条紧（O 形）、电瓶 |
| **凯旋** | 油门响应、链条紧 |
| **KTM** | 空气滤芯（越野）、链条 |

**加入对应车型的车友群**——**问问常见故障**——**避坑**。

### 20.11.5 故障预防比维修更重要

**老师傅的实际建议**：

**预防胜过维修**：
- **保养好的车** = **少故障**
- **保养差的车** = **多故障**

**预防的核心**：
1. **骑前检查**（5 分钟）
2. **按周期保养**（按说明书）
3. **及时换易损件**（油液、滤芯、火花塞）
4. **关注小问题**（异响、抖动、油耗）

【经验】 **老师傅经验**：**修车师傅的"老客户"和"新客户"**：
- **老客户**：每次来都是小保养——**10 年车还很新**
- **新客户**：每次来都是大修——**5 年车快报废**

**你想做哪种客户？**——**选择在于保养**。

### 20.11.6 何时该认怂送修

**新手该认怂的信号**：

- 【送修】 **不懂原理**的故障（如 ABS、ECU）
- 【送修】 **涉及大件**的故障（如缸盖、变速箱、曲轴）
- 【送修】 **专用工具**的故障（如轴承拉拔、扭角扳手）
- 【疑难】 **诊断不出的**故障（查了所有都正常但还有问题）
- 【送修】 **维修后出新问题**（不懂为什么会出现）
- 【送修】 **没信心**的（**没信心不要硬上**）

【经验】 **老师傅经验**：**送修不丢人**——**修坏了才丢人**。**老师傅也不是什么都自己修**——**送修为主、自己干为辅**是更聪明的策略。

学完本章后想进阶：

3. **【进阶】** 用诊断仪读故障码
4. **【高级】** 拆解检查、确认病因
5. **【专业】** 综合诊断 + 维修

### 20.11.8 网络实战案例汇编（来自论坛、技师分享）●●

### 案例 A：本田 CB500F 冷启动短时白烟（冬天）

**症状**：冬天冷启动后几秒白烟，很快消失
**踩坑过程**：以为是烧冷却液
**可能原因**：**冷凝水汽**——**排气管内凝结的水分蒸发**
**处理建议**：冬天冷车短暂白雾/滴水通常是正常的；如果热车后持续白烟、冷却液减少或机油乳化，立即停骑检查缸垫
**教训**：**冬天冷车短暂白雾**可能正常；热车持续白烟必须检查。案例里的"症状 = 原因"只作教学化口号，真实诊断见 CH04，必须多症状交叉验证。❓

### 案例 B：雅马哈 MT-07 冬天启动难

**症状**：冬天启动要按 5 次
**踩坑过程**：以为是火花塞
**可能原因**：**冬天机油粘度大**——**启动阻力大**
**处理建议**：按说明书允许的低温粘度选择机油，先检查电瓶状态和启动系统，不要只因冬天就改成 0W
**教训**：冬天启动困难可能与机油粘度、电瓶、启动系统和供油有关；真实诊断见 CH04。❓

### 案例 C：宝马 R1200GS 中速熄火

**症状**：60 km/h 时熄火
**踩坑过程**：以为是火花塞
**可能原因**：**节气门位置传感器**——**信号漂移**
**处理建议**：**重置 ECU**
**教训**：中速熄火可能与传感器、供油、点火、进气和线路有关；真实诊断见 CH04。❓

### 案例 D：哈雷 Sportster 怠速忽高忽低

**症状**：怠速不稳
**踩坑过程**：以为是节气门
**可能原因**：**怠速控制阀脏**
**处理建议**：**清 ISC**
**教训**：怠速不稳可能与 ISC/怠速阀、进气漏气、节气门、点火和气门间隙有关；真实诊断见 CH04。❓

### 案例 E：川崎 Ninja 400 高速失火

**症状**：高速失火
**踩坑过程**：以为是火花塞
**可能原因**：**点火线圈老化**
**处理建议**：**换点火线圈**
**教训**：高速失火可能与点火线圈、火花塞、燃油压力、传感器和线束有关；真实诊断见 CH04。❓

### 案例 F：杜卡迪 Monster 烧机油严重

**症状**：每 1000 km 加 200 ml 机油
**踩坑过程**：以为是正常
**可能原因**：**气门油封坏**
**处理建议**：**换油封**
**教训**：烧机油可能与气门油封、活塞环、缸壁磨损和曲轴箱通风有关；真实诊断见 CH04。❓

### 案例 G：凯旋 Tiger 900 ADV 越野后无力

**症状**：越野后动力下降
**踩坑过程**：以为是发动机
**可能原因**：**空滤堵**
**处理建议**：**清空滤**
**教训**：越野后无力可能与空滤、进气、燃油和传动负载有关；真实诊断见 CH04。❓

### 案例 H：本田 Africa Twin 雨天打火困难

**症状**：雨天打火难
**踩坑过程**：以为是电瓶
**可能原因**：**火花塞湿**——**高压线漏电**
**处理建议**：**擦干 + 换高压线**
**教训**：雨天打火困难可能与高压漏电、接插件进水、电瓶和传感器有关；真实诊断见 CH04。❓

### 案例 I：铃木 SV650 烧灯泡

**症状**：一个月烧 2 个灯泡
**踩坑过程**：以为是灯泡质量
**可能原因**：**电压调节器坏**——**电压过高**
**处理建议**：**测电压 + 换调压器**
**教训**：烧灯泡可能与充电电压、灯泡规格、插座接触和震动有关；真实诊断见 CH04。❓

### 案例 J：本田 NC750X 链条异响

**症状**：骑 2 万 km 链条响
**踩坑过程**：以为是链条松
**可能原因**：**链条+链轮都到寿命**

**教训**：链条异响可能与松紧、润滑、链轮磨损、链条磨损和后轮对中有关；真实诊断见 CH04。❓

### 这些案例的共同教训 ●●

**新手最常踩的 5 个大坑**（基于论坛统计）：
1. **乱猜** = **换了 N 个零件 = 修不好**
2. **不读故障码** = **ECU 自带诊断**
3. **不查传感器** = **跳过传感器直接换件是常见误诊来源**
4. **不看数据** = **不知道真假**
5. **不查论坛** = **别人早遇到过**

【经验】 **老师傅总结**：故障诊断 = 先看 + 再听 + 再测。先排除保养件、接头、油液、故障码和基本测量，再判断是否需要大修。

【注意】 网络案例常把复杂诊断压缩成"症状 = 单一原因"，这里只能当教学化口号。真实诊断必须按 CH04 多症状交叉验证：症状一样原因可以不同，症状不同原因也可以一样；先验证，再更换。
