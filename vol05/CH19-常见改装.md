## 19.1 改装前必看（强烈建议先读）★★★

### 19.1.1 改装的真相

**真相 1**：**原厂车已经很好了**。

**原厂车的设计**：
- 几百小时台架测试
- 上万公里实路测试
- 工程师根据市场反馈优化
- 平衡了动力、油耗、可靠性、成本

**改装店**：
- 几小时静态测试
- 几十公里路试
- 商家关注利润

**真相 2**：**改装是"系统问题"**。

**单点改装** = 浪费钱。
- 单独换空滤 → 1-3%（几乎感觉不到）
- 单独换排气 → 2-5%（几乎感觉不到）
- 空滤 + 排气 + ECU → 8-15%（能感觉到）

**真相 3**：**改装有副作用**。

| 改装 | 副作用 |
|------|--------|
| 改进气 | 噪音增加、滤芯寿命缩短 |
| 改排气 | 噪音大、可能违法、可能影响扭矩曲线 |
| ECU 调校 | 影响保修、可能影响可靠性 |
| 改刹车 | 需要换刹车油、可能影响 ABS |
| 改避震 | 需要重新调校、可能改变几何 |

### 19.1.2 改装前问自己的 4 个问题

**问题 1**：**我要什么？**
- 动力？操控？舒适？美观？
- 不同目标改的部位不同

**问题 2**：**我的预算？**
- 改装的成本是原厂的 2-5 倍
- "几百元改出 30% 动力提升"是不存在的

**问题 3**：**我要失去什么？**
- 保修？
- 油耗？
- 噪音？
- 可靠性？

**问题 4**：**我骑车的目的是什么？**
- 通勤？长途？赛道？越野？
- 不同用途改的部位不同

### 19.1.3 改装的法律风险 ★★★

**改装法规灰色地带**：

| 项目 | 风险 |
|------|------|
| 改排气（滑动段） | 【注意】 部分国家/地区违法 |
| 拆触媒 | ✗ 道路车辆通常违法或无法通过排放/年检，按当地法规处理 |
| 改大灯（颜色、亮度） | 【注意】 部分国家/地区违法 |
| 改 ECU（解锁极速） | ✗ 违法 |
| 改车身颜色 | 【注意】 需备案 |
| 加装防摔架 | ✓ 大部分合法 |
| 改仪表 | 【注意】 需备案 |
| 升级刹车 | ✓ 合法 |

【来源】 **数据来源等级**：★（**你的国家/地区法规请查当地**）。

【严重警告】 **严重警告**：**改装违法会被罚款 + 强制还原**。**改装店不会告诉你**——**为了卖货**。**自己要知道**。

### 19.1.4 改装的预算分配原则

**新手推荐预算分配**：

```
1. 改装前：基础保养做好（500-2000 元）
2. 第一笔：改最有价值的（操控 > 动力）
3. 第二笔：改第二有价值的
4. 最后一笔：装饰、外观
```

**老师傅推荐预算分配**：
- **轮胎 > 刹车 > 避震 > 排气 > ECU > 空滤 > 装饰**

【经验】 **老师傅经验**：**改装第一原则**：**轮胎好 = 操控好 = 安全好**。**改装第二原则**：**刹车好 = 安全好**。**改装第三原则**：**避震好 = 操控好**。**最后才考虑动力**。

## 19.2 进气改装

### 19.2.1 高流量空滤

**项目**：换 K&N 或同类高流量空滤。

**真实效果**：**1-3% 动力**。

**成本**：300-800 元。

**是否推荐**：✗ **不推荐**——**单独换空滤几乎没感觉**——**除非配合 ECU 调校**。

**副作用**：
- 噪音增加（进气噪音）
- 滤芯寿命缩短（要更频繁清洁）
- 过滤效率可能略降

### 19.2.2 高流量进气管

**项目**：换高流量进气管（也称"高流量风箱"）。

**真实效果**：**3-8% 动力**。

**成本**：500-3000 元。

**是否推荐**：【注意】 **看需求**——**配合 ECU 调校有效果**。

### 19.2.3 进气导风管（Ram Air）

**项目**：利用车速冲压进气。

**真实效果**：**高速时 5-15% 动力**。

**成本**：1000-5000 元。

**是否推荐**：【注意】 **赛道专用**——**街道几乎用不到**。

## 19.3 排气改装

### 19.3.1 滑动段排气（Slip-On）

**项目**：只换消音器段，保留原厂触媒和头段。

**真实效果**：**2-5% 动力**。

**成本**：1000-5000 元。

**是否推荐**：【注意】 **看需求**——**想听声浪可以**——**想提升动力意义不大**。

**副作用**：
- 噪音大幅增加
- 可能影响低速扭矩
- 油耗可能略增

### 19.3.2 全段排气（Full System）

**项目**：替换原厂整段排气管（包括触媒）。

**真实效果**：**8-15% 动力**。

**成本**：3000-30000 元。

**是否推荐**：【注意】 **慎重**——**改装店最爱推**——**配套 ECU 调校才有效**。

**副作用**：
- 噪音巨大
- 可能违法（道路车辆拆除或失效化触媒通常不合规）
- 影响保修
- 油耗增加
- 扭矩曲线变化

### 19.3.3 高流量触媒

**项目**：换高流量触媒（不拆触媒）。

**真实效果**：**3-8% 动力**。

**成本**：2000-8000 元。

**是否推荐**：【注意】 **配套改装**——**单独换效果有限**。

### 19.3.4 排气改装的真相

【严重警告】 **重要事实**：

**滑动段的"5%"提升** = **心理安慰大于实际感受**。
**全段排气的"15%"提升** = **必须配套 ECU 调校**。

**老师傅的真实看法**：
- **滑动段**：花钱买声浪，不是买动力
- **全段**：想提升动力必须 ECU 调校
- **单独改排气不调 ECU** = **浪费钱**

## 19.4 制动改装

### 19.4.1 升级刹车片 ★★

**项目**：换高性能刹车片（如 EBC、Brembo 等）。

**真实效果**：**5-10% 刹车力提升** + **耐高温**。

**成本**：300-1000 元/对。

**是否推荐**：✓ **强烈推荐**——**性价比最高的改装**。

**副作用**：
- 噪音可能略增
- 磨合期（**前 100 km 轻刹**）
- 盘磨损略快（**用对应材质的片**）

### 19.4.2 升级刹车钢喉 ★★

**项目**：换金属编织刹车软管（钢喉）。

**真实效果**：**5% 刹车手感提升** + **热衰减减少**。

**成本**：200-500 元/根。

**是否推荐**：✓ **强烈推荐**——**便宜效果好**。

### 19.4.3 升级刹车卡钳

**项目**：换多活塞卡钳（如 Brembo）。

**真实效果**：**10-30% 刹车力提升**。

**成本**：3000-15000 元。

**是否推荐**：【注意】 **中高级玩家**——**街道车没必要**。

**副作用**：
- **必须配大刹车盘**
- **必须配钢喉**
- **必须配高性能片**
- **整套下来 1-3 万**

### 19.4.4 升级刹车盘

**项目**：换浮动盘、打孔盘等。

**真实效果**：**散热更好、衰减更少**。

**成本**：1000-5000 元/对。

**是否推荐**：【注意】 **看需求**——**街道几乎用不到浮动盘**。

## 19.5 悬挂改装

### 19.5.1 升级后避震 ★★

**项目**：换高端后避震（如 Öhlins、WP、YSS）。

**真实效果**：**操控大幅提升**——**骑行感受完全不同**。

**成本**：3000-15000 元。

**是否推荐**：✓ **强烈推荐**——**改装里性价比最高**。

### 19.5.2 升级前叉 ★★★

**项目**：换可调前叉（如 Öhlins、KYB、Showa）。

**真实效果**：**操控大幅提升**——**前叉决定 50% 操控**。

**成本**：5000-30000 元。

**是否推荐**：【注意】 **看预算**——**前叉改造成本高**。

### 19.5.3 避震调校（不需要改装）

**项目**：原厂避震调校（见第 18 章）。

**真实效果**：能明显改善骑姿匹配和操控信心，成本低，但效果取决于车手身高、体重、车况和原设定。

**是否推荐**：✓ **优先做调校**——**调校后再考虑改装**。

### 19.5.4 降低车身

**项目**：换低坐垫、改装下联板等。

**真实效果**：**重心降低、操控略好**——**但坐高降低骑行姿势不舒服**。

**是否推荐**：【注意】 **看身高**——**个子矮的车友可以**。

## 19.6 其他常见改装

### 19.6.1 改装链轮 ★★

**项目**：换前/后链轮。

**真实效果**：**改变车的"性格"**：
- 前链轮小一齿 = 终传比变大，起步/加速更强，极速和巡航经济性通常下降
- 后链轮大一齿 = 类似前链轮小齿，但变化幅度通常更小

**成本**：500-2000 元。

**是否推荐**：【注意】 **看需求**——效果明显，但会影响链条长度、车速表、ABS/TC 标定和油耗。

【注意】 **注意**：改齿比前先确认车速信号来源，并查同车型案例；安全系统敏感的车型不建议新手自行改。

### 19.6.2 改装轮胎 ★★

**项目**：换运动胎、越野胎、定制胎等。

**真实效果**：**抓地大幅提升**——**最影响骑行的改装**。

**成本**：500-2000 元/对。

**是否推荐**：✓ **强烈推荐**——**改装第一优先级**。

### 19.6.3 LED 大灯 ★★

**项目**：换 LED 灯泡。

**真实效果**：**亮度大幅提升**——**夜间骑行更安全**。

**成本**：200-1000 元。

**是否推荐**：✓ **推荐**——**实用改装**。

**注意**：**要买有解码功能的**——**否则仪表报错**。

### 19.6.4 加热把手 ★

**项目**：换加热把手。

**真实效果**：**冬季神器**——**手不冷**。

**成本**：200-800 元。

**是否推荐**：✓ **冬季必装**——**骑过的都说好**。

### 19.6.5 改装坐垫 ★★

**项目**：换舒适坐垫、加凝胶垫等。

**真实效果**：**长途骑行舒适度大幅提升**。

**成本**：500-2000 元。

**是否推荐**：✓ **长途车主推荐**。

### 19.6.6 防摔架（Crash Cage）★★

**项目**：加装防摔架保护发动机和车架。

**真实效果**：**摔车保护**——**减少维修费**。

**成本**：500-2000 元。

**是否推荐**：✓ **强烈推荐**——**比维修便宜**。

### 19.6.7 大灯护网

**项目**：加装金属护网。

**真实效果**：**防止石子打碎大灯**。

**成本**：100-300 元。

**是否推荐**：✓ **越野/ADV 必装**。

### 19.6.8 改装仪表 ★★

**项目**：换 TFT 仪表、智能仪表等。

**真实效果**：**科技感、可显示更多信息**。

**成本**：500-3000 元。

**是否推荐**：【注意】 **看需求**——**原厂仪表够用**。

### 19.6.9 行车记录仪

**项目**：加装运动相机或专用行车记录仪。

**真实效果**：**事故记录**——**保护自己**。

**成本**：500-3000 元。

**是否推荐**：✓ **推荐**——**事故责任清晰**。

### 19.6.10 手机支架 ★

**项目**：车把/油箱/镜架位置加手机支架。

**真实效果**：**导航**——**部分车型可连 ECU 看数据**。

**成本**：50-300 元（支架）。

**是否推荐**：✓ **推荐**（**长途、ADV 必备**）。

【注意】 **注意**：
- **横屏**比**竖屏**好（更稳）
- **金属支架** > **塑料支架**（**振动大** = **塑料易断**）
- **带防丢绳** = **掉了不丢手机**
- **雨季** = **防水袋必备** = **手机泡水 = 几千**

### 19.6.11 USB 充电接口 ★★

**项目**：加装 12V → USB 充电口（**有 SAE / 翘板开关 / 直接电瓶三种**）。

**真实效果**：**手机/相机/加热装备充电**——**长途必备**。

**成本**：30-200 元。

**是否推荐**：✓ **强烈推荐**（**长途**）。

**三种方案对比**：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **SAE 接口** | 通用、断开容易 | 长期不骑要拔 |
| **翘板开关** | 可关、可控 | 走线要细心 |
| **直接电瓶** | 简单 | **忘了拔 = 耗光电** |

【注意】 **强烈建议**：
- **加 SAE 接头** = **长期停放断开** = **不耗电**
- **接 ACC 钥匙门** = **关钥匙断电** = **保险**
- **不要直接接电瓶**（除非你记得每次拔）

### 19.6.12 改装喇叭（音量升级）★

**项目**：换更响的喇叭或多喇叭。

**真实效果**：**让"鬼探头"更可能听到**——**城市骑行有用**。

**成本**：50-500 元。

**是否推荐**：✓ **推荐**（**城市通勤**）。

**注意**：
- **大功率喇叭** = **电瓶负载大**
- **多喇叭** = **线路要粗**
- **带继电器** = **保护按钮**
- **不要太响** = **被路人骂**

### 19.6.13 改装车把（高把/低把）★

**项目**：换不同高度/角度的车把。

**真实效果**：**改变骑行姿势**——**舒适度**。

**成本**：200-1500 元。

**是否推荐**：【注意】 **看个人**（**先试坐**）。

**注意**：
- **高了** = **风阻大** = **高速累**
- **低了** = **风阻小** = **激进骑**
- **改装车把** = **线缆可能不够长** = **要换线**
- **改装车把** = **拉索/油管可能卡**

【经验】 **老师傅经验**：**改装车把** = **看起来简单** = **改完很多问题**——**新手先别动**。

### 19.6.14 改装后视镜（防抖/广角）★

**是否推荐**：✓ **推荐**（**折叠式**对城市有用）。

**类型**：
- **原厂同款** = **稳定** = **推荐**
- **广角凸面镜** = **视野大** = **但变形** = **距离感变差**
- **折叠式** = **窄路防撞** = **推荐**
- **短款** = **好看** = **但视野小**

### 19.6.15 改装后挡泥板（防甩泥）★

## 19.7 【经验】 老师傅经验沉淀（应写尽写）

### 19.7.1 新手必踩的 10 个改装坑 ★★★

1. **听商家忽悠"提升 30%"** —— 没有同车型、同工况台架或赛道数据就不要信
2. **单点改装** —— 必须配套
3. **改装不改 ECU** —— 浪费钱
4. **改装不改保修** —— 失去保修
5. **拆触媒** —— 违法
6. **改装不试车** —— 装完就骑危险
7. **改装店比原厂懂你的车** —— 不可能
8. **改装预算不够就改** —— 装一半不如不改
9. **改装后不重新调校** —— 各种问题
10. **改装后不上保险** —— 风险大

### 19.7.2 老师傅不外传的 8 个诀窍 ★★★

1. **【维修】 改装前先把原厂骑熟**：知道自己要什么
2. **【维修】 改装第一笔投轮胎**：最影响骑行
3. **【维修】 改装第二笔投刹车**：安全
4. **【维修】 改装第三笔投避震**：操控
5. **【维修】 最后才考虑动力**：原厂动力已经够
6. **【维修】 改装要配套**：单点改装 = 浪费
7. **【维修】 改装要找专业店**：不要找路边店
8. **【维修】 改装后要重新调校**：悬挂、ECU 都要

### 19.7.5 改装 vs 调校 vs 保养（区别）

### 改装的核心原则

1. **改装前先把原厂骑熟**

- **升级轮胎**：抓地大幅提升
