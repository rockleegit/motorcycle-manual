## 18.1 调校的基本原则

### 18.1.1 什么是调校

**调校**（Tuning）：**在不改变原厂硬件的前提下**，**调整各种参数**，让发动机和车架达到**当前状态下的最佳性能**。

**调校的本质**：
- 恢复原厂设定（很多新车都没调好）
- 适配驾驶习惯（一个人骑还是载人）
- 适配气候/海拔（温度、气压影响空燃比）
- 适配车龄（老车参数会漂移）

### 18.1.2 调校的目标

**调校追求的是"平衡"**：

| 目标 | 说明 |
|------|------|
| **动力** | 加速、最高速 |
| **油耗** | 经济性 |
| **响应** | 油门反应 |
| **平顺性** | 不抖动、不窜车 |
| **可靠性** | 不出故障、不磨损 |

**调校不可能全部最优化**——**只能平衡**。

### 18.1.3 调校的基本流程

```
1. 确认原厂设定（看说明书）
2. 评估当前状态（哪些参数偏离了）
3. 设定调校目标（要动力还是要油耗）
4. 一次只调一个参数
5. 试车记录
6. 评估效果
7. 调整到最佳
8. 记录最终值
```

### 18.1.4 调校的"三大纪律"

【经验】 **老师傅经验**：调校最忌"一下调太多"——**一次只调一点点**，**试车后再调**。**调坏了一辆车都毁**——**从原厂设定开始最容易恢复**。

【注意】 **三大纪律**：
1. **一次只调一个参数**——**不要同时调怠速 + 混合气**
2. **从原厂设定开始**——**有基准**
3. **记录每次调整**——**可逆**

### 18.1.5 调校前基线检查 ●●●

调校前先确认车本身是健康的，否则调出来的是"掩盖故障"。

**基线检查清单**：
- **胎压**：冷胎用胎压表测，参 CH11/CH16，以车主手册为准
- **链条**：松紧、润滑、左右对中，参 CH10
- **火花塞间隙**：参 CH06，按车型手册确认
- **气门间隙**：参 CH06，冷车用塞尺测
- **进气漏气**：怠速时少量喷化油器清洗剂/进气检漏剂，若转速变化，优先查接口和密封；在发动机与排气冷却后进行，远离排气管/线束，通风、备灭火器；优先用专用检漏剂/烟雾检漏（易燃气雾剂，防火）
- **电瓶电压**：12.6V 左右通常表示铅酸电瓶满电，参 CH13；不同电瓶类型以手册为准
- **制动液**：液位、颜色、规格，参 CH12

【来源】 **数据来源等级**：⭐（通用维修基线；具体车型数值以车主手册为准）。

## 18.2 化油器调校（化油器车）

### 18.2.1 化油器调校原理

**化油器可调参数**：
- **怠速转速**（怠速螺丝）
- **怠速混合气**（怠速空气螺钉/怠速燃油螺钉，依化油器类型不同）
- **主油针位置**（中高速）
- **主喷嘴型号**（主喷嘴）

**每个参数对应一个工况**：
- 怠速：怠速螺丝 + 怠速空气/燃油螺钉（依化油器类型不同）
- 中速：主油针
- 高速：主喷嘴 + 主油针

### 18.2.2 怠速调整 ●●

**目的**：让怠速稳定在厂家规定值（一般 1200-1500 rpm）。

**步骤**：
```
1. 热车 5 分钟（达到工作温度）
2. 找到怠速螺丝（一般在节气门下方）
3. 拧到厂家规定的转速
4. 等 30 秒稳定
5. 听是否平稳
6. 微调到最佳
```

【注意】 **电喷车怠速边界**：电喷车怠速多由 ISC/IAC/电子节气门控制，不能像化油器一样随便拧怠速。调校前先做：
1. **清节气门**
2. **查故障码**
3. **做自学习/重新编程**
4. **以车主手册/诊断仪为准**

【来源】 **数据来源等级**：⭐（**你的车怠速值看说明书**）。

### 18.2.3 怠速混合气调整 ●●

**目的**：找到怠速最稳定的混合气浓度。

**步骤**：
```
1. 怠速稳定后
2. 先确认你调的是哪一种螺钉
   - 怠速空气螺钉（air screw）：只影响怠速混合气
   - 怠速燃油螺钉（fuel screw）：只影响怠速供油
   - 同步螺钉（linkage/sync screw）：多缸化油器用，不是混合气螺钉
3. 小幅调整怠速空气/燃油螺钉
   - "顺时针 = 浓"只对部分类型适用，不能套用
   - 具体方向看说明书
4. 找到发动机转速最高点
5. 来回拧几次找最稳定的点
6. 重新调怠速转速（混合气变了转速会变）
7. 重复几次直到平衡
```

【经验】 **老师傅经验**：**最高怠速法**可作粗调；**最终**仍要按手册基准圈数、怠速 CO/AFR、响应和热车稳定性复核。

【来源】 **数据来源等级**：⭐（化油器类型差异大；具体螺钉方向以车主手册为准）。

### 18.2.4 主油针调整（中级）

**目的**：调整中速（3000-5000 rpm）的混合气。

**油针位置**：
- **降一档**（卡低）：混合气变浓
- **升一档**（提上）：混合气变稀

**怎么判断浓稀**：
- 火花塞黑色 = 浓 → 升一档
- 火花塞白色 = 稀 → 降一档
- 火花塞浅褐色 = 合适

**调整步骤**：
```
1. 试骑中速（3000-5000 rpm）
2. 看动力是否顺畅
3. 看火花塞颜色
4. 调整油针位置
5. 重复试骑
6. 找到最佳位置
```

### 18.2.5 主喷嘴调整（高级）

**主喷嘴**控制大油门/高负荷区混合气——**老车/重改才需要**。

**调整方法**：
- 换不同流量的主喷嘴
- 流量大 = 浓
- 流量小 = 稀

【送修】 **该送修了**：**主喷嘴**调整需要**专业知识和测试设备**——**新手不要碰**。

### 18.2.6 化油器同步（多缸化油器）●●●

**目的**：让多缸发动机各缸进气量一致，改善怠速抖动、低速顿挫和油门响应。

**工具**：同步仪（vacuum gauge / carb synchronizer）。

**步骤**：
```
1. 先确认气门间隙、点火状态、进气系统无漏气
2. 暖车到工作温度
3. 怠速稳定后连接同步仪
4. 测各缸负压（通常应接近，目标常见在 ±1 cmHg 内）
5. 用同步螺钉调整各缸一致
6. 调完复查怠速和油门回落
```

【注意】 **关键点**：同步不是调怠速，而是调**各缸进气量一致**。怠速螺钉改变整体转速，同步螺钉改变各缸相对开度。

【来源】 **数据来源等级**：⭐⭐（通用多缸化油器同步原则；允许误差以维修手册为准）。

## 18.3 悬挂调校（核心）●●●

### 18.3.1 为什么要调悬挂

**悬挂调校**是**最实用的调校**——**直接影响骑行感受**。

**为什么原厂悬挂"不够好"**：
- 厂家要兼顾各种骑行情况
- 厂家要兼顾不同体重车手
- 厂家要兼顾单人/双人骑

**调校** = **适配你的具体情况**。

### 18.3.2 后避震预载 ●●

**最简单、最常用的调校**。

**调整方法**：
```
1. 找到后避震下方调节环
2. 用钩形扳手（一般随车工具）
3. 顺时针拧 = 预载增加（静态下沉减少，感觉更支撑）
4. 逆时针拧 = 预载减少（静态下沉增加，感觉更低更舒适）
```

【注意】 **预载边界**：预载调整改变的是初始静态下沉，不是弹簧硬度；感觉更支撑 = 静态位置变化，不是弹簧变硬。

【来源】 **数据来源等级**：⭐（悬挂预载通用原则；具体下沉量和调节方向以车主手册为准）。

**调整建议**：

| 骑手/载重 | 调整 |
|----------|------|
| **单人、轻体重** | 标准或减一档 |
| **单人、标准体重** | 标准 |
| **单人、重体重** | 加一档 |
| **双人骑** | 加 1-2 档 |
| **双人 + 行李** | 加 2-3 档 |
| **越野（轻载）** | 减 1-2 档 |

### 18.3.3 后避震阻尼（高端车）●●●

**阻尼**控制弹簧运动的快慢。

**调整**：
- **压缩阻尼**（车被压下去时）：影响过坑时车下沉的速度
- **回弹阻尼**（车被弹回来时）：影响车弹回的速度

**回弹阻尼最关键**：
- **回弹太快**：车身颠簸、操控不稳
- **回弹太慢**：过坑时压缩后弹不回来

**调整标准**：**压缩后 1-2 次稳定**。

### 18.3.4 前叉预载 ●●

**调整方法**：
```
1. 找到前叉顶盖（叉管顶端）
2. 用卡尺或专用工具
3. 顺时针拧 = 预载增加
4. 逆时针拧 = 预载减少
5. 左右调整量一致（用刻度）
```

### 18.3.5 前叉阻尼（高端车）●●●

**前叉可调参数**：
- **预载**（静态高度）
- **高速压缩** = 避震快速压缩（如坑洞/棱角冲击），不是车速（如 Öhlins、WP）
- **低速压缩** = 刹车点头/加速后坐等车身姿态变化，不是车速
- **回弹阻尼**

**调整思路**：
- **阻尼更弱**：颠簸路舒适，但操控差
- **阻尼更强**：操控好，但颠簸
- **找到平衡点**

【送修】 **该送修了**：
- 第一次调前叉阻尼（**建议老手指导**）
- 没说明书 / 不了解原厂设定

【来源】 **数据来源等级**：⭐（悬挂阻尼通用调校术语；具体旋钮功能和基准圈数以车主手册为准）。

### 18.3.6 调校流程 ●●●

**前后悬挂联动调整**：

```
1. 先调后避震预载（更易调）
2. 试骑 30 km
3. 感觉车头重或车尾重
4. 调整前叉预载平衡
5. 试骑再调整
6. 调阻尼（如果感觉车不稳）
7. 最终调到平衡
```

【经验】 **老师傅经验**：**悬挂调校**没有"标准答案"——**每个人的感受不同**。**试骑 + 微调 + 再试骑** = 找到自己的"甜点"。

## 18.4 油门线、离合线调整 ●●

### 18.4.1 油门线自由行程 ●●

**目的**：油门响应顺畅、不卡顿。

**步骤**：
```
1. 找到油门线调整器（一般在车架中部）
2. 松开锁紧螺母
3. 拧调整螺母：
   - 拧紧 = 拉线紧（响应快，但可能拉不到底）
   - 拧松 = 拉线松（响应慢，但安全）
4. 调到合适的自由行程（一般 2-5 mm）
5. 紧固锁紧螺母
6. 必做安全测试：
   - 把手左右打满，怠速不得升高
   - 松手油门必须啪地回位，无阻滞
   - 自由行程过小会导致高怠速 + 转向带油（危险）
   - 试车确认无异常
```

【来源】 **数据来源等级**：⭐（**你的车具体值看说明书**）。

### 18.4.2 离合线自由行程 ●

**目的**：离合器分离彻底、接合平顺。

**离合拉线自由行程检查**（参 CH10 修后内容）：
```
1. 找到离合线调整器
2. 松开锁紧螺母
3. 检查自由行程：
   - 自由行程过大（太松）：分离不彻底、换挡困难、起步发冲 → 调紧
   - 自由行程过小（太紧）：离合打滑、动力传递不全、烧摩擦片 → 调松
4. 调到标准自由行程（通常 10-20 mm，以车主手册为准）
5. 紧固锁紧螺母
6. 测试（捏到底 + 换挡）
```

【来源】 **数据来源等级**：⭐（参 CH10；**你的车具体值看说明书**）。

### 18.4.3 链条调整摘要 ●●

链条调整详细步骤参 CH10 10.2.4，本章只给调校入口。

**关键检查**：
- **自由行程**：按车主手册在规定位置测，不要凭手感
- **左右对中**：两侧调整量一致，复核后轮对齐
- **后轴螺母扭矩**：按手册扭矩锁紧，锁紧后复查自由行程

【严重警告】 **事故风险**：链条过松可能脱落，链条过紧会加速轴承/链轮磨损；链条脱落可能直接摔车。

【来源】 **数据来源等级**：⭐（参 CH10；具体自由行程和后轴扭矩以车主手册为准）。

## 18.5 ECU 调校（Flash 改写）●●●

### 18.5.1 什么是 ECU 调校

**ECU**（行车电脑）控制：
- 喷油量
- 点火时刻
- 油门响应
- 各种保护限制

**ECU 调校** = 改写 ECU 内部的"程序"。

### 18.5.2 ECU 调校能做什么

| 调整 | 效果 |
|------|------|
| 改喷油量 | 增加动力 / 省油 |
| 改点火时刻 | 提升响应 |
| 解除限制 | 解除极速限制（**违法**） |
| 解锁 ECU | 解锁高级功能 |
| 匹配改装硬件 | 让改装的进气/排气正常工作 |

### 18.5.3 ECU 调校的真实效果 ●●●

【严重警告】 **重要事实**：
- **只换空滤**：ECU 调校能补偿的增益很小（无可靠固定百分比，需同车测功对比）
- **空滤+进气管**：ECU 调校恢复/补偿损失可有体感；健康原厂车通常提升有限，需同车测功前后对比
- **空滤+排气+ECU 配套调校**：提升幅度因车与调校质量而异（❓），需同车测功前后对比

**结论**：**ECU 调校配合改装才能发挥效果**——**单独调 ECU 提升有限**。

### 18.5.4 ECU 调校的实施

**步骤**：
```
1. 选择 ECU 调校品牌（如 Woolich、FTECU、EcuTek 等）
2. 选择对应车型的"刷写包"（Map）
3. 通过 OBD 接口或专用工具写入 ECU
4. 测试
5. 必要时专业调校（带车到调校店，连接测功机）
```

【送修】 **该送修了**：**ECU 调校**基本要**送修**——**需要专用工具和专业知识**。

### 18.5.5 ECU 调校的风险 ●●●

**风险**：
- **刷坏 ECU** = 整车不工作
- **调坏参数** = 动力下降、油耗高
- **影响保修** = 厂家不再保修
- **影响排放** = 过不了年检
- **法律风险** = 解锁极速限制违法

【费用】 **参考价格**：
- **刷写包（自刷）**：500-2000 元
- **专业调校**（带车去）：2000-8000 元

【经验】 **老师傅经验**：**ECU 调校**性价比取决于**改装程度**——**什么都没改就刷 ECU**，**效果不明显**；**全套改装再刷**，**效果最大**。**新手第一次不建议**——**先玩好原厂**。

## 18.6 其他调校

### 18.6.1 油门响应调整（电控油门）●●

**现代电控油门**有几种模式：
- **运动**（响应快）
- **标准**
- **舒适/雨天**（响应慢）

**调整**：通过仪表菜单切换。

### 18.6.2 牵引力控制调整

**现代车**有牵引力控制（TC）——**可调灵敏度或关闭**。

**注意**：**关闭 TC 在公共道路很危险**——**只在赛道关闭**。

### 18.6.3 ABS 模式调整

**现代车**ABS 有时也可调（如弯道 ABS 开关）。

### 18.6.4 仪表显示调整

- 单位（km/h vs mph）
- 油耗显示
- 维护提醒

### 18.6.5 气门间隙调校 ●●●

气门间隙是发动机调校的基础项，详细机制和完整步骤参 CH06 6.3。

**通用入口**：
```
1. 冷车测量（热胀会改变间隙）
2. 用塞尺测量，不用卡尺
3. 按车主手册调整（常见 0.05-0.20 mm）
4. 调整后双重锁紧螺母
5. 转动曲轴复查一次
```

【严重警告】 **别找错 TDC**：找错上止点会导致气门间隙测量错误，可能把正常间隙误调错；按 CH06 的正时标记和手册步骤确认。

【来源】 **数据来源等级**：⭐⭐（参 CH06；具体间隙值以车主手册为准）。

### 18.6.6 点火正时 ●●

点火正时决定火花出现的时刻，影响动力、温度和爆震风险。

**调校边界**：
- **现代电喷车**：点火正时由 ECU 控制，不能手动乱调；需要诊断仪/专业调校设备
- **机械点火/化油器老车**：用正时灯对飞轮或曲轴标记检查，按车主手册调整
- **点火过早**：容易爆震、启动反冲
- **点火过晚**：动力不足、排气温度升高、发动机过热

【来源】 **数据来源等级**：⭐（通用点火调校原则；具体标记和提前角以车主手册为准）。

## 18.7 【经验】 老师傅经验沉淀（应写尽写）

### 18.7.1 新手必踩的 8 个调校坑 ●●●

1. **一次调太多参数** —— **调坏了找不回**
2. **不记录原厂设定** —— **调坏了恢复不了**
3. **不试骑就调** —— **试都没试过怎么知道要调**
4. **听商家忽悠** —— **"ECU 调校提升 30%" 是夸大**
5. **ECU 刷坏不送修** —— **整车不工作**
6. **改装不调校** —— **单点改装效果小**
7. **改写 ECU 影响/失去保修** —— **刷 ECU 前先确认厂家保修条款**
8. **非法改装** —— **解锁极速限制违法**

### 18.7.2 老师傅不外传的 8 个诀窍 ●●●

1. **【维修】 一次只调一个参数**：试车后再调
2. **【维修】 从原厂设定开始**：有基准
3. **【维修】 记录每次调整**：可逆
4. **【维修】 调完试骑 30 km**：再判断
5. **【维修】 调悬挂先预载后阻尼**：简单到复杂
6. **【维修】 前后悬挂联动调**：找到平衡点
7. **【维修】 ECU 调校必送修**：自己刷坏概率高
8. **【维修】 调校和改装分开**：基础保养式调校通常合规；涉及 ECU、排放、限速和安全系统的调校需按当地法规和年检要求确认

### 18.7.3 调校优先级建议

**新手建议调校顺序**：

```
1. 基线检查（胎压/链条/火花塞/气门/进气漏气/电瓶/制动液）
2. 发动机调校（怠速/混合气/气门/点火）
3. 悬挂调校（预载/阻尼/几何）
4. 试车确认
```

【来源】 **数据来源等级**：⭐（通用调校优先级；具体项目以车主手册和故障现象为准）。

### 18.7.4 调校 vs 改装 vs 保养的区别

| 项目 | 性质 | 是否合规 |
|------|------|---------|
| **保养** | 维护 | ✓ 合规 |
| **调校** | 微调 | 基础保养式调校通常合规；涉及 ECU、排放、限速和安全系统需按当地法规和年检要求确认 |
| **改装** | 变更原厂 | 【注意】 部分违法 |

### 18.7.5 调校的真实效果

**车主常问**：**"调校能提升多少动力？"**

**真实答案**（基于经验）：
- **化油器调校**（针对老车）：恢复/补偿损失可有体感；健康原厂车通常提升有限，需同车测功前后对比
- **ECU 调校**（针对现代车）：恢复/补偿损失可有体感；健康原厂车通常提升有限，需同车测功前后对比（**配套改装**更依赖专业调校）
- **悬挂调校**：**没有"动力提升"**，但**骑行感受大幅改善**

【经验】 **老师傅经验**：**调校的真实价值**不是**提升数字**——**是让车更适合你**。**原厂车**对**每个人都不完美**。**调校** = **让车成为"你的车"**。

### 18.7.6 不同车型的调校重点

| 车型 | 调校重点 |
|------|---------|
| **街车** | 悬挂调校、化油器调校（老车） |
| **运动车** | ECU 调校（带车去专业店）、悬挂精细调校 |
| **ADV** | 悬挂预载（适应载重变化）、油门响应 |
| **复古车** | 化油器调校（精细） |
| **踏板车** | 一般不调 |
| **电动摩托** | 通过 APP 调响应模式 |

### 18.7.7 进阶学习路径 ●●

学完本章后想进阶：

1. **【入门】** 调悬挂预载、调油门/离合线
2. **【基础】** 调化油器怠速、混合气
3. **【进阶】** 调前叉阻尼、化油器主油针
4. **【高级】** ECU Flash（送修）
5. **【专业】** 定制 Map、动态调校
