## 可靠性原则

1. **车型数据不写死**：扭矩、油液容量、胎压、链条垂度、气门间隙、保养周期等必须查具体车型手册。
2. **安全件从严**：刹车、轮胎、转向、悬挂、车架、燃油泄漏、电气短路相关内容，默认建议新手检查为主，首次维修需老手现场指导或送修。
3. **经验不能冒充标准**：论坛经验、师傅经验、AI 生成内容只能作为线索，不能作为出版级事实来源。
4. **通用表只做范围提醒**：任何“常见范围”都不能替代厂家数据。
5. **改装先看法规和系统匹配**：排气、灯光、制动、ECU、轮胎规格、传动齿比等改动可能影响合法性、安全系统和保险理赔。
